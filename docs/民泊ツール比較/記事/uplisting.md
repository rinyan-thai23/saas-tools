# Uplisting（アップリスティング）の評判・口コミまとめ｜日本の民泊で使える？

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

## 先に結論：Uplisting はこんな人に向く

> - **向く人**：**都市部で複数の物件を運営し、Airbnb・Booking.com・Vrbo をまとめたい**人。公式の想定は「10〜300室以上」ですが、数室の利用者もいます。14日間、カード不要で試せます。
> - **向かない人**：日本語が必須の人。円での請求も記載がなく、**契約条件が公式ページ同士で食い違って**います。
> - **口コミの特徴**：使いやすさと Airbnb 連携が好評。不満は**サポートの時間外対応**と、スマホアプリの弱さです。
> - **日本の民泊新法の人は要注意**：Airbnb の日本向けルールで、ツール経由の掲載が受け付けられない場合があります（[詳しくはこちら](#japan)）。

## Uplistingとは？何ができるツールか

Uplisting は、民泊や短期賃貸の予約管理とチャネルマネージャーを提供する英国のサービスです（運営は Uplisting Limited）。公式は「都市部の管理会社（10〜300室以上）」を主な対象に挙げ、利用者の多くは20室以上だと書いています。検索では、AirDNA に買収されたという記載もありましたが、公式ページでは確認できていません。

### 主な機能
#### 予約サイトの一元管理
Airbnb は公式ソフトウェアパートナー（Preferred+）、Booking.com は Premier Partner と表示しています。Vrbo も公式連携です。Expedia は Vrbo 経由か iCal で、保証はないと書かれています。Agoda の記載はありません。

#### ゲストへのメッセージ・本人確認
統合受信箱、自動メッセージ、AI返信、電子署名の契約書、ゲストの本人確認（1回 $1.65など、従量）があります。**日本語テンプレートや自動翻訳の記載は見つかりませんでした。**

#### 直接予約サイト・決済
予約サイトを作れます（基本は全プラン、上位版は月£30）。決済には Stripe のアカウントが必要です。サイトの多言語化は、料金表では「準備中」、ヘルプには Google 翻訳を使う方法があり、表記が合っていません。

#### 清掃・オーナー管理・スマートロック
清掃スケジュール、オーナー向け明細（月£40〜、上位プランは込み）があります。スマートロックは August・Yale・Nuki・TTLock などと連携します。Akerun・SESAME は載っていません。

## Uplistingの料金はいくら？

**料金は公開されています。通貨はポンド（GBP）、ユーロ、ドル、豪ドル、NZドル、カナダドルから選びます。円の選択肢はありません。** 3つのプランがあり、「物件ごとの単価」と「プランの最低月額」の高い方が請求されます。

| プラン | 対象 | 目安 |
|---|---|---|
| Independent Host | 4物件まで | 1室 £40／3室 £72。または、基本料金なしで予約額の3%（従量） |
| Operator | 物件数の上限なし | 5室 £90／10室 £160（最低月額£90）。10物件までは予約額の1.5%の従量もあり |
| Manager | 同上 | 月£208〜（1物件£13〜）。大きい運営向け |

- 目安は公式の単価からの計算です。41室以上は個別見積りです。
- **追加料金（アドオン）**：スマートロック連携（Independent Host は月£10。Operator 以上は込み）、オーナー管理、本人確認、AIの無制限利用などが、プランによって別料金です。スマートロックは、料金ページでは「月£10」、ヘルプでは「1台£4」と、記載が合っていません。
- **無料トライアル**：14日間、カード不要。
- **年払い**：Operator と Manager は10%引き。
- 料金は、見直しの記録があり、変わる可能性があります。

## 契約は「縛りなし」？ 公式ページ同士で食い違っている

ここは、申し込む前に必ず確認してください。

- 料金ページには、「契約なし、解約の事前通知なし。月払いは毎月更新で、いつでも解約できる」とあります。
- 一方、利用規約（2024年版）には、「最低12か月」「期間の終わりに自動更新」とあります。
- どちらの条件が自分に当てはまるかは、確認できませんでした。
- 返金：契約から14日以内に解約しない場合、期間の途中の返金はありません（ヘルプ）。

**申込前に、メールで「月払いで、最低期間なしで解約できるか」を書面で確認する**のが安全です。

## Uplistingの評判・口コミまとめ

海外のレビューサイト（Capterra）の口コミ53件を読んで、日本語にまとめました。**件数が少ない**ので、傾向は目安です。

> **読む前に**
> - 英語圏の運営者の声が中心で、日本の運営者の声ではありません。
> - 投稿者の約9割は、**2〜10人規模の事業者か自営業**。使用期間は、半年以内が約半数、1年以上が約3割です。
> - 件数は、口コミ中の話題をキーワードで数えたおおよその数です。

### 良い口コミ：使いやすさ、連携、サポート

- **使いやすい**（良い点に挙げた人が約35%で最多）：設定が簡単、画面が分かりやすい。
- **予約サイトの連携・同期**（約3割）：Airbnb との連携が良い、複数のサイトを1つで管理できる。
- **サポート**（約28%）：返信が速い、数分で解決した、という声。
- **自動化・価格**：メッセージの自動化、手頃な価格、という声。

### 悪い口コミ：サポートの時間外、アプリ、安定性

- **サポート**（改善点に挙げた人が約22%）：夜間や週末に連絡が取れない、電話窓口がない、ヘルプ記事に肝心な情報が抜けている、という声。応答の目安は公式でプラン別に「2時間／1時間／45分」と書かれています。電話はいちばん上のプラン（Manager）だけです。
- **スマホアプリ**：基本的な機能だけ、Android アプリがない、スマホ向けの画面になっていない、という声（古い投稿が多め）。
- **カレンダーの動作**：部屋を移したら、全部の部屋が閉じてしまう恐れがある、という警告（2024年）。
- **連携・同期**（約26%）：価格ツール（PriceLabs）との最低宿泊日数の同期に問題がある、という声。
- **レポート・会計**（約1割）：機能が足りない、という声。

### 低評価（1〜2点）の傾向

53件のうち、1〜2点は4件（約7%）です。内容は「サポートの弱さ」「スマホ対応」「ヘルプ記事の不足」「不安定さ」でした。2026年の低評価には、**AirDNA に買収されてから更新が放置されている**、更新後に直接予約サイトが予約を受けられなくなった、という内容があります。これは1件の主張で、事実かどうかは確認できていません。

## <span id="japan"></span>Uplistingは日本で使える？民泊の注意点

### 日本語は確認できない
公式サイトとヘルプの言語は、英語だけです。管理画面の日本語、ゲスト向けの日本語テンプレートは、記載が見つかりませんでした。サポートの対応言語と時間帯も、公式に載っていません。SMS の送信番号は、米・英・豪・スペインの地域番号です。

### 円での請求はできない
料金ページの通貨は、ポンド・ユーロ・ドル・豪ドル・NZドル・カナダドルで、**円の記載はありません**（規約もユーロ、ドル、豪ドル、ポンドと書いています）。

### 住宅宿泊事業法（民泊新法）の場合は、先に確認が必要
- Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。Uplisting は Airbnb の公式パートナーですが、**民泊新法の掲載を受け付ける例外に当たるかは、確認できませんでした。**
- 年180日の管理、届出番号の表示、定期報告、インボイスなど、日本の制度に当たる機能は、公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。

### 楽天トラベル・じゃらんには出せる？
楽天トラベルとじゃらんは、民泊新法・特区民泊の施設を対象外としています。Uplisting の公式ページに、楽天トラベル・じゃらん・Agoda の記載はありません。旅館業法の許可施設は、Uplisting に接続の可否を聞いてください。

### 乗り換えの手助けはある
全プランに、無料の1対1の導入支援があり、掲載・料金・カレンダーの取り込みを手伝うと書かれています。

詳しくは [住宅宿泊事業法への対応](/articles/jp-minpaku-law/)、[楽天トラベル・じゃらん等の国内予約サイト連携](/articles/jp-ota-rakuten-jalan/)、[日本語UI・日本語サポート](/articles/jp-japanese-ui-support/) へ。

## Uplistingが向いている人・向いていない人

| | 向いている人 | 向いていない人 |
|---|---|---|
| 規模 | 数室〜数十室。都市部で複数物件 | 1室だけ（最低月額あり） |
| 言語 | 英語の画面で困らない | 日本語の画面・サポートが必須 |
| 請求 | ポンドやドルの請求でも構わない | 円で請求してほしい |
| 契約 | 月払いの条件を書面で確認できる | 契約条件があいまいなのが困る |
| 営業形態 | 旅館業法の許可施設（要確認） | 民泊新法のみ（Airbnb の扱いを要確認） |

## 申し込む前に Uplisting へ聞くこと

1. 自分の物件数・使いたい機能での、正確な月額（アドオン込み）。
2. 月払いで最低期間なしか。利用規約の「最低12か月」は自分に適用されるか（書面で）。
3. 円で請求できないが、ドルやポンドの請求時の為替手数料は誰が負担か。
4. 日本語のゲストへのメッセージをどう扱うか。
5. サポートの時間帯（日本時間でいつ対応か）。
6. 私の営業形態で、Airbnb・Booking.com に接続できるか。
7. 買収後の開発体制と、直近の更新・不具合の状況。

## よくある質問

### Uplisting は日本語に対応していますか？
公式サイトとヘルプの言語は英語だけで、管理画面の日本語、ゲスト向けの日本語テンプレートは、記載が見つかりませんでした。サポートの日本語対応も確認できていません。

### Uplisting の料金はいくらですか？
通貨はポンドなどで、円はありません。公式の単価からの計算で、3室は Independent Host の£72、5室は Operator の£90、10室は Operator の£160です。基本料金なしで予約額の3%（4室まで）や1.5%（10室まで）を払う従量の選択肢もあります。

### Uplisting に無料トライアルはありますか？
14日間の無料トライアルがあり、カード登録は不要です。

### 契約期間や解約条件は？
料金ページは「契約なし、いつでも解約できる」ですが、利用規約には「最低12か月、自動更新」とあり、食い違っています。どちらが自分に当てはまるか、申込前に書面で確認してください。契約から14日を過ぎた解約では、期間途中の返金はありません。

### 日本の民泊新法の宿でも使えますか？
Airbnb のヘルプには、日本の民泊新法の宿について、ソフト連携で作った掲載を受け付けないという記載があります。例外は Airbnb と契約した日本のAPIパートナーです。Uplisting が該当するかは確認できていないため、Airbnb と Uplisting の両方に確認してください。

### 楽天トラベルやじゃらんにつなげられますか？
公式ページに、楽天トラベルとじゃらんの記載はありません。両サイトは民泊新法・特区民泊の施設を対象外としています。旅館業法の許可施設は、Uplisting に接続の可否を問い合わせてください。
