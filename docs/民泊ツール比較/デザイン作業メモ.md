- GitHub Pages の公開元に docs を使うため。`git mv` で履歴は残る。
- 参照の書き換えは README と `_作り方/` だけで済んだ（build.py は相対パスなので無修正）。

### 2026-11-07 #2 トップに「あなたの状況は？」カード4枚

### 2026-11-07 #3 公開URL問題を解消
- 出力先を `docs/minpaku/` に変更（英語名・短いURL）。`docs/.nojekyll` を追加（md をJekyllに変換させない）。
- build.py が全リンクに `--base`（既定 `/saas-tools/minpaku`）を付ける。独自ドメインなら `--base=''`。
- 公開URL：`https://rinyan-thai23.github.io/saas-tools/minpaku/`（Pages設定は main / docs。要確認）。
- 旧 `出力/` は削除。ビルドは `python3 ビルド/build.py`。

## 学び・次回気をつけること
- （解決済み #3）**Pages のURL問題**：公開すると `https://<user>.github.io/saas-tools/民泊ツール比較/出力/` になる。
  本文リンクが `/articles/...` の絶対パスなので、このままだと**リンクが全部切れる**。
  対策案：(a) 独自ドメインを使う (b) ビルド時に base パスを付ける (c) `出力/` の中身を docs 直下へ出す。
- 日本語フォルダ名はURLが長いエンコードになる。公開側は英語名が無難（要検討）。
- 警告「disclosure に未設定」は運営者情報が未記入のため（人が決める事項）。
