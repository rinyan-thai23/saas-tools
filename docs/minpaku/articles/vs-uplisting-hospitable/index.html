Uplisting と Hospitable を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

結論

  • 金額はどちらも確認できました（Hospitable は公式ヘルプの表、Uplisting は料金ページの計算ロジックから算出）。Uplisting の請求通貨に円はなく（宿泊料の円設定は未確認）、Hospitable の料金表は米ドル表示で請求通貨は請求先住所で決まります。円請求の記載は見つかりませんでした。
  • 管理画面の日本語は、Hospitable は「英語のみ」と公式に記載。Uplisting は日本語の記載が見つかりませんでした（ログイン後の画面は未確認）。
  • 楽天トラベル・じゃらんは、どちらの公式ページにも記載が見つかりませんでした（「接続できない」と確認したわけではありません）。Agoda は Hospitable だけが公式に載せています。

先に知っておくこと

営業形態によって、載せられる予約サイトが変わります。予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

予約サイト 公式に書かれている条件
楽天トラベル 旅館業の営業許可が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は Rakuten Oyado で登録、と案内
じゃらんnet 旅館業の宿泊営業許可が対象。民泊新法・特区民泊は「ご参画いただけません」
Airbnb ヘルプ：日本の民泊新法の宿は、ソフト連携で作成したリスティングを受け付けない。例外は Airbnb とライセンス契約した日本のAPIパートナー（名前は公式ページで見つからず）
  • Rakuten Oyado が「そのまま使える」とする既存ツールは、ねっぱん、AirHost、Beds24、suitebook です。Uplisting と Hospitable の名前はありません。
  • 届出番号は、ツールを使っていても自分で Airbnb にログインして追加する必要がある、とヘルプにあります。
  • 制度側には、外国人宿泊者の国籍・旅券番号の記載と旅券の写しの保存、年180日の上限、2か月ごとの定期報告があります（観光庁・e-Gov）。Uplisting は公式の書類管理が英国向けの記述で、Hospitable は日本の届出番号の専用欄を確認できませんでした。適格請求書も、どちらも記載が見つかりません。
  • 楽天トラベル・じゃらんは民泊新法・特区民泊を対象外と明記しています。旅館業の許可施設をこの2製品につなげられるかは、どちらも未確認です。

条件別の選び方

  • 3〜5室で公式の単価を比べたい人： どちらも公開しています。金額の出どころ（ヘルプの表／料金ページのスクリプト）と通貨が違うので、請求通貨とカードの為替手数料を確認してから比べてください。
  • Agoda も使う人： Hospitable は公式に載っています。Uplisting は記載が見つかりません。
  • 日本語のゲスト対応が中心の人： Hospitable の定型メッセージに日本語はありません。Uplisting も日本語の記載がありません。手書きで運用できるか、トライアルで試してください。
  • 契約期間を短くしたい人： Hospitable の月払いは縛りなしです。Uplisting は料金ページと規約が食い違うため、書面で確認してください。

申し込む前に確認すること

  • [ ] 自分の営業形態（届出／許可／特区民泊）で、使いたい予約サイトに載せられるか。Airbnb には民泊新法の掲載をツールにつなげるかも確認した
  • [ ] 請求通貨と、カードの為替手数料。ダイレクト予約で円を扱えるか
  • [ ] Uplisting：契約が「縛りなし」か「最低12か月」か、有料アドオンの現行額
  • [ ] Hospitable：稼働物件の数え方、Essentials のサポート範囲
  • [ ] 日本語が通じるサポートと日本時間の窓口があるか
  • [ ] 宿泊者名簿、年180日のカウント、定期報告を、ツール内で行うか別の方法かを決めた

未確認のこと

  • 管理画面・ゲスト向けメッセージの日本語（Uplisting）。円請求と日本の決済の可否
  • 楽天トラベル・じゃらんへの接続、Uplisting の Agoda 接続
  • Hospitable の値上げ条項、Uplisting のダイレクト予約手数料（定額プラン）
  • 日本の届出番号、年180日、定期報告、適格請求書、Akerun・SESAME への対応、日本語・日本時間のサポート
