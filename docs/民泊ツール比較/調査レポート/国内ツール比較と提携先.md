# 調査レポート：国内の民泊・宿泊管理ツールと海外ツールの比較／各ツールの提携先（ASP）

- 作成日：2026-11-07　／　対象：HTMLページには未反映（社内メモ）
- 目的：①海外ツールの「強み」が、国内ツールと比べて言えるのか ②各ツールのアフィリエイト（紹介）の提携先を整理する
- 読み方：【公式】＝公式サイトのページを開いて確認／【2次】＝比較記事など第三者／【未確認】＝確かめられていない

## 1. 要約（結論）

1. **「国内ツールにない強み」と、言い切れる点は、今回の調べでは見つからなかった。** 国内の AirHost は、PMS・サイトコントローラー・予約エンジン・スマートチェックインまで一体で、PriceLabs 連携や英日中の画面、清掃管理、宿泊者名簿（全プラン）まで持つ。海外ツールの強み（接続の広さ、AI返信、公開料金）は、**国内ツールの一部にも当てはまる**。
2. **国内ツールの確かな強み：日本語の画面・サポート、楽天トラベル・じゃらん・Rakuten Oyado への接続、円建て・日本の販売会社。** 海外ツールで同じものを確認できたのは Beds24（日本の販売会社経由）だけ。
3. **国内ツールにも、民泊新法の機能（届出番号・年180日・定期報告）の公式記載は、見つかっていない。** 海外ツールと同じ状況（ただし、AirHost は宿泊者名簿を全プランに載せている）。
4. **AirHost は Airbnb の「特別推奨パートナー」に、airbnb.jp のソフト連携パートナー一覧で載っている。** ただし、日本の民泊新法の宿で、掲載を受け付ける「例外のAPIパートナー」に当たるかは確認できていない。
5. **提携先（ASP）：** 海外11製品のうち、PartnerStack は Guesty・Hostaway・Hostfully、LeadDyno は Lodgify、Rewardful は Uplisting、自社運営は Hospitable・OwnerRez・iGMS・Sirvoy・Beds24・PriceLabs。**国内ツール（AirHost・Staysee・ねっぱん！・手間いらず）は、公開情報ではアフィリエイト／紹介制度を確認できなかった。** 日本のASP（A8.net など）の案件検索は、ログインが必要で、今回は確認できていない。
6. **このサイトの方針に関わる点：** Hostfully と Sirvoy の紹介規約には、**自社の評判を損なう言及を禁じる条項**がある（比較サイトで批判を書きにくい）。広告リンクを付けていないのは、この判断どおり。

## 6. 「海外ツールの強み」として、言えること／言えないこと

**言えること（根拠あり）**
- 海外ツールの多くが、**料金表を公開し、月払いの縛りなしや無料プランを用意**している（国内も料金公開が多く、差は大きくない）。
- 予約サイトの接続数を前面に出すのは、**Guesty（60以上）、Hostaway（連携ツール100以上）**。
- AI返信・AIアシスタントを、**公式に機能として載せている数は、海外の方が多い**（OwnerRez の ChatGPT／Claude 連携など）。ただし質は未検証。
- 円以外の通貨・海外ゲスト向けの多言語（31言語など）は、Sirvoy・Beds24・iGMS が目立つ。

**言えないこと（根拠なし）**
- 「国内ツールにない機能」：AirHost は、PriceLabs 連携、清掃管理、宿泊者名簿、請求書、API、AI、多言語PMSまで持つ。
- 「海外の方が安い」：3室で、AirHost ¥6,000、ねっぱん ¥6,600、Staysee ¥980〜¥3,980。海外の$70前後とは、為替次第で近い。
- 「海外の方が民泊新法に強い」：どちらも機能の記載が見つかっていない。

**示唆：** サイトの「英語版のメリット」は、「国内にない」ではなく、「**国内に近いものがあるが、海外にはこの点で強みがある**」という書き方が正確。
