# 経済事件コンテンツ

経済事件・詐欺・サイバー犯罪を題材にした、コンテンツ作りの作業場。
作成日: 2026-11-10

## ゴール

TSV 355件のうち、読者に学びのある事件を、力学（テーマ）ごとにコンテンツ化する。
除外した事件は削除し、足りない力学には事件を足していく（TSVは仮のデータ）。
本の仮題：『マーケティングは悪（ワル）から学べ！〜希代の詐欺師たちのスキームと、個人ビジネスへの応用思考〜』

## 考え方

- 読者（Who）：個人ソロプレナー。ビジネス・副業をしている、AIを使う人。
- 核：悪は粗悪品を売るために24時間知恵を絞っている。いい商品を持つ人は、その悪知恵を借りよう。マーケティングは真面目にやるな。
- 詳しくは `00_企画/企画書.md`。事件を選ぶルール（人殺し系は主役にしない）もここ。

## フォルダ

```

│  ├ world_major_fraud_cases_100.tsv      世界 100件
│  ├ japan_major_fraud_cases_100.tsv      日本 155件（ファイル名は100だが実際は155）
│  └ cyber_crime_history_cases_100.tsv    サイバー 100件
├ 00_ナレッジ/                    書き上がっているサンプル
│  ├ 統合原稿.md                  序章＋第1〜7章＋終章（1本にまとめたもの）
│  ├ 構成案.md                    最初の構成案（章ごとの箇条書き）
│  └ 原文/                        アップロードされたままの2ファイル（触らない）
├ 01_型/
│  ├ 評価基準.md                  総合ランク(S〜C)の物差し
│  ├ 章の型.md                    1章の骨組みと守ること
│  └ 文体ガイド.md                サンプルの文体の癖
├ 03_原稿/                       書いた章（1事件＝1ファイル。統合しない）
└ 02_進行/
   ├ 事件台帳.tsv                 主役・脇役 156件の進行表（区分・力学・状態・裏取り・読者）
   ├ 除外リスト.tsv               除外した199件（理由つき・復活できるよう保管）
   ├ テーマ一覧.md                力学A〜N（件数つき）
   └ サンプル章の裏取りリスト.md   公開前に確認したい事実
```

## 進め方

1. ~~事件を主役／脇役／除外に仮分類し、力学を当てる~~（済）
2. 仮分類をあなたが見て直す。足りない力学に事件を追加する（今ここ）
3. 力学ごとに章の単位を決める
4. 章ごとに Who を決める → 型に沿って執筆 → 裏取り
5. 台帳の「状態」を更新

## 運用

- ブランチは切らず、`main` に直接プッシュする。
- TSVの金額・年・固有名詞は、書く前に一次情報で裏取りする。取れていないものは「未確認」と書く。
