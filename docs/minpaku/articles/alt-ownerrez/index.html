OwnerRez の代替ツール：日本語・サポート・追加課金で選ぶ5候補

結論

  • OwnerRez は基本料金が低く契約もない一方、表示言語の一覧に日本語UIがなく、日本向けの記載・サポートの対応時間の記載も見つからなかった。日本語を公式で確認できたのは Beds24 の日本の販売会社版（WeIns / Co-Reception。リンクなし）だけで、その申込は Beds24（海外公式。PRリンク）とは別。
  • 立ち上げの支援や Expedia の API 接続を重く見るなら Lodgify・Hostaway（Hospitable も無料のオリエンテーション通話あり）。月払いで軽く動かしたいなら Hospitable・iGMS。
  • 料金は、月払いの有料プランを並べた表の範囲で OwnerRez が Hospitable・iGMS より低い（アドオン別。Hospitable の $0 プラン・iGMS の無料／FLEX・iGMS の年払い〔PRO 5室 約$87〕は除く）。Beds24 は計算値がさらに低いが、通貨と契約条件が別。

先に知っておくこと

  • 楽天トラベルの新規参画ページ（公式）は民泊新法の施設は参画不可とし、同グループの「Rakuten Oyado」を案内。じゃらんnet の参画案内（公式）も民泊新法・特区民泊は不可。両社とも民泊新法・特区民泊は対象外と明記しているが、旅館業法の許可施設への接続可否は各ツールで未確認。制度の判断はこの記事ではしない。
  • Airbnb の公式ヘルプは、日本の住宅宿泊事業ではソフト連携で作ったリスティングを受け付けないとし（例外の「日本のAPIパートナー」の名前は見つからなかった）、届出番号は Airbnb に直接ログインして入れる案内。既存の掲載を接続する場合の扱いは未確認。

候補ごとの要点

  • Hospitable：Professional $59＋物件数に応じた追加料金、Mogul $99＋追加。管理画面は英語のみ、定型メッセージは英・西・仏・独で、日本語の追加要望のステータスは「New」（2026-11-05 取得時）で、実装済みかは未確認。オーナーポータルは Mogul のみ。
  • iGMS：年払い（10物件未満）は返金不可。Expedia・Tripadvisor は iCal（1時間更新）。サポートは英語・スペイン語。
  • Beds24：海外公式（ユーロ建て、英独のみ。PRリンクはこちら）と日本の販売会社版（円建て、日本語、最低1か月・解約は毎月20日までにメール、再登録5万円、カードのみ）で条件が別。日本語UI・円建て等は販売会社版の情報で、申込は海外公式のリンクとは別。Capterra に UI の分かりにくさの指摘。
  • Lodgify：更新前の通知がない自動更新。オンライン決済に別途1%。表示通貨は EUR・USD・GBP。
  • Hostaway：価格は見積り。サポートは「24/7の電話」と自社が主張（日本語は確認できず）。
