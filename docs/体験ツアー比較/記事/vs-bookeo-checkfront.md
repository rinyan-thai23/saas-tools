# 【体験・ツアー】BookeoとCheckfrontを比較｜手数料なしの月額制か、月額＋3%か

## 先に結論

> - **予約サイトへの配信が主力でなく、自分のサイトの予約が中心の小さな事業者は、Bookeo が安く済みます。** 予約が増えても手数料が増えない月額制です（Capterra に載る公式の説明）。
> - **レンタルや宿泊も予約したい、予約サイトとの連携も使いたいなら Checkfront。** 月額$99＋オンライン予約3%（公式）。店頭・電話の予約は手数料なしです。
> - **日本の事業者には、どちらも日本の窓口がありません。** Bookeo は日本語対応が Capterra の表記にありますが、公式サイトは日本語ではありません。Checkfront はサポートが英語のみです。
> - **注意**：Bookeo の料金は、公式の料金ページに今回は接続できず、**現在の金額を確認できていません**。

## 料金を比べる（計算）

**前提**：Bookeo は Capterra に載る公式の説明（月額$39.95から、手数料なし）、Checkfront は公式の料金ページ（$99＋3%）で計算します。決済会社の手数料、SMS（Bookeo は有料）、為替は含みません。

| 月のオンライン売上 | Bookeo | Checkfront |
|---|---|---|
| $2,000 | $39.95 | $159 |
| $5,000 | $39.95 | $249 |
| $10,000 | $39.95 | $399 |

（計算）

- **月の売上が増えるほど、差が広がります。** Bookeo は固定、Checkfront は売上に比例して増えます。
- Checkfront は、手数料をお客さんに上乗せできます（公式）。その場合の事業者の負担は、月額$99だけです。
- Bookeo の「月額$39.95から」は、プランによって予約件数などの上限があるかもしれません。現在のプランと金額は、公式で確認してください。

## できることの違い

- **Bookeo**：ツアー、教室・講座、個別予約の3つの製品。Capterra ではヨガ、ダンス、サロン、フィットネスなど多くの分野に登録されています。**間口が広いが、機能は浅め**という口コミ（「特殊な予約の形に合わない」「道具の共有ができない」）があります。
- **Checkfront**：いろいろな予約の形（1日、複数日、時間枠）、レンタルや宿泊、電子の同意書、予約サイトとの連携が標準。**幅が広い代わりに、月額と手数料が高め。**

## 口コミ（海外のレビュー）の違い

| | Bookeo | Checkfront |
|---|---|---|
| 良い点で多い話 | 使いやすさ（約3割）、値段が手頃（約2割） | 使いやすさ（約4割）、サポート（約3割）、価格が手頃 |
| 悪い点で多い話 | 画面が古い、機能が限られる、サポート（電話なし） | 値上げ、レポートが弱い、予約サイト連携の遅れ |
| 低評価（1〜2点） | 3件（約7%）。すべて2024〜2025年 | 4件（約3%） |
| 日本の投稿者 | 0人 | 2人（どちらも4点） |

**件数は Bookeo が少なく（約43件）、傾向は参考程度です。** Bookeo の低評価は、サポートの対応と「電話がない、SMSは別料金」に集中しています。

## 日本の事業者として見るポイント

- **日本語**：どちらも、管理画面と予約画面の日本語は確認できていません。Bookeo は公式サイトの言語が5つで、日本語がありません。Checkfront はサポートが英語のみです。
- **決済と円**：どちらも、日本の事業者が契約できる決済会社、円での受け取りは確認できていません。
- **日本の予約サイト**：どちらも記載が見つかりませんでした。
- **日本の声**：Checkfront に、日本の宿のオーナーが「サポートが一番良い」と書いた口コミがあります。Bookeo には日本の投稿者がいません。

## よくある質問

### 手数料が安いのはどちらですか？
Bookeo は予約ごとの手数料がありません（Capterra に載る公式の説明）。Checkfront はオンライン予約に3%かかります。ただし、Bookeo の現在の金額は確認できていません（計算は参考値）。

### 教室やヨガにも使えますか？
Bookeo は教室・講座向けの製品があり、ヨガ、ダンスなどにも使われています。Checkfront は主にツアー、レンタル、宿泊向けです。

### どちらも日本語に対応していますか？
Bookeo は Capterra の表記では日本語ありですが、公式サイトの言語に日本語はありません。Checkfront はサポートが英語のみです。どちらも、申込前に確認してください。

### 日本の予約サイトにつながりますか？
どちらも、日本の予約サイトとの連携は確認できませんでした。
