# Beds24 と Lodgify を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

> **結論**
> - Beds24 には入口が2つあります。海外の公式（Beds24 GmbH、ユーロ建て、英独のみ）と、日本の販売会社 株式会社WeIns（円建て、日本語）です。料金・契約・サポートが別なので、どちらで契約するかを先に決めてください。この記事の Beds24 の PR リンクは海外公式側だけで、WeIns の申込は別手続きです。
> - 日本語の管理画面とサポートを資料で確認できたのは、日本の販売会社（WeIns）版の Beds24 だけです（WeIns 自身の資料に基づく情報）。Lodgify は公式サイトに日本語ページがなく、管理画面の言語は未確認です。
> - 楽天トラベル・じゃらんは、Beds24（WeIns）の資料に記載があります。Lodgify の公式ページには記載が見つかりませんでした。なお、楽天トラベル・じゃらんは民泊新法・特区民泊を対象外と明記しています。旅館業の許可施設への接続可否は、Lodgify では未確認です。

## 先に知っておくこと

営業形態によって、載せられる予約サイトが変わります。予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

| 予約サイト | 公式に書かれている条件 |
|---|---|
| 楽天トラベル | 旅館業の営業許可が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は Rakuten Oyado で登録、と案内 |
| Rakuten Oyado | 「楽天トラベルに民泊施設を配信できるのはRakuten Oyadoだけです」と同社ページ。配信はインスタントブッキング対応施設のみ。販売手数料は一律3%。「そのまま使える」既存ツールに Beds24 を記載（Lodgify はなし） |
| じゃらんnet | 旅館業の宿泊営業許可が対象。民泊新法・特区民泊は「ご参画いただけません」 |
| Airbnb | ヘルプ：日本の民泊新法の宿は、ソフト連携で作成したリスティングを受け付けない。例外は Airbnb とライセンス契約した日本のAPIパートナー（名前は公式ページで見つからず）。届出番号は自分でログインして追加する必要がある |

制度側には、外国人宿泊者の国籍・旅券番号の記載と旅券の写しの保存、年180日の上限、2か月ごとの定期報告があります（観光庁・e-Gov）。

## 条件別の選び方

- **日本語の画面とサポートが必要な人：** 資料で確認できたのは WeIns 経由の Beds24 です。ただし電話は基本操作の説明まで、設定や不具合はメールです。
- **楽天トラベル・じゃらんにも出したい人：** Beds24（WeIns）の資料に記載があります。楽天トラベルは民泊新法の施設に Rakuten Oyado での登録を案内し、じゃらんは民泊新法・特区民泊を受け付けないと書いています。
- **ダイレクト予約サイトをノーコードで作りたい人：** Lodgify は Starter 以上でノーコードの作成機能を持ちます。ただし円の表示・決済は確認できていません。
- **契約を軽くしたい人：** Beds24 公式は1か月前通知です。WeIns は毎月20日締め、Lodgify は料金ページが「長期契約なし」、規約は自動更新で更新前の通知なしと、書き方が分かれています（実際の運用は未確認）。

[Beds24（海外公式）の紹介リンク（PR）](/go/beds24/) ／ [Lodgify の料金と申込（PR）](/go/lodgify/)

Beds24 の PR リンクは、海外公式（beds24.com）側の紹介リンクです。日本の販売会社（株式会社WeIns、co-reception.com）にはリンクを付けておらず、名称のみの記載です。円建て・日本語UI・日本語サポート・宿泊者名簿オプションは日本の販売会社版の情報で、その申込は上のリンクとは別です。

## 申し込む前に確認すること

- [ ] 自分の営業形態（届出／許可／特区民泊）で、使いたい予約サイトに載せられるか。Airbnb には民泊新法の掲載をツールにつなげるかも確認した
- [ ] Beds24 は公式と WeIns のどちらで契約するか決めた（料金通貨、トライアル期間、解約の締め日が違う）
- [ ] WeIns の国内OTA連動で、楽天トラベルの現行の接続方式と、月額・初期費用の総額を確認した
- [ ] Lodgify：3室以上のプランの金額、円で表示・決済できるか、管理画面の言語を確認した
- [ ] 日本語が通じるサポートの受付時間帯を確認した
- [ ] 宿泊者名簿、年180日のカウント、定期報告を、ツール内で行うか別の方法かを決めた

## 未確認のこと

- Akerun・SESAME への対応（両社とも記載なし）
