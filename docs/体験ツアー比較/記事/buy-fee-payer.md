# 【体験・ツアー】予約手数料は誰が払う？お客さんに上乗せできる予約システムと、価格の決め方

## 先に結論

> - **予約手数料の負担は、「お客さんが払う」「事業者が払う」「選べる」の3通りです。** 製品によって違い、**契約の前に、自分が選べるかを確認する**ことが大事です。
> - **公式に「お客さんか自分かを選べる」と書かれているのは、Bókun、Rezdy、Checkfront、Zaui です。**
> - **Xola と FareHarbor は、お客さんが払う仕組みが中心**です（Xola は公式。FareHarbor は口コミ）。
> - **どちらが良いかは、「価格で競争するか」「手数料を見せるか」で変わります。** 独立した調査データは見つかりませんでした（下で説明）。

「記載なし」は、公式で見つけられなかったことを指します。

## 手取りを同じにするための価格の計算

**お客さんに上乗せしないで、手数料を自分で負担する場合**、手取りを同じにするには、価格を上げる必要があります。

**価格 ＝ 手取りにしたい金額 ÷（1 − 手数料率）**

たとえば、手取り¥10,000にしたい体験の価格（計算）：

| 手数料率 | 必要な価格 | お客さんに上乗せする場合のお客さんの支払い |
|---|---|---|
| 3% | ¥10,309 | ¥10,300 |
| 3.5% | ¥10,363 | ¥10,350 |
| 6% | ¥10,638 | ¥10,600 |

- 「お客さんに上乗せ」は、手数料を価格の外に足す形です。「事業者が負担（価格に含める）」は、価格を少し上げて、手数料を中に含める形です。**どちらも、お客さんの支払いは近い金額になります。**
- 違うのは、**予約画面で、手数料が別の行として見えるか、価格に含まれるか**です。

## どちらを選ぶか：考え方

業界の解説（予約システム会社などが書いたもの。立場があります）で、次のように言われています。

- **上乗せする側の考え方**：手数料の分を価格に上げずに済み、**表示の価格を安く保てます**。高価格帯や専門性の高い体験は、手数料を別に見せることが多い、とされています。
- **負担する側の考え方**：予約の最後に出る手数料は、**カゴ落ち（予約の途中でやめる）**の原因になる、とされています。ほかの体験と価格で比べられやすい市場では、手数料込みの1つの価格にしたほうがよい、という考え方があります。
- **口コミの声**：FareHarbor や Xola の口コミに、「お客さんが払う6%は高い」「他のサイトに逃げる原因になる」という声がある一方、「お客さんに転嫁しても、予約は増えた」という声も、両方あります。

**この記事で調べた範囲では、どちらの方が予約が増えるかを示す、独立した調査（比較実験など）は見つかりませんでした。** 上の考え方は、いずれも会社の主張や口コミです。

## 日本の事業者として確認すること

- **価格の表示ルール**：手数料を別の行にする場合、お客さんに見せる価格の表示が、日本の表示のルール（総額の表示など）に合うかは、この記事では調べていません。**消費者庁や、都道府県の窓口で確認してください。**
- **予約サイト（OTA）経由の予約**：手数料は、予約サイトと事業者の契約で決まります。予約システムの手数料の負担とは別です。
- **事前決済の手数料**：予約手数料とは別に、決済会社の手数料がかかる場合があります（[手数料の早見表](/articles/buy-fee-table/)）。

## 申し込む前に聞くこと

1. **予約手数料を、お客さんに上乗せするか、自分で負担するかを、自分で選べるか。** 自分のプランでも選べるか。
2. 選べる場合、**いつでも切り替えられるか。**
3. お客さんに上乗せする場合、**予約画面で、手数料はどう表示されるか**（別の行か、価格に含むか）。
4. 事前決済・決済会社の手数料は、誰が払うか。
5. 返金のときの手数料の扱い。

## よくある質問

### 手数料をお客さんに上乗せしても大丈夫ですか？
事業者の判断です。口コミには、上乗せしても予約が増えた、という声と、お客さんから不満が出た、という声の両方があります。独立した調査は見つかりませんでした。

### 手数料を自分で負担すると、いくら値上げすればいいですか？
手取りを同じにするには、「手取り ÷（1 − 手数料率）」の価格にします。たとえば手取り¥10,000で手数料3.5%なら、約¥10,363です（計算）。

### 選べない製品は、避けるべきですか？
一概には言えません。手数料の割合、機能、サポートも合わせて、総合で選んでください。
