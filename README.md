# saas-tools

Capterra 日本のデータを土台にして、「特定の業種向けのSaaS比較サイト」を量産するための作業場。
最初の1本が `docs/民泊ツール比較/`（記事42本）。同じやり方で、別の業種のサイトを作れる。

## フォルダ

```
saas-tools/
├ データ/                 Capterra日本から集めた表（段階順）
│  ├ 01_カテゴリ.tsv         カテゴリ 1,023件
│  ├ 02_掲載_重複あり.tsv     カテゴリごとの掲載 33,033件（同じ製品が複数カテゴリに出る）
│  ├ 03_製品マスタ.tsv        02 の重複を消した台帳 5,756件（レビュー数・評価つき）
│  ├ 04_詳細/               レビュー100件以上の1,291製品の詳細と、アフィリエイト有無
│  ├ 05_選定30.tsv          日本向けのおすすめ30（ゴールド／シルバー／ブロンズ）
│  └ README.md             各表の列の意味
├ 取得スクリプト/           00〜07。取得の記録.md に経緯と注意
└ docs/
   ├ 民泊ツール比較/         1本目のサイト（記事・事実カード・校閲・ビルド・制作メモ）
   └ _作り方/               次のサイトを作る手順と、役割ごとのプロンプト雛形
```

## 次のサイトを作るとき

1. `docs/_作り方/手順.md` を読む。
2. 業種を決める → `03_製品マスタ.tsv` と `04_詳細/製品詳細.tsv` から、その業種の製品を探す。
3. `docs/<業種>比較/` を作り、民泊ツール比較の `README.md`（設計）を雛形にする。
4. リサーチ → 執筆 → 校閲 → 修正 → ビルドの順。プロンプトは `docs/_作り方/プロンプト雛形.md`。

## 注意

- データの取得日は 2026-11-03〜04。評価・レビュー数・アフィリエイトの有無は、その時点の値。
- 動かして確かめていないことは「未確認」と書く（リポジトリのルール）。
- 02 のTSVは約25MB、`04_詳細/レビュー1ページ目.tsv` は約5MB。リポジトリを軽くしたいときは、この2つを別置きにしても、03 と 04 の詳細から作業できる。
