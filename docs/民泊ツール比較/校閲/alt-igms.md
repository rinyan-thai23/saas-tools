## 指摘

### 要修正

1. **Hospitable の年払い返金の起点が抜けている（買う直前の判断に直結）**
   - 記事（条件別）：「Hospitable の年払いは30日以内なら全額返金」
   - カード Hospitable「契約縛り（年払い）」：「トライアル開始から30日以内は全額返金で解約可。30日経過後は更新期間の終わりに解約が有効になり返金なし」。トライアルは14日のため、トライアル終了後に年払いを始めた場合の返金可能期間は約16日になりうる。
   - 修正案：「年払いは、トライアル開始から30日以内なら全額返金」と起点を明記する。

### 注意

2. **Lodgify の Expedia の食い違いを落としている**
   - 記事（条件別）：「Lodgify は FAQ で API と記載」
   - カード Lodgify：Expedia は FAQ では API、料金ページの機能表には記載なし（記述の食い違い・確認済）。
   - 修正案：「FAQ では API、料金ページの機能表には Expedia の記載がなく食い違い」。

3. **Hospitable の日本語メッセージを「未対応のまま」と断定**
   - 記事（要点）：「日本語の追加要望は未対応のまま」
   - カード：要望のステータスは取得時「New」（票1）。実装済みかは未確認。
   - 修正案：「追加要望のステータスは『New』（2026-11-05 取得時）」。

4. **宿泊者名簿の一文が候補のカードと合わない**
   - 記事：「各候補の本体機能は、Beds24 日本側の有料オプション以外は記載が見つからなかった」
   - カード：Beds24 は Pre-Arrival tool・公式の宿泊者登録フォーム、Hospitable はゲスト確認（ID撮影）、Uplisting は Stripe Identity による本人確認、Lodgify は Guest Registration（いずれも日本の名簿要件への適合は未確認）。
   - 修正案：「日本の名簿要件に合う本体機能の記載は…（ID収集の機能は複数あるが適合は未確認）」。

5. **Beds24 の楽天の接続方式の一本化**
   - 記事（比較表）：「楽天は Rakuten Oyado 経由、じゃらんは日本の販売会社が提供」
   - カード Beds24：公式Wiki（Vacation STAY＝Rakuten Oyado 経由）と日本の販売会社（R-Connect＋Rakuten for Business）で記述が併存し、現行は未確認。
   - 修正案：「公式Wikiでは Rakuten Oyado 経由。日本の販売会社は別手順の記載で現行方式は未確認」。

6. **/go/beds24/ の遷移先と「日本の販売会社経由」の不一致の可能性**
   - 記事：結論「[Beds24](/go/beds24/)（日本の販売会社経由）」（末尾コメントにも遷移先未確定と記載）
   - カード：Beds24 の紹介制度は海外公式の referrercode 方式。日本の販売会社の紹介制度は未確認。
   - 修正案：遷移先が WeIns でないなら文言を「Beds24（海外公式）」に改め、日本の販売会社は別に説明する。

### 軽微

7. 結論2：「価格の自動調整は別ツール（PriceLabs）に切り出す手もある」→ 自動翻訳・オーナー明細など PRO+ の他機能は PriceLabs で代替されない。また PriceLabs の月額（5件 $47.95）が iGMS の料金に加算される旨は要点にあるが、結論側には無い。修正案：「価格の自動調整に限り」「別途 PriceLabs の料金がかかる」と添える。
