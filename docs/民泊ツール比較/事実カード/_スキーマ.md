# 事実カードの書式

1製品（または1テーマ）につき1ファイル `事実カード/<名前>.md`。リサーチ役だけが書く。

## 規則

- 事実は、**出典URL・取得日・確度**を必ず付ける。取得日は 2026-11-05
- 確度は3つ：`確認済`（公式ページ・公式ドキュメントを開いて確認）／`第三者のみ`（公式を開けず、第三者の情報だけ）／`未確認`
- 公式を開けない（ログイン必須・JavaScript描画など）ときは、そう書く。**推測で埋めない**
- 引用は短く（1〜2文）。原文のまま、英語なら英語のまま
- 文章（記事）は書かない。判断・おすすめも書かない

## 項目（1行 = 1事実の表）

| 項目 | 値 | 出典URL | 取得日 | 確度 |
|---|---|---|---|---|

必須の項目：
1. 基本：運営会社、対象規模（物件数の目安）
2. 料金：課金モデル、最低料金、物件数別の目安（1・3・5・10・20室）、無料トライアル、契約縛り、解約条件、追加手数料（ダイレクト予約手数料など）
3. チャネル：Airbnb、Booking.com、Vrbo、Expedia、Agoda、**楽天トラベル、じゃらん**、その他。接続方式（公式連携か）
4. 機能：自動メッセージ、カレンダー同期（二重予約防止）、清掃タスク、スマートロック連携先、価格ツール連携、オーナーポータル、ダイレクト予約サイト、会計
5. 日本対応：UIの日本語、ゲスト向けメッセージの日本語、サポート言語と対応時間、通貨（JPY）、決済手段、請求書・インボイス、宿泊者名簿・パスポート確認の機能、住宅宿泊事業法に関する機能（届出番号表示など）
6. アフィリエイト：有無、種別、申込URL、報酬、規約上の制限（ブランド名の入札禁止、コンテンツの制限など）
7. 乗り換え：データ移行の支援、インポート方法、他ツールからの移行ガイドの有無
8. 注意すべき点（利用者の不満が多い点など）：出典付きで

末尾に、**「調べられなかったこと」**の一覧を書く。
