Checkfront（チェックフロント）の評判・口コミまとめ｜日本の体験・ツアーで使える？

先に結論：Checkfront はこんな人に向く

  • 向く人：ツアーだけでなく、レンタルや宿泊も一緒に予約管理したい小さな事業者。電話や窓口の予約が多い人（窓口の予約は手数料なし）。
  • 向かない人：日本語のサポートが必須の人。毎年の値上げが気になる人。細かいレポートが必要な人。
  • 日本の人は要注意：公式は「サポートは英語のみ」と書いています。さらに、公式の決済サービス「Checkfront Payments」の対応国に日本は入っていません（詳しくはこちら）。

Checkfrontとは？何ができるツールか

Checkfront は、ツアー・アクティビティ・レンタル・宿泊などの予約をまとめて管理するシステムです。公式サイトでは、ツアー、アクティビティ、レンタル、宿泊、アドベンチャーパーク、脱出ゲームなどが対象と書いています。

主な機能

いろいろな予約の形

1日単位、複数日、時間枠、「フレックス」など、1分から1週間までの予約の形を設定できると、公式は説明しています。

在庫・道具の管理

車、席、道具、部屋などの資源を管理し、二重予約を防ぎます。公式は、競合より「高度」と説明しています（自社の主張）。

予約サイトとの連携

Google の「Things to do」、Viator、GetYourGuide などとつながります。公式は「2万以上の販売会社と連携できる」と書いています（自社の主張）。

同意書（ウェーバー）、メールとSMS

電子の同意書が最初から入っています。予約の状態に合わせて、リマインドや口コミのお願いを、メールやSMSで自動送信します。

自分のサイトへの組み込み

WordPress、Drupal、Joomla に対応。予約ウィジェットは4種類から選べます。Zapier でほかのアプリとつなげられます。

2023年に Rezdy と合併

業界報道によると、Checkfront は2023年6月に、オーストラリアの Rezdy と合併しました。2つのブランドは別々に続けるとされています。値上げの声や、機能の追加が遅いという声に、この合併が関わっているかは確認できていません。

Checkfrontの料金はいくら？

料金は公開されています。 公式の料金ページは、次のとおりです。

  • 月額$99＋オンライン予約手数料3%。初期費用なし、隠れた費用なし。
  • 3%は、お客さんに上乗せするか、事業者が負担するかを選べると、公式にあります。
  • 窓口や電話などオフラインの予約には、手数料がかかりません。
  • 予約サイト（OTA）経由は、Checkfront の追加手数料なし。公式は、競合ではOTA手数料に上乗せして最大2%かかる、と比べています（自社の主張）。
  • カード決済の手数料は別に、決済会社との契約でかかります（Checkfront Payments は「固定手数料」と書かれていますが、料率は確認できませんでした）。

サイトによっては、月額$49〜$199の複数プランを載せていますが、公式の料金ページには見当たりませんでした。古い情報の可能性があります。

値上げの声があります。 2025年の口コミに「年額が20%上がった。前年も25%上がっていた。事前の連絡なしで、次年度の請求書で知った」とあります（1人の声）。

Checkfrontの評判・口コミまとめ

海外のレビューサイト（Capterra）の口コミ約120件を読んで、日本語にまとめました。

読む前に

  • 投稿者の国が分かるもののうち、約9割がアメリカ・カナダ・英国・オーストラリアです。日本の投稿者は2人だけです（下で紹介します）。
  • 投稿者は、2〜10人規模の事業者か自営業が約6割。使用期間が「1年以上」の人も約6割で、長く使っている人が多めです。
  • 件数は、口コミ中の話題をキーワードで数えたおおよその数です。

良い口コミ：使いやすさとサポート、手頃な価格

  • 使いやすい（良い点に挙げた人が約4割で最多）。新しいスタッフに教えやすい、予約の流れが分かりやすい、という声。
  • サポートが親身（約3割）。要望を聞いてくれる、すぐ返事が来る、という声。
  • 価格が手頃（約15%）：「高い代替品がやることを、小さな事業者が払える値段でやってくれる」という声。
  • 機能がそろう：同意書、会計ソフトとの連携、請求書や顧客の管理が1か所にある、という声。

悪い口コミ：値上げ、レポート、予約サイト連携の遅れ

  • 値上げ（改善点で約15%）：上の20%＋25%の値上げのほか、「新しい機能のたびに上のプランが必要」という昔の声もあります（2019年。今は同意書が標準で入っていると公式にあります）。
  • レポートが弱い（約1割）：自由なレポートが作れない、複数日のツアーに向いていない、という声。
  • 予約サイトとの連携が遅れている（約1割）：ほかのシステムより、OTAとの連携が遅れている、という声。
  • サポートの時間帯：欧州の事業者から、「サポートはカナダ西部の時間で9〜17時。ヨーロッパとは8時間差で、営業時間が合わない」という声が1件ありました。日本は冬で17時間差です（計算。冬なら日本時間の午前2時〜10時ごろ）。公式で確認できていないので、申込前に確認してください。
  • 設定が分かりにくい：新しい商品の設定が直感的でない、という声。

低評価（1〜2点）の傾向

口コミ約120件のうち、1〜2点は4件（約3%）です。理由は、事前連絡なしの値上げ、画面とウィジェットのバグ＋サポート時間の遅れ、マーケティング機能の弱さ（2023年の口コミ。GA4に未対応と指摘）、商品や料金の設定のしにくさ（2017年）です。高評価が大半で、不満の中心は値上げと、レポート・連携の弱さです。

Checkfrontは日本で使える？体験・ツアーの注意点

日本の投稿者の声（2人）

  • 日本の宿のオーナー（2〜10人規模、使用2年以上、4点）：「家族経営の小さな事業なので、複雑すぎない機能でちょうどいい。サポートが一番良い。いつも早く、時間をかけて解決してくれる」。一方で、「日本なので、翻訳をもっと柔軟にできると、請求書などで使いやすい」と要望を書いています。
  • 日本の自営業者（使用6〜12か月、4点）：「使いやすい。サポートはとても親切」。ただし「予約画面を印刷すると、コメント欄が消える」という不満があります（2019年）。

どちらも英語でレビューを書いています。日本の小さな事業者が、サポートは良いと書いている点は、安心材料です。ただし2人だけの声です。

日本語の画面・サポート

Capterra の表記では、対応言語に日本語が入っています。公式の「多言語」のページによると、言語はメンバーが翻訳した「コミュニティ翻訳」です。サポートと資料は英語のみと書かれています。また、1つのアカウントで複数の言語を混ぜて使えない（日本語と英語の両方の予約画面を出せない）と書かれています。このページの日付は分からないので、今も同じか、申込前に確認してください。

日本のお客さんと外国人のお客さんの両方を受けたい場合は、ここが一番の注意点です。

決済と円

公式の決済サービス「Checkfront Payments」の対応国は、カナダ、アメリカ、英国、オーストラリア、ヨーロッパの国々で、日本は入っていません。公式は、対応していない国でも、32の決済会社（230の国）と連携できると書いています。連携先として公式に Stripe、Square、PayPal が載っています。お客さんが自分の通貨で表示・支払いできる機能もあります。円で受け取れるか、日本の事業者が使える決済会社は、公式に書かれていませんでした。

日本の予約サイトにつながる？

連携先として公式に載っているのは、Google、Viator、GetYourGuide などです。じゃらん、アソビュー、楽天などの日本のサイトは、記載が見つかりませんでした（「できない」と確認したわけではありません）。

Checkfrontが向いている人・向いていない人

向いている人 向いていない人
事業の形 ツアー＋レンタル＋宿泊を1つで管理したい ツアーだけで、予約サイト連携が主力
料金 月額＋3%を納得できる。窓口の予約が多い 値上げが心配。予約が非常に多い（3%が積み上がる）
言語 英語のサポートで困らない 日本語のサポートが必須。日本語と英語を両方出したい

申し込む前に Checkfront へ聞くこと

  1. 日本の事業者が使える決済会社はどれか。 円で受け取れるか。
  2. 日本語と英語の予約画面を、1つのアカウントで両方出せるか（今の仕様で）。
  3. サポートの対応時間（日本時間でいつか）。日本語で問い合わせできるか。
  4. 月額・3%の手数料の変更ルール。値上げの事前連絡の期間。
  5. 同意書やSMSなど、追加料金がかかる機能の一覧。
  6. 日本の予約サイトに接続できるか（使いたいサイト名で）。
  7. 解約の条件と、データの書き出し。

よくある質問

Checkfront は日本語に対応していますか？

Capterra の表記では、対応言語に日本語が入っています。ただし、公式の説明では、言語はメンバーによる翻訳で、サポートと資料は英語のみです。1つのアカウントで複数の言語を混ぜて使えない、とも書かれています。申込前に、今の仕様を確認してください。

Checkfront の料金はいくらですか？

公式の料金ページでは、月額$99＋オンライン予約の3%です。窓口などオフラインの予約には手数料がかかりません。3%は、お客さんに上乗せしても、事業者が負担してもよいとされています。カード決済の手数料は別です。

Checkfront は無料で試せますか？

公式の料金ページには、デモの申込の案内があります。無料トライアルの条件は確認できませんでした。

日本の事業者でも使えますか？

日本の投稿者が2人、使っているとレビューに書いています。ただし、公式の決済サービスの対応国に日本は入っていません。ほかの決済会社（Stripe、Square、PayPal など）と連携できると、公式にあります。円での受け取りは、申込前に確認してください。

日本の予約サイトにつなげられますか？

公式の連携先は、Google、Viator、GetYourGuide などです。日本の予約サイトの記載は見つかりませんでした。

値上げはありますか？

2025年の口コミに、年額が20%上がり、前年も25%上がったという声が1件あります。値上げのルールは、契約前に書面で確認してください。
