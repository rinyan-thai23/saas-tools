# 【クラウド電話】RingEX（RingCentral）とDialpadを比較｜日本の事業者が申し込む前に見ること

## 先に結論

> - **日本で使うなら、今回確認できた範囲では Dialpad のほうが、条件が具体的に見えます。** ソフトバンクが販売していて、**円の料金表、050と03・06の番号、本人確認の書類、日数**が公開されています。
> - **RingEX（RingCentral）は、日本向けの条件が見つかりませんでした。** 公式の緊急通報ポリシー（2023年12月版）に「日本は東京の市外局番の番号のみ」とあるだけで、日本語の公式サイトと円の料金は確認できませんでした。
> - **どちらも、110・119は前提にしないでください。** RingEX は公式ポリシーに「利用できない」と、Dialpad は公式ヘルプの抜粋に「発信できない」とあります。

## 日本の番号

- **Dialpad**：ソフトバンクのページに、050は1ライセンスに1つ、固定番号（03・06など）は「Dialpad Air 0AB-J」で工事なしで使える、と書かれています。番号は事業所の住所に結びつきます。
- **RingEX**：公式の緊急通報ポリシーに「提供するのは東京の市外局番の番号のみ」とあります。大阪・名古屋の番号は、公式の記載で確認できません。050とフリーダイヤルも確認できていません。**2023年12月の版なので、今の条件は直接確認してください。**

## 料金

- **Dialpad（円・税抜）**：Standard ¥1,000（AIなし）／¥2,500（AIあり）、Professional ¥1,500／¥3,000、Enterprise ¥2,000／¥3,500。Standard は1ライセンスから。ほかに、0AB-J の番号、通話料（従量）、ユニバーサルサービス料などがかかります。
- **RingEX（ドル）**：Core $20、Advanced $25、Ultra $35（年払い、1ユーザー）。米国向けの料金ページです。**日本の番号の月額と日本宛の通話料は、確認できていません。**

**ドルと円は、そのまま並べて比べられません。** 為替と、通話料の条件で変わります。申込前に、総額の見積もりをもらってください。

## 日本語・サポート

- **Dialpad**：日本語の公式サイトがあり、ソフトバンクのサポートは平日9:00〜17:00です。管理画面とアプリの日本語は、確認できていません。
- **RingEX**：Capterra の対応言語に日本語はありますが、日本語の公式サイトとサポートは、今回の調査で確認できませんでした。

## 口コミ（海外のレビュー）の違い

どちらも、投稿者は約8割が米国で、**日本の事業者の口コミはありません**。

| | RingEX | Dialpad |
|---|---|---|
| 良い点で多い話 | 使いやすさ（約4割）、固定電話の工事なしで導入できる | 使いやすさ（約4割）、AIの文字起こし・要約 |
| 悪い点で多い話 | 料金（約15%）、サポート（約13%）、通話の途切れ | サポート（約12%）、通話の質、解約・自動更新 |
| 低評価（1〜2点） | 約16件（約8%）。契約・解約、安定性 | 13件（約7%）。サポート、解約、通話の質 |
| 口コミの時期 | 2024〜2026年は約25件 | 2018〜2020年が約100件、2025〜2026年は24件 |

どちらも**「契約・解約」への不満**が出ています。年間契約と自動更新の条件は、申込前に必ず確認してください。

## 申し込む前に聞くこと

1. 自分の住所で取れる番号の種類（03・06・050・0120）と、**必要書類・日数**。
2. 通話料を含めた**月の総額の見積もり**（円で）。
3. 今の電話番号を移せるか。費用と日数は。
4. **110・119**にかけられない場合の備え。
5. 契約期間、自動更新、解約の条件。
