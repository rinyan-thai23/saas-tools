【体験・ツアー】予約システムの日本語対応を比較｜管理画面・予約画面・サポートの言語（11製品）

先に結論

  • 「日本語対応」には3つあります：①事業者が使う管理画面 ②お客さんが使う予約画面 ③サポート。製品の「日本語対応あり」は、このどれを指すのかが、はっきりしないことが多いです。
  • 日本語のサポート（電話・メール）が公式に書かれているのは、OMUSUBI（国産）と rezio です。 Bókun の日本版（JTB BÓKUN）は、日本語サポートの記載がありますが、窓口の詳細は確認できていません。
  • 海外製品（Checkfront、Rezdy、Xola、FareHarbor、TrekkSoft、Bookeo、Regiondo、Zaui）は、日本語のサポートを確認できませんでした。 Checkfront は、サポートが英語のみと公式に書いています。
  • 管理画面が英語でも、ブラウザの翻訳で読むことはできますが、誤訳や個人情報の扱いに注意が必要です（下で説明）。

製品ごとのポイント

日本語で相談できる：OMUSUBI、rezio

  • OMUSUBI：国産で、電話・メール・オンラインの画面共有でサポートします。乗り換えは「通常10営業日」と公式にあります。
  • rezio：日本の運営会社（株式会社KKDAY JAPAN）の電話窓口が、平日9〜18時（日本時間）とあります。メールでの問い合わせ先も、利用規約に載っています。管理画面が日本語かは、確認できていません。

日本向けの窓口がある：JTB BÓKUN

Bókun の公式ブログ（2021年）に「日本語のサポートと日本向けの分析を備えた JTB BÓKUN」とあります。JTB の資料には、個別相談会とマニュアルの案内があります。管理画面が日本語か、サポートの対応時間は、確認できていません。

日本語の記載が見つからない：海外製品

  • Checkfront は、サポートは英語のみ、言語パックはメンバーの翻訳で、1つのアカウントでは言語を混ぜられない、と公式に書いています。日本のお客さんと外国人のお客さんの両方を受けたい事業者には、制約になります。
  • Capterra の「日本語対応あり」（Xola、Checkfront、Bookeo）は、公式サイトで日本語の記載が確認できないものがあります。「あり」でも、管理画面か予約画面か、どちらかは分かりません。

英語の管理画面を使うとき

海外製品を選ぶ場合は、管理画面が英語になります。ブラウザの翻訳で、日本語に変えて読む方法があります。

  • ブラウザの翻訳（Chrome、Edge など）：ページ全体を日本語に訳して表示できます。
  • DeepL の拡張機能：選んだ文章をその場で訳せます。画面全体を訳すには、有料の DeepL Pro が必要と、検索で見えた解説にあります（DeepL の公式ページは確認していません）。無料のアカウントでも、部分的な翻訳はできるとされています。
  • 注意点（このサイトで実際に試した結果ではなく、一般的な注意です）：
  • 管理画面のボタン名や設定項目を訳すと、意味が変わることがあります。料金や返金の設定は、英語の原文も見て確認してください。
  • 画面にお客さんの名前や連絡先が出ている場合、翻訳サービスに送られることになります。社内のルールや、翻訳サービスの利用条件を確認してください。
  • 翻訳の拡張機能のオン・オフが面倒、という声があります（DeepL の利用者のレビュー）。

サポートへの問い合わせは、翻訳に頼ると、行き違いが出ることがあります。 設定でつまずいたときに、日本語で相談できるかは、製品選びで効いてきます。

申し込む前に聞くこと

  1. 管理画面は日本語か。 日本語のマニュアルはあるか。
  2. お客さん向けの予約画面は、日本語と何語に対応するか。 自分のプランでも使えるか。
  3. サポートは日本語か。 連絡手段（電話・メール・チャット）と、日本時間の対応時間。
  4. 設定の初期支援（導入の手助け）は、日本語で受けられるか。
  5. 日本語と英語など、複数の言語を、1つのアカウントで同時に出せるか。

よくある質問

日本語に対応している予約システムは？

日本語のサポートが公式に書かれているのは、OMUSUBI（国産）と rezio です。JTB BÓKUN は、日本語サポートの記載があります。海外製品は、日本語のサポートを確認できませんでした。

管理画面が英語でも使えますか？

ブラウザの翻訳で読めますが、料金や返金の設定は、原文も確認してください。翻訳サービスにお客さんの情報が送られる点にも注意が必要です。

「日本語対応あり」と書かれていれば安心ですか？

いいえ。管理画面、予約画面、サポートのどれが日本語かは、はっきりしないことがあります。申込前に、3つに分けて確認してください。
