## ログ

### 2026-11-07 #1 フォルダ名 `サイト` → `docs`
- GitHub Pages の公開元に docs を使うため。`git mv` で履歴は残る。
- 参照の書き換えは README と `_作り方/` だけで済んだ（build.py は相対パスなので無修正）。

### 2026-11-07 #2 トップに「あなたの状況は？」カード4枚
- 長い説明文より先に、読者が自分の状況で選べる入口を置いた。
- 記事mdにHTMLをそのまま書ける（markdownライブラリが通す）。CSSは build.py の `CSS` に追記。
- 新しい環境では `pip install markdown` が先に必要だった。

## 学び・次回気をつけること
- ⚠ **Pages のURL問題（未対応）**：公開すると `https://<user>.github.io/saas-tools/民泊ツール比較/出力/` になる。
  本文リンクが `/articles/...` の絶対パスなので、このままだと**リンクが全部切れる**。
  対策案：(a) 独自ドメインを使う (b) ビルド時に base パスを付ける (c) `出力/` の中身を docs 直下へ出す。
- 日本語フォルダ名はURLが長いエンコードになる。公開側は英語名が無難（要検討）。
- 警告「disclosure に未設定」は運営者情報が未記入のため（人が決める事項）。
