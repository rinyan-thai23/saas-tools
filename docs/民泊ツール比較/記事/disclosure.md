# 広告表示と運営方針

> 本サイトには広告（アフィリエイトリンク）が含まれます。どのリンクが広告か、広告があっても内容をどう守っているかを、このページに書いています。

## 広告（PR）の表示

- 記事には、各社の申込ページへの**アフィリエイトリンク**を含むものがあります。リンク経由でツールが申し込まれると、運営者が各社から紹介報酬を受け取ることがあります。
- **広告リンクは、リンクの文末に「（PR）」を付けています。** 広告リンクを含む記事は、冒頭に「この記事にはアフィリエイトリンク（PR）が含まれます」と書きます。
- 報酬が発生する条件や仕組みは、会社ごとに違います（紹介リンクの有効期間、一定期間の利用継続が条件、利用料の一定割合が一定期間続く、など）。
- Beds24 は、紹介リンクが**海外公式（beds24.com）側**の仕組みに基づきます。日本の販売会社（株式会社WeIns）にはリンクを付けていません。
- 広告表示は、景品表示法のいわゆるステルスマーケティング規制（2023年10月施行）を意識して、広告であることが分かるように書いています。規制の詳細は、消費者庁の公式資料で確認してください。

### リンクの有無

| 区分 | 広告リンク |
|---|---|
| Guesty、Hostaway、Lodgify、OwnerRez、Hospitable、iGMS、Uplisting、Beds24（海外公式側）、PriceLabs | あり（PR） |
| Sirvoy、Hostfully Guidebooks | なし。公式サイトへの通常のリンクのみ |

## 運営方針：リンクの有無や報酬で内容を変えません

- ツールの順番や書き方、良い点・悪い点の扱いは、**広告リンクの有無や報酬の多寡では決めません。**
- 広告リンクのあるツールでも、**料金が公開されていない、契約が長い、日本語の記載が見つからない、口コミで低評価が多い**といった不利な事実は省きません。
- 広告リンクのない Sirvoy と Hostfully Guidebooks も、他のツールと同じ手順で書きます。
- 「このツールが一番」とは書きません。条件ごとに「この条件ならこちらを先に確認する」と書きます。
- **日本の運営者向け**に、民泊新法・旅館業法・特区民泊の違いと、日本語・国内予約サイト・円請求といった、日本で使うときの注意を必ず書きます。

## 情報の集め方

1. **公式サイト・ヘルプ・利用規約**を開いて、料金・契約・機能・言語を確認します（確認日は、各記事の末尾に書きます）。
2. **海外のレビューサイト（Capterra）の口コミ**を、関連順と新着順の両方で集め、日本語に要約します。原文の転載はしません。投稿者の規模と使用期間、低評価（1〜2点）の割合も書きます。**英語圏の運営者の声が中心で、日本の運営者の実感ではありません。**
3. **Web検索**で、第三者の比較や、日本語の情報を調べます。ツール事業者・競合の比較ページは、「自社の主張」「競合の主張」と書き、そのまま信じません。
4. 民泊の制度は、**観光庁・e-Gov・国税庁・自治体などの一次資料**を使います。

## 書き方のルール

- 公式ページで**確認できたこと**と、**確認できなかったこと**を分けます。見つからなかったことは「記載が見つからなかった」と書き、「できない」とは書きません。
- 公式が合計額を載せていないものは、「計算」と書きます。自社の実績の数字は「自社の主張」と書きます。
- 口コミ中の話題の数（「約3割」など）は、キーワードで数えたおおよその数です。口コミが少ない・偏っているときは、そう書きます。
- 本文には、出典のURLを並べません。情報源は、このページのとおりです。
- 法律・税務の助言はしません。最終的な判断は、観光庁・自治体・税理士などで確認してください。
- 料金や仕様は変わります。申込前に、公式ページで再確認してください。
- 本サイトは各社の公式サイトではなく、各社の公式の見解を示すものでもありません。

## 記事の作り方

1. **ツールごとの紹介ページ**を先に作ります（公式サイトの確認、口コミの集計、Web検索）。
2. そのうえで、比較・代替・乗り換え・日本対応・買う直前の記事を、**1本ずつ、毎回新しく調べて**書きます。
3. 書いたあとは、リンク切れ、禁句、本文の金額が紹介ページに載っているかを、機械的に確認します。

## 誤りの連絡と訂正

- 料金・仕様・契約条件・日本対応について、誤りや古くなった点にお気づきの場合は、下記の連絡先までお知らせください。
- 連絡先：**【公開前に必須・未記入】ここに連絡先を記入してください。未記入のまま公開しないでください**
- 誤りが確認できた場合は、該当のページを訂正し、[更新履歴](/changelog/) に記録します。
- お知らせいただく際は、該当ページ、誤りだと思う箇所、根拠となる公式ページの URL をいただけると、確認が早くなります。
