【民泊】Hostaway と iGMS どっちがいい？料金・サポート・口コミ・日本で使えるかを比較

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

先に結論：小さく安く始めるなら iGMS、導入の手助けと規模なら Hostaway

  • 1〜数室で、料金を見て、無料から試したい → iGMS。 無料プランと14日間のトライアルがあり、泊数払い（FLEX）や物件ごとの月額が公開されています。
  • 導入の手助けがほしい、複数の予約サイトで運営を広く自動化したい → Hostaway。 ただし料金は見積り制で、契約期間も個別契約です。
  • 口コミの低評価の割合は、iGMS が約3%（114件中3件）、Hostaway が約4%（約170件中7件）。どちらも低い水準です。
  • 日本語は、どちらも不向き。 iGMS の画面は英語とスペイン語、Hostaway は確認できません。
  • 日本の民泊新法の人は、どちらも先に確認が必要（Airbnb の扱い）。

各ツールの詳しい情報は、Hostaway の評判・口コミ、iGMS の評判・口コミにまとめています。

料金：iGMS は公開、Hostaway は見積り

iGMS（公式、月額・米ドル）

  • 無料：月$0（予約5件、メッセージ10件まで）。
  • FLEX：予約された泊数あたり$1（物件ごとに最低月$20）。
  • PRO（月払い）：1物件あたり、1室$48／3室$23.33／5室$19.80／10室$17.40。公式の単価からの計算で、合計は3室約$70、5室約$99、10室約$174です。
  • PRO+：PRO より高く、翻訳や収益管理などが付きます。

Hostaway：料金ページは、物件数を答えると見積りが来る入力フォームです。月額は第三者の推定がバラバラで、公式の裏付けがありません。

差の見方：小規模では、iGMS の方が安く始められる傾向があります。第三者の比較も同じ見方です（ただし、どちらの価格も条件で変わります）。Hostaway は見積りを取って比べてください。

契約と解約

  • iGMS：月払いは解約手数料なし（月の途中の返金なし）。10室未満の年払いは、一括前払いで途中解約しても返金なし。口コミに、「解約の方法が分からず、サポートに強く頼まないと対応してもらえなかった」という低評価（2025年）があります。公式ヘルプは、解約を営業日48時間以内に処理すると案内しています。
  • Hostaway：期間は個別契約。値上げは14日前に通知され、同意しない場合は、発効の5日前までの通知で解約できます。口コミに、「営業の説明と導入後が違った」「12か月契約で、試用なしだった」「解約の連絡後も請求が続いた」という低評価があります。

第三者の比較サイトでも、Hostaway はサポートの評価が高め、iGMS は直近の裏付けが少ない、という見方でした。

日本で使うときの注意（両社共通）

  • 日本語：Hostaway は公式サイトに日本語ページがなく、管理画面・サポートの日本語も確認できません。iGMS の画面は英語とスペイン語で、サポートも同じです。ゲスト向けの自動メッセージは109言語と書かれていますが、日本語が含まれるかは確認できません。
  • 民泊新法の人は先に確認：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーで、両社が該当するかは確認できていません。
  • 楽天トラベル・じゃらん：民泊新法・特区民泊の施設は、どちらも対象外です。両社とも、公式の連携先に楽天トラベル・じゃらんの記載がありません。
  • Agoda：どちらも公式の一覧には確認できていません。
  • 請求通貨：どちらも円は確認できません。
  • 年180日の管理、届出番号、定期報告、インボイスなどの機能は、両社とも公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。

よくある質問

Hostaway と iGMS の一番大きな違いは何ですか？

料金の公開と、想定する規模です。iGMS は無料プランがあり、料金が公開され、2〜8室の個人ホスト向けです。Hostaway は料金が見積りで、導入支援と、複数サイトの運営の自動化が強みです。

1〜2室ならどちらが安いですか？

公式に料金が出ているのは iGMS です（無料プラン、FLEX、PRO の1室$48）。Hostaway は公式の料金がなく、見積りが必要です。

無料トライアルがあるのはどちらですか？

iGMS に14日間のトライアルと無料プランがあります。Hostaway は、公式ページでは確認できず、デモの申込のみです。

解約しやすいのはどちらですか？

iGMS は月払いなら縛りがありませんが、10室未満の年払いは返金がなく、口コミに解約の手順が分からなかったという低評価があります。Hostaway は期間が個別契約なので、書面での確認が必要です。

日本語で使えるのはどちらですか？

どちらも、公式には日本語の管理画面もサポートも確認できませんでした。iGMS は英語とスペイン語です。
