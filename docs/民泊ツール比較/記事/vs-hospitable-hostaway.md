# Hospitable と Hostaway を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

> **結論**
> - Hospitable は公式ヘルプに基本料金と追加物件の単価が載っており、3室で月$74（Professional）または$99（Mogul）と計算できます（計算値。現行の公式表示は未確認）。Hostaway は価格非公開で、見積りを取る形でした。
> - Hospitable の管理画面は英語のみと公式FAQにあります。Hostaway は日本語の記述を確認できず、公式には「ある」とも「ない」とも言えない状態です。
> - 楽天トラベル・じゃらんは、どちらの公式ページにも記載が見つかりませんでした。Agoda は Hospitable が全プランで接続と表示し、Hostaway は確認できていません。

## 先に知っておくこと（日本で使うときの前提）

予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

- **楽天トラベル**：旅館業法の営業許可証を取得した施設が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は「Rakuten Oyado」で登録、と案内。
- **じゃらんnet**：旅館業法の宿泊営業許可を得た施設が対象。住宅宿泊事業法に基づく民泊と特区民泊は「ご参画いただけません」。
- **Rakuten Oyado** で「そのまま使える」とされる既存ツールは、ねっぱん、AirHost、Beds24、suitebook。Hospitable・Hostaway の名前は載っていません。
- **Airbnb**：ヘルプに「In Japan, we don't accept listings created through software connections for places to stay (minpaku)…」とあり、例外は日本のAPIパートナー。その名前は公式で見つかりませんでした。既存の掲載を後からつなぐ場合の扱いは未確認です。届出番号は「ツールを使っていても、自分でログインして」追加する必要があります。
- 取得できた公式ページに、日本向けの届出番号欄・年180日の管理・定期報告・適格請求書（インボイス）に当たる機能の記載は、両社とも見つかりませんでした。

## 比較表

【確認済】公式ページ・規約を開いて確認／【自社の主張】公式が書くが第三者の検証なし／【第三者のみ】公式を開けず第三者情報だけ／【未確認】確かめられていない／【計算値】公式の単価からの計算。金額は USD。

海外レビュー（Capterra、2026-11-03時点、英語圏の評価）：Hospitable 145件／4.7、Hostaway 1,623件／4.8。Hospitable は、カード変更を機に旧レートを失ったという1.0評価の投稿と、1物件だと割高という投稿がありました（個々の口コミの記載で、真偽は未検証）。Hostaway は値上げ・サポートの質の指摘が検索抜粋にあります。

## 条件別の選び方

- **料金を公式の資料で計算して比べたい人：** Hospitable。ただし Host は2室まで、オーナーポータルは Mogul のみ、ダイレクト予約は Professional 以上です。
- **管理画面の日本語を優先する人：** Hospitable は英語のみと確認できています。Hostaway も確認できていないため、デモで画面を見てください。
- **Agoda も使う人：** Hospitable は接続表示があります。Hostaway は確認できていません。Expedia は逆に Hostaway が対応で、Hospitable は iCal です。
- **他ツールから移る人：** Hospitable は自動のデータ移行がなく、自動メッセージの作り直しが要ります。14日の無料トライアルで先に設定を進められます。Hostaway は見積り時に移行支援の中身を聞いてください。
- **楽天トラベル・じゃらんが必須の人：** 民泊新法・特区民泊の施設は両サイトの対象外と各社が書いています。旅館業法の許可施設については、Hospitable・Hostaway とも接続可否が未確認です（Hospitable は iCal 取り込みの対象になり得ますが、楽天側が iCal を出すかは未確認）。申込前に各社へ問い合わせてください。

## 申し込む前に確認すること

- [ ] 営業形態（届出／許可／特区）で、使いたい予約サイトに載せられるか
- [ ] Airbnb に、民泊新法の掲載（既存分を含む）をツールにつなげるかを確認した
- [ ] Hospitable で、自分の物件数と必要な機能に合うプランの月額を試算した（active property の数え方を含む）
- [ ] 年払いにする場合、30日を過ぎると返金されない点を確認した
- [ ] Hostaway の見積りで、月額・初期費用・アドオンの内訳を書面で受け取った
- [ ] 請求通貨が円か、USD等の場合のカードの為替手数料を確認した
- [ ] 日本語のサポートと日本時間の窓口を書面で確認した
- [ ] 英語の管理画面で運用できるか、14日トライアル（Hospitable）やデモ（Hostaway）で試した
- [ ] 宿泊者名簿・年180日・定期報告・インボイスを、ツール内か別の方法かで決めた
