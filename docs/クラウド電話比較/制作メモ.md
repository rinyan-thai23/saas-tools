# クラウド電話比較 制作メモ（3つ目のカテゴリ）

## 2026-11-07 準備と #1 RingEX（商品ページ1本目）
- 準備：民泊・体験・ツアーと同じ型。`サイト設定.json`（出力 phone）、`ビルド/build.py` コピー、README（設計）、口コミ取得（10製品、関連順＋新着順、裏で実行）。
- 材料：口コミ191件、公式の料金ページ（米国向け・USD）、**公式の緊急通報ポリシー（2023年12月版、国別の表）**、検索3回。
- **最大の発見**：RingCentral公式の緊急通報ポリシーの国別の表に、日本は「RingCentralが提供するのは東京の市外局番の番号のみ」「緊急通報は利用できない」とあった。体験・ツアーでの教訓（公式の規約・ポリシー・FAQまで読む）が効いた。ただし2023年版（現行ページは別の国表）なので「古い版。現在は直接確認」と明記。
- 日本語の公式サイトが見つからない（/jp/ja・/ja は404、co.jpはプロキシで到達不可）。「確認できなかった」と書き、「存在しない」とは書かなかった。
- 口コミ：米国約8割、日本0人、2022〜23年に集中。投稿年の分布を数えて注記。
- 料金ページが米国向けで、日本の円の料金・日本の番号の月額は確認できず。質問リストの最初に置いた。

## #2 Nextiva（商品ページ2本目）
- 材料：口コミ185件、公式の料金ページ、公式サポート記事（国際電話、2025-08更新）、検索2回。
- 学び
  - **Nextivaは日本の番号の記載が見つからない製品**。「取れない」と書かず「書かれていない」。公式のサポート記事で確認できたのは国際電話を「かける」機能（初期状態は無効、サポートに依頼して有効化）だけ。**番号の取得（着信）と、かける機能を混同しない。**
  - 口コミの年の分布が極端（2023〜24年に約160件、2025〜26年は12件）。最近の口コミ（低評価が集中）を重く見るよう注記。
  - 検索の要約にあった「Nextivaは国際サービスを提供していない。カナダの番号は一部対応」は公式ページで裏が取れず、採用しなかった。

## #3 CallHippo（商品ページ3本目）
- 材料：口コミ179件、公式の日本向けページ（番号の種類・必要書類・日数の表）、公式の料金ページ、検索2回（英語・日本語）。
- 学び
  - **公式の「Japan virtual number」ページに、番号別の必要書類と日数の表**があった（他社のページと突き合わせられる）。ただし自社の主張で、**Zoom公式（日本の事業所の書類が必要）と条件が食い違って見える**（050は国外住所でも可、と書く）→ 「どちらが正しいか未確認。書面で確認」と併記。
  - **「通話無制限」は米国・カナダ宛のみ**（公式の注記）。日本向けの通話は従量。見出しの「無制限」だけを信じさせない注意を結論に入れた。
  - 090/080/070の携帯番号を取れるという自社の主張は、他の公式（Zoom）が挙げていない。裏付けなしと明記。
  - 口コミは国がインド約5割。使用期間が短い（1〜5か月が5割）ので「始めたばかりの感想」と注記。**未払いで突然番号が止まる**という複数の声（2026年）を拾った。
  - 公開前に他の記事へのリンク（zoom-phone）を書いてしまい、ビルド前に気づいて外した。**未作成のページへリンクしない**（後で足す）。

## #4 GoTo Connect（商品ページ4本目・補助）
- 材料：口コミ178件、検索2回。**GoToの公式サイト・サポートの全ページが403（アクセス拒否）**で、料金・対応国を確認できなかった。
- 対応：冒頭に「公式サイトに接続できず、公式の料金と日本の番号の記載は確認できていない」と明記。確認できたことと、できなかったことを分けて書いた。料金の数字は第三者の数字を使わず、載せなかった。
- 口コミの約7割が2018〜2019年（2023年以降は約20件）。年の分布を数えて「古い」と注記。直近の低評価2件（サポート）を取り上げて、古い良い評価との落差を伝えた。
- 検索結果の「Japan」はGoToMeetingの古い会議ダイヤルインのお知らせで、GoTo Connectの番号提供ではない（混同しないよう明記）。

## #5 Dialpad（商品ページ5本目）
- 材料：口コミ181件、**ソフトバンクの日本向け料金ページ・FAQ・2021年の発表（一次資料・円の料金、本人確認、納期）**、Dialpad日本語サイト、検索3回。Dialpad公式ヘルプはCloudflareで403→検索の抜粋のみ（110・119発信不可は「抜粋。ページ本体は未確認」と明記）。
- **発見**：日本では**ソフトバンクが販売元**として、円・税抜の料金表、0AB-J（03・06）の基本料（月500円）、ポータビリティ費用、本人確認の必要書類（登記事項証明書など）と郵送（簡易書留）、開通日数（最短10〜15営業日）を公開。海外製品なのに、日本の条件が最も具体的に分かる。**海外製品は「日本の販売代理店（ソフトバンク等）」の公式ページを探す**（体験・ツアーのJTB BÓKUNと同じ型）。
- 通話料の表は表形式が崩れて読み取りに不確かさがあり、「読み取りに不確かさがある」と注記して載せた。数字を自信を持って断定しない。
- 書いた後の照合で、通話料の宛先の取り違えと、根拠が薄いトライアル条件（アカウント15以下）を修正。

## #6 Aircall（商品ページ6本目）
- 材料：口コミ173件、公式の料金ページ、**公式ヘルプ2本（緊急通報と短い番号／通話バンドル）を直接取得**、検索2回。
- 発見：公式ヘルプの緊急通報の対応国（AT,AU,CA,DE,ES,FR,IE,US,UK）に日本なし／通話バンドルの「アジア・北米」で日本は固定電話宛のみ。日本の番号の取得は公式で確認できず（「100か国以上」は自社の説明）。
- 書いた後の照合で、**事実でない一文（Professionalは全発信無制限）を修正**、使用期間・低評価件数を数え直した。料金表の「無制限」は、プランごとに範囲が違うので、料金表の行と文を突き合わせる。
- 最低3ライセンスは1〜2人の読者に直撃するので結論に置いた（日本の個人事業主向けという読者像に合わない製品は、合わないと言い切る）。

## #7 CloudTalk（商品ページ7本目・補助）
- 材料：口コミ104件、**公式の日本向けページ（番号の種類・月額・日数・必要書類）と、番号の要件のヘルプ（国別の大きな表・約40万字）**、料金ページ、検索2回。
- 発見：日本の番号は東京の03（$6、初回15〜25営業日）と0120/0800（$35、着信のみ）。050・大阪は載っていない。**日本向けページとヘルプで書類条件が細かく食い違う**ため「最新は確認」と書いた。ヘルプの国別表は、他製品の日本の条件を比べる材料にもなる（番号の取り方の記事で使える）。
- 口コミは2019〜2020年が7割、2023年以降11件。低評価は全て2020〜22年。「最近の低評価がない＝問題なし」とは言えないと明記。
- 書いた後の照合で、根拠のない「スロバキア発」を削除、件数（9→11）を修正。
