# 校閲：switch-lodgify-to-hostaway

照合したカード：Lodgify、Hostaway、日本のOTA連携。記事は変更していない。

件数：要修正 1／注意 2／軽微 2

## 指摘

### 要修正

1. **判断表「Lodgify の更新日が近い：解約の締切（アカウント画面なら終了の1日前）。更新後に解約しても返金はない」**
   - カード：Lodgify §2「返金（規約）」＝消費者には14日間のクーリングオフがあり、「年払い・2年払いは更新時にも適用、月払いは初回のみ」。事業者として契約する場合の扱いは「Consumer」の定義に依存し未確認。
   - 問題：更新後の返金なしを言い切っている。カードでは、年払い・2年払いの消費者には更新時にもクーリングオフがある。記事の契約表の行（「…未確認」と注記）とも食い違う。
   - 修正案：「更新後の解約は原則返金なし（規約。消費者向けクーリングオフの当たり方は未確認）」とする。

### 注意

2. **結論1「期間の途中で解約しても返金はありません。」**
   - カード：同上。
   - 問題：結論だけ読むと例外（クーリングオフ）が落ちる。
   - 修正案：「規約上、期間途中の解約は返金なし（消費者向けクーリングオフの扱いは本文参照）」とする。

3. **結論2「Hostaway 側の Booking Website に作り替えることになります。移行の方法は、開いた公式ページに記載が見つかりませんでした。」／チェックリスト「独自ドメインと決済アカウント（Stripe など）の付け替え」**
   - カード：Hostaway §4「ダイレクト予約サイト」＝Booking Website の機能のみ。Lodgify のサイトから Hostaway への移行を調べた行はない（Lodgify §7 にもない）。
   - 問題：「作り替えることになる」はカードにない推測。「記載が見つからなかった」という調査結果もカードにない（追加調査依頼のコメントにあるだけ）。
   - 修正案：「Hostaway 側で予約サイトを用意する必要があります（移行方法は未調査）」とする。

### 軽微

4. **機能表の下「楽天トラベル・じゃらん・Agoda：どちらも公式ページに記載が見つかりませんでした」**
   - カード：Hostaway §3 の Agoda＝「公式のチャネル一覧には無い」が、ブログに Agoda の解説と "A channel manager, like the one built into Hostaway, keeps your Agoda calendar aligned" の文があり、接続は断定できない（未確認）。
   - 問題：記事1・2は「公式の一覧になく断定できない」と書いており、記事3だけ書き方が違う。
   - 修正案：記事1・2の書き方にそろえる。

5. **「Lodgify の Agoda は、iCal 経由の可否が個別確認とされています」**
   - カード：Lodgify §3 Agoda＝「連携一覧に掲載なし。iCal経由の可否は個別確認が必要」（リサーチ役の注記）。
   - 問題：Lodgify 側が「個別確認」と案内しているように読める。
   - 修正案：「iCal 経由で使えるかは、Lodgify に個別に確認が必要です」とする。
