# 【民泊】表計算（スプレッドシート）管理から管理ツールへ｜何室から？費用と切り替えのタイミング

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：「何室から」より、「どんな運営か」で決まります

> - **「何室から」を示す、信頼できる基準は見つかりませんでした。** 業界のブログには「数十室で表計算が破綻しやすい」といった目安もありますが、販売会社の見解で、民泊の部屋数に当てはめた根拠はありません。
> - **部屋数が少なくても、切り替えを考えるサインがあります。** 複数の予約サイトに出している、複数人で管理している、予約を手入力している——この3つのどれかです。
> - **費用の目安：3室で月$70前後（OwnerRez、iGMS の PRO）、5室で月$88〜$104、Beds24 は5室で月€31（2チャネル）。** 1室なら無料プランもあります。
> - **切り替えの前に、日本の注意**：民泊新法の人は、Airbnb がツール経由の掲載を受け付けない場合があります。先に確認してください。

## 切り替えを考えるサイン

表計算が悪いわけではありません。次のようなときに、手作業のミスが出やすくなります。

| サイン | なぜ問題か |
|---|---|
| 複数の予約サイト（Airbnb・Booking.com・Vrbo など）に出している | 1つの予約が入るたび、ほかのサイトの同じ日を手で閉じる必要があり、1回の更新ミスが二重予約になる |
| 複数人で管理している（共同ホスト・清掃スタッフ） | 表計算は、同時にリアルタイムで情報を共有する用途に弱い |
| ゲストへのメッセージが多い | 予約確認、チェックイン案内などを、毎回手で送っている |
| 清掃の手配に時間がかかる | 予約の変更に合わせて、清掃の連絡を手で直している |
| 売上や経費の集計に時間がかかる | 予約サイトごとの入金や手数料を、別々にまとめている |

**1つの予約サイトだけで、1人で運営しているなら、表計算で足りる**場合も多いです。

## 管理ツールで変わること

公式ページで、次の機能がどのツールにも載っています（表計算では手作業になる部分）。

- **二重予約を防ぐ**：1つのサイトで予約が入ると、ほかのサイトの同じ日を自動で閉じる。
- **ゲストへの自動メッセージ**：予約確認や案内を、タイミングに合わせて自動で送る。
- **清掃タスクの自動作成**：予約が入ると清掃タスクができ、予約が変わるとタスクも変わる。
- **予約サイトの一元管理**：全サイトの予約を、1つのカレンダーで見る。

ただし、これらの効果が、**費用に見合うか**は運営によって変わります。

## 「元が取れるか」を、自分で計算する

「何室から元が取れる」は、運営によって違います。次の式で、自分の数字を入れてください。

1. **手作業の時間**（月）：予約の入力、カレンダーの更新、メッセージ、清掃の連絡にかかる時間。
2. **時間の価値**：1時間あたり、自分の時間をいくらと見るか。
3. **二重予約の損失**：1回あたり、代替の宿の手配、返金、レビューの低下。
4. **ツールの月額**：上の表の目安。

「手作業の時間×時間の価値＋起こりうる損失」が、ツールの月額より大きければ、切り替えの価値があります。**ツールの効果（時間がいくら減るか）は、公式でも口コミでも確認できる数字がありません**ので、無料プランや14日間のトライアルで、自分の運営で試して決めるのが確実です。

## 切り替えの手順（簡単に）

1. **現状を書き出す**：予約、料金、ルール、ゲスト情報を表計算にまとめる。
2. **無料プラン・トライアルで試す**：実際に使う予約サイトを接続して、カレンダーが同期するか確認。
3. **並行運用する**：表計算を止めずに、ツールを数日見て、ずれがないか確認。
4. **二重予約を防ぐ**：切り替えの前に、近い日付の空室を手動で閉じる。切り替え後、各予約サイトのカレンダーを確認。
5. **表計算を引退させる**：ツールに切り替えて、一定期間は表計算を残して照合。

詳しくは [移行チェックリスト（二重予約の防ぎ方）](/articles/switch-checklist-double-booking/) へ。

## 日本で切り替えるときの注意

- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。**どのツールが該当するか確認できていない**ため、申込前に Airbnb と各社に確認してください。
- **日本語**：Beds24（日本の販売会社経由）以外は、公式に日本語の管理画面・サポートを確認できません。
- **楽天トラベル・じゃらん**：民泊新法・特区民泊の施設は、どちらも対象外です。
- 年180日の管理、届出番号、定期報告、宿泊者名簿、インボイスなどの機能は、各ツールの公式ページに記載が見つかりませんでした。**当面は表計算など別の方法で管理する**前提にしてください。

## よくある質問

### 何室から管理ツールを入れるべきですか？
「何室から」を示す信頼できる基準は見つかりませんでした。複数の予約サイトに出している、複数人で管理している、予約を手入力している、のどれかに当てはまるなら、部屋数が少なくても検討する価値があります。

### 無料で試せるツールはありますか？
iGMS（予約5件・メッセージ10件まで）、Hospitable（Essentials）、Sirvoy（1室まで）に無料プランがあります。OwnerRez と iGMS は14日間、Hospitable は14日間、Lodgify は7日間の無料トライアルです。

### 日本の制度（年180日、届出番号）の管理は、ツールでできますか？
今回調べたツールでは、公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。当面は、表計算など別の方法で管理する前提にしてください。

### 日本語で使えるツールはありますか？
Beds24 の日本の販売会社（株式会社WeIns）版が、日本語の画面とサポートを提供しています。そのほかは、公式には確認できませんでした。
