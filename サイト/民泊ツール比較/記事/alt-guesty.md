# Guesty の代替ツール：契約・価格・日本対応で選ぶ5候補

> **結論**
> - Guesty が合わない理由が「契約期間と解約金」「Pro の価格が見えない」なら、料金表が公開されていて月単位の契約がある [Hospitable](/go/hospitable/)・[OwnerRez](/go/ownerrez/)・[iGMS](/go/igms/) が比較の出発点。
> - 日本語UI・円建て請求・楽天トラベル／じゃらん連携を公式ページで確認できたのは、今回調べたPMSのうち、Beds24 の日本の販売会社（WeIns / Co-Reception）版だけ（WeIns 自身の資料に基づく情報）。ただし別の癖がある。この記事の PR リンクは [Beds24（海外公式）](/go/beds24/) 側で、日本の販売会社への申込は別手続き。
> - 住宅宿泊事業法の届出番号・年180日の専用機能は、公式ページに記載が見つからなかった。Beds24 の日本の販売会社には年180日の解説記事の存在を見つけたが、本体機能かは未確認。

## 先に知っておくこと（日本で使うときの前提）

- **国内予約サイトは、物件の制度で話が変わる。** 楽天トラベルの新規参画ページ（公式）には「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」とあり、民泊新法・特区民泊は同じ楽天グループの「Rakuten Oyado」で登録する案内がある。じゃらんnet の参画案内（公式、更新日の記載なし）にも、住宅宿泊事業法に基づく民泊と特区民泊は「ご参画いただけません」とある。両サイトとも民泊新法・特区民泊は対象外と明記している。旅館業の許可施設を各ツールにつなげられるかは、いずれも未確認。自分の物件がどの制度に当たるかの判断は、この記事ではしない。
- **Airbnb の公式ヘルプ**には、日本の住宅宿泊事業（民泊）について "we don't accept listings created through software connections" とあり、例外は "Japanese API partners who have entered into the license agreement" とある。例外にあたるパートナー名は公式ページで見つからなかった。届出番号は "You need to directly log in to your account ... even if you usually use management tools" とあり、管理ツール経由ではなく Airbnb に直接ログインして入れる案内。既存の掲載をツールに接続するときにこの方針がどう働くかは、取得した資料には書かれていない（未確認）。
- **宿泊者名簿**：観光庁の民泊制度ポータルに、宿泊者全員分の記載、日本国内に住所のない外国人は国籍・旅券番号の記載と旅券の写しの保存、という記載がある。**定期報告**は2か月ごとに宿泊日数・宿泊者数・国籍別の内訳。管理ツールがこれらを肩代わりするかが比較点になるが、日本の名簿要件に合う本体機能の記載は、Beds24 の日本の販売会社（有料の宿泊者名簿オプションと、定期報告用の外部シート）以外は、公式ページに見つからなかった（ID・パスポート確認の機能を持つ製品はあり得るが、日本の様式に合うかは未確認）。
- **Guesty 自身の日本対応**：日本語UIの記載なし（現行の対応言語は第三者の情報のみ。予約エンジンの日本語は第三者の抜粋のみ）、サポート言語は English・Spanish・French・Italian・German・Hebrew・Portuguese で日本語なし、請求は原則USD。つまり「Guesty から乗り換えれば日本語になる」とは限らず、日本語の面では下の候補にも英語のみと確認できたものが多い（Hospitable・iGMS・OwnerRez）。

## 候補ごとの要点

### Hospitable：料金と解約は見えやすい。日本語は弱い

- 料金：Essentials $0（機能制限あり）／Host $29（最大2物件）／Professional $59／Mogul $99。基本料金に含まれる物件数を超えると1件ごとに $10／$15／$30 が加わる。物件数が増えるほど Mogul は割高になりやすい（計算値は上の表）。
- チャネル：Airbnb・Vrbo・Booking.com・Agoda は直接接続（公式）。Expedia は iCal のみの扱いで、反映は即時ではない。楽天トラベル・じゃらんの記載は見つからなかった。
- 弱い点：管理画面は英語のみ（公式FAQ）。ゲスト向け定型メッセージは英語・スペイン語・フランス語・ドイツ語で、日本語の追加要望は 2026-06-08 の投稿が「New」のまま（票1）。Essentials のサポートは AI とコミュニティのみ。オーナーポータルは Mogul のみ。
- 乗り換え：他PMSからの自動データ移行はない（公式）。リスティングは再作成せず接続し、自動メッセージは作り直しが必要。無料のオリエンテーション通話がある。
- 向く人：英語UIで運用でき、価格と解約条件を先に確定させたい人。向かない人：日本語UI／日本語サポートが必須の人。

### OwnerRez：基本料金が安く契約なし。日本向けの情報はほぼ無い

- 料金：1物件目 $40（最低月額も$40）、2〜3物件目 各$15、4物件目 $10、5〜9物件目 各$8、10〜19物件目 各$7。5室で $88（公式の表示）。Property Management・QuickBooks・Hosted Sites・SMS・Rezzy AI・ドアロック連携などは別料金なので、実際は上の目安より上がる。
- 契約：契約縛りなし、14日トライアル。ただし未使用期間の返金なし、支払いはクレジットカードのみ。
- チャネル：Airbnb・Booking.com・Vrbo・Google Vacation Rentals は API 連携。Expedia・Agoda・楽天トラベル・じゃらんは連携一覧に記載が見つからなかった。API 連携のあるチャネルに iCal を併用してはならない旨の記載がある。
- 弱い点：UI言語に日本語なし。サポートはメール・フォーム・アプリ内チケットで、対応時間・言語の記載なし（"We may not respond immediately"）。通貨は1物件1つで換算しない（2023年の社員回答）。JPY で運用できるかは公式に確認できなかった。公式サイト上のレビューに "Steep Learning Curve" の題がある。
- 向く人：英語で自力設定でき、機能を必要な分だけ足したい人。
- 海外レビュー（Capterra、2026-11-03時点）：271件／4.9。

### iGMS：月払いは解約しやすいが、UIは英語・スペイン語のみ

- 料金：PRO は1物件あたりの単価が物件数で下がる表（月払い：5室 $19.80、10室 $17.40）。請求は1物件目の後は「その月に予約のあった物件のみ」。FLEX は泊数あたり$1（最低$20／物件／月）。
- 契約：月払いは解約手数料なし。年払い（10物件未満）は全額返金不可。10物件以上の年間契約は、途中解約で月払い料金との差額を請求される。
- チャネル：Airbnb・Vrbo・Booking.com は API。Expedia・Tripadvisor は iCal（1時間ごとの更新）。Agoda・楽天トラベル・じゃらんは記載が見つからなかった。
- 弱い点：UI は英語・スペイン語、サポートも ENG/ESP と表記。メールの応答は「48時間以内」の表記。Dynamic Pricing は米・加・豪・メキシコ・英・スペインのみで日本は対象外の表示。Capterra に、Airbnb の手動ブロックが API 接続後に消えたという口コミ（2026-07-06、個別の投稿）。
- 向く人：2〜8物件の独立ホスト向けと自称するサービス。月払いで試し、合わなければ解約したい人。
- 海外レビュー（Capterra、2026-11-03時点）：307件／4.6。

- 弱い点：Capterra の低評価に UI の分かりにくさと学習コスト（"DIY solution"）。日本語レビューに「国内OTAとの接続はサポートへの依頼が必要で手間」。日本の販売会社のお知らせ欄に連動エラーの投稿が多数あるが、件名を確認しただけで件数・期間は集計していない。

### Hostaway：Guesty と同じ「見積り型」。違いは契約・値上げの条項

- 価格は非公開（フォーム→見積り）。第三者の推定は食い違いが大きい。無料トライアルは公式ページで確認できなかった（デモ申込はある）。
- 契約期間は規約では個別契約による。値上げは14日前に通知、同意しない場合は値上げ発効の5日前までの通知で解約できる（規約）。
- 日本語UI・JPY・楽天トラベル／じゃらんは、Guesty と同じくどちらも記載が見つからない。サポート言語は、Guesty は日本語なしと確認済、Hostaway は対応言語の記載がなく未確認。「24/7の電話サポート」は自社の主張。
- 向く人：オーナーポータルや内蔵の価格機能などを備えた製品を探していて、見積りを取る手間を許容できる人。
- 海外レビュー（Capterra、2026-11-03時点）：1,623件／4.8。

### 補助：PriceLabs（価格だけ別にしたいとき）

PMS ではなく価格調整ツール。日本は提供国に含まれる（条件：競合の物件が追跡できること。日本での精度は確認できず）。日本の料金区分は、公式の文言どおりなら「Rest of the world」に当たると読めるが、日本が明示されたページは見つからなかった。この区分なら 3件 $28.97／5件 $47.95／10件 $92.90（**計算値**、税別）。30日トライアル、月単位で解約可。請求はUSDで、JPYの記載は見つからなかった。申込は [PriceLabs](/go/pricelabs/)。海外レビュー（Capterra、2026-11-03時点）：250件／4.9。
