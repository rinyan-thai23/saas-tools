# 【クラウド電話】申込前チェックリスト

## 先に結論

> - **申し込む直前に確認することは、「契約」「解約」「稼働保証」「サポート」「管理者」の5つです。** 口コミの低評価で多い不満は、機能ではなく、**契約・解約・請求**です。
> - **稼働保証（SLA）は、上位プランだけにつく製品が多い**です。小さなプランでは、保証がない場合があります。
> - 乗り換えの流れは、[乗り換えチェックリスト](/articles/switch-checklist/)にあります。この記事は、**申込ボタンを押す直前**の確認です。

## 誰のための記事か

候補を絞り終わって、**これから契約する**日本の小さな事業者向けです。料金は [料金早見表](/articles/buy-fee-table/)、試し方は [無料トライアル比較](/articles/buy-trial-compare/) をどうぞ。

## 1. 契約の形

- [ ] **契約者は誰か**（会社名・代表者名・請求先）。個人事業主の場合、屋号と個人名のどちらか。
- [ ] **プラン**と**ライセンス数**。最低ライセンス数（Aircall は3、CallHippo の Starter と JustCall は2）を満たしているか。
- [ ] **月払いか年契約か**。Aircall のヘルプによると、年契約・一括払いは割引があるが、途中でライセンスを減らせない。
- [ ] **見積書の内容**が、画面の料金と同じか。通話料・番号・初期費用が入っているか。
- [ ] **営業の説明を、メールで書面にもらった**か。（口コミに「営業の説明と実際が違った」という声が複数あります）

## 2. 更新・解約・返金

口コミの低評価に多い内容です（各製品の商品ページ参照）。

- [ ] **最低利用期間**はあるか。
- [ ] **自動更新**か。更新日はいつか。**何日前までに通知**が必要か。
  - Aircall の公式ヘルプ：1〜10ライセンスは30日前の書面通知が不要で、ダッシュボードから解約できる。11ライセンス以上は30日前までの書面通知が必要。
- [ ] **日割り**はあるか。（Dialpad（ソフトバンク）は、解約月は満額で日割りなし）
- [ ] **返金**の条件。（CloudTalk は前払いで返金なし）
- [ ] 解約すると、**番号はどうなるか**（他社へ移せるか、消えるか）。→ [今の番号をそのまま移せる？](/articles/switch-keep-number/)
- [ ] **使わなくなったライセンス・番号**を、自分で減らせるか。（口コミに、使わない契約が約1年続いた、担当者の退職後も請求が続いた、という声があります）

## 3. 稼働保証（SLA）と障害

公式の記載の例です。

| 製品 | 稼働・SLAの記載（公式） |
|---|---|
| [Zoom Phone](/articles/zoom-phone/) | 日本語の製品ページに「99.999%のSLA」（自社の主張）。BYOC やフェイルオーバーのオプションの記載あり |
| [Nextiva](/articles/nextiva/) | 料金ページのフッターに「99.999% Uptime」（自社の表示） |
| [Aircall](/articles/aircall/) | 「Enterprise-grade SLA」は **Enterprise プラン**（最低25ライセンス） |
| [JustCall](/articles/justcall/) | 「Enterprise-grade SLA」は **Enterprise プラン** |
| [CallHippo](/articles/callhippo/) | 「Service-Level Agreement (SLA)」は、最低50ユーザーのプランの記載 |
| RingEX、Dialpad、CloudTalk | 今回の料金ページでは、SLAの記載を確認できていません |

- [ ] **自分のプランに、SLA（稼働の保証）がつくか。** つかない場合、障害のときの補償はどうなるか。
- [ ] **障害のお知らせ**の方法（状況ページ、メール）。日本語か。
- [ ] **インターネットや電源が止まった日**の備え（携帯への転送、スマホの回線）。
- [ ] **110・119**は、携帯電話などで備える。→ [110・119にかけられる？](/articles/jp-emergency-calls/)

## 4. サポート

- [ ] **窓口**（電話、チャット、メール）と、**日本時間の対応時間**。
- [ ] **日本語**で相談できるか。→ [日本語で使える？](/articles/jp-language-support/)
- [ ] 口コミで、**サポートへの不満**（保留が長い、折り返しがない、解決しない）が出ている製品は、申込前にサポートへ質問を送って、返事の速さを見る。（RingEX、GoTo Connect、Aircall、Dialpad、Nextiva、JustCall の口コミ）
- [ ] 契約後の**担当者**はつくか。プランによって違う（Aircall は10ライセンス以上で担当の CSM がつく、とヘルプにあります）。

## 5. 管理者・権限・退職者

- [ ] **管理者を2人**にしておく。（管理者がいなくなると、契約や請求を変えられなくなる）
- [ ] **ライセンスの割り当てと削除**の方法。退職者のアカウントを、すぐ止められるか。
- [ ] **録音を見られる人**の権限。→ [通話録音と個人情報](/articles/jp-privacy-recording/)
- [ ] 契約のメールアドレスは、**個人のメールではなく、会社の共有アドレス**にする。

## 6. 番号・請求

- [ ] 取る番号の種類と、**必要書類・日数**。→ [日本の電話番号の取り方と審査](/articles/jp-number-acquisition/)
- [ ] **請求書は円か。インボイスの形式か。** → [通話料・円・インボイス](/articles/jp-billing-invoice/)
- [ ] 通貨がドルの場合の**為替・カード手数料**。
- [ ] **ユニバーサルサービス料など**、月額以外の費用。

## 7. 申込の直前に

- [ ] 見積書・約款・料金表の**日付**を保存した。（料金は変わります。CallHippo は日本向けページと料金ページで記載が違いました）
- [ ] 契約書・約款の**日本語版**があるか。なければ、英語の約款で、**解約・返金・番号**の条項を読んだ。
- [ ] 更新日・解約の通知期限を、**カレンダー**に入れた。
- [ ] 古い電話回線は、**新しい番号で問題がないと確かめてから**解約する。
- [ ] 法律・税の扱い（個人情報、消費税）が不安なら、**専門家に相談**する。→ [電気通信の決まり](/articles/jp-telecom-rules/)

## よくある質問

### 一番大事な項目は？
更新と解約の条件です。低評価の口コミで、一番多い不満が、契約・解約・請求だからです。

### SLA（稼働保証）がないプランは、避けるべきですか？
この記事では判断しません。SLAがない場合は、障害のときの代わりの電話（携帯への転送など）を用意して、障害の連絡方法を確認してください。

### 英語の契約書は、どこを読めばよいですか？
解約（Termination）、更新（Renewal）、返金（Refund）、料金の変更（Price changes）、データ（Data）の条項を、最低限読んでください。
