OwnerRez（オーナーレズ）の評判・口コミまとめ｜日本の民泊で使える？

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

先に結論：OwnerRez はこんな人に向く

  • 向く人：料金が見える状態で、手数料や縛りのないツールを選びたい人。物件数別の料金表が公開されていて、予約手数料も契約縛りもありません。小規模の運営者が中心です。
  • 向かない人：日本語が必須の人。管理画面の言語に日本語は載っていません。
  • 口コミの特徴：サポートの評価が飛び抜けて高い（口コミの約4割が良い点に挙げています）。不満は、最初に覚えることが多いこと。
  • 日本の民泊新法の人は要注意：Airbnb の日本向けルールで、ツール経由の掲載が受け付けられない場合があります（詳しくはこちら）。

OwnerRezとは？何ができるツールか

OwnerRez は、米国の会社（OwnerRez, Inc.）が作る、民泊・短期賃貸の予約管理ソフトです。Airbnb 日本サイトのソフト連携パートナー一覧にも名前があります。「小さな個人ホストから大きな管理会社まで」を対象にしています。

主な機能

予約サイトの一元管理

Airbnb・Vrbo・Booking.com・Google Vacation Rentals と連携し、予約・料金・空室を同期します。基本料金に含まれます。

ゲストへの自動メッセージ・AI

自動返信、ルールで動かす自動化（トリガー）、AIアシスタント（Rezzy AI、月$9/物件）があります。ChatGPT や Claude からつなぐ機能もあります。

直接予約サイト

独自ドメインのサイト（Hosted Sites）や、WordPress のプラグイン、予約ウィジェットがあります。予約手数料や、ゲストへの上乗せ手数料はありません（決済会社の手数料は別）。

スマートロック・価格ツール

Schlage・Igloohome・Hubitat は直接連携（1台月$4）。そのほか多数と連携しますが、Akerun・SESAME など日本製は、連携一覧に載っていません。PriceLabs・Wheelhouse・Beyond など価格ツールとの連携も多めです。

そのほか

チームのログインは無制限、オーナー用・清掃スタッフ用のポータル、電子署名、会計（QuickBooks）連携があります。

  • 追加の有料機能：物件管理（Property Management）、独自ドメインの予約サイト、QuickBooks 連携、SMS、AI、ロック連携などは、別料金です。足していくと、上の目安より高くなります。

OwnerRezの評判・口コミまとめ

海外のレビューサイト（Capterra）の口コミ102件を読んで、日本語にまとめました。

読む前に

  • 英語圏の運営者の声が中心で、日本の運営者の声ではありません。
  • 投稿者の約9割は、2〜10人規模の事業者か自営業。使用期間は、半年以内が約4割、1年以上が約3分の1です。
  • この口コミ集には、低評価（1〜2点）が1件もありません。 5点が約9割と、他の商品より極端に高く、実際より良く見えている可能性があります。
  • 件数は、口コミ中の話題をキーワードで数えたおおよその数です。

良い口コミ：サポート、使いやすさ、連携

  • サポートが丁寧で速い（良い点に挙げた人が約44%で最多）：問い合わせに必ず返信があった、担当者が詳しい、という声。
  • 使いやすい（約3割）：画面が分かりやすい、自由度が高い、という声。
  • 予約サイトとの連携・同期（約4分の1）：カレンダーが正確に同期する、という声。
  • 自動化（約14%）：時間が減った、という声。
  • コスパ：必要な機能に比べて安い、という声。

悪い口コミ：覚えることが多い

  • 最初に学ぶことが多い（改善点に挙げた人が約16%で最多）：機能が多くて慣れるまで時間がかかる。ただし「その価値はあった」と添える人が多めです。
  • サポートの遅れ（約15%）：メールの返信が遅いことがある、24時間対応ではない、という声。公式も「すぐ返信できないことがあります」と書いています。
  • 足りない機能：SMS が本当のテキストメッセージでは送られない、長期滞在向けの機能がほしい、予約サイトのデザイン支援がほしい、という声。
  • 統合受信箱：Guesty から移った人が、全メッセージを1か所で見られる機能と、Vrbo とのメッセージ連携の改善を望んでいます。
  • 連携先が少ない：他社（競合）のブログには、連携の数が Hostaway や Guesty より少ない、との指摘があります。競合の見方なので、割り引いて読んでください。

低評価の傾向

この口コミ集には、1〜2点がありません。3点が1件、4点が5件で、ほとんどが5点です。「欠点がない」というより、満足した人が書きやすい仕組みの可能性があります。検索で見つかった範囲では、サポートに返答をもらえなかったという3点の口コミが、2023年にありました。

OwnerRezは日本で使える？民泊の注意点

日本語は確認できない。多言語化は「計画中」

アカウントの表示言語は11言語ですが、日本語は挙がっていません（英・西・仏・蘭・独・葡・伊・希・デンマーク・フィンランド・スウェーデン）。公式のフォーラムには、多言語化の要望が「計画中」で出ていますが、日付は2022年で、日本語の時期は示されていません。サポートの言語と対応時間は、公式に見つかりませんでした。電話番号は米国のものです。

住宅宿泊事業法（民泊新法）の場合は、先に確認が必要

  • Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。OwnerRez が該当するかは、確認できませんでした（Airbnb 日本サイトのパートナー一覧に名前があることと、民泊新法の掲載を受け付けることは別の話です）。
  • 年180日の管理、届出番号の表示、定期報告、インボイスなど、日本の制度に当たる機能は、公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。
  • 請求は米ドル表示です。円での請求は確認できませんでした。

楽天トラベル・じゃらんには出せる？

楽天トラベルとじゃらんは、民泊新法・特区民泊の施設を対象外としています。OwnerRez の連携一覧には、楽天トラベルも Agoda も Expedia の本体連携もありません。旅館業法の許可施設は、OwnerRez に聞いてください。

乗り換えは自力が基本

他社からのデータ移行を代行する記載はありません。導入時の無料の通話、チェックリスト、動画、週1回のデモ配信が用意されています。

詳しくは 住宅宿泊事業法への対応、楽天トラベル・じゃらん等の国内予約サイト連携、日本語UI・日本語サポート へ。

申し込む前に OwnerRez へ聞くこと

  1. 自分の物件数・使いたい機能での、正確な月額（追加の有料機能を含む）。
  2. 円で請求できるか。USD なら為替手数料は誰が負担か。
  3. 日本語で問い合わせできるか。サポートの対応時間（時差）。
  4. 私の営業形態で、Airbnb・Booking.com に接続できるか。
  5. 今使っているツールがあるとき、データはどう引き継ぐか。
  6. 解約時の返金（未使用期間は返金なし）と、解約後のデータの扱い。

よくある質問

OwnerRez は日本語に対応していますか？

アカウントの表示言語は、英語・スペイン語・フランス語・オランダ語・ドイツ語・ポルトガル語・イタリア語・ギリシャ語・デンマーク語・フィンランド語・スウェーデン語で、日本語は挙がっていません。サポートの日本語対応も、確認できませんでした。

OwnerRez の料金はいくらですか？

1物件目が月$40（最低月額）、2〜3物件目が各$15、4物件目が$10、5〜9物件目が各$8です。公式の単価からの計算で、3室は月$70、5室は月$88、10室は月$127です。独自ドメインのサイトや SMS などは別料金です。

OwnerRez に無料トライアルはありますか？

14日間の無料トライアルがあり、期間中はプレミアム機能も無料です。導入時の無料通話（Jumpstart）も付きます。

契約期間や解約条件は？

契約縛りも解約金もなく、いつでもアカウントを閉鎖できます。ただし、未使用期間の返金はありません。閉鎖すると、決済、予約サイト連携、サイトなどが止まります。

日本の民泊新法の宿でも使えますか？

Airbnb のヘルプには、日本の民泊新法の宿について、ソフト連携で作った掲載を受け付けないという記載があります。例外は Airbnb と契約した日本のAPIパートナーです。OwnerRez が該当するかは確認できていないため、Airbnb と OwnerRez の両方に確認してください。

楽天トラベルやじゃらんにつなげられますか？

公式の連携一覧に、楽天トラベルもじゃらんも載っていません。両サイトは民泊新法・特区民泊の施設を対象外としています。旅館業法の許可施設は、OwnerRez に接続の可否を問い合わせてください。
