# 【民泊】宿泊者名簿・本人確認（旅券）の要件と、管理ツールでできること・できないこと

この記事に広告リンク（アフィリエイト）はありません。法律の助言ではありません。

## 先に結論：日本の要件に合うかを確認できた海外ツールは、まだない

> - **宿泊者名簿は、宿泊者全員分**を作り、**作成から3年間保存**します。代表者だけの記載は認められません（観光庁の民泊制度ポータル）。
> - **日本に住所がない外国人**は、**国籍と旅券番号**を記載し、**旅券の呈示を求め、写しを名簿とともに保存**します。
> - **本人確認は、宿泊の開始までに、宿泊者それぞれ**について行います。
> - **海外の管理ツールの本人確認機能（Guesty、Hostaway の連携サービスなど）が、日本の要件に合うかは、公式ページで確認できませんでした。**「合わない」と確認したわけではなく、**記載が見つからなかった**ということです。
> - **国（国土交通省）の民泊制度運営システムで、電子の宿泊者名簿を作るソフトが配布されています**（旅券番号は、国籍が日本以外のときに入力）。当面の選択肢になります。

## 日本の要件（住宅宿泊事業・民泊新法）

| 項目 | 内容 |
|---|---|
| 名簿の備置き | 届出住宅や、事業者の営業所・事務所に備える（法第8条、規則第7条） |
| 記載事項 | 氏名、住所、職業、宿泊日。**日本に住所がない外国人は、国籍と旅券番号** |
| 宿泊者全員 | **全員分を記載**。代表者のみは認められない |
| 保存 | 作成の日から**3年間** |
| 電子化 | 電磁的記録で、必要に応じて紙面に明確に表示できるなら、名簿への記載に代えられる |
| 外国人の旅券 | **旅券の呈示を求め、写しを名簿とともに保存**。拒否する場合は、旅券不携帯の可能性があるものとして、最寄りの警察署に連絡するなど適切な対応 |
| 本人確認の時期 | **宿泊の開始までに、宿泊者それぞれ** |
| 長期滞在（7日以上） | 定期的な面会などで確認 |

### 対面でない場合（無人のチェックインなど）
民泊制度ポータルは、対面でない場合は、次の両方を満たす方法とします。
- 宿泊者の**顔と旅券が画像により鮮明に確認できる**こと。
- その画像が、**届出住宅内または近傍から発信されている**ことが確認できること。

つまり、「パスポートの写真をアップロードしてもらう」だけでは足りない可能性があります。**発信場所の確認**まで求められています（詳細は、観光庁・自治体の最新の案内で確認してください）。

### ほかの営業形態
簡易宿所営業（旅館業法）も、宿泊者名簿は3年間保存、外国人は国籍と旅券番号です（施行規則）。特区民泊は、滞在者名簿を備える（保存期間は今回未確認）。

## 国が配布している、電子名簿ソフト

国土交通省の民泊制度運営システムでは、**電子の宿泊者名簿を作るソフトが配布**されています（費用は、案内で確認してください）。名簿と、2か月ごとの宿泊実績の定期報告データを作成できる、と案内されています。旅券番号は、国籍が日本以外のときに入力します。海外の管理ツールを使っても、**名簿は別に作る**前提なら、まずここから始められます（詳細は民泊制度運営システムの案内で確認してください）。

### 検索で見つかった、日本向けをうたうサービス（今回は内容を確認していません）

## 運用のポイント

1. **全員分**の名簿を作る（予約サイトで代表者だけの情報しかなくても）。
2. 外国人には**旅券の呈示と写し**を求める。拒否されたときの対応も決めておく。
3. **宿泊の開始までに**本人確認を終える（無人のチェックインでも）。
4. 画像で確認する場合は、**顔と旅券が鮮明に写り、届出住宅内または近傍から発信**されていること。
5. **3年間保存**する（紙でも電子でも）。個人情報の保管場所（海外のサーバーか）も確認する。
6. 2か月ごとの**定期報告**（宿泊日数、宿泊者数、国籍別の人数）にも、名簿のデータを使う。

## よくある質問

### 宿泊者名簿は、代表者だけでよいですか？
いいえ。民泊制度ポータルは、宿泊者全員を記載する必要があり、代表者のみの記載は認められないとしています。

### パスポートの写しは、必ず保存しますか？
日本国内に住所がない外国人宿泊者については、旅券の呈示を求め、旅券の写しを宿泊者名簿とともに保存するよう、観光庁が示しています。

### 無人のチェックインで、本人確認はできますか？
民泊制度ポータルは、顔と旅券の画像が鮮明に確認でき、画像が届出住宅内または近傍から発信されていることが確認できる方法を示しています。ツールが、これを満たすかは、各社に確認してください。

### 海外の管理ツールで、名簿は作れますか？
本人確認の機能を持つツールはありますが、日本の要件に合うかは、公式ページで確認できませんでした。国の電子宿泊者名簿ソフトを併用する選択肢があります。
