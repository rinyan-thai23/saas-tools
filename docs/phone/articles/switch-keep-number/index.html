【クラウド電話】今の電話番号をそのままクラウド電話へ移せる？

先に結論

  • 固定電話の番号（03・06など）は、番号ポータビリティの仕組みで、事業者を変えても同じ番号を使える場合があります。 総務省の公式ページによると、手続きはこれから契約する会社に申し込むだけ（ワンストップ方式）です。
  • ただし、製品・番号の種類で違います。 Zoom Phone は、0ABJ とフリーダイヤルの移行に対応し、050は移行できません。Dialpad は、0AB-J の移行に対応します（1番号 ¥2,000）。
  • 移すと、元の会社との契約は解約になります。 費用、残りの支払い、ネット回線の扱いを、先に確認してください。
  • この記事は、制度の説明ではなく、公式の記載の整理です。法律の判断はしていません。

誰のための記事か

  • 名刺・ホームページ・取引先に、今の固定電話の番号を載せていて、変えたくない人。
  • 固定電話（ひかり電話など）からクラウド電話へ、乗り換えを考えている人。
  • 先に、全体の流れは 固定電話・スマホからクラウド電話へ乗り換える手順 をどうぞ。

総務省の公式ページに書かれていること

総務省の「固定電話の番号ポータビリティ」のページ（電気通信番号制度）には、次のように書かれています。

  • 仕組み：利用者が固定電話番号を変更することなく、固定電話サービスを提供する会社を変更できる仕組み。
  • 手続き：これから契約する固定電話会社に申し込むだけで完了するワンストップ方式。
  • 注意点： 1. 番号ポータビリティの費用のほか、解約と新規契約に伴う費用がかかる場合がある。 2. 今の会社との間に残債（分割払いの回線工事費の残りや未払い）があれば、解約にあたって精算が必要。 3. 固定電話をインターネット回線と一緒に契約している場合、インターネット回線の解約には別の手続きが必要な場合がある。 4. 付随するサービスの解約には、別の申込みが必要な場合がある。
  • 事業者の対応：電気通信番号計画（令和元年総務省告示第6号）に基づき、令和7年（2025年）1月末日以降、固定電話番号を使ったサービスを提供する全ての事業者は、原則、固定電話番号の番号ポータビリティを可能とする必要がある、とあります。ただし例外があり、技術的な困難性などを総務大臣が特に認める場合（たとえば、移転元と移転先で、設備が収容できる番号帯が違う場合）は、実施の例外です。
  • 実施に関するガイドラインは、令和7年1月30日に策定され、1月31日から適用されています。

これは「どのクラウド電話でも、必ず移せる」という意味ではありません。 製品ごとに、移せる番号の種類と、条件が違います。

移す前に確認すること（チェックリスト）

  1. 今の番号の種類：加入電話・INSネット・ひかり電話・他社の固定電話・050。
  2. 移せる範囲：同じ住所・同じエリアで、新しいサービスに収容できるか（総務省も、番号帯が違う場合を例外としています）。
  3. 解約の費用：今の会社の解約金、残債（工事費の分割の残り）、ネット回線の扱い。
  4. 移行の日数と費用：新しい会社の見積もり。
  5. 切り替えの日：番号が使えない期間が出ないよう、新しい会社に、日程を聞く。
  6. FAX・警備・機器の回線：同じ番号を使っている場合は、先に別の手段を決める。
  7. 緊急通報（110・119）：クラウド電話からかけられない製品が多いので、携帯などを残す。

050の番号は？

  • Zoom Phone の050は、移行できません（公式の日本向けページ）。
  • 050の番号は、IP電話の番号です。今の050を引き継ぎたい場合は、新しい会社が移行に対応しているかを、先に確認してください。
  • 050の新規取得には、本人確認が必要な製品があります。ソフトバンクのFAQ（Dialpad）には、2024年4月以降、新しい050の払い出しに本人確認が必要、とあります。総務省は、050アプリ電話も本人確認の対象にする省令改正案について、令和5年6月28日〜7月31日に意見募集をしました（総務省の意見募集のページ。改正後の内容は、今回は確認していません）。実際の手続きは、各社の案内を見てください。

よくある質問

今の固定電話の番号を、クラウド電話に移せますか？

総務省のページによると、固定電話番号は番号ポータビリティの仕組みがあり、手続きは移転先に申し込むだけです。ただし、移転先の製品が対応しているか、番号の種類、エリアの条件で変わります。Zoom Phone は0ABJとフリーダイヤルに、Dialpad は0AB-J に対応します。

移すと、今の会社の契約はどうなりますか？

総務省のページに、変更前の会社との契約は解約になり、変更後の会社と新規契約になる、とあります。費用や残債が発生する場合があります。

いつまでに申し込めばよいですか？

製品で違います。Zoom Phone は番号の移行が最大15営業日、Dialpad は開通が最短10〜15営業日です。余裕をもって、1か月以上前に動いてください。
