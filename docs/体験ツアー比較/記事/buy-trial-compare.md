# 【体験・ツアー】予約システムの無料トライアル・デモを比較｜試せる期間と、試すことのチェックリスト

## 先に結論

> - **自分で触って試せる「無料トライアル」があるのは、Bókun（14日。日本版は30日）、Rezdy（21日）、Bookeo（30日）、OMUSUBI（1か月）です。** rezio と Zaui は、月額0円のプランから始められます。
> - **Checkfront、FareHarbor、Xola、TrekkSoft、Regiondo は、公式で確認できたのは「デモ」（担当者の説明）**で、無料トライアルの記載は確認できませんでした。
> - **トライアルは、機能を見て回る期間ではなく、「自分の毎日の業務が回るか」を確かめる期間**です。実際の商品を登録して、テスト予約を入れるのが基本です。
> - **予約サイトとの連携は、トライアルの期間内に試しにくい**ことがあります。使いたいサイトの名前で、試せるかを先に聞いてください。

## トライアルとデモの違い

- **無料トライアル**：自分で、自分のアカウントを触って試せます。実際の商品を登録して、テスト予約を入れられます。
- **デモ**：担当者が画面を見せて説明します。**自分の業務で動くかは、自分で触らないと分かりません。** デモのときは、自分の商品（定員、料金、開始時間）を、担当者に入力してもらうよう頼むのが有効です。
- **月額0円のプラン**（OMUSUBI フリー、rezio ENTRY、Zaui Free）：ずっと使えますが、**機能の制限**があります。無料トライアルの代わりに、小さく始めるのに向きます。

## トライアル中に試すことのチェックリスト

以下は、海外の導入の解説と、日本のホテル向けのトライアルの解説（体験向けの解説は見つからなかったため）を参考にした、**一般的なチェックリスト**です。製品ごとの公式の手順ではありません。

### 1. 毎日使う機能から試す
- [ ] **実際の商品を、1〜2つ登録**する（定員、開始時間、料金、大人・子どもの料金、追加オプション）。
- [ ] **自社サイトの予約画面から、テスト予約**を入れる（スマホの画面でも）。
- [ ] **確認メール**が届くか。内容と、送信元の名前は、自分の事業として適切か。
- [ ] 予約を**変更・キャンセル**して、在庫と予約台帳が正しく変わるか。
- [ ] **電話・窓口の予約を、手で入力**して、在庫が減るか。

### 2. 例外のケースを試す
- [ ] **定員いっぱいの予約**、**同じ時間に2件**の予約を同時に入れる。
- [ ] 天候による**中止**の連絡の流れ。
- [ ] **団体や貸切**の予約（人数が多い、複数日）。

### 3. 決済を試す
- [ ] **事前決済**を、実際のカードでテストする（可能なら少額で）。
- [ ] **返金**をテストする。返金の手数料の扱いを、画面で確認する。
- [ ] 決済会社の手数料が、**予約手数料とは別に**どれだけかかるかを、画面や明細で確認する。

### 4. 日本の事業者として試す
- [ ] **管理画面とメールが日本語か**（[日本語対応の比較](/articles/jp-language-support/)）。
- [ ] **外国語の予約画面**から、実際に予約を入れる。確認メールも外国語か（[外国語の予約画面](/articles/jp-inbound-multilingual/)）。
- [ ] **円で受け取れるか**、**日本の銀行口座**に入金される流れになっているか（[契約・決済・円](/articles/jp-contract-payments/)）。
- [ ] 国内の予約サイトを使っている場合、**予約メールの取り込みや在庫の売り止め**を試す（OMUSUBI など。[日本の予約サイトとの連携](/articles/jp-ota-integration/)）。

### 5. 予約サイト（OTA）との連携を試す
- [ ] **1つの予約サイトを実際につなぎ**、在庫が**両方向**に同期するか確認する。
- [ ] 2か所から**同時に予約**が入ったときに、売りすぎ（二重予約）にならないか。
- [ ] 試用期間内に、実際の予約サイトにつなげるか、**テスト用の環境**があるか、を先に聞く。

### 6. 出口を確認する
- [ ] **データの書き出し**（予約、顧客）を、トライアルの間に1回やってみる。やめるときに出せるかを確かめる。
- [ ] トライアルが**終わったあとの扱い**（自動で有料になるか、カード登録は必要か）。

## デモで担当者に聞くこと

1. **自分の商品**（定員、料金、時間）を、その場で入力してほしい。
2. **日本の事業者として契約できるか。** 円で受け取れるか。
3. 日本語のサポートは。日本時間の対応は。
4. 予約サイトとの連携を、トライアルや導入前に**試せるか**。
5. 月額・予約手数料・決済手数料の**総額の見積り**（[手数料の早見表](/articles/buy-fee-table/)も参考に）。
6. 手数料の負担を、自分で選べるか（[手数料は誰が払う](/articles/buy-fee-payer/)）。

## よくある質問

### 無料で、長く試せるのは？
OMUSUBI のフリープランは期限なしで無料です。rezio の ENTRY プランと Zaui の Free プランは月額0円です。機能や手数料の条件が違うので、確認してください。

### トライアルだけで、判断できますか？
一般的な解説では、デモの画面だけでなく、実際の予約や決済で確かめることが勧められています。ただし、予約サイトとの連携は、期間内に試しにくい場合があります。

### トライアルの後、自動で課金されますか？
製品によります。Bókun、Rezdy、Bookeo は、クレジットカード不要と公式にあります。ほかは、確認してください。
