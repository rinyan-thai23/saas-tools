先に結論

  • 調べた海外中心の10製品のうち、アソビュー・じゃらん・楽天トラベルなど日本の大手予約サイトとの連携が公式に書かれているものは、ありませんでした。 「つながらない」と確認したわけではなく、書かれていません。
  • 日本の予約サイトとの連携で、記載が見つかったのは2つ：①rezio の公式の沿革に、2022年に Activity Japan（アクティビティジャパン）と API でつながった、とあります。②国産の OMUSUBI は、じゃらん・アソビュー・アクティビティジャパンなどの予約通知メールを自動で取り込むと公式にあります。
  • JTB BÓKUN と OMUSUBI は、2025年9月から連携しています。 海外の予約サイトの予約（Viator など）を JTB BÓKUN で受け、国内の予約サイトの予約を OMUSUBI で受ける、という組み合わせが、公式の発表にあります。
  • 日本の予約サイトの在庫を、海外の予約システムと自動で合わせられる前提で選ぶのは危険です。 使いたいサイトの名前で、各社に確認してください。
  • つながらない場合の現実的なやり方は、「枠を分ける」「手で合わせる」「国内の在庫管理を併用する」の3つです（下で説明）。

つながらないときの現実的なやり方

1. 枠を分ける

日本の予約サイトに出す枠と、海外の予約システムで売る枠を、最初から別々にします。たとえば「午前の枠は日本の予約サイト、午後の枠は海外の予約システム」のように決めると、二重予約が起きません。ただし、売れる機会は減ります。

2. 手で合わせる

予約が入ったら、もう一方の在庫を、毎回、手で減らします。件数が少ないうちは現実的ですが、手が空かないと二重予約になります。担当者を決めて、1日に何回か見比べる運用にします（乗り換えチェックリストも参考に）。

3. 国内の予約台帳を併用する（OMUSUBI × JTB BÓKUN）

国産の OMUSUBI は、じゃらん・アソビュー・アクティビティジャパンなどの予約通知メールを自動で取り込み、国内の主要な予約サイトの在庫を、管理画面から一括で売り止めできる、と公式にあります（詳細は問い合わせ）。2025年9月からは、JTB BÓKUN に入った新規予約・キャンセルが、Webhook で OMUSUBI に自動で反映されます（SEEC と JTB の発表）。海外の予約サイトと国内の予約サイトの両方に出す事業者に向く組み合わせです。ほかの海外製品との併用は、確認できていません。

上の Actim（2019年）や、アソビューのウラカタも国内の在庫管理の仕組みですが、今の提供状況や、海外の予約システムとの併用は、確認できていません。

4. 日本の窓口がある製品を選ぶ

rezio は、日本の運営会社（株式会社KKDAY JAPAN）があり、Activity Japan と連携しています。OMUSUBI は、国内の予約サイトの予約メールの自動取込が公式にあります。日本の予約サイトとの連携を重視するなら、この2つを先に相談する候補です。rezio は、アソビューやじゃらんとの連携は記載が見つかりませんでした。

よくある質問

アソビューやじゃらんと連携できる海外の予約システムはありますか？

調べた海外中心の10製品では、公式に書かれているものはありませんでした。国産の OMUSUBI は、じゃらん・アソビューなどの予約通知メールの自動取込が公式にあり、JTB BÓKUN と連携します。rezio は、Activity Japan との API 連携が公式の沿革にあります。使いたいサイトの名前で、各社に確認してください。

日本の予約サイトに出しながら、海外の予約システムを使えますか？

使えますが、在庫を自動で合わせられないかもしれません。枠を分ける、手で合わせる、といった運用が必要になる場合があります。

連携がなくても、二重予約は防げますか？

手で合わせる運用でも、防げます。ただし、担当者の見比べが漏れると起きます。予約が増えたら、連携のある製品への乗り換えを考えてください。
