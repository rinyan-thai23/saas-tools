## 指摘

### 注意

1. **「Hostaway からのデータの書き出し方法は、開いた公式ページに記載が見つかりませんでした（ヘルプセンターは403で未取得）。」**
   - カード：Hostaway カードに書き出しを調べた行はない。「調べられなかったこと」は「データ移行・インポートの手順、解約手続き」までで、書き出しは載っていない。
   - 問題：「記載が見つからなかった」という調査結果がカードにない。
   - 修正案：「未調査」とするか、追加調査を依頼する。

2. **Guesty 表の日本語行「管理画面・サポート言語に日本語なし。移行支援も日本語は一覧にない」（表題は「公式の記載」）**
   - カード：Guesty §5＝管理画面の日本語は「確認済（2019年の記述）／現行は第三者のみ」。サポート言語は確認済で日本語なし。
   - 問題：管理画面に日本語がないことは、現行については第三者の情報のみなのに、「公式の記載」の表で断定している。
   - 修正案：「管理画面は、2019年の公式ブログと検索抜粋の範囲で日本語なし（現行は第三者のみ）。サポート言語に日本語はなし（公式）」とする。

3. **記事内の食い違い：判断表「日本語で相談したい：どちらも公式で日本語の窓口は確認できていない」／未確認リスト「両社の…日本語サポート」と、Guesty 表「サポート言語に日本語なし」**
   - カード：Guesty §5・§7＝サポート・移行支援に日本語なしは確認済。Hostaway は未確認。
   - 問題：同じ記事の中で、Guesty の日本語サポートが「なし」と「確認できていない」の両方で書かれている。
   - 修正案：Guesty は「公式のサポート言語に日本語なし」、Hostaway は「未確認」と分けて書く。

4. **Lite にも 13か月が当たるかの注記がない（結論2、Guesty 表「契約」、判断表「契約期間を短くしたい」）**
   - カード：Guesty 冒頭の注「規約が Lite と Pro のどちらにも同じ形で当たるかは未確認」。
   - 問題：記事1にはこの注記があるが、記事2は1〜3室向け Lite の行でも「13か月が基本」とだけ書いている。
   - 修正案：「Lite への適用は未確認」を添える。

### 軽微

5. **チェックリスト「USD請求の場合のカードの為替手数料を確認した」**
   - カード：Guesty §2＝請求は原則USD、JPYは未確認。カードの為替手数料の記載は無い。
   - 問題：一般的な助言で、カードにない事実（カード会社の為替手数料）が前提になっている。
   - 修正案：「USD請求の場合の為替の扱い（カード会社の手数料など）を確認した」と、確認項目の形にする。

6. **リンク文言「[Hostaway の契約確認（PR）](/go/hostaway/)」**
   - 問題：/go/ は申込・見積りの導線で、契約内容を確認できるページではない。文言が行き先を誤認させる。
   - 修正案：「Hostaway の見積り（PR）」にそろえる。

7. **Capterra「Guesty 1,031件／4.6」**
   - カード：Guesty §8は「Capterra 4.4（477件）」（検索抜粋）。README は 1,031件／4.6。記事は README に従っており誤りではない。
   - 修正案：カード側の更新をリサーチ役に依頼する。
