【民泊】iGMS と Hospitable どっちがいい？料金・自動メッセージ・口コミ・日本で使えるかを比較

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

先に結論：どちらも小規模向け。料金の払い方と、必要な機能で選びます

  • どちらも、1〜10室ほどの小さな運営向けで、無料プランがあります。 自動メッセージが中心の道具という点も似ています。
  • 稼働が低い月は安く、高い月は高くなる払い方がいい → iGMS の FLEX。 泊数あたり$1（物件ごとに最低月$20）。
  • 毎月の料金を固定で見たい、Agoda も使う → Hospitable。 基本料金＋稼働物件の追加料金。Agoda は接続先に入っています（iGMS は公式の一覧になし）。
  • 日本語は、どちらも不向き。 iGMS の画面は英語とスペイン語、Hospitable は英語のみ。
  • 口コミの低評価の割合は、iGMS が約3%、Hospitable が約5%。どちらも低い水準ですが、件数が少なめです。

契約と解約

  • iGMS：月払いは解約手数料なし（月の途中の返金なし）。10室未満の年払いは一括前払いで、途中解約しても返金なし。10室以上は年間契約です。口コミに、「解約の方法が分からず、サポートに強く頼まないと対応してもらえなかった」という低評価（2025年）があります。公式のヘルプは、解約の申請を営業日48時間以内に処理すると案内しています。
  • Hospitable：月払いは契約も縛りもなく、当月末で終了。年払いは12か月で、トライアル開始から30日以内は全額返金、それ以降は返金なしです。

口コミ：どちらも「自動メッセージ」が好評

Capterra の海外レビュー（iGMS 114件、Hospitable 57件）を読んだ結果です。英語圏の運営者の声が中心で、日本の運営者の声ではありません。

iGMS は、画面やスマホアプリの重さ、Airbnb との接続で設定が変わる、という声があります。接続前に、手動でブロックした日を控えておくと安心です。Hospitable は、サポートの融通と、連携先の少なさが不満に挙がっています。

日本で使うときの注意（両社共通）

  • 日本語：iGMS の画面は英語とスペイン語（サポートも同じ）。ゲスト向けの自動メッセージは「109言語」と書かれていますが、日本語が含まれるかは確認できません。Hospitable の画面は英語のみで、ゲスト向けの定型は英・西・仏・独です（日本語の追加要望は「新規」のまま）。
  • 民泊新法の人は先に確認：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーで、両社が該当するかは確認できていません。
  • 楽天トラベル・じゃらん：民泊新法・特区民泊の施設は、どちらも対象外です。両社とも、公式の連携先に楽天トラベル・じゃらんの記載がありません。
  • 請求通貨：どちらも円は確認できません。
  • 年180日の管理、届出番号、定期報告、インボイスなどの機能は、両社とも公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。

よくある質問

iGMS と Hospitable の一番大きな違いは何ですか？

料金の払い方です。iGMS は泊数あたり$1の FLEX を選べて、稼働に応じて払えます。Hospitable は基本料金＋稼働物件の追加料金の固定的な形です。接続先は Hospitable に Agoda が入っています。

無料で使えるのはどちらですか？

どちらにも無料プランがあります。iGMS は予約5件・メッセージ10件まで、Hospitable は機能に制限があり、サポートはAIとコミュニティのみです。

5室だとどちらが安いですか？

公式の単価からの計算で、iGMS の PRO（月払い）は約$99、Hospitable の Professional は約$104と、ほぼ同じです。iGMS の FLEX は、稼働が低ければ安く、高ければ高くなります。

解約しやすいのはどちらですか？

どちらも月払いなら縛りがありません。iGMS の10室未満の年払いは返金がなく、口コミに解約の手順が分からなかったという低評価があります。Hospitable の年払いは、トライアル開始から30日以内なら返金されます。

日本語で使えるのはどちらですか？

どちらも、公式には日本語の管理画面もサポートも確認できませんでした。iGMS は英語とスペイン語、Hospitable は英語のみです。
