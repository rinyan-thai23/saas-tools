## 日本の運営者が、先に知っておくこと（3つ）

1. **民泊新法の人は、Airbnb の扱いを先に確認。** Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。どのツールが該当するか、今回は確認できていません。→ [住宅宿泊事業法への対応](/articles/jp-minpaku-law/)
2. **楽天トラベル・じゃらんは、民泊新法・特区民泊の施設を対象外としています。** 民泊を楽天トラベルに出す窓口は Rakuten Oyado です。海外ツールで国内サイトへの接続が確認できたのは、Beds24（日本の販売会社経由）だけです。→ [楽天トラベル・じゃらん等の国内予約サイト連携](/articles/jp-ota-rakuten-jalan/)
3. **日本語の管理画面・サポートが確認できたのも、Beds24 の日本の販売会社版だけです。** そのほかは英語で運用する前提です。円で払えるのも、このツールだけでした。→ [日本語UI・日本語サポート](/articles/jp-japanese-ui-support/)

なお、年180日の管理、届出番号の表示、定期報告、宿泊者名簿（日本の要件）、インボイスの機能は、**今回調べたどのツールも、公式ページに記載が見つかりませんでした**（「できない」と確認したわけではありません）。
