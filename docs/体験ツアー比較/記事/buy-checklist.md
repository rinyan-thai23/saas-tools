# 【体験・ツアー】予約システムの申込前チェックリスト｜日本の事業者向け

## 先に結論

> - **申し込む前に、次の7つを「書面（メール）」で確認して、記録を残してください。** ①契約できるか ②料金の総額 ③日本語 ④決済と円の入金 ⑤予約サイトとの連携 ⑥個人情報・データ ⑦解約と値上げ。
> - **口頭の説明は、あとで食い違うことがあります。** 口コミにも、営業の説明と契約後の条件が違った、契約後に料金が変わった、という声があります（FareHarbor、Rezdy、Checkfront など）。
> - このチェックリストは、一般的な確認事項です。法律・税務の助言ではありません。

## 1. 契約できるか
- [ ] **日本の法人（または個人事業）として、契約できるか。**
- [ ] 日本の銀行口座に、**円で**入金されるか。入金の時期は。
- [ ] 契約の相手は、どの会社か（日本の会社か、海外の会社か）。契約書・規約は、日本語か。
- → 詳しくは [契約・決済・円の確認表](/articles/jp-contract-payments/)

## 2. 料金の総額
- [ ] **月額、予約手数料、決済手数料**の合計は、自分の売上でいくらか。
- [ ] 手数料は、**お客さんに上乗せできるか、自分で負担するか**を選べるか。
- [ ] **最低保証、初期費用、追加オプション**はあるか。
- [ ] 税込か、税別か。為替手数料はあるか。
- → [手数料・月額の早見表](/articles/buy-fee-table/)、[手数料は誰が払う](/articles/buy-fee-payer/)

## 3. 日本語
- [ ] **管理画面**は日本語か。
- [ ] **お客さん向けの予約画面と確認メール**は、何語に対応するか（自分のプランで使えるか）。
- [ ] **サポート**は日本語か。連絡手段と、日本時間の対応時間は。
- → [日本語対応の比較](/articles/jp-language-support/)、[外国語の予約画面](/articles/jp-inbound-multilingual/)

## 4. 決済
- [ ] **使える決済会社**はどれか。日本の事業者が使えるか。
- [ ] **JCB、海外発行のカード、Alipay、WeChat Pay、PayPay** など、必要な決済に対応するか。
- [ ] **事前決済**と、**返金**のときの手数料の扱い。

## 5. 予約サイト（OTA）との連携
- [ ] **使いたい予約サイトの名前**（じゃらん、アソビュー、Viator、GetYourGuide など）で、連携できるか。
- [ ] 連携できないとき、**在庫をどう合わせるか**（枠を分ける、手で合わせる、国内の台帳との併用）。
- [ ] 連携を、**トライアルや導入前に試せるか。**
- → [日本の予約サイトとの連携](/articles/jp-ota-integration/)

## 6. 個人情報・データ
- [ ] **お客さんの個人情報（名前、連絡先）は、どの国のサーバーに保存されるか。**
- [ ] **データの書き出し**（予約、顧客）はできるか。形式は。
- [ ] 契約を終えたあと、**データはどうなるか**（削除、返却）。

**個人情報保護委員会（公式のQ&A）の考え方**：外国の会社のクラウドサービスを使う場合で、その会社が個人データを取り扱わない約束になっているときは、「提供」には当たりません。ただし、事業者は、**安全管理の一環として、サーバーがある国の名前と、その国の個人情報保護の制度を把握**し、講じた措置を本人が知れる状態にしておく必要がある、とされています。予約システムの会社が個人データを取り扱う場合などは、別の整理になる可能性があります。**この記事では判断しません。個人情報保護委員会や、専門家に確認してください。**

## 7. 解約・値上げ・契約条件
- [ ] **最低契約期間**、**自動更新**、**解約の予告期間**は。
- [ ] **値上げ**は、どれくらい前に通知されるか。**上限**はあるか。同意しない場合に解約できるか。
- [ ] **規約を変えるときの通知**の方法。
- [ ] **準拠法**と**裁判管轄**は、どの国か（海外の会社の場合）。
- [ ] 障害のとき、**稼働率の保証や補償**はあるか。

日本語の解説では、解約条件は「最低利用期間」「自動更新」「解約予告期間」の3点を見ると整理しやすい、海外のサービスでは「準拠法・裁判管轄・データ移転」も確認する、とされています。

**口コミの例**：2025年に「年額が20%上がった、前年は25%上がった」（Checkfront）、「契約後に、店頭の予約にも割合の手数料がかかるプランへの変更を求められた」（Rezdy、2026年）という声があります（1人ずつの声）。

## 8. 法令・営業の形
- [ ] **他社の商品を売る機能**（代理店・販売会社への卸し、セット商品など）を使う場合は、**旅行業法の登録が関わるか**、窓口に確認する。
- → [旅行業法の確認窓口](/articles/jp-travel-agency-law/)（法的判断はしません）

## 9. 試す・乗り換える

- [ ] 今の予約を、**どう移すか**。二重予約を防ぐ順番は決まっているか。

## よくある質問

### 全部を確認する必要がありますか？
特に、①契約できるか ②料金の総額 ⑦解約と値上げは、後から困りやすい項目です。口頭ではなく、メールなど記録に残る形で確認してください。

### 日本の製品なら、確認は少なくて済みますか？
国産・日本版（OMUSUBI、rezio、JTB BÓKUN）は、契約・円・日本語の確認が少なくなります。ただし、料金の総額、予約サイトとの連携、個人情報、解約の条件は、同じように確認してください。
