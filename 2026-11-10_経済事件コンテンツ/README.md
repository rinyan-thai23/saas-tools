# 経済事件コンテンツ

経済事件・詐欺・サイバー犯罪を題材にした、コンテンツ作りの作業場。
作成日: 2026-11-10

## 考え方

- 「誰に読んでほしいか」を先に決める。事件の中身（what）は、そのあとで選ぶ。
- 読んだ人が「自分は騙されないぞ」「身近な人に教えよう」と思えるものにする。

## フォルダ

```
2026-11-10_経済事件コンテンツ/
├ README.md
└ TSV-DATA/            前提知識（元ネタの表）
   ├ world_major_fraud_cases_100.tsv      世界の経済事件 100件
   ├ japan_major_fraud_cases_100.tsv      日本の経済事件 155件（ファイル名は100だが実際は155件）
   └ cyber_crime_history_cases_100.tsv    サイバー犯罪史 100件
```

## TSVの列

| ファイル | 列 |
|---|---|
| world | ID / 事件・事案名 / 時期・年代 / 主な国・地域 / 被害・流通規模 / 手口・ビジネススキームの特徴 / 備考・後世や現代への影響 |
| japan | ID / 事件・事案名 / 時期・年代 / 被害・流通規模 / 手口・ビジネススキームの特徴 / 備考・後世や現代への影響 |
| cyber | ID / 事件・事案・攻撃者名 / 発生・摘発時期 / 主な国・地域 / 被害規模・対象データ / 手口・攻撃ベクトル・ビジネスモデル / 歴史的意義・セキュリティへの影響 |

## 注意

- TSVはアップロードされたものをそのまま置いている。金額・年代・固有名詞は、記事にするときに一次情報で裏取りする。
- 裏が取れていないことは「未確認」と書く。
