# Guesty と Hostaway、日本の民泊ならどっち？

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。情報は公式ページ等の記載（2026-11-05 時点）に基づきます。

> **先に結論**
> - **英語の画面で運用できて、1〜3室から小さく始めたい人 → Guesty Lite。** 料金が公開されていて、14日間カード不要で試せます。
> - **4室以上の人 → どちらも「見積りを取ってから」。** 価格は非公開なので、同じ質問を両社に出して比べるのが近道です。
> - **楽天トラベル・じゃらんに出したい人 → どちらも、申し込む前に必ず問い合わせを。** 公式ページでは連携を確認できませんでした。
> - **日本語の画面やサポートが必須の人 → どちらも向きません。** 公式には、日本語の管理画面もサポートも見つかりませんでした。

## 1. 日本で民泊をやるなら、ツール選びの前に確認したいこと

ツールの機能の前に、**自分の営業形態で、そもそも載せられる予約サイトがあるか**を確認してください。

| 予約サイト | 公式の案内（要点） |
|---|---|
| 楽天トラベル | 旅館業法の許可がある施設が対象。民泊新法の施設は「ご参画いただけません」。民泊新法・特区民泊は「Rakuten Oyado」へ |
| じゃらんnet | 旅館業法の許可施設が対象。民泊新法・特区民泊は「ご参画いただけません」 |
| Rakuten Oyado | 楽天トラベルに民泊施設を出せる窓口。販売手数料は一律3%。そのまま使える既存ツールは、ねっぱん・AirHost・Beds24・suitebook。**Guesty と Hostaway の名前はありません** |
| Airbnb | 日本の民泊新法の宿では、ソフト連携で作った掲載を受け付けない。例外は、Airbnb と契約した日本のAPIパートナー |

民泊新法で運営している人は、**Airbnb・Booking.com・Vrbo など海外サイトが中心**になりやすい、ということです。そのうえで Airbnb は、「既に載っている民泊新法の宿を、後からツールにつなぐ場合」の扱いが公式ページで確認できませんでした。ここは、申込前に Airbnb と各社に聞いてください。

## 2. 料金：Guesty は1〜3室だけ公開、あとは見積り

| | Guesty | Hostaway |
|---|---|---|
| 1〜3室 | **Lite**：月$9/室＋予約ごとに1%（従量）、または月$20/室〜（年払い）、月$29/室〜（月払い） | 公開なし |
| 4室以上 | **Pro**：見積り（非公開） | 見積り（非公開） |
| 無料トライアル | Lite は14日間・カード不要 | 公式ページでは確認できず（デモ申込はある） |
| 3室の目安 | 従量なら月$27＋予約の1%（公式の単価からの計算） | － |

5〜10室の相場は、第三者の推定だけで公式の裏付けがなく、数字もバラバラです。ここは**見積りを取るのが唯一確実**です。

## 3. 契約：縛りの強さが違う

| | Guesty | Hostaway |
|---|---|---|
| 契約期間 | 規約上、**最初の13か月＋以後12か月ごとの自動更新**（ただし契約書の記載が優先） | 規約上は「個別契約による」。見積り時に確認 |
| 途中解約 | 最低月額×残り月数の早期解約金 | 規約本文に解約金の記載なし（個別契約） |
| 値上げ | 事前通知はあるが日数の記載なし（料金ページには「契約期間中は変わらない」とも） | 14日前に通知。同意しなければ、発効の5日前までに通知して解約できる |
| 請求通貨 | 原則USD。円は不明 | 記載なし。円は不明 |

**ここが一番の分かれ道です。** Guesty は「長く使う前提」、Hostaway は「見積り次第」。どちらも、**契約期間・解約金・値上げ条件は書面でもらう**のが安全です。

## 4. 日本語：どちらも「英語で使う」前提

- 公式サイトに日本語ページはありません（両社とも）。
- Guesty は、サポートの言語一覧に日本語がありません。管理画面も日本語は確認できませんでした。
- Hostaway は、サポート言語の記載が見つかりませんでした。
- ゲスト向けの予約サイト：Guesty は30言語を謳い、日本語は第三者の情報では含まれるようです（公式では未確認）。Hostaway は英・西・仏・伊などで、**日本語は第三者の情報では「なし」**です。

「英語のメールや管理画面で困らない」「ゲストとのやり取りは翻訳機能に頼る」という運用ができるなら、問題になりにくい部分です。

## 5. 日本の制度への対応：機能の記載は見つからなかった

次の項目について、**両社の公式ページに、日本向けの機能の記載は見つかりませんでした**（「できない」と確認したわけではありません）。

- 住宅宿泊事業法の年180日の管理
- 届出番号の表示
- 2か月ごとの定期報告
- 宿泊者名簿（外国人の旅券番号・写しの保存）
- 適格請求書（インボイス）

宿泊者の本人確認は、Guesty なら GuestVerify／AutoComply、Hostaway なら Chekin などの外部サービスが選択肢に挙がりますが、**日本の名簿要件に合うかは未確認**です。日本の要件は、ツールの外（表計算など）で管理する前提で考えておくと安全です。

## あなたはどちら向き？

| あなたの状況 | おすすめ |
|---|---|
| 1〜3室で、まず試したい | **Guesty Lite**（接続先は Airbnb・Booking.com・Vrbo。オーナーポータルは使えない） |
| 4室以上で、条件を比べたい | **両社に見積り依頼**（下の質問リストをそのまま使えます） |
| 契約期間を短くしたい | **Hostaway から交渉**（規約は個別契約。見積り時に確認） |
| Agoda も使う | **Guesty**（公式に掲載あり。Hostaway は接続を確認できず） |
| 楽天トラベル・じゃらんが必須 | **どちらも要問い合わせ**。民泊新法の施設は両サイトとも対象外と明記。旅館業法の許可施設なら、両社に接続可否を確認 |
| 日本語の画面・サポートが必須 | **どちらも不向き**。別の選択肢は [日本語UI・日本語サポート](/articles/jp-japanese-ui-support/) へ |

## 申し込む前に、両社へ聞く質問

そのまま問い合わせにコピーして使えます。

1. 月額・初期費用・オンボーディング費用・有料アドオンの内訳を、書面で。
2. 契約期間、自動更新の条件、途中解約の費用。
3. 値上げの通知期間と、同意しない場合の解約条件。
4. 請求通貨は円にできるか。USDなら、カードの為替手数料は誰が負担か。
5. 日本語で問い合わせできるか。日本時間の窓口はあるか。
6. 私の営業形態（住宅宿泊事業法／旅館業法／特区民泊）で、Airbnb・楽天トラベル・じゃらんに接続できるか。
7. 日本の宿泊者名簿・年180日の管理は、ツール内でできるか。できないなら、運用はどうするのが一般的か。
8. 使いたい日本のスマートロック（Akerun、SESAME など）は連携できるか。

より詳しい確認項目は [申込前チェックリスト](/articles/buy-checklist/) にあります。

## 利用者の声（海外）

Capterra の海外レビュー（2026-11-03時点）は、Guesty が 1,031件／4.6、Hostaway が 1,623件／4.8です。英語圏の運営者の声で、日本の運営者の実感ではありません。

- **Guesty**：契約期間・早期解約金の説明がなかった、という苦情あり。オンボーディング担当への称賛もあります。
- **Hostaway**：値上げが頻繁、契約中に機能が追加料金になった、という投稿あり。サポートが速い、という称賛もあり、評価は割れています。

この記事は法的な助言ではありません。制度の判断は観光庁・自治体などの一次資料で確認してください。
