# Hostaway の代替ツール：価格・契約・日本対応で選ぶ5候補

> **結論**
> - 「価格が非公開（フォーム→見積り）」「契約期間は個別契約」が合わないなら、料金表が公開されている [Hospitable](/go/hospitable/)・[OwnerRez](/go/ownerrez/)・[iGMS](/go/igms/) が出発点。
> - 日本語UI・円建て請求・楽天トラベル／じゃらんを資料で確認できたのは、Beds24 の日本の販売会社（WeIns / Co-Reception）版だけ（WeIns 自身の資料に基づく情報）。ただし契約条件に癖がある。この記事の PR リンクは [Beds24（海外公式）](/go/beds24/) 側で、日本の販売会社への申込は別手続き。
> - Hostaway は日本語UI・サポート言語・JPY・楽天／じゃらんのいずれも公式に記載が見つからなかった。Hospitable・iGMS・OwnerRez は管理画面に日本語がないと確認でき、Hostaway は記載が見つからない状態（同じ条件ではない）。日本語UIを確認できたのは Beds24（日本の販売会社版）だけ。

## 先に知っておくこと

- 楽天トラベルの新規参画ページ（公式）は民泊新法の施設は参画不可とし、同グループの「Rakuten Oyado」を案内。じゃらんnet の参画案内（公式）も民泊新法・特区民泊は不可。制度の判断はこの記事ではしない。
- Airbnb の公式ヘルプは、日本の住宅宿泊事業ではソフト連携で作ったリスティングを受け付けない（例外は「日本のAPIパートナー」。名前は公式で見つからなかった）とし、届出番号は Airbnb に直接ログインして入れる案内。既存の掲載を接続する場合の扱いは未確認。

## Hostaway が合わなくなりやすい点

| 項目 | 内容 | 確度 |
|---|---|---|
| 価格 | 公式に価格表なし。第三者の推定は食い違う（5〜9室で月$175〜$250など） | 確認済（非公開）／推定は第三者のみ |
| 契約・値上げ | 期間は個別契約による（規約）。値上げは14日前に通知、不同意なら発効5日前までの通知で解約可 | 確認済（契約書の中身は未確認） |
| トライアル | 公式ページで確認できず（デモ申込はある）。導入費$500は自社比較ページの主張 | 未確認／自社の主張 |
| 利用者の声 | 値上げの頻度、通知なしの増額、サポート対応が割れる、価格の同期漏れで約$400安く予約が入った、との投稿 | 第三者のみ（個別の口コミ） |
| 日本対応 | 日本語ページなし。管理画面の日本語・サポート言語・JPY請求・インボイス・住宅宿泊事業法の機能は記載が見つからなかった（ヘルプセンターは403で開けず） | 確認済（サイト）／他は未確認 |

## 候補ごとの要点

- **Hospitable**：基本 $59（Professional）に物件数に応じ追加料金。月払いは契約なし、年払いは30日以内なら全額返金。他PMSからの自動データ移行はなく、自動メッセージは作り直し。オーナーポータルは Mogul のみ。
- **OwnerRez**：1物件目 $40、以降は単価が下がる。契約なし、返金なし、カードのみ。Expedia は連携一覧に独立した記載が見つからなかった。サポートの対応時間の記載なし。
- **iGMS**：月払いは解約手数料なし、年払い（10物件未満）は返金不可。Expedia・Tripadvisor は iCal（1時間更新）。サポートは英語・スペイン語。
- **Beds24**：海外公式（ユーロ建て、英独のみ、月末まで1か月前通知）と日本の販売会社（円建て、日本語、最低1か月・解約は毎月20日までにメール、再登録5万円、カードのみ）で条件が別。日本側の例は10室・3部屋タイプ・5サイトで ¥17,280／月。楽天トラベル・じゃらんは民泊新法・特区民泊を対象外と明記（旅館業の許可施設への接続可否は未確認）。
- **Uplisting**：10〜300室超向けと自己説明（会員の多くは20室以上だが、20室未満の利用者も多いとも書いている）。料金ページは「契約なし」だが規約に「最低12か月・自動更新」とあり、現行は未確認。請求通貨に JPY なし。

## 申し込む前に確認すること

- [ ] Hostaway の個別契約の期間・解約手続きを書面で確認し、旧契約の終了日と新ツールの切替日の順序を決める
- [ ] 切替時の空室同期：Hospitable のガイドは、Airbnb は旧PMSを切断してから接続（Hostaway からの切断解放は24〜48時間かかることがある）、Booking.com は接続変更中の一時停止を推奨と案内
- [ ] JPY 払いと適格請求書：Hospitable・OwnerRez・iGMS・Uplisting は記載が見つからなかった（[円請求・インボイスの整理](/articles/jp-yen-invoice/)）
- [ ] 宿泊者名簿は全員分、外国人は旅券番号と旅券の写しの保存（観光庁）。本人確認（ID・パスポート）の機能を持つ候補（Hospitable、Uplisting など）はあるが、日本の名簿要件に合う本体機能の記載は、Beds24 日本側の有料オプション以外は見つからなかった
- [ ] 無料トライアル中に実際の掲載を接続し、二重予約にならないかを確認する

## 未確認のこと

- Hostaway のヘルプセンターは開けず、管理画面の対応言語、移行・インポート手順、解約手続き、最低料金、標準の契約期間、1室向けプランは不明。
- 楽天トラベル・じゃらんへの配信可否（記載が見つからなかっただけで、できないと確認したわけではない）、JPY 請求、Akerun・SESAME との連携。価格は取得日時点。
