この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

先に結論

  • 日本の事業者は、Bókun（JTB BÓKUN）が先です。 円の料金表と日本語サポートの記載があります。Rezdy は日本の窓口を確認できませんでした。
  • 手数料は Bókun の方が低めです（同じ月額なら、予約手数料が半分）。Rezdy は全プラン一律3%です。
  • Rezdy の良いところ：21日間の無料トライアル（カード不要）。予約サイト・代理店との接続が全プランで無制限。
  • 口コミの新しい傾向：Rezdy は2025〜2026年に低評価が集中しています。Bókun は低評価が少なめです。

料金を計算してみる

海外版の公式の価格で、オンライン予約の売上が月いくらのとき、いくらかかるかを計算しました。

計算の前提：オンライン予約のみ。決済会社の手数料と為替は含みません。手数料をお客さんに上乗せする場合、事業者の負担はその分減ります。プランごとに機能は違います。

月のオンライン売上 Bókun Start Bókun Plus Rezdy Foundation Rezdy Accelerate
$2,000 $79 $174 $109 $159
$5,000 $124 $211.5 $199 $249
$10,000 $199 $274 $349 $399

（計算。Start = $49＋1.5%、Plus = $149＋1.25%、Foundation = $49＋3%、Accelerate = $99＋3%。）

  • 同じ$49のプランどうしなら、Bókun が必ず安い（手数料の割合が半分）。
  • Plus は、Accelerate より機能が多い分、月額が高い。売上が月約$2,860を超えると、Rezdy Accelerate より Bókun Plus の方が安くなります（計算）。
  • Viator 経由の予約は、Bókun の手数料が0%（公式）。店頭などオフラインの予約も0%です。Rezdy の店頭の手数料については、口コミに契約後の変更を訴える声が1件あります（下で説明）。

予約サイト（OTA）との連携

  • Bókun：「2,600以上の販売会社、うち70以上の世界の予約サイト」（公式の自社の主張）。Viator とは同じグループで、商品を取り込めると説明しています。
  • Rezdy：予約サイト・代理店・販売会社との接続は、全プランで無料・無制限（公式）。「1万2千以上の代理店が集まる市場」（自社の主張）。

数字は、数え方が違う自社の主張で、並べて比べられません。どちらも、日本の予約サイトとの連携は確認できませんでした。 つなぎたいサイトの名前で、問い合わせてください。

よくある質問

日本の事業者はどちらがいいですか？

手数料が安いのはどちらですか？

無料で試せますか？

Bókun は14日間（日本版は30日間）、Rezdy は21日間（カード不要）です。
