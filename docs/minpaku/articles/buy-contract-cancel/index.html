【民泊】管理ツールの契約期間・自動更新・解約条件｜11ツールを比較して分かった落とし穴

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

先に結論：「縛りなし」と書いてあっても、規約まで読む

  • 更新の通知なしに自動更新されるのは Lodgify（規約）。期間途中の返金もありません。
  • 契約が最も重いのは Guesty の Pro。最初の13か月＋12か月ごとの自動更新で、途中解約は最低月額×残り月数の早期解約金です。
  • Uplisting は、料金ページ（契約なし）と規約（最低12か月・自動更新）が食い違っています。 書面で確認が必要です。
  • 縛りなしで分かりやすいのは、OwnerRez、Hospitable（月払い）、iGMS（月払い）、Sirvoy、PriceLabs。 ただし、返金の条件はそれぞれ違います。
  • Hostaway は期間が個別契約。 口コミに、解約の連絡後も請求が続いたという低評価があります。
  • 申込前に、期間・更新日・解約の方法・返金・値上げの条件を書面で。契約書の記載が、公式ページより優先されることがあります。

口コミに出た、契約・解約のトラブル

Capterra の海外レビューに、次のような投稿があります（個別の体験で、一人の声です）。

  • Lodgify：年間契約が警告なしに自動更新され、解約を頼んだらアカウントは閉じたが、年額は返金されなかった（2026年）。
  • Hostaway：解約の連絡後も請求が続いた。営業の説明と導入後が違った。12か月契約で、試用なしだった。
  • Guesty：契約期間・早期解約金の説明がなかった（BBB への苦情）。
  • iGMS：解約の方法が分からず、サポートに強く頼まないと対応してもらえなかった（2025年）。
  • PriceLabs：トライアルが自動で有料に切り替わった（公式は、トライアル後に請求が始まると説明）。

申込前に確認する項目（書面で）

  1. 契約期間：最低期間はあるか。月払いと年払いで違うか。
  2. 自動更新：あるか。更新日の通知は来るか。解約の期限は何日前か。
  3. 解約の方法：ボタンか、メールか、チャットか。受け付けの記録は残るか。
  4. 途中解約の費用：早期解約金の計算式。残りの期間の扱い。
  5. 返金：未使用期間、トライアル後の返金の可否。
  6. 値上げ：通知の日数。同意しない場合の解約。
  7. データ：解約後に、データを書き出せるか。いつまでアクセスできるか。
  8. 契約主体：どこの会社か、準拠法はどこか（Guesty は米国法人、Lodgify は英国法人、Hostaway はフィンランド法人、Hospitable はオランダ法人で規約の準拠法はエストニア法、Uplisting は英国法）。

カレンダーに更新日の1週間前を入れるのが、いちばん簡単な予防です。

日本で契約するときの注意

  • 日本の販売会社がある Beds24 は、窓口で条件が違います。 日本の販売会社は、解約が毎月20日までにメールのみ、再登録に5万円、支払いはカードのみです。
  • 請求通貨：円で請求できるのは、Beds24 の日本の販売会社版だけです。ほかはドルなどで、為替の実質の手数料が変わります。
  • 契約は英語：規約は英語で、海外の法律が準拠法になります。重要な契約は、書面での確認を英語または日本語の訳でもらってください。
  • 民泊新法の人は先に確認：契約の前に、Airbnb と各ツールに、掲載をつなげられるかを確認してください。Airbnb は、日本の民泊新法の宿で、ツール経由で作った掲載を受け付けません（例外あり）。

よくある質問

自動更新に気をつけるべきツールは？

Lodgify（更新の通知なしに自動更新、期間途中の返金なし）、Guesty の Pro（13か月＋12か月ごとの自動更新）、Uplisting（規約に自動更新。料金ページと食い違い）です。

縛りなしで始められるツールは？

OwnerRez、Hospitable（月払い）、iGMS（月払い）、Sirvoy、PriceLabs です。ただし、返金の条件は違います。OwnerRez は未使用期間の返金がなく、iGMS の10室未満の年払いは返金がありません。

解約したのに請求が続いたら？

解約の連絡は、メールなど記録の残る方法で行い、日付を控えてください。Hostaway の口コミに、そうした低評価があります。

契約書と公式ページ、どちらが優先ですか？

Guesty の規約には、契約書の記載が優先とあります。公式ページの「契約なし」などの表示だけで判断せず、契約書や規約を確認してください。
