## 先に結論

> - **調べた10製品のうち、アソビュー・じゃらん・楽天トラベルなど日本の大手予約サイトとの連携が公式に書かれているものは、ありませんでした。** 「つながらない」と確認したわけではなく、**書かれていません**。
> - **日本の予約サイトとの連携で、記載が見つかったのは1つだけ**：rezio の公式の沿革に、2022年に Activity Japan（アクティビティジャパン）と API でつながった、とあります。
> - **日本の予約サイトの在庫を、海外の予約システムと自動で合わせられる前提で選ぶのは危険です。** 使いたいサイトの名前で、各社に確認してください。
> - つながらない場合の現実的なやり方は、**「枠を分ける」「手で合わせる」「国内の在庫管理を併用する」**の3つです（下で説明）。

## 日本の予約サイトの動き（報道で確認できたこと）

- **アソビュー**：事業者向けシステム「ウラカタ」で在庫を一元管理し、海外のB2B基盤 BeMyGuest（シンガポール）を通じて、リアルタイムに予約を受け付けられるようにする、と2026年8月の業界報道にあります。海外の販路への連携は、アソビュー側のシステムが入口になっています。**海外の予約システムとアソビューをつなぐ方法は、確認できませんでした。**
- **アクティビティジャパン（HIS 子会社）**：2019年の業界報道に、国内の事業者向けに、複数のオンラインサイトの予約・在庫を一元管理するシステム「Actim（アクティム）」を開発した、とあります。**今も提供されているかは、確認できていません。**
- **楽天**：Xola に2016年に出資した、と業界報道にあります（[Xola の商品ページ](/articles/xola/)）。ただし、日本の事業者が Xola と楽天の予約サイトを連携できるという記載は、見つかりませんでした。

## つながらないときの現実的なやり方

### 1. 枠を分ける
日本の予約サイトに出す枠と、海外の予約システムで売る枠を、**最初から別々にします**。たとえば「午前の枠は日本の予約サイト、午後の枠は海外の予約システム」のように決めると、二重予約が起きません。ただし、売れる機会は減ります。

### 2. 手で合わせる
予約が入ったら、もう一方の在庫を、**毎回、手で減らします**。件数が少ないうちは現実的ですが、手が空かないと二重予約になります。担当者を決めて、1日に何回か見比べる運用にします（[乗り換えチェックリスト](/articles/switch-checklist/)も参考に）。

### 3. 国内の在庫管理を併用する
日本の予約サイトの在庫を一元管理する国内の仕組み（上の Actim や、アソビューのウラカタなど）があります。海外の予約システムと併用できるかは、確認できていません。

### 4. 日本の窓口がある製品を選ぶ
rezio は、日本の運営会社（株式会社KKDAY JAPAN）があり、Activity Japan と連携しています。日本の予約サイトとの連携を重視するなら、先に相談する候補です。ただし、アソビューやじゃらんとの連携は、記載が見つかりませんでした。

## よくある質問

### アソビューやじゃらんと連携できる海外の予約システムはありますか？
調べた10製品では、公式に書かれているものはありませんでした。rezio は、Activity Japan との API 連携が公式の沿革にあります。使いたいサイトの名前で、各社に確認してください。

### 日本の予約サイトに出しながら、海外の予約システムを使えますか？
使えますが、在庫を自動で合わせられないかもしれません。枠を分ける、手で合わせる、といった運用が必要になる場合があります。

### 連携がなくても、二重予約は防げますか？
手で合わせる運用でも、防げます。ただし、担当者の見比べが漏れると起きます。予約が増えたら、連携のある製品への乗り換えを考えてください。
