# Capterra日本 カテゴリ一覧

Capterra日本のディレクトリ（https://www.capterra.jp/directory ）に載っているソフトウェアカテゴリを、URLつきで一覧にしたもの。次のステップ（各カテゴリ配下の製品取得）の入口。

## 中身

- `データ/01_カテゴリ.tsv`：1,023件
  - 列：カテゴリID / カテゴリ名 / スラッグ / URL
  - カテゴリIDの昇順。IDの重複なし、全行4列

## 取得方法

- 2026-11-03、`/directory` を1回だけ取得（HTTP 200、約430KB）。HTMLのリンクから抽出
- 取得は正直な形で1回のみ。連続アクセスはしていない
- robots.txt：`/directory` 自体の取得は禁止されていない。クエリ付きURLは原則禁止だが、`/directory/*?page=` は許可
