Telnyx（テルニクス）の評判・口コミまとめ｜日本の電話番号は？

先に結論：Telnyx はこんな人に向く

  • 向く人：エンジニアがいて、電話・SMS・音声AIを自分のサービスに組み込みたい人。電話の回線（SIP）や API を、自分で設定できる人。
  • 向かない人：設定なしで、すぐ使える「電話のアプリ」を探している人。 Telnyx は、完成した電話システムというより、電話の部品を売る会社です。日本語の画面・サポートが必要な人。
  • 日本の番号は、公式の日本向けページに載っています（ローカル番号は月$5から）。ただし、必要書類が重い（登記事項、印鑑証明など）です（詳しくはこちら）。

Telnyx とは？何ができるサービスか

Telnyx は、米国の通信会社です。自社の回線網を持ち、電話・SMS・音声AIなどを、API（プログラムから使う仕組み） で提供します（自社の主張）。公式の日本の番号ページでは、番号の手続きは、管理画面（Mission Control Portal）に登録して、番号を探し、SIP 接続に割り当てる、という流れです。

ほかのページのクラウド電話（RingEX や Dialpad など）は、「アカウントを作って、すぐ電話を使い始める」形です。Telnyx は、通話の部分を自分で組み立てることが多く、使い方の想定が違います。

Telnyx の評判・口コミまとめ

海外のレビューサイト（Capterra）の口コミ約80件（関連順＋新着順、重複を除いた80件）を読んで、日本語にまとめました。

読む前に

  • 投稿者の国が分かる56件のうち、米国が約6割（33件）、英国が5件、カナダ・インドが各3件など。日本の事業者の口コミはありませんでした。
  • 投稿者は、2〜10人規模が約5割（43件）、自営業が12件で、小さな事業者が多めです。使用期間は「1〜5か月」が半数で、始めたばかりの感想が多めです。
  • 年は、2024〜2025年が56件で新しめです。
  • 評価は、5点が66件と高めです。件数は、話題をキーワードで数えたおおよその数です。

良い口コミ：サポート、使いやすさ、価格

  • サポート（良い点で約4割で最多）：対応が早い、担当者が詳しい、という声。
  • 使いやすい（約4割）：アカウント作成、SIP 接続、番号の購入、認証までが早い、という声。
  • 価格（約2割）：他社より安い、という声。
  • 番号の管理：ポート（番号の移行）の申請や番号の購入を、自分で管理できる、という声。

悪い口コミ：サポート、レポート、通話の品質

  • サポート（改善点で約3割）：連絡が取れない、という声（下の低評価を参照）。
  • レポート・請求まわり（約1割）：画面の集計や請求の見え方が足りない、という声。
  • 通話の品質：ブラウザ（WebRTC）で、片方向の音声、発信前の固まり、音声の劣化があった、という声（2026年8月）。

低評価（1〜2点）の傾向

口コミ80件のうち、1〜2点は3件（約4%）です。内容は、(1) 音声の信頼性の問題（2026年8月）、(2) 本人確認（KYC）の流れで、2年使ったアカウントが閉じられ、サポートにつながらなかった（2024年9月）、(3) 通貨の変更にアカウントの作り直しが必要と案内された（2020年）です。本人確認とアカウントの停止は、日本の番号の書類が重い点とあわせて、申込前に確認してください。

Telnyx は日本で使える？番号・書類・緊急通報

日本の電話番号

  • 公式の日本向けページに、ローカル番号は月$5から、国番号 +81、既存の日本の番号のポート（移行）に対応、とあります（自社の説明）。
  • 対応国の一覧（Coverage）にも、日本があります。
  • 050、0120の扱いは、確認できていません。 日本の番号の種類は、公式の必要書類のヘルプでは「National Numbers」と書かれています。市外局番（03など）の指定方法と、開通までの日数は、確認できていません。
  • 日本向けページの「日本の規制の情報」は、「準備中（coming soon）」と表示されています。

必要書類（公式のヘルプ「Japan DID Requirements」）

個人の場合：氏名、連絡先の電話、本人の書類（運転免許証、マイナンバーカード、パスポート、健康保険証 など、いずれか1つ）。 法人の場合：代表者の氏名、連絡先、会社名、登記事項（履歴事項全部証明書）、印鑑証明書（発行から3か月以内）、必要に応じて委任状（代表者の氏名と印が入ったもの）。 住所の確認（共通）：日本の住所（番地、建物名、郵便番号）と、住所の証明書。契約者の書類の住所と、使う場所の住所が違う場合は、税金の領収書、納税証明書、社会保険料の領収書、公共料金（電気・ガス・水道・固定電話）の領収書など、追加の書類が必要です。

  • 有効期限のある書類は期限内、期限のない書類は発行から3か月以内、とあります。
  • 同じ名前のヘルプ記事が2つあります（古い版は中身を読めませんでした）。申込前に、管理画面の「国別の要件のツール」で、最新を確認してください。

よくある質問

Telnyx で日本の電話番号は取れますか？

公式の日本向けページに、ローカル番号が月$5からと載っています。050、0120の扱いは、確認できていません。必要書類は、公式のヘルプにあります。

Telnyx は電話のアプリですか？

いいえ。公式の説明は、API で電話・SMS・音声AIを使う、開発者向けの形です。すぐ使えるクラウド電話を探す人は、ほかの製品のほうが近いです。

Telnyx の料金はいくらですか？

公式の番号の料金は、ローカル番号が月$1から（米国の例）、日本のローカル番号は月$5からです。通話料は別です。
