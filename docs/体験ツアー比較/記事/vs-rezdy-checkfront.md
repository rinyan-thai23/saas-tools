# 【体験・ツアー】RezdyとCheckfrontを比較｜2023年に合併した兄弟。違いと選び方

## 先に結論

> - **Rezdy と Checkfront は、2023年に合併した同じグループの製品です。** 業界報道では、ブランドは別々に続けるとされています。製品も料金も、今は別々です。
> - **選び方の目安**：予約サイトや代理店への配信を広げたいなら Rezdy。ツアー以外にレンタルや宿泊も予約したい、窓口の予約が多いなら Checkfront。
> - **日本の事業者には、どちらも日本の窓口がありません**。サポートは英語です。日本向けの窓口が確認できているのは [Bókun（JTB BÓKUN）](/articles/bokun/)です。
> - **合併後の料金や製品の統合は、今後変わる可能性があります。** 申込前に、今の方針を聞いてください。

## 合併について（分かっていること）

- 業界報道によると、2023年6月に Checkfront と Rezdy が合併しました。Regiondo も同じ年にグループに加わった、とされています（[Regiondo](/articles/regiondo/) の公式の沿革は「手を組んだ」と書いています）。
- ブランドは別々に続けると、経営陣が話したと報じられています。
- 業界紙の見出しに「経営陣の入れ替え」とありますが、記事の全文は読めず、内容は確認できていません。
- 競合の Bókun の解説には「合併後、料金を Rezdy に合わせる動きがある」とあります。**競合の主張で、確認できていません。**

## 料金を比べる

**3%という割合は同じです。** 違いは月額と、プランごとの中身です。

| 月のオンライン売上 | Rezdy Foundation（$49＋3%） | Rezdy Accelerate / Checkfront（$99＋3%） |
|---|---|---|
| $2,000 | $109 | $159 |
| $5,000 | $199 | $249 |
| $10,000 | $349 | $399 |

（計算。オンライン予約のみ。決済会社の手数料と為替は含まず、手数料を事業者が払う場合）

- **Rezdy Accelerate と Checkfront は、月額・割合が同じ**（$99＋3%）です。この価格帯では、機能で選ぶことになります。
- Rezdy は、$49の Foundation から始められるのが安い点です。
- Checkfront は、**店頭・電話の予約に手数料がかからない**と公式にあります。窓口の予約が多い事業者に向きます。
- Rezdy は、契約後に店頭の予約の手数料が変わったという口コミが1件あります（1人の声）。**店頭の予約の扱いを、書面で確認してください。**

## 機能の違い

- **Rezdy**：予約サイト・代理店・販売会社との接続が、全プランで無制限・無料（公式）。上位プランで詳しいレポートとAPI。
- **Checkfront**：1日、複数日、時間枠など、いろいろな予約の形。レンタルや宿泊の予約。電子の同意書が標準。公式は、予約サイトとの連携を「2万以上の販売会社」と説明しています（自社の主張）。

## 口コミ（海外のレビュー）の違い

| | Rezdy | Checkfront |
|---|---|---|
| 良い点で多い話 | 使いやすさ（約5割）、サポート（昔の口コミが中心） | 使いやすさ（約4割）、サポート（約3割）、価格が手頃 |
| 悪い点で多い話 | 料金（約2割）、サポートの遅れ、不具合 | 値上げ、レポートが弱い、予約サイト連携の遅れ |
| 低評価（1〜2点） | 約9件（約9%）。うち7件が2025〜2026年 | 4件（約3%） |
| 投稿者の国 | オーストラリア約5割、米国約3割 | 米・加・英・豪で約9割。日本の投稿者2人 |
| 日本の投稿者 | 0人 | 2人（宿のオーナー、自営業。どちらも4点） |

**直近の評判では、Rezdy の方が厳しい声が多めです。** 特に2025年以降の口コミに、サポートの遅れ、合併後の混乱、契約後の料金変更への不満が集中しています。Checkfront は低評価が少ないものの、2025年に「年額が20%上がった」という声が出ています。

## 日本の事業者として見るポイント

- **サポートと言語**：どちらも英語です。Checkfront は、1つのアカウントで日本語と英語の予約画面を混ぜられない、と公式に書かれています（日付は不明）。
- **決済**：Checkfront の決済サービスの対応国に日本は入っていません（他社の決済会社と連携できます）。Rezdy の決済ページは、国の選択に日本が入っていますが、日本を選んだ結果は確認できていません。
- **日本の予約サイトとの連携**：どちらも記載が見つかりませんでした。
- **日本の声**：Checkfront には、日本の宿のオーナーが「サポートが一番良い」と書いた口コミがあります（2人だけの声です）。
