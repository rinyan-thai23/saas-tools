## 取得方法

- 2026-11-03、各カテゴリの一覧ページ（`/directory/<ID>/<slug>/software` と `?page=N`）のみを取得。製品ページには行っていない
- `?page=` は robots.txt で許可されている形。絞り込み条件付きのURLと `/x/*` は取得していない
- 間隔は1.5〜5秒のランダム、たまに10〜25秒の休み。ブロック（403）は出なかった
- 評価・レビュー数は一覧のカードから、製品名・URL・説明は構造化データ（JSON-LD）から抽出

### アフィリエイト調査（日本語対応576件が対象）

`データ/04_詳細/製品詳細.tsv` の右端に6列を追加した：アフィリエイト / アフィリ種別 / 申込URL / 判定の根拠 / 確認日 / アフィリ備考。値は「あり」「要確認」「見つからず」「未調査」。**「見つからず」は「ない」の証明ではない。**

結果（日本語対応576件）：**あり258／要確認102／見つからず202／未調査14**。日本語対応でない715件は対象外（「未調査」のまま）。

進め方（段階）：
1. PartnerStack の全掲載（406件）と製品名を照合（86件）：`04_PartnerStack照合.py`
2. 製品の公式サイトを自動で確認（Bing で公式ドメインを推定 → トップページのリンクと /affiliate など定番パスを確認。リンク先が第三者ネットワークなら種別に書く）：`06_自社サイト確認.py`
3. 2で見つからなかった製品を、公式ドメイン推測・追加パス・sitemap で再確認（4並列）：`07_自社サイト再確認.py`
4. それでも見つからなかった製品を、検索ツールで1件ずつ調査（人手）。大企業の製品群は会社単位で当てはめた
5. 結果の反映：`05_アフィリ結果反映.py`（`アフィリ調査結果.tsv` → `製品詳細.tsv`）

補助ファイル：`アフィリ_公式ドメイン.tsv`（推定した公式ドメイン。誤りがありうる）、`自社確認済_なし.txt`／`自社再確認_なし.txt`（自動確認で見つからなかった製品ID）、`PartnerStackプログラム一覧.tsv`

注意：

- 自社（公式）か第三者かは、公式ページからのリンク先と検索結果で判断。第三者があるものは第三者を優先して種別に書いた
