# 【体験・ツアー】電話・メール・表計算の予約管理から予約システムへ｜乗り換えの手順と、店頭予約の手数料

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

## 先に結論

> - **電話や窓口の予約が多い人は、「店頭・電話の予約にかかる手数料」を先に見てください。** 製品によって、0%のものと、かかるものがあります。
> - **乗り換えの順番**：今の予約を洗い出す → 商品・料金・定員を整理する → 無料トライアルで試す → 切り替える日を決める → その日から表計算を止める。
> - **二重予約を防ぐ一番の方法は、「予約を入れる場所を1つにする」こと**です。電話の予約も、すべて新しいシステムに入れます。
> - **日本の事業者は、日本語の窓口がある rezio、国産の OMUSUBI、Bókun の日本版（JTB BÓKUN）から**試すのが現実的です。

## 予約システムに移すと変わること

電話・メール・表計算の管理では、次のようなことが起きがちです。

- 営業時間外の予約を取りこぼす。
- 電話と別の予約サイトの予約が重なり、二重予約になる。
- 確認メールやリマインドを、手で送る。

予約システムに移すと、**24時間の受付、空き状況の自動更新、確認・リマインドの自動送信**ができる、と各社は説明しています（自社の主張）。ただし、**システムを入れただけでは、運用が整いません。** 予約のルール（定員、受付の締め切り、キャンセル期限）を先に決めておくと、現場の混乱が減ります。

## 乗り換えの手順

これは一般的な進め方です。各社の公式の手順ではありません。

### 1. 今の予約を洗い出す
- 先の日付の予約を、すべて一覧にします（日付、商品、人数、名前、連絡先、支払い済みか）。
- 電話・メール・LINE・予約サイト（OTA）に分けて、どこから来た予約かを書きます。

### 2. 商品・料金・定員を整理する
- 商品ごとに、定員、開始時間、所要時間、料金（大人・子ども）、追加オプションを書き出します。
- キャンセルの規定、締め切り（前日何時まで）を決めます。システムの設定で聞かれます。

### 3. 無料トライアルで試す
- 無料トライアルがあるのは、Bókun（14日。日本版は30日）、Rezdy（21日・カード不要）、Bookeo（30日）です。rezio は日本語ページに「無料体験」の案内があります（条件は未確認）。
- 試すときは、**実際の商品を1〜2つ登録**して、予約を入れ、確認メールが届くかを確かめます。

### 4. 切り替える日を決める
- **いつから「新しいシステムだけ」に予約を入れるか**を、日付で決めます。
- 切り替え前の予約は、新しいシステムに入れ直します。FareHarbor は、公式に「ダッシュボードを作り、今後の予約を移す」と案内しています。他の製品は、各社に移行の手助けがあるか聞いてください。

### 5. 表計算を止める（予約を入れる場所を1つにする）
- 切り替えの日から、表計算への新しい入力をやめます。**電話の予約も、新しいシステムに入れます。**
- 数日は、表計算と見比べて、ずれがないか確認します（短い並行運用）。

### 6. 予約サイトとつなぐのは、最後
- Viator、GetYourGuide、KKday などとつなぐのは、システムの運用が安定してからにします。**つなぐと、販売先すべての在庫が連動する**ためです。
- 日本の予約サイト（じゃらん、アソビュー、楽天など）との連携は、どの製品も記載が見つかりませんでした。使いたいサイトの名前で、各社に確認してください。

## 乗り換えで失敗しやすいこと

- **電話の予約を、システムに入れ忘れる**：二重予約の一番の原因です。入れる担当者を決めます。
- **商品の設定が複雑で、途中で止まる**：口コミで「初期設定に時間がかかる」という製品があります（Bókun、Zaui など）。最初は商品を絞ります。
- **サポートが英語で、困る**：日本語の窓口がある製品なら、設定の相談ができます。

## よくある質問

### 電話の予約も、システムに入れる必要がありますか？
はい。二重予約を防ぐには、すべての予約を1つのシステムに入れる必要があります。多くの製品は、店頭・電話の予約の入力に対応しています。手数料は製品で違います。

### 表計算のデータは移せますか？
製品ごとに違います。FareHarbor は公式に、今後の予約の移行を案内しています。ほかの製品は、各社に聞いてください。確認できていません。

### いつ予約サイトとつなげばいいですか？
システムの運用が安定してからです。つなぐと、複数の販売先の在庫が連動するので、先に自分のサイトと電話の予約で慣れておくと安全です。
