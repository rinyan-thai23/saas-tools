Hostaway と Lodgify を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

結論

  • 公式ページで料金を確認できたのは Lodgify だけです（1室あたりの表示価格。3室以上の合計は取得できず。Lodgify は公式サイトの公開コピーから取得し、www 側との一致は未照合）。Hostaway は価格非公開で、物件数を答えて見積りを受ける形でした。
  • 無料で試せると確認できたのは Lodgify（7日間、カード不要）。Hostaway は無料トライアルを公式ページで確認できず、デモ申込のみでした。
  • 日本語の管理画面は、どちらも公式には確認できませんでした。楽天トラベル・じゃらんも、どちらの公式ページにも記載が見つかりませんでした（「接続できない」と確認したわけではありません）。

先に知っておくこと（日本で使うときの前提）

予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

  • 楽天トラベル：旅館業法の営業許可証を取得した施設が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は「Rakuten Oyado」で登録、と案内。
  • じゃらんnet：旅館業法の宿泊営業許可を得た施設が対象。住宅宿泊事業法に基づく民泊と特区民泊は「ご参画いただけません」。
  • Rakuten Oyado のページで「そのまま使える」とされる既存ツールは、ねっぱん、AirHost、Beds24、suitebook。Hostaway・Lodgify の名前は載っていません。
  • Airbnb：ヘルプに「In Japan, we don't accept listings created through software connections for places to stay (minpaku)…」とあり、例外は日本のAPIパートナー。その名前は公式で見つかりませんでした。既存の掲載を後からツールにつなぐ場合の扱いは未確認です。届出番号は「ツールを使っていても、自分でログインして」追加する必要があります。
  • 取得できた両社の公式ページに、届出番号の表示・年180日の管理・2か月ごとの定期報告・適格請求書（インボイス）に当たる機能の記載は見つかりませんでした。宿泊者名簿は、日本の名簿要件に合う本体機能の記載は見つかりませんでした（Lodgify に Guest Registration、Hostaway に Chekin 等との提携はありますが、日本の要件に合うかは未確認）。

条件別の選び方

  • 1〜2室で、価格を見て試したい人： Lodgify。Starter までが2物件の範囲で、7日間試せます。
  • 3室以上の人： Lodgify は合計額が取得できず、Hostaway は見積りです。両社に同じ条件で出してもらってください。
  • 契約の手間を減らしたい人： Lodgify は「長期契約なし」ですが、自動更新の通知が来ません。更新日を控えてください。Hostaway は期間が個別契約なので、見積り時に確認します。
  • 清掃タスク・オーナー精算まで使う人： Hostaway は清掃タスクの機能があります（プラン別の制限は記載が見つかりませんでした）。Lodgify では清掃タスクもオーナー向けの精算・レポートも Ultimate のみです。
  • Expedia も使う人： Hostaway は対応と確認できました。Lodgify は公式の記述が食い違う（チャネルのページは API 接続、料金ページの機能表には記載なし）ので、申込前に確認してください。
  • 楽天トラベル・じゃらんが必須の人： 民泊新法・特区民泊の施設は両サイトの対象外と各社が書いています。旅館業法の許可施設については、Hostaway・Lodgify とも接続可否が未確認なので、申込前に各社へ問い合わせてください。
