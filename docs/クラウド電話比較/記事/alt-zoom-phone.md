# 【クラウド電話】Zoom Phoneの代替｜日本の事業者が選べるクラウド電話6つ

## 先に結論

> - **Zoom Phone は、日本の条件が公式で一番細かく読める製品です。** それでも合わない人はいます。理由で選び直しましょう。
> - **通話が少ない1〜数人の事業者**は、Dialpad の Standard（¥1,000、税抜）のほうが、月額を抑えやすいです。Zoom 日本の公式ブログ自身が、通話が月に数十件程度なら、ほかの安価なクラウド電話を比べる価値がある、と書いています。
> - **今の050を移したい人は、Zoom Phone では移せません。** 日本の要件ページに、050は番号の移行に対応していない、とあります。
> - **110・119は、どの製品も前提にしないでください。**

## Zoom Phone が合わない主なケース

[Zoom Phone の商品ページ](/articles/zoom-phone/)で書いたとおり、次のような人には向きません。

- **通話が少ない、1〜数人の事業者**：1ユーザーあたりの月額が割高になりえます。
- **今の050の番号を、そのまま移したい人**：050は移行できません（0ABJとフリーダイヤルは対応）。
- **本人確認の手間を減らしたい人**：eKYC（オンラインの本人確認）と、住所確認の郵送が必要です。
- **110・119にかけたい人**：日本向けページに、発信不可とあります。

## 番号の扱いにも注意（Zoom の番号規定）

Zoom の日本語の「Zoom Phone 番号規定」（2021年9月施行）には、次のように書かれています。

- Zoom は、法令・技術的な理由・通信事業者の要件で必要な場合に、**お客様の番号を変更する権限を留保**します。
- お客様には、Zoom Phone を通じて割り当てられた番号の**所有権はありません**。
- 番号の移行（転入・転出）の完了までの期間は、**期限が固定されていません**。

これは Zoom 固有の特別な条件、とは限りません。ただ、**番号を長く使う事業者は、どの製品でも、番号の扱いの規定を読んでください。**

## 1. Dialpad（ソフトバンク経由）

円・税抜の料金表と、本人確認の書類・日数が公開されています。**050が1つ含まれ**、03・06は1番号 月¥500（税抜）で足せます。通話料は従量で、国内かけ放題の記載は確認できていません。詳しくは [Dialpad の商品ページ](/articles/dialpad/)、[Dialpad と Zoom Phone の比較](/articles/vs-dialpad-zoom-phone/)、[Dialpad の代替](/articles/alt-dialpad/)へ。

## 2. CallHippo

日本向けの番号ページがあります。050が数日で取れる、と自社が説明しています。通話は従量で、「無制限」は米国・カナダ宛だけです。詳しくは [CallHippo の商品ページ](/articles/callhippo/)へ。

## 3. CloudTalk

東京の03と、0120・0800（着信のみ）が載っています。前払い・返金なしの契約です。詳しくは [CloudTalk の商品ページ](/articles/cloudtalk/)へ。

## よくある質問

### Zoom Phone の代替で、日本語の公式情報が読めるのは？
Dialpad（ソフトバンクの日本向けページ）です。CallHippo と CloudTalk には、日本向けの番号ページ（英語）があります。

### 通話が少ない場合、どちらが安いですか？
月額だけなら、Dialpad の Standard（¥1,000）が、Zoom の従量制（¥1,275）より低いです（どちらも税抜）。通話料と番号の費用は別なので、見積もりで比べてください。

### Zoom Phone の番号は、他社に移せますか？
0ABJとフリーダイヤルは、番号の移行に対応しています。050は対応していません。完了までの期間は固定されていません。
