# 【民泊】iGMS と Hospitable どっちがいい？料金・自動メッセージ・口コミ・日本で使えるかを比較

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：どちらも小規模向け。料金の払い方と、必要な機能で選びます

> - **どちらも、1〜10室ほどの小さな運営向けで、無料プランがあります。** 自動メッセージが中心の道具という点も似ています。
> - **稼働が低い月は安く、高い月は高くなる払い方がいい → iGMS の FLEX。** 泊数あたり$1（物件ごとに最低月$20）。
> - **毎月の料金を固定で見たい、Agoda も使う → Hospitable。** 基本料金＋稼働物件の追加料金。Agoda は接続先に入っています（iGMS は公式の一覧になし）。
> - **日本語は、どちらも不向き。** iGMS の画面は英語とスペイン語、Hospitable は英語のみ。
> - **口コミの低評価の割合**は、iGMS が約3%、Hospitable が約5%。どちらも低い水準ですが、件数が少なめです。

## 2つのツールの違い（早見表）

| | iGMS | Hospitable |
|---|---|---|
| 得意なこと | メッセージの自動化、チーム・清掃の管理 | メッセージの自動化（Airbnb 中心）、AI返信 |
| 公式が想定する規模 | 個人ホストの2〜8室。20物件以上は専任担当 | 1〜10室（11〜20室、21室以上は別枠） |
| 無料プラン | あり（予約5件・メッセージ10件まで） | あり（Essentials。機能に制限あり） |
| 無料トライアル | 14日間・カード不要 | 14日間・カード不要 |
| 料金の払い方 | FLEX（泊数あたり）／PRO・PRO+（物件ごとの月額） | 基本料金＋稼働物件の追加料金 |
| 契約 | 月払いは縛りなし。10室未満の年払いは返金なし | 月払いは縛りなし。年払いは30日以内なら返金 |
| 接続先 | Airbnb・Vrbo・Booking.com。Expedia等はiCalのみ | Airbnb・Vrbo・Booking.com・Agoda。Expedia等はiCalのみ |
| 管理画面の言語 | 英語・スペイン語 | 英語のみ |
| 口コミの低評価率 | 約3%（114件中3件） | 約5%（57件中3件） |

各ツールの詳しい情報は、[iGMS の評判・口コミ](/articles/igms/)、[Hospitable の評判・口コミ](/articles/hospitable/)にまとめています。

## 料金：払い方が根本的に違う

**iGMS（公式、月額・米ドル）**

| プラン | 払い方 |
|---|---|
| 無料 | 月$0。予約5件、メッセージ10件まで |
| FLEX | 予約された泊数あたり$1（物件ごとに最低月$20） |
| PRO（月払い） | 1物件あたり、1室$48／3室$23.33／5室$19.80／10室$17.40 |
| PRO+（月払い） | PRO より高い。翻訳、収益管理など |

- PRO の月払いの合計は、公式の単価からの計算で、3室約$70、5室約$99、10室約$174です。年払いは安くなります。
- FLEX は、稼働が高い月に高くなります。たとえば、1物件で月に30泊埋まると、$30です。
- 内蔵の料金自動調整は PRO+ ですが、米国・カナダ・豪州・メキシコ・英国・スペインだけで、日本は対象外です。

**Hospitable（公式、月額・米ドル）**

| プラン | 基本料金 | 含まれる物件 | 追加物件 |
|---|---|---|---|
| Essentials | $0 | 無制限（機能に制限あり） | なし |
| Host | $29 | 1（最大2物件） | $10/件 |
| Professional | $59 | 2 | $15/件 |
| Mogul | $99 | 3 | $30/件 |

- 5室で Professional なら、月$104です（公式の単価から計算）。
- 「稼働している物件」（請求期間中に1回以上チェックインがあった物件）だけが追加料金の対象です。

**5室の月額で比べると**：iGMS の PRO は約$99、Hospitable の Professional は約$104と、ほぼ同じ水準です（どちらも公式の単価からの計算。機能の範囲は違います）。

なお、Hospitable の比較ページには、「Hospitable は料金調整が全プランに含まれ、iGMS は外部連携に頼る」とあります。**競合の主張**なので、見積りや画面で確かめてください。

## 契約と解約

- **iGMS**：月払いは解約手数料なし（月の途中の返金なし）。10室未満の年払いは一括前払いで、**途中解約しても返金なし**。10室以上は年間契約です。口コミに、「解約の方法が分からず、サポートに強く頼まないと対応してもらえなかった」という低評価（2025年）があります。公式のヘルプは、解約の申請を営業日48時間以内に処理すると案内しています。
- **Hospitable**：月払いは契約も縛りもなく、当月末で終了。年払いは12か月で、トライアル開始から30日以内は全額返金、それ以降は返金なしです。

## 口コミ：どちらも「自動メッセージ」が好評

Capterra の海外レビュー（iGMS 114件、Hospitable 57件）を読んだ結果です。英語圏の運営者の声が中心で、日本の運営者の声ではありません。

| | iGMS | Hospitable |
|---|---|---|
| 良い点で多い話題 | 自動化・メッセージ（各約3割）、使いやすさ、連携 | 自動化（約3分の1）、使いやすさ、メッセージ |
| 改善点で多い話題 | 料金（約2割）、連携・同期、画面・アプリの重さ | 連携先の少なさ、メッセージ、料金 |
| 特徴的な低評価 | 解約できない、Airbnb の手動ブロックが接続後に消えた | 休日に問い合わせを閉じられた、古い料金の優遇が戻らなかった |

**iGMS は、画面やスマホアプリの重さ、Airbnb との接続で設定が変わる、という声**があります。接続前に、手動でブロックした日を控えておくと安心です。**Hospitable は、サポートの融通と、連携先の少なさ**が不満に挙がっています。

## 日本で使うときの注意（両社共通）

- **日本語**：iGMS の画面は英語とスペイン語（サポートも同じ）。ゲスト向けの自動メッセージは「109言語」と書かれていますが、日本語が含まれるかは確認できません。Hospitable の画面は英語のみで、ゲスト向けの定型は英・西・仏・独です（日本語の追加要望は「新規」のまま）。
- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーで、**両社が該当するかは確認できていません。**
- **楽天トラベル・じゃらん**：民泊新法・特区民泊の施設は、どちらも対象外です。両社とも、公式の連携先に楽天トラベル・じゃらんの記載がありません。
- **請求通貨**：どちらも円は確認できません。
- 年180日の管理、届出番号、定期報告、インボイスなどの機能は、**両社とも公式ページに記載が見つかりませんでした**（「できない」と確認したわけではありません）。

## 申し込む前に、両社へ聞く質問

1. 自分の物件数・稼働日数での、正確な月額（FLEX と PRO、Professional の損益分岐）。
2. 契約期間、年払いの返金条件、解約の手順。
3. 日本語のゲストに、自動メッセージが日本語で届くか。
4. 請求通貨は円にできるか。ドル請求なら、実質の手数料はいくらか。
5. 日本語で問い合わせできるか。人間のサポートの対応時間（時差）。
6. 私の営業形態で、Airbnb・Booking.com・楽天トラベル・じゃらんに接続できるか。
7. 今 Airbnb でブロックしている日や設定は、接続後に残るか。

## よくある質問

### iGMS と Hospitable の一番大きな違いは何ですか？
料金の払い方です。iGMS は泊数あたり$1の FLEX を選べて、稼働に応じて払えます。Hospitable は基本料金＋稼働物件の追加料金の固定的な形です。接続先は Hospitable に Agoda が入っています。

### 無料で使えるのはどちらですか？
どちらにも無料プランがあります。iGMS は予約5件・メッセージ10件まで、Hospitable は機能に制限があり、サポートはAIとコミュニティのみです。

### 5室だとどちらが安いですか？
公式の単価からの計算で、iGMS の PRO（月払い）は約$99、Hospitable の Professional は約$104と、ほぼ同じです。iGMS の FLEX は、稼働が低ければ安く、高ければ高くなります。

### 解約しやすいのはどちらですか？
どちらも月払いなら縛りがありません。iGMS の10室未満の年払いは返金がなく、口コミに解約の手順が分からなかったという低評価があります。Hospitable の年払いは、トライアル開始から30日以内なら返金されます。

### 日本語で使えるのはどちらですか？
どちらも、公式には日本語の管理画面もサポートも確認できませんでした。iGMS は英語とスペイン語、Hospitable は英語のみです。
