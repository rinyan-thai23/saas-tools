# 【民泊】Uplisting と Hospitable どっちがいい？料金・契約・口コミ・日本で使えるかを比較

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：小さく安く始めるなら Hospitable、都市部で複数物件を管理するなら Uplisting も候補

> - **1〜10室で、無料から試したい、月払いで縛られたくない → Hospitable。** 無料プラン（Essentials）と14日間のトライアル、月払いは縛りなし。
> - **都市部で複数物件を運営する → Uplisting も候補。** 公式の想定は「10〜300室以上」。ただし**料金はポンド建て**で、**契約条件が公式ページ同士で食い違って**います。
> - **契約の確認が必要なのは Uplisting。** 料金ページは「契約なし」、利用規約は「最低12か月・自動更新」です。
> - **口コミの低評価の割合**は、Uplisting が約7%（53件中4件）、Hospitable が約5%（57件中3件）。どちらも件数が少なく、目安です。
> - **日本語は、どちらも不向き。** 円での請求も、どちらも確認できません。

## 2つのツールの違い（早見表）

| | Uplisting | Hospitable |
|---|---|---|
| 得意なこと | 都市部の複数物件の運営、清掃スケジュール、ゲスト本人確認 | ゲストへのメッセージの自動化、AI返信 |
| 公式が想定する規模 | 10〜300室以上（数室の利用者もいる） | 1〜10室（11〜20室、21室以上は別枠） |
| 料金の通貨 | ポンド、ユーロ、ドル、豪ドル、NZドル、カナダドル | 米ドル中心（円の記載なし） |
| 無料プラン | なし | あり（Essentials） |
| 無料トライアル | 14日間・カード不要 | 14日間・カード不要 |
| 契約 | 料金ページは「契約なし」。規約は「最低12か月・自動更新」 | 月払いは縛りなし。年払いは30日以内なら返金 |
| 管理画面の言語 | 英語だけ（日本語の記載なし） | 英語のみ（公式に明記） |
| 口コミの低評価率 | 約7% | 約5% |

各ツールの詳しい情報は、[Uplisting の評判・口コミ](/articles/uplisting/)、[Hospitable の評判・口コミ](/articles/hospitable/)にまとめています。

## 料金：どちらも公開だが、数字の見方が違う

**Uplisting（公式、月額・ポンド）**

| プラン | 目安 |
|---|---|
| Independent Host（4物件まで） | 1室 £40、3室 £72。または、基本料金なしで予約額の3% |
| Operator | 5室 £90、10室 £160（最低月額£90）。10物件までは予約額の1.5%の従量もあり |
| Manager | 月£208〜（1物件£13〜） |

- 「物件ごとの単価」と「プランの最低月額」の高い方が請求されます。スマートロック連携、オーナー管理、本人確認、AIの無制限利用は、プランによって別料金です。
- 第三者の比較サイトには、「1物件$29」「月$100から」といった数字もあり、**公式の料金ページと合いません**。この記事は公式の料金表に合わせています。

**Hospitable（公式、月額・米ドル）**

| プラン | 基本料金 | 含まれる物件 | 追加物件 |
|---|---|---|---|
| Essentials | $0 | 無制限（機能に制限あり） | なし |
| Host | $29 | 1（最大2物件） | $10/件 |
| Professional | $59 | 2 | $15/件 |
| Mogul | $99 | 3 | $30/件 |

- 5室で Professional なら、月$104です（公式の単価から計算）。Uplisting の Operator の5室は£90です。**通貨が違い、機能の範囲も違う**ので、同じ土俵では比べられません。
- 「稼働している物件」だけが追加料金の対象です（季節営業には向きます）。

## 契約と解約：Uplisting は書面で確認を

- **Uplisting**：料金ページに「契約なし、解約の事前通知なし。月払いは毎月更新」とあります。一方、利用規約（2024年版）には「最低12か月」「期間の終わりに自動更新」とあり、**どちらが自分に当てはまるか確認できません**。契約から14日を過ぎた解約では、期間途中の返金はありません。
- **Hospitable**：月払いは契約も縛りもなく、当月末で終了。年払いは12か月で、トライアル開始から30日以内は全額返金、それ以降は返金なしです。

Uplisting は、**「月払いで最低期間なし」かどうかをメールで確認し、書面で残す**のが安全です。

## 口コミ：どちらも件数が少ない

Capterra の海外レビュー（Uplisting 53件、Hospitable 57件）を読んだ結果です。英語圏の運営者の声が中心で、日本の運営者の声ではありません。件数が少なく、傾向は目安です。

| | Uplisting | Hospitable |
|---|---|---|
| 良い点で多い話題 | 使いやすさ（約35%）、連携・同期、サポート | 自動化（約3分の1）、使いやすさ、メッセージ |
| 改善点で多い話題 | 連携・同期、サポート（時間外）、メッセージ | 連携先の少なさ、メッセージ、料金 |
| 特徴的な低評価 | 部屋を移すと全部の部屋が閉じる恐れ、スマホ対応の弱さ、「買収後、更新が放置されている」（1件の主張） | 休日に問い合わせを閉じられた、古い料金の優遇が戻らなかった |

**どちらも、サポートの融通への不満が出ています。** Uplisting は夜間・週末の連絡、電話窓口の有無（いちばん上のプランだけ）、Hospitable は最安プランのサポートがAIとコミュニティのみ、という点に注意してください。第三者の比較サイトには、両社の別サイトでの評価を並べたものもありますが、評価のばらつきが大きく、この記事では使いませんでした。

## 日本で使うときの注意（両社共通）

- **日本語**：Uplisting は公式サイトとヘルプが英語だけで、管理画面・ゲスト向けテンプレートの日本語も記載が見つかりません。Hospitable は管理画面が英語のみで、ゲスト向けの定型は英・西・仏・独です。
- **円の請求**：Uplisting は通貨の一覧に円がなく、Hospitable も円の記載が見つかりません。
- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。Uplisting は Airbnb の公式パートナーですが、**民泊新法の掲載が例外に当たるかは確認できていません。**
- **楽天トラベル・じゃらん**：民泊新法・特区民泊の施設は、どちらも対象外です。両社とも、公式の連携先に楽天トラベル・じゃらんの記載がありません。
- **Agoda**：Hospitable は接続先に入っています。Uplisting は記載がありません。
- 年180日の管理、届出番号、定期報告、インボイスなどの機能は、**両社とも公式ページに記載が見つかりませんでした**（「できない」と確認したわけではありません）。

## 申し込む前に、両社へ聞く質問

1. 自分の物件数・使いたい機能での、正確な月額（アドオン込み）。
2. 契約期間、自動更新、解約時の返金。Uplisting は「月払いで最低期間なし」かの書面確認。
3. 請求通貨は円にできるか。ポンドやドルなら、実質の手数料はいくらか。
4. 日本語で問い合わせできるか。サポートの対応時間（時差）。
5. 私の営業形態で、Airbnb・Booking.com・楽天トラベル・じゃらんに接続できるか。
6. 今使っているツールがある場合、データはどう引き継ぐか（Hospitable は自動移行なし）。
7. 日本語のゲストへの自動メッセージを、どう運用するか。

## よくある質問

### Uplisting と Hospitable の一番大きな違いは何ですか？
想定する規模と、契約の分かりやすさです。Hospitable は1〜10室の小さな運営向けで、無料プランがあり、月払いは縛りがありません。Uplisting は都市部の複数物件向けで、料金はポンド建て、契約条件が公式ページ同士で食い違っています。

### 無料で使えるのはどちらですか？
Hospitable に無料プラン（Essentials）があります。ただし機能に制限があります。Uplisting に無料プランはなく、14日間のトライアルのみです。

### 契約しやすいのはどちらですか？
Hospitable は月払いなら縛りがなく分かりやすいです。Uplisting は、料金ページの「契約なし」と規約の「最低12か月」が食い違うので、書面で確認してください。

### 日本語で使えるのはどちらですか？
どちらも、公式には日本語の管理画面もサポートも確認できませんでした。英語の画面で運用できるかを、トライアルで確かめてください。
