### 1. 注意：Lodgify のセルは公式本体ではなく「公開コピー」で確認したもの
- 記事：「この表の読み方」「特に書かない限り、すべて 2026-11-05 に公式ページ・公式ヘルプ・公式規約で確認した内容です」。Lodgify の各セルの（確認済）。
- カード：Lodgify 調査の前提：www.lodgify.com と help.lodgify.com は 403 で開けず、webflow-mkt.lodgify.com（マーケティングサイトの公開コピー）で代用。「www 側の同名ページと内容が同一かは未照合」。
- 問題：更新履歴の注記にはあるが、表のページには書かれていない。表だけを見る人は本体サイトで確認したと読む。
- 修正案：「この表の読み方」に「Lodgify は公式の公開コピーで確認（本体サイトとの一致は未照合）。詳細は更新履歴」と1行足す。

### 2. 軽微：Lodgify「期間途中の解約は返金なし」に、カードの消費者クーリングオフが落ちている
- 記事（節3）：「期間途中の解約は返金なし（確認済）」
- カード：Lodgify「返金（規約）」消費者には14日間のクーリングオフ（年払い・2年払いは更新時にも適用、月払いは初回のみ）。事業者として契約する場合の扱いは未確認。
- 修正案：「ただし消費者向けに14日間の取消しの記載あり。事業者の扱いは未確認」。

### 3. 軽微：補助ツールの説明「予約サイトに接続する製品ではない」が節7の PriceLabs の行と食い違って読める

- 修正案：「予約を受け付けるチャネルマネージャーではないため（PriceLabs は価格の送り先として連携、Hostfully Guidebooks は予約サイトに接続しない）」。
