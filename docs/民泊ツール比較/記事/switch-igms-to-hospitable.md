# 【民泊】iGMS から Hospitable へ乗り換える手順と注意点｜予約の取り込み・Vrbo・二重予約

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：iGMS の契約を確認し、Hospitable の「自動移行なし」を前提に進める

> - **iGMS が年払い（10室未満）なら、途中解約しても返金なし。** 年払いの終わりに合わせて乗り換えるのが、費用を抑える基本です。月払いは解約手数料なし（月の途中の返金はなし）。
> - **Hospitable は、他のツールからの自動データ移行がありません。** 予約は、手入力か CSV。CSV の取り込みは**サポートが実施**します（自分では実行できない、と公式のヘルプ）。
> - **現在・今後の予約は、予約サイトを接続すると同期で入る**と、Hospitable の移行ページにあります。直接予約・手動の予約が、手作業の対象です。
> - **Vrbo は付け替えの手続きが必要**。Vrbo に、新しいツールへの移行を依頼します。その予約の支払いは、旧ツールから受け取る形になります（Hospitable のヘルプ）。
> - **民泊新法の人は、先に Airbnb の扱いを確認。** どちらのツールも、民泊新法の掲載に対応できるか確認できていません。

## 乗り換える理由は、足りていますか？

iGMS の不満は、料金、画面・アプリの重さ、Airbnb 接続時の設定の消失、解約・返金です（低評価の割合は約3%）。Hospitable も、サポートの融通と連携先の少なさに不満があり、低評価の割合は約5%です。**似た自動メッセージ中心のツール同士**なので、乗り換えで解決する不満かを確認してください。理由別の選択肢は [iGMS の代替](/articles/alt-igms/) にまとめています。

## 乗り換えの流れ（8ステップ）

### 1. iGMS の契約を確認する
- 月払いか年払いか。年払いなら、更新日と返金の可否（10室未満は返金なし）。10室以上は年間契約で、途中で解約すると月払い料金との差額を請求されます。
- 解約は、ヘルプのリンクから申請し、営業日48時間以内に処理されます。口コミには「解約の方法が分からなかった」という低評価があります。申請の記録を残してください。

### 2. Hospitable のプランを決める
- Essentials は$0（機能に制限、サポートはAIとコミュニティのみ）。Host $29（最大2物件）、Professional $59＋追加$15/件、Mogul $99。
- 5室で Professional なら月$104（公式の単価から計算）。iGMS の PRO（5室で約$99）とほぼ同じ水準です。
- 14日間、カード不要で試せます。

### 3. iGMS のデータを書き出す
- 予約（過去・未来）、ゲスト情報、メッセージのテンプレート、清掃の指示、メモを書き出します。
- **iGMS のアカウント削除で、テンプレート・メモ・清掃指示も消えます**（iGMS のヘルプ）。先に控えてください。
- Airbnb で**手動でブロックした日、ルール、カレンダーの設定**を控えます。iGMS の口コミに、接続後に消えたという警告があります。

### 4. Hospitable に予約サイトを接続する
- 接続すると、現在・今後の予約が同期で入ります。接続の順番は、1つずつにします。
- **Vrbo は、Vrbo に移行を依頼します。** その予約の支払いは旧ツール（iGMS）から受け取る形になります。

### 5. 直接予約・手動の予約を入れる
- 少数なら手入力。大量なら CSV を作り、**Hospitable のサポートに依頼**して取り込んでもらいます。

### 6. 自動メッセージ・清掃・ロックを再設定する
- メッセージのテンプレートは作り直しです。日本語のゲスト向け定型は、Hospitable にありません（英・西・仏・独のみ）。
- 清掃のスタッフや共同ホストの招待、スマートロック（Akerun・SESAME は両社とも一覧にない）を再設定します。

### 7. 二重予約を防ぐ
- 切り替えの前に、近い日付の空室を手動で閉じるか、同期を一時停止します。
- 切り替え後、各予約サイトのカレンダーを自分の目で確認します。

### 8. iGMS を解約する
- 新しいツールで数日動作を確認してから、iGMS を解約します。**解約するとテンプレートやメモが消える**ので、書き出し済みか再確認します。

## 契約・料金の比較（乗り換える前に）

| | iGMS（今） | Hospitable（移行先） |
|---|---|---|
| 契約 | 月払いは縛りなし。10室未満の年払いは返金なし | 月払いは縛りなし。年払いは30日以内なら返金 |
| 料金 | 無料／FLEX（泊数あたり$1）／PRO 5室約$99 | Essentials $0／Professional 5室 $104 |
| 課金の対象 | FLEX は予約が入った物件のみ | 稼働物件（その期間にチェックインがあった物件、または料金調整をオンにした物件） |
| 管理画面の言語 | 英語・スペイン語 | 英語のみ |
| 接続先 | Airbnb・Vrbo・Booking.com | Airbnb・Vrbo・Booking.com・Agoda |
| データ移行 | 自動移行の機能は見つからず | 自動移行なし。CSV はサポートが取り込み |

なお、iGMS の公式比較ページには、「Hospitable は予約の有無に関わらず物件ごとの追加料金がかかる」とあります。Hospitable の公式は「稼働物件のみ」と説明しており、**競合の主張とは合いません**。見積りで確かめてください。

詳しくは [iGMS と Hospitable の比較](/articles/vs-igms-hospitable/) へ。

## 日本で乗り換えるときの注意

- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。**両社が該当するかは確認できていません。**
- **日本語**：iGMS の画面は英語とスペイン語、Hospitable は英語のみ。どちらも日本語のサポートは確認できません。
- **楽天トラベル・じゃらん**：民泊新法・特区民泊の施設は、どちらも対象外です。両社とも、公式の連携先に記載がありません。
- **請求通貨**：どちらも円は確認できません。
- 年180日の管理、届出番号などの機能は、両社とも公式ページに記載が見つかりませんでした。別の方法で管理する前提にしてください。

## 乗り換え前に、Hospitable へ聞く質問

1. 自分の物件数・稼働日数での、正確な月額（稼働物件の数え方）。
2. 年払いの返金条件（30日以内か）と、月払いからの切り替え。
3. CSV の取り込みをサポートに依頼する手順と、かかる日数。
4. Vrbo の移行の手順と、旧ツールからの支払いのタイミング。
5. 日本語のゲストへの自動メッセージを、どう運用するか。
6. 日本語で問い合わせできるか。人間のサポートの対応時間（時差）。
7. 私の営業形態で、Airbnb・Booking.com に接続できるか。

## よくある質問

### iGMS から Hospitable に、データは移せますか？
自動の移行機能はありません。現在・今後の予約は、予約サイトを接続すると同期で入ります。直接予約や手動の予約は、手入力か、CSV をサポートに依頼して取り込んでもらいます。

### iGMS の年払いは、途中で解約できますか？
10室未満の年払いは、一括前払いで、途中解約しても返金はありません。月払いは解約手数料がありません。10室以上は年間契約で、途中で解約すると月払い料金との差額を請求されます。

### 乗り換え中に二重予約を防ぐには？
近い日付の空室を手動で閉じる、同期を一時停止する、予約サイトを1つずつ切り替えて確認する、の3つが基本です。詳しくは [移行チェックリスト](/articles/switch-checklist-double-booking/) へ。

### 日本語で使えるのはどちらですか？
どちらも、公式には日本語の管理画面もサポートも確認できませんでした。
