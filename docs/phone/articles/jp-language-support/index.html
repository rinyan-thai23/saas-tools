【クラウド電話】日本語で使える？日本語の公式サイト・画面・サポートを製品別に整理

先に結論

  • 日本語の公式サイトがあることを確認できたのは、Dialpad と Zoom Phone です。 どちらも、日本語のページで、料金や番号の条件を読めます。
  • CallHippo は、日本向けの番号ページがありますが、ページ自体は英語でした。ページの中で「IVR・留守電・SMS は日本語に対応」「サポートは24時間」と案内しています（自社の主張）。
  • 管理画面とアプリの日本語表示は、どの製品も、公式の記載を確認できていません。 日本語のサイトがあることと、画面が日本語であることは、別です。
  • 日本語の窓口が必要なら、申込前に、日本語の画面を見せてもらい、サポートの対応時間を書面で確認してください。

誰のための記事か

英語が得意ではない、日本の小さな事業者です。「日本語で相談できるか」「画面は日本語か」「請求は円か」を知りたい人向けです。

よくある質問

日本語の画面で使えるクラウド電話は？

日本語の公式サイトを確認できたのは、Dialpad と Zoom Phone です。ただし、管理画面とアプリが日本語かどうかは、公式の記載を確認できていません。デモや無料トライアルで確認してください。

日本語のサポートはありますか？

Dialpad は、ソフトバンクのサポートが平日9:00〜17:00です。Zoom Phone は、有償の導入支援とプレミアサポートがあります。CallHippo は24時間と案内していますが、日本語の対応は確認できていません。

英語の製品を使うのは、不利ですか？

番号の条件を細かく公開している製品もあります（CloudTalk、CallHippo）。ただし、問い合わせや契約のトラブルのときに、英語で対応する必要が出ます。
