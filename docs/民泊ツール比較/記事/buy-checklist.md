# 【民泊】海外の管理ツールの申込前チェックリスト｜契約・料金・日本語・民泊新法の確認項目

この記事に広告リンク（アフィリエイト）はありません。

## 先に結論：最初に確認するのは「自分の営業形態で、つなげられるか」

> - **まず、営業形態**（住宅宿泊事業法／旅館業法／特区民泊）を決める。ここで、使える予約サイトとツールが変わります。
> - **民泊新法の人は、料金より先に Airbnb の扱いを確認。** Airbnb は、日本の民泊新法の宿で、ツール経由で作った掲載を受け付けません（例外は、Airbnb と契約した日本のAPIパートナー）。どのツールが例外に当たるか、今回は確認できていません。
> - **次に契約。** 自動更新・解約の期限・返金・値上げの条件を、**書面で**。公式ページの「縛りなし」だけで判断しない。
> - **日本語・日本時間のサポートは、ほぼ期待できない**前提で、英語の画面で運用できるかをトライアルで試す。
> - **年180日の管理、届出番号などは、ツールの機能が見つからなかった**ため、別の方法で管理する前提にする。

以下のチェックリストは、そのまま問い合わせメールに使えます。

## A. 営業形態と予約サイト（最優先）

- [ ] 自分の営業形態を決めた（住宅宿泊事業法／旅館業法／特区民泊）
- [ ] **民泊新法の人**：Airbnb に「このツールで、私の掲載（既存の掲載を含む）をつなげられるか」を確認した
- [ ] 出したい予約サイトが、自分の営業形態を受け付けるか確認した（楽天トラベル・じゃらんは、民泊新法・特区民泊を対象外と明記。民泊を楽天トラベルに出す窓口は Rakuten Oyado）
- [ ] ツールが、使いたい予約サイト（Airbnb・Booking.com・Vrbo・Agoda など）に**直接つなげられる**か、公式の一覧で確認した
- [ ] iCal（カレンダーの取り込み）だけの接続は、更新が遅く、二重予約のリスクがあると理解した
- [ ] 旅館業法の許可施設の人：楽天トラベル・じゃらんにつなげられるか、ツールに直接聞いた（Beds24 の日本の販売会社以外は、公式に記載が見つからなかった）

詳しくは [楽天トラベル・じゃらん等の国内予約サイト連携](/articles/jp-ota-rakuten-jalan/) へ。

## B. 料金

- [ ] 自分の**物件数・使いたい機能**での、正確な月額を、**書面で**受け取った
- [ ] 初期費用・オンボーディング費用・有料アドオン（スマートロック、AI、独自ドメインなど）の内訳を確認した
- [ ] **請求通貨**：円にできるか。ドルなら、為替の実質の手数料（Guesty の口コミ：手数料1%が実質1.6%）
- [ ] 予約手数料と、決済会社の手数料の両方を確認した（Lodgify は決済に別途1%、Hospitable の直接予約は4%＋3%など）
- [ ] 物件が増えたときの、上位プランの金額を確認した
- [ ] 稼働物件の数え方（Hospitable は、チェックインがあった物件、または料金調整をオンにした物件）を確認した

詳しくは [物件数別の料金早見表](/articles/buy-price-by-listings/)、[直接予約の手数料・決済](/articles/buy-direct-booking-fees/) へ。

## C. 契約・解約

- [ ] 最低契約期間（Guesty の Pro は最初の13か月）
- [ ] **自動更新**の有無、更新日の通知の有無（Lodgify は通知なし）、解約の期限（何日前か）
- [ ] 解約の方法（ボタンか、メールか。受け付けの記録は残るか）
- [ ] 途中解約の費用、返金の可否（OwnerRez は未使用期間の返金なし、iGMS の10室未満の年払いは返金なし）
- [ ] 値上げの通知の日数と、同意しない場合の解約（Hostaway は14日前通知、同意しなければ発効の5日前までに通知して解約）
- [ ] 公式ページと規約・契約書の記載が**食い違っていないか**（Uplisting は、料金ページ「契約なし」、規約「最低12か月」）
- [ ] 契約書の記載が公式ページより優先されることを理解した（Guesty）
- [ ] カレンダーに、更新日の1週間前を入れた

詳しくは [最低契約・解約条件](/articles/buy-contract-cancel/) へ。

## D. 日本語・サポート

- [ ] 管理画面の言語（日本語はあるか。Beds24 の日本の販売会社以外は、公式に確認できなかった）
- [ ] サポートの**対応言語**と、**日本時間での対応時間**、窓口（電話・チャット・メール）。プランによる違い（Lodgify は電話が Professional 以上、チャットは Ultimate のみ）
- [ ] 応答の目安（Uplisting は2時間／1時間／45分）
- [ ] 緊急時（二重予約、接続切れ）の連絡先
- [ ] ゲスト向けの自動メッセージ・予約サイトを**日本語**にできるか（Hospitable の定型は英・西・仏・独、Sirvoy の予約画面は日本語を含む31言語、Beds24 の予約ページも日本語を含む）
- [ ] 英語の画面で、自分とスタッフが運用できるか、トライアルで試した

詳しくは [日本語UI・日本語サポート](/articles/jp-japanese-ui-support/)、[サポート時間（日本時間）](/articles/buy-support-hours-jst/) へ。

## E. 機能（運営の自動化）

- [ ] 二重予約の防止（接続後に、テスト予約で、ほかのサイトが閉じるか）
- [ ] ゲストへの自動メッセージ（タイミング、テンプレート、翻訳、重複しないか）
- [ ] 清掃タスクの自動作成（予約に連動するか）。清掃スタッフの権限
- [ ] スマートロック（Akerun・SESAME などの日本製は、調べた範囲でどのツールの一覧にもなかった）
- [ ] 料金の自動調整（PriceLabs などの外部ツールとの連携。内蔵の機能は、国が限られる場合がある）
- [ ] 直接予約サイトが必要か。必要なら、表示言語と決済手段

## F. 日本の制度（ツールで管理できるか）

次は、**今回調べたどのツールも、公式ページに機能の記載が見つかりませんでした**（「できない」と確認したわけではありません）。各社に聞くか、別の方法で管理してください。

- [ ] **年180日**の上限の管理（届出住宅ごと）
- [ ] **届出番号**の表示（標識、予約サイトでの表示）。Airbnb は、ツールを使っていても、自分でログインして追加する必要がある、と案内
- [ ] **定期報告**（2か月ごと）
- [ ] **宿泊者名簿**（外国人宿泊者の国籍・旅券番号の記載、旅券の写しの保存、作成から3年間の保存）
- [ ] **適格請求書（インボイス）**への対応

詳しくは [住宅宿泊事業法への対応](/articles/jp-minpaku-law/)、[宿泊者名簿・本人確認](/articles/jp-guest-register/)、[円請求・インボイス](/articles/jp-yen-invoice/) へ。

## G. データ・個人情報

- [ ] ゲストの氏名・旅券情報などの**保管場所**（海外のサーバーか）と、アクセス権限の管理
- [ ] 解約後の**データの書き出し**と、いつまでアクセスできるか（Guesty は止めるとアクセスできなくなる、という指摘）
- [ ] 契約主体（Guesty：米国、Lodgify：英国、Hostaway：フィンランド、Hospitable：オランダ、OwnerRez：米国、Uplisting：英国、Beds24：ドイツ）と準拠法

## H. 導入・移行

- [ ] 導入支援（オンボーディング）の範囲と費用、言語
- [ ] 今のツールからの**データ移行**の方法（Hospitable は自動移行なし、OwnerRez は代行なし）
- [ ] 切り替えの手順と、二重予約の防ぎ方。Airbnb の手動ブロックが消えないか（iGMS の口コミ）
- [ ] 今のツールの契約の更新日・解約の期限

詳しくは [移行チェックリスト（二重予約の防ぎ方）](/articles/switch-checklist-double-booking/) へ。

## I. トライアル

- [ ] 無料トライアルの期間と、カード登録の要否（[無料トライアル比較](/articles/buy-free-trial/)）
- [ ] トライアル中に、**実際の物件で**接続、テスト予約、問い合わせまで試した
- [ ] トライアル後の自動課金の開始日と、止め方（PriceLabs の口コミ：自動で有料に切り替わった）

## よくある質問

### 最初に確認すべきことは？
自分の営業形態と、Airbnb への接続の可否です。民泊新法の人は、Airbnb がツール経由の掲載を受け付けない場合があるため、料金より先に確認してください。

### 書面で確認する、とはどういうことですか？
メールなど、記録に残る形で、質問と回答を残すことです。公式ページや営業の口頭の説明は、契約書の記載と違うことがあります（口コミに、営業の説明と導入後が違ったという低評価があります）。

### 日本の制度に対応したツールはありますか？
今回調べた範囲では、年180日の管理、届出番号、定期報告、宿泊者名簿、インボイスの機能は、どのツールの公式ページにも記載が見つかりませんでした。別の方法で管理する前提にしてください。

### 英語が不安でも使えますか？
トライアルで、実際に画面とサポートを試してください。日本語で相談できるのは、Beds24 の日本の販売会社版が確認できる範囲です。
