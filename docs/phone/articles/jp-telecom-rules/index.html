【クラウド電話】電気通信の決まりを総務省の資料で確認

先に結論

  • この記事は、総務省の公式資料を引用して整理したものです。 ほかの解説サイトは使っていません（各社の案内は、例として挙げた箇所だけです）。法律の判断はしていません（どの製品が決まりに当たるか、適法か、は書きません）。
  • 総務省は、外国の会社が日本向けに電気通信サービスを提供する場合の考え方を公表しています。 日本語での提供、円での決済、日本向けの販売促進などが、日本向けの意図を示す例として挙げられています。
  • 番号、050の本人確認、固定電話の番号ポータビリティにも、総務省の資料があります。
  • 事業者として確認したいことは、最後の「聞くこと」にまとめました。

誰のための記事か

海外のクラウド電話を日本で使う小さな事業者が、「国の決まりとして、どんなものがあるか」を、公式の資料で一度見ておきたい場合に使います。

1. 外国の会社が日本向けに提供するとき（電気通信事業法の考え方）

総務省の学術雑誌『情報通信政策研究』の立案担当者解説（令和3年9月掲載）には、総務省が令和3年2月12日に公表した「外国法人等が電気通信事業を営む場合における電気通信事業法の適用に関する考え方」が、次のように紹介されています。

  • 令和2年5月22日公布の改正法（令和3年4月1日施行）で、外国法人等が電気通信事業を営む場合の規定が整備された。
  • 電気通信事業法は、①外国法人等が日本国内で電気通信役務を提供する場合のほか、②外国から日本国内にある者に対して電気通信役務を提供する場合にも適用される。
  • ②について、国内向けにサービスを提供する意図が明らかかどうかを基準とし、外形的な事実の例として、(1)サービスが日本語で提供されていること（画面の言語のほか、日本語の契約書類・約款、日本語のサポートも例）、(2)有料サービスの決済通貨に日本円があること、(3)国内向けの広告や販売促進を行っていること、が挙げられている。ただし、実際に国内向けサービスに当たるかは、個別具体的な事例で判断する、とされている。
  • 外国法人等が電気通信事業を営もうとする場合は、登録（第9条）又は届出（第16条第1項）が必要（一部を除く）。電気通信回線設備を日本国内に設置せずに事業を営む場合は、登録ではなく届出。
  • 登録又は届出の際は、国内における代表者又は国内に住所を有する者（国内代表者等）の指定が必要。
  • 法令等に違反した者の氏名等を、公表する制度もある。

この記事では、特定の製品がこれらに当たるかは判断しません。 解説の筆者の意見にわたる部分は、筆者の個人的見解、と同資料に書かれています。

申込前に、事業者へ聞けること

  1. 日本で提供するサービスについて、電気通信事業法に基づく登録・届出をしているか。（している場合、届出の番号や、国内の連絡先）
  2. 契約の相手は誰か（日本の会社か、海外の会社か）。契約書・約款は日本語か。
  3. 日本の窓口と、問い合わせの方法。

2. 番号の決まり（電気通信番号制度）

総務省の「電気通信番号制度」のページ（電気通信番号指定状況は令和8年10月1日時点）では、番号の区分を次のように示しています。

  • 固定電話番号（0AB〜J）、特定IP電話番号（050）、付加的役務電話番号（0120・0800、0570など）、緊急通報番号（110・118・119）、携帯電話の番号など。
  • 0120・0800は、通話料を着信者が支払う番号（総務省のQ&A）。

詳しくは、日本の電話番号の取り方と審査へ。

3. 050の本人確認

総務省は、令和5年6月28日から7月31日まで、「携帯音声通信事業者による契約者等の本人確認等及び携帯音声通信役務の不正な利用の防止に関する法律施行規則」の一部を改正する省令案の意見募集を行いました。意見募集のページには、次の趣旨が書かれています。

  • 特定IP電話番号（050）を使った通話を可能にするアプリ（いわゆる050アプリ電話）による特殊詐欺が多く発生している。
  • 政府の対策パッケージ（令和5年3月17日）を受け、050アプリ電話についても、役務提供契約を結ぶときの本人確認の対象にする、省令の改正を行う。

今回、この省令の公布・施行日の一次資料は確認できていません。 実際の本人確認の手続きは、各社の案内を見てください（例：ソフトバンクのFAQ（Dialpad）には、2024年4月以降、新しい050の払い出しに本人確認が必要、とあります）。

4. 固定電話の番号ポータビリティ

総務省の「固定電話の番号ポータビリティ」のページには、次のように書かれています。

  • 利用者が固定電話番号を変更することなく、固定電話サービスの提供会社を変更できる仕組み。手続きは、これから契約する会社に申し込むだけ。
  • 電気通信番号計画（令和元年総務省告示第6号）に基づき、令和7年1月末日以降、固定電話番号を使ったサービスを提供する全ての事業者は、原則としてポータビリティを可能とする必要がある。例外あり。
  • 変更前の会社との契約は解約となり、費用・残債・ネット回線の扱いなどに注意が必要。

5. 緊急通報

総務省の情報通信白書（平成21年版）は、050型IP電話は緊急通報（110、119等）を利用できない点がある、0AB〜J型IP電話は緊急通報を利用できるなどの特徴がある、と説明しています（2009年の記述）。各製品の今の扱いは、各社の公式の記載を見てください。詳しくは、110・119にかけられる？へ。

事業者として、書面で確認すること

  1. 電気通信事業法に基づく届出の有無と、国内の連絡先。
  2. 契約の相手と、契約書・約款の言語。
  3. 本人確認の手続き（050、0AB-J）。必要書類は。
  4. 番号ポータビリティに対応しているか。条件・費用・日数は。
  5. 緊急通報の扱い。
  6. トラブルのときの窓口（日本時間）。

よくある質問

海外のクラウド電話を、日本で使うのは問題ありませんか？

この記事では判断しません。総務省は、外国から日本国内にいる人にサービスを提供する場合も電気通信事業法が適用される、とする考え方を公表しています。個別の製品が当たるかは、専門家か総務省の窓口に確認してください。

「日本語対応」と「日本向けサービス」は同じですか？

総務省の解説では、日本語での提供、円の決済、国内向けの販売促進は、国内向けの意図を示す外形的な例とされています。実際の判断は、個別具体的な事例ごとです。

どこに相談できますか？

総務省の電気通信消費者情報コーナー（固定電話番号ポータビリティの相談窓口として、総務省のページに案内があります）や、各自治体の消費生活センターなどに相談できます。
