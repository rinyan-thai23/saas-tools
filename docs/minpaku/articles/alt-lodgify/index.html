【民泊】Lodgify の代替・乗り換え先｜理由別に選ぶ6つのツール

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

先に結論：Lodgify をやめたい「理由」で、代わりが変わります

  • 同期・接続の不満 → Hostaway、Guesty、OwnerRez。 ただしこの3つも、接続の不満が口コミに出ます。トライアルで接続を試すのが先です。
  • 自動更新が不安 → OwnerRez（縛りなし）、Hospitable（月払いは縛りなし）。
  • 予約サイトの見た目は妥協できる、運営の自動化がほしい → Hospitable、iGMS。
  • 日本語・国内の予約サイトがほしい → Beds24（日本の販売会社経由）。
  • 自分の予約サイトが目的なら、Lodgify は依然として有力。 第三者の比較でも、直接予約サイトの作りやすさは高めです。
  • どれも、日本語は期待薄です。 Lodgify も日本語の画面・サポートは確認できていません。

Capterra の海外レビュー約190件で、Lodgify の1〜2点は14件（約7%）でした。日本語の口コミは見つかっていません。

理由別の詳しい選び方

同期・接続の安定を重視したい

Lodgify の不満の中心は同期・接続です。ただし代替の候補も、接続の不満が口コミに出ます（Guesty は接続トラブル、iGMS は Airbnb 接続時の設定消失、Hospitable は一部機能の不具合）。無料トライアルで、実際に使う予約サイトを接続して確かめてください。

自動更新・返金が不安

  • OwnerRez：契約縛りなし。ただし未使用期間の返金はありません。
  • Hospitable：月払いは縛りなし。年払いは12か月で、トライアル開始から30日以内は全額返金。
  • iGMS：月払いは解約手数料なし。10室未満の年払いは返金なし。

自分の予約サイトを持ちたい（Lodgify の強みを残したい）

  • 代替で同じことができるツールは、今回調べた範囲では見つかっていません。OwnerRez は独自ドメインの予約サイトが別料金のプレミアム機能、Hospitable は Professional 以上、Beds24 は予約エンジンが含まれますが、デザインは簡素という声があります。

日本語・国内の予約サイトがほしい

  • Beds24：日本の販売会社（株式会社WeIns）経由で、日本語の画面・サポート、楽天トラベル・じゃらんなどの連携（旅館業法の許可施設）。民泊新法・特区民泊は、じゃらんは対象外です。

乗り換えの前に（Lodgify から移るとき）

  1. 自動更新の日付を確認する：更新の通知が来ません。解約はアカウント画面から期間終了の1日前、メールなら5日前まで。期間途中の返金はありません。
  2. 新しいツールを先に準備する：今のツールをすぐ止めず、並行して準備。
  3. 予約と接続の移し方を決める：既存の予約は、手入力か CSV になる場合があります（Hospitable は自動移行なし、OwnerRez は代行なし）。
  4. 予約サイトのドメインと設定：Lodgify で作った予約サイトと独自ドメインの扱いを、先に決めておく。
  5. Airbnb の接続の扱い：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。どの代替ツールも該当するか確認できていないため、申込前に Airbnb と各社に確認してください。

日本で使うときの注意（代替先すべて共通）

  • 日本語：Beds24（日本の販売会社経由）以外は、公式に日本語の管理画面・サポートを確認できません。
  • 楽天トラベル・じゃらん：民泊新法・特区民泊の施設は、どちらも対象外です。
  • 年180日の管理、届出番号、定期報告、インボイスなどの機能は、各ツールの公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。

よくある質問

Lodgify の代わりに、一番おすすめなのはどれですか？

理由によって変わります。自動更新と契約が不安なら OwnerRez や Hospitable、導入支援や運営の自動化なら Hostaway、日本語や国内の予約サイトなら Beds24（日本の販売会社経由）です。

Lodgify を解約するときの注意は？

更新の通知なしに前払いの期間が自動更新されます。解約は、アカウント画面なら期間終了の1日前、メールなら5日前までです。期間の途中で解約しても、返金はありません。

Lodgify の予約サイトは、乗り換え先に移せますか？

今回調べた範囲では、移行の手順は確認できませんでした。予約サイトの作り直しが必要になる可能性があります。乗り換え先に、予約サイトと独自ドメインの扱いを確認してください。

日本語で使える代わりのツールはありますか？

Beds24 の日本の販売会社（株式会社WeIns）版が、日本語の画面とサポートを提供しています。そのほかは、公式には確認できませんでした。
