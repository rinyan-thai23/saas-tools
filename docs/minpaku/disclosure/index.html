広告表示と運営方針

本サイトには広告（アフィリエイトリンク）が含まれます。どのリンクが広告か、広告があっても内容をどう守っているかを、このページに書いています。

広告（PR）の表示

  • 本サイトの記事には、各社の申込ページへのアフィリエイトリンクを含むものがあります。リンク経由でツールが申し込まれた場合、運営者が各社から紹介報酬を受け取ることがあります。
  • 広告リンクは、すべて /go/ から始まるリンクです。 /go/ から始まらないリンク（本サイト内の他のページへのリンクなど）は広告ではありません。
  • 広告リンクを含む記事は、冒頭に「この記事にはアフィリエイトリンク（PR）が含まれます」と書きます。リンクの文言にも、原則として「（PR）」を付けるか、「申し込みページ（PR）」の見出しの下に置きます。
  • 報酬が発生する条件や仕組みは、会社ごとに違います（紹介リンクの有効期間、一定期間の利用継続が条件、利用料の一定割合が一定期間続く、など）。各社の公式ページに書かれた内容は、本サイトの調査記録に残しています。
  • Beds24 については、本サイトの紹介リンクは海外公式（beds24.com）側の紹介の仕組みに基づきます（記事では「Beds24（海外公式。PRリンク）」と書きます）。日本の販売会社（株式会社WeIns / Co-Reception）にはリンクを付けておらず、同じ紹介の仕組みがあるかも確認できていません。日本語UI・日本語サポート・円建てなどは日本の販売会社版の情報で、その申込は海外公式のリンクとは別です。円建て・日本語サポートの契約を希望する場合は、申込画面がどちらの窓口かを確かめてください。

運営方針：リンクの有無や報酬で内容を変えません

  • ツールの順番や書き方、良い点・悪い点の扱いは、広告リンクの有無や報酬の多寡では決めません。
  • 広告リンクのあるツールでも、価格が公開されていない、契約期間が長い、日本語の記載が見つからない、といった不利な事実は省きません。
  • 広告リンクのない Sirvoy と Hostfully Guidebooks も、他のツールと同じ手順（公式ページの確認→調査記録→記事）で書きます。
  • 「このツールが一番」という書き方はしません。条件ごとに「この条件ならこちらを先に確認する」と書きます。
  • 買う直前・乗り換え・比較の記事だけを扱います。民泊の始め方や収益の一般論は扱いません。
根拠を見る（情報源と取得日）

情報源と取得日

  • 料金・仕様・契約条件は、各社の公式の料金ページ・公式ヘルプ・利用規約を開いて確認します。確認した日は 2026-11-05 です。この日付は記事に書き、調査記録の各行にも付けています。
  • 確度は3つに分けて書きます。
  • 確認済：公式ページ・公式規約を開いて確認した
  • 第三者のみ：公式を開けず、第三者の情報だけで見た
  • 未確認：確かめられていない
  • 公式ページに書かれていなかったことは「公式に記載が見つからなかった」と書きます。「できない」「非対応」とは書きません。調べていない項目は「今回は調べていない（未調査）」と書き、「ない」とは区別します。
  • Lodgify のように公式サイトの本体を開けず、公式の公開コピーで確認した製品は、記事の中でその旨を書いています。
  • 公式が合計額を載せていないものは、単価表からの計算値だと明記します。各社が自分のページで書いている評価・実績は「自社の主張」と書きます。
  • Capterra の評価・口コミ数は、「海外レビュー（Capterra、2026-11-03時点）」と明記して使います。英語圏のレビューで、日本の運営者の実感ではありません。
  • 民泊の法令は、観光庁・自治体など一次資料だけを使います。本サイトは法律・税務の助言ではなく、法的な判断もしません。
  • 料金や仕様は変わります。申込前に、必ず公式ページで再確認してください。
  • 本サイトは各社の公式サイトではなく、各社の公式の見解を示すものでもありません。

記事の作り方

記事は、調べる役・書く役・照合する役を分けて作ります。

  1. 調べる役が、公式ページ等で確認した事実を「調査記録」に残します（出典URL・取得日・確度つき）。
  2. 書く役は、調査記録の内容だけを材料に記事を書きます。記録にない事実は書かず、「未確認」と書きます。
  3. 照合する役が、記事の主張を調査記録と突き合わせ、合わないものを差し戻します。

誤りの連絡と訂正

  • 料金・仕様・契約条件・日本対応について、記載の誤りや古くなった点にお気づきの場合は、下記の連絡先までお知らせください。
  • 連絡先：【公開前に必須・未記入】ここに連絡先を記入してください。未記入のまま公開しないでください
  • 誤りが確認できた場合は、該当の記事・表を訂正し、更新履歴 に記録します。
  • お知らせいただく際は、該当ページ、誤りだと思う箇所、根拠となる公式ページの URL をいただけると、確認が早くなります。
