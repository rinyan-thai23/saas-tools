## 学び・次回気をつけること
- （解決済み #3）**Pages のURL問題**：公開すると `https://<user>.github.io/saas-tools/民泊ツール比較/出力/` になる。
  本文リンクが `/articles/...` の絶対パスなので、このままだと**リンクが全部切れる**。
  対策案：(a) 独自ドメインを使う (b) ビルド時に base パスを付ける (c) `出力/` の中身を docs 直下へ出す。
- 日本語フォルダ名はURLが長いエンコードになる。公開側は英語名が無難（要検討）。
- 警告「disclosure に未設定」は運営者情報が未記入のため（人が決める事項）。

### 2026-11-07 #4 記事リライト試作（vs-guesty-hostaway）
- 直した型：①結論は「あなたが〜なら◯◯」 ②調査の言い回し（「確認できました／見つかりませんでした」）を減らし、1節に1回だけ注意書き ③確度タグ【確認済】等を本文から削除 ④「申込前に聞く質問」をコピペ可能な形に ⑤表は「状況→おすすめ」へ ⑥長い機能表は要点だけに圧縮。
- 29.7KB → 約半分。事実は変えていない（出典・取得日は残した）。
- 学び：①事実カードを渡すだけだと「報告書調」になる。ライター指示に「読者は申込直前の運営者。先輩の助言として書く」を足す必要あり。②「未確認」は消さず「問い合わせる質問」に変える。
- 次：読んで良ければ、同じ型を他の記事へ（指示書を `_作り方/プロンプト雛形.md` に反映してから）。
