先に結論

  • 月額だけで比べないでください。 最低人数、日本の番号の費用、通話料が別になる製品が多いです。
  • 1人で使うなら、最低ライセンスの数で順位が変わります。 Aircall は最低3、CallHippo と JustCall は最低2です（下の計算）。
  • 円で料金表を確認できたのは、Dialpad と Zoom Phone だけです。ほかはドル・ユーロの表示なので、為替と請求書の形式も確認してください。
  • 確認日 2026-11-07。料金は変わります。 申込前に、公式の最新を見てください。

月額に含まれないもの

  • 通話料：Dialpad は従量（050宛 ¥8／3分、固定宛 ¥7.9／3分、携帯宛 ¥16／分。読み取りに不確かさあり）。Zoom Phone は、かけ放題なら国内の発信が0円。CallHippo・Aircall の「無制限」は、米国・カナダ宛のみ。
  • ユニバーサルサービス料：Dialpad Air 0AB-J は、1番号 月2.2円（ソフトバンクの公表）。
  • AIオプション：Aircall の AI Assist Pro は月$49／ユーザー（別売）、CallHippo の AI Voice Agent は月$45／エージェント＋通話料 など。
  • 国際通話・SMS：Aircall は、月ごとの利用額で請求。
  • 契約の縛り：CloudTalk は前払い・返金なし。Aircall は年契約だと、途中でライセンスを減らせない場合がある。Dialpad（ソフトバンク）は日割りなし。

詳しくは、通話料・円・インボイスの確認ポイントへ。

よくある質問

一番安いのはどれですか？

ライセンス費用だけなら、1人で円のものは Dialpad Standard（¥1,000）、ドルでは Nextiva Core（$15）です。ただし、日本の番号の費用と通話料が別なので、総額は見積もりで比べてください。

料金は変わりますか？

変わります。CallHippo は、日本向けページと料金ページで、Starter の月額が違いました（$19／$18）。申込前に、公式の最新を確認してください。
