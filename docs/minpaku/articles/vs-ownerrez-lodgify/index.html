OwnerRez と Lodgify を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

結論

  • 物件数別の料金表が公式ヘルプに載っているのは OwnerRez です（3室で月$70、10室で月$127【計算値】、ただし機能の追加で上がる）。Lodgify は1物件の価格しか確認できず、3室以上は未確認です。
  • 日本語は、どちらも管理画面で確認できませんでした。OwnerRez の画面言語の一覧に日本語はなく、Lodgify は公式サイトに日本語ページがありません。
  • 楽天トラベル・じゃらんは、どちらの公式ページにも記載が見つかりませんでした（「接続できない」と確認したわけではありません）。

先に知っておくこと

営業形態によって、載せられる予約サイトが変わります。予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

予約サイト 公式に書かれている条件
楽天トラベル 旅館業の営業許可が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は Rakuten Oyado で登録、と案内
じゃらんnet 旅館業の宿泊営業許可が対象。民泊新法・特区民泊は「ご参画いただけません」
Airbnb ヘルプ：日本の民泊新法の宿は、ソフト連携で作成したリスティングを受け付けない。例外は Airbnb とライセンス契約した日本のAPIパートナー（名前は公式ページで見つからず）。届出番号は自分でログインして追加する必要がある
  • Rakuten Oyado が「そのまま使える」とする既存ツールは、ねっぱん、AirHost、Beds24、suitebook です。OwnerRez と Lodgify の名前はありません。
  • 制度側には、外国人宿泊者の国籍・旅券番号の記載と旅券の写しの保存、年180日の上限、2か月ごとの定期報告があります（観光庁・e-Gov）。両社とも対応する機能の記載は公式ページで見つかりませんでした。適格請求書も同様です。

条件別の選び方

  • 3〜10室で、公式の料金表から総額を計算したい人は OwnerRez。 ただし、サイト作成・精算・SMS などを足すと上がります。Lodgify の3室以上の金額は確認できていません。
  • 日本語の画面を前提にする人： どちらも確認できません。英語の画面で運用できるか、トライアルで試してください。
  • ダイレクト予約サイトを手早く作りたい人： Lodgify は Starter 以上でノーコードの作成機能があります。ただし円での表示・決済は確認できていません。
  • 契約を軽くしたい人： OwnerRez は縛りなし・未使用の返金なし。Lodgify は料金ページが「長期契約なし」、規約は自動更新で更新前の通知なしと、書き方が分かれています（実際の運用は未確認）。
  • 楽天トラベル・じゃらんが必須の人： この2製品では確認できませんでした。民泊新法・特区民泊は両サイトとも対象外と明記しています。旅館業の許可施設への接続可否は、どちらも未確認です。
