## 指摘

### 1. 注意：タイトル・description の「日本語非対応」が Guesty の画面言語の確度を超えている
- 記事（title）：「Guesty の代替ツール｜契約縛り・価格非公開・日本語非対応から選ぶ5候補」。description にも「日本語非対応」。
- カード：Guesty 5章 管理画面の日本語は、2019年の公式ブログ（確認済）と現行は検索抜粋（第三者のみ）で、日本語なし。サポート言語（English、Spanish、French、Italian、German、Hebrew、Portuguese）は公式で確認済。ヘルプ抜粋では、日本語は予約エンジンとリスティング内容では対応（第三者のみ）。
- 問題：タイトルは断定だが、画面の日本語は「記載なし／現行は第三者のみ」。本文の記述（「日本語UIの記載なし」）と強さが違う。
- 修正案：「日本語サポートなし」または「日本語UIの記載なし」とし、本文の言い方に合わせる。

### 2. 注意：結論3「どの候補も…専用機能は公式ページに記載が見つからなかった」と Beds24 のカードがずれる
- 記事（結論）：「どの候補も、住宅宿泊事業法の届出番号・年180日の専用機能は公式ページに記載が見つからなかった。」
- カード：Beds24 5章 住宅宿泊事業法に関する機能。日本の販売会社の「count-180days-automatically」という解説記事の URL はあるが内容は開いていない（本体機能は未確認）。申込フォームに許可種別の項目あり。
- 問題：「見つからなかった」ではなく「URL はあるが未確認」。本文（先に知っておくこと）はシートの存在を書いているが、結論は「どの候補も」と言い切っている。
- 修正案：「Beds24 は年180日の解説記事の存在は見つけたが、本体機能かは未確認。ほかは記載が見つからなかった」とする。

### 3. 注意：Hostaway の日本対応を「Guesty と同様」としている
- 記事（Hostaway の節）：「日本対応は Guesty と同様で、日本語UI・サポート言語・JPY・楽天トラベル／じゃらんのいずれも公式ページに記載が見つからなかった。」
- カード：Guesty のサポート言語は公式で日本語なしと確認済（5章）。Hostaway のサポート言語は「対応言語の記載は確認できず」（未確認）、管理画面は第三者のみ。Guesty には Agoda の公式掲載があるが、Hostaway は公式の一覧になく未確認。
- 問題：確度の違うものを「同様」とまとめている。
- 修正案：「どちらも日本語UI・JPY・楽天／じゃらんの記載は見つからない。サポート言語は Guesty が日本語なしと確認済、Hostaway は記載なし（未確認）」とする。

### 4. 注意：「Guesty に近い機能の幅」「Guesty 同等」はカードにない比較
- 記事（条件別）：「Guesty に近い機能の幅（オーナー向け明細など）が必要｜Hostaway／Hospitable（Mogul）／iGMS（PRO 以上）」
- 記事（Hostaway）：「向く人：機能の幅（オーナーポータル、内蔵の価格機能など）を Guesty 同等で見たく」
- カード：各カードに Guesty との機能比較はない。Guesty 4章 オーナーポータルは Pro 以上（Lite は対象外）。OwnerRez はポータルが基本料金内（4章）だがこの行に出てこない。
- 修正案：「オーナーポータル・明細が必要」とし、「Guesty に近い／同等」の表現を外す。OwnerRez も並べる。

### 5. 注意：Beds24 を「日本の販売会社経由」として推薦しつつ、PR リンクは公式側の可能性がある
- 記事（結論）：「日本語UI・円建て請求・楽天トラベル／じゃらん連携を公式ページで確認できたのは、今回調べたPMSのうち [Beds24](/go/beds24/)（日本の販売会社経由）だけ。」
- 関連：vs-beds24-lodgify は「Beds24 の PR リンクは、海外の公式側の入口です。日本の販売会社には PR リンクを付けておらず」と書く。本記事末尾のコメントは遷移先を未確認としている。
- 問題：日本語・円・国内サイトの利点は WeIns 側の条件なのに、リンクは公式側の可能性があり、記事同士が食い違う。
- 修正案：リンク先を確認するまで、リンクの文脈に「このリンクは海外公式側」と注記するか、WeIns 側の案内であることをリンクの外に書く。

### 6. 軽微：Guesty Lite の価格に付く "Limited time offer" が落ちている
- 記事：「Pay as you grow：月$9/室＋予約ごとに1%／Annual：月$20/室〜／Monthly：月$29/室〜」
- カード：Guesty 2章「"Limited time offer" の表示あり」。
- 修正案：「期間限定の表示あり」と添える。

### 7. 軽微：Guesty の Capterra の数字がカードと README で違う
- 記事：「1,031件／4.6」（README の値、第三者のみ）
- カード：Guesty 8章「Capterra：4.4（477件）」（検索抜粋。件数は取得時点で変動）。
- 問題：記事は README と一致するので誤りではないが、カードと数字が違う。
- 修正案：リサーチ役に確認（記事は README の値を維持してよい）。

### 8. 軽微：比較表の行見出し「（USD）」に Beds24 の € が入っている
- 記事：「3室（USD）」「5室（USD）」「10室（USD）」の行で Beds24 は「公式 €24.00」など。
- 修正案：行見出しを「3室」「5室」「10室」にし、各セルに通貨を残す。

### 9. 軽微：Guesty の予約エンジンで日本語が使える可能性が書かれていない
- 記事（先に知っておくこと）：「Guesty から乗り換えれば日本語になる」とは限らず、日本語の面では下の多くの候補も同じ条件」
- カード：Guesty 4章／5章 ヘルプ抜粋では、日本語はダッシュボードではなく、リスティング内容と予約エンジンで対応（第三者のみ）。
- 修正案：「予約エンジンの日本語は第三者の抜粋のみ」と一言足す。
