# 民泊ツール比較サイト（設計図）

**誰に**：日本の物件を3〜15室運営していて、表計算や国内ツールから海外の管理ツール（PMS／チャネルマネージャー）へ切り替える、または初導入を、**申込の直前**に検討している民泊運営者。Guesty や Hostaway などの名前は知っている。

**何を**：買う直前・乗り換え検討・比較の記事だけ。「民泊とは」「始め方」「収益」などの一般論は作らない。検索ボリュームは気にしない（1日10アクセスで最高、月100アクセスで大成功）。

**目標**：20〜50記事（本計画は38記事＋固定ページ）。24時間で1サイトを仕上げる。

## 記事の共通の部品

結論1行／条件別の判断表（「この条件ならA」）／公式の料金・仕様の出典と取得日／未確認は未確認と書く／申込導線。**買う直前の1本の質を最優先**にする。

## 体制（必ず分離する）

| 役 | 仕事 | 禁止 |
|---|---|---|
| リサーチ | 公式の料金・仕様・日本対応を調べ、`事実カード/` に残す | 文章（記事）を書かない |
| ライター | 事実カードだけを材料に `記事/` を書く | カードにない事実を足さない |
| 校閲 | 記事の主張を事実カードと照合し、差し戻す | 書き直さない |

## 事実カードの書式

`事実カード/_スキーマ.md` を参照。

## 注意

- 民泊の法令は、観光庁・自治体など一次資料のみを使う。法的な判断はしない
- 広告であることを明記する（ステルスマーケティング規制）
- Capterra の数字は「海外レビュー」と明記する
- 日本語対応が「なし」の製品（Hostaway など）のアフィリエイトは、事実カードで初めて調べる

## 進捗（2026-11-07）

- 記事42本（比較10・乗り換え8・代替6・日本対応8・買う直前6・固定4）を `記事/` に作成。校閲（`校閲/`）で全記事を事実カードと照合し、指摘を反映済み。
- 静的サイトのビルド：`python3 ビルド/build.py`（要 `pip install markdown`）→ `docs/minpaku/` に生成。既定は noindex。`--publish` を付けると、運営者情報の未記入・リンク切れ・PR表記抜けなどをエラーにする。
- `/go/<slug>/` の遷移先は `ビルド/go-links.tsv`。いまは全て公式トップ（仮）。アフィリエイトの承認後にこのTSVだけを書き換える。
- 公開前に人が決めること：①運営者名・連絡先（`記事/disclosure.md`）②ホスティング先・ドメイン ③アフィリエイト申込（9社）と紹介URLの差し替え。
- 記事末尾の `<!-- 追加調査依頼 -->` は、次の調査ラウンドの材料。ビルド時に本文から除去される。
