【クラウド電話】乗り換え・導入前のチェックリスト

先に結論

  • 順番は「番号 → 書類 → 通話料込みの月額 → 緊急通報 → 契約・解約 → 試す」です。 先に製品を決めると、あとで番号や書類でつまずきます。
  • 「固定電話が使えなくなる」と急かされても、慌てて契約しないでください。 国民生活センターは、固定電話のIP網移行に便乗した光回線などの勧誘に注意を呼びかけています（2022年4月）。
  • このチェックリストは、確認する項目を整理したものです。法律の判断はしていません。

誰のためのチェックリストか

固定電話やスマホの電話で仕事をしている、1〜10人くらいの小さな事業者が、クラウド電話に乗り換える前に使います。流れの説明は 固定電話・スマホからクラウド電話へ乗り換える手順 へ。

1. 目的と、今の電話を整理する

  • [ ] 乗り換える理由は何か（コスト、外出先で出たい、番号を持ちたい、テレワーク）。
  • [ ] 今の番号を書き出した（代表、FAX、携帯、警備・機器の回線）。
  • [ ] 月の通話の量（かける・受ける、固定宛・携帯宛）をだいたい把握した。
  • [ ] 何人が電話に出るか。管理者を含めて何ライセンス必要か。

2. 番号を決める

  • [ ] 今の番号を引き継ぐか、新しい番号にするか。→ 今の番号をそのまま移せる？
  • [ ] 050、03・06など、0120のどれが必要か。
  • [ ] 引き継ぐ場合、その製品が移行に対応しているか（Zoom Phone は050の移行不可。0ABJ・フリーダイヤルは対応）。
  • [ ] 今の会社の解約費用・残債・ネット回線の扱いを確認した（総務省のページにある注意点）。

3. 本人確認の書類を確認する

  • [ ] 法人か個人事業主か。製品ごとの書類を確認した（Zoom Phone は、個人事業主は開業届で足りる、と公式にあります）。
  • [ ] 書類の発行から何か月以内か（Dialpad は3か月以内、Zoom Phone は6か月以内の記載）。
  • [ ] 本人確認の郵送物を受け取れる住所か（受け取らないと開通しない製品があります）。
  • [ ] 開通までの日数（Zoom Phone の新しい番号は最短3営業日、Dialpad は最短10〜15営業日、CallHippo の050は数日）。月初・月末の遅れも聞いた。

4. 通話料込みの月額を、見積もりで比べる

  • [ ] ライセンスの月額（円か、ドルか）。
  • [ ] 日本宛の通話料（固定・携帯）と、「かけ放題」「無制限」の範囲。
  • [ ] 番号の月額と、初期費用（開通、番号の移行）。
  • [ ] ユニバーサルサービス料など、別の費用。
  • [ ] ドルの場合、為替と、請求書の形式（インボイス）。

例：CallHippo の「無制限」は米国・カナダ宛だけ。Aircall の「無制限」も米国・カナダの範囲。Zoom Phone の「国内かけ放題」は、国内の発信が0円。

5. 緊急通報・特殊な番号

  • [ ] 110・119をクラウド電話からかけられるか。かけられない製品が多い（Zoom Phone は110・119・118の発信不可と公式にあります）。
  • [ ] 携帯電話か固定電話を、緊急用に残すことを決めた。
  • [ ] 0570、115、117、171、188など、特殊な番号が必要か。Zoom Phone は、これらの発信不可を公式に書いています。

6. 契約・解約を確認する

  • [ ] 最低利用期間、自動更新、解約の通知、日割りの有無。
  • [ ] 月払いか年契約か。年契約は、途中でライセンスを減らせない場合がある（Aircall の公式ヘルプ）。
  • [ ] 解約したとき、番号がどうなるか（他社へ移せるか、消えるか）。
  • [ ] 営業の説明を、メールなどの書面でもらった。口頭の約束だけにしない。

7. 急かす勧誘への備え

国民生活センターの公表（2022年4月26日）には、次のように書かれています。

  • 固定電話のIP網移行に伴う局内設備切替では、利用者側での手続きや自宅での工事は不要で、利用中の電話機や電話番号はそのまま利用できます。
  • 「このままでは固定電話が使えなくなる」と言って、光回線などの契約を勧める便乗勧誘に注意してください。
  • 不要な契約は断り、不安があれば、消費者ホットライン「188」から、最寄りの消費生活センター等に相談できます。

その場で契約しないで、書面をもらってから、比べて決める。 これが一番の備えです。

8. 試す・切り替える

  • [ ] 無料トライアルや、新しい番号で、音質、スマホの着信、転送、留守電を試した。
  • [ ] 日本時間のサポートの連絡先を控えた。
  • [ ] インターネットが止まった日の備え（スマホの回線、携帯への転送）を決めた。
  • [ ] 名刺、ホームページ、Google などの登録の番号を、順に変える計画を立てた。
  • [ ] 古い回線は、新しい番号で問題がないことを確かめてから、最後に解約する。

9. 切り替えたあと

  • [ ] 1週間、着信の取りこぼしがないか見る。
  • [ ] 通話料の請求を、見積もりと比べる。
  • [ ] 更新日をカレンダーに入れる。

よくある質問

何から始めればいいですか？

今の電話の棚卸し（番号、通話量、人数）です。そのあとで、番号の種類を決めて、2つの製品から通話料込みの見積もりをもらってください。

チェックリストは全部必要ですか？

1人で通話が少ないなら、2〜6の項目を中心に確認してください。FAX や機器の回線がある場合は、1の項目が大事です。

情報は、国民生活センターの公表（2022年4月26日）、総務省のページ、各社の公式ページとヘルプを読んで日本語にまとめたものです。法律の判断はしていません。確認日 2026-11-07。料金や仕様は変わるため、申込前に公式で再確認してください。
