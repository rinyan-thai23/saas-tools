# iGMS の代替ツール：言語・料金の段差・解約条件で選ぶ5候補

> **結論**
> - iGMS が合わない理由が「UIが英語・スペイン語のみ」「年払いは返金不可」なら、日本語UIを公式で確認できたのは Beds24 の日本の販売会社版（WeIns / Co-Reception。リンクなし）だけ。その申込は [Beds24（海外公式。PRリンク）](/go/beds24/)とは別。月払いで軽く試すなら [Hospitable](/go/hospitable/)・[OwnerRez](/go/ownerrez/)。
> - 「PRO+ にしないと使えない機能（自動翻訳、Dynamic Pricing など）が多い」点が理由なら、価格の自動調整に限れば、別ツール（[PriceLabs](/go/pricelabs/)）に切り出す手もある（別途 PriceLabs の料金がかかり、自動翻訳・オーナー明細などは代替されない）。
> - 楽天トラベル／じゃらんの記載は、iGMS と同様に Hospitable・OwnerRez・Uplisting・Lodgify でも公式に見つからなかった。

## 先に知っておくこと

- 楽天トラベル（公式の参画ページ）は民泊新法の施設は参画不可で、同グループの「Rakuten Oyado」を案内。じゃらんnet（公式）も民泊新法・特区民泊は不可。両社とも民泊新法・特区民泊は対象外と明記しているが、旅館業法の許可施設への接続可否は各ツールで未確認。制度の判断はこの記事ではしない。
- Airbnb の公式ヘルプは、日本の住宅宿泊事業ではソフト連携で作ったリスティングを受け付けないとし（例外の「日本のAPIパートナー」の名前は見つからなかった）、届出番号は Airbnb に直接ログインして入れる案内。既存の掲載を接続する場合の扱いは未確認。

## 条件別の選び方

## 候補ごとの要点

- **Hospitable**：管理画面は英語のみ。定型メッセージは英・西・仏・独で、日本語の追加要望のステータスは「New」（2026-11-05 取得時）で、実装済みかは未確認。他PMSからの自動データ移行はない。直接比較は [iGMS と Hospitable の比較](/articles/vs-igms-hospitable/)。
- **OwnerRez**：1物件目 $40、以降は単価が下がる。カードのみ。Hosted Sites・SMS などは別料金。
- **Beds24**：海外公式（ユーロ建て、英独のみ。PRリンクはこちら）と日本の販売会社版（円建て、日本語、最低1か月・解約は毎月20日までにメール、再登録5万円）で条件が別。日本語UI・円建ては販売会社版の情報で、申込は海外公式のリンクとは別。
- **Uplisting**：10〜300室超向けと自己説明。請求通貨に JPY なし。
- **Lodgify**：オンライン決済に別途1%。表示通貨は EUR・USD・GBP。本体サイトは開けず公開コピーで確認。
- **補助：PriceLabs**：PMS ではなく価格調整ツール。日本は提供国に含まれる（競合の物件が追跡できる場合。精度は確認できず）。公式の文言どおり「Rest of the world」区分なら 5件 $47.95／10件 $92.90（計算値、税別）。30日トライアル、月単位で解約可、請求は USD。

## 申し込む前に確認すること

- [ ] iGMS の解約は申請から営業日48時間以内に処理され、アカウント削除でテンプレ・メモ・清掃指示が消える。先に控えを取る。年払い・年間契約は更新日と差額請求の条件を確認
- [ ] 切替時の空室同期：Airbnb は同時に1つの公式ソフトとしかフルアクセスで接続できない（Uplisting の公式説明）。Hospitable のガイドは、旧PMSを切断してから接続、Booking.com は接続変更中の一時停止を推奨と案内。接続後に手動ブロックの日付が残っているか確認する
- [ ] JPY 払いと適格請求書：Hospitable・OwnerRez・Uplisting・Lodgify は記載が見つからなかった（[円請求・インボイスの整理](/articles/jp-yen-invoice/)）
- [ ] 宿泊者名簿は全員分、外国人は旅券番号と旅券の写しの保存（観光庁）。日本の名簿要件に合う本体機能の記載は、Beds24 日本側の有料オプション以外は見つからなかった（ID・パスポート収集の機能は Beds24・Hospitable・Uplisting・Lodgify などにあるが、日本の名簿要件との適合は未確認）

- 楽天トラベル・じゃらんへの配信可否（記載が見つからなかっただけで、できないと確認したわけではない）、Akerun・SESAME との連携。価格は取得日時点。
