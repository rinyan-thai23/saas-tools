【体験・ツアー】予約システムの手数料・月額の早見表｜月の売上別の費用を計算

先に結論

  • 月の売上が小さいうちは「月額0円」の製品が安く、売上が増えるほど「月額は高いが手数料が低い」プランが得になります。 分かれ目は、製品ごとに違います（下の計算を参照）。
  • 事前決済（予約のときのカード決済）を使うと、国産の「予約手数料が無料」のプランでも、実質は3〜5%になります。 予約手数料と決済手数料は、合算して見てください（計算）。
  • 円の製品とドルの製品は、為替が違うので、別々の表にしました。 為替手数料は、どちらにも含みません。
  • この記事の数字は、すべて公式の料金表（自社の発表）を使った「計算」です。 実際の請求は、プランの機能、最低保証、税、為替で変わります。

計算の前提

  • オンラインの直販予約の売上だけで計算します（自社サイト経由）。予約サイト（OTA）経由の手数料、店頭・電話の予約は含みません。
  • 手数料はすべて事業者が払うとして計算します（お客さんに上乗せする場合、事業者の負担は減ります。→ 手数料を誰が払うか）。
  • 月額は、公式の表示のまま（rezio は税込、JTB BÓKUN は税別、ドルのものは税抜き）。税の違いは調整していません。
  • プランごとの機能の差は、含みません。

費用を決める4つの要素

  1. 月のオンライン売上：小さいうちは月額0円、増えたら月額が高くても手数料が低いプラン。
  2. 事前決済の割合：事前決済を使うと、決済手数料が上乗せされます。
  3. 手数料を誰が払うか：お客さんに上乗せできる製品は、事業者の負担が減ります。
  4. 必要な機能：安いプランでは、予約メールの自動取込、多言語化、API などが使えないことがあります。

申し込む前に聞くこと

  1. 予約手数料と決済手数料は、合算して何%か。 海外発行カードの場合は。
  2. 自分の売上の規模で、一番安いプランはどれか（見積りを書面で）。
  3. 安いプランで、使えない機能は何か。
  4. 最低保証、初期費用、解約の違約金はあるか。
  5. 為替手数料は、誰が、いくら払うか。

よくある質問

一番安い予約システムはどれですか？

売上と事前決済の割合で変わります。売上が小さいうちは、月額0円のプランが安く、売上が増えると、手数料の割合が低いプランが得になります。この記事の計算を、自分の売上に当てはめてください。

手数料に消費税はかかりますか？

製品で表示が違います（rezio は税込、JTB BÓKUN は税別、ドルのものは税抜き）。税の扱いは、見積りで確認してください。

事前決済は使うべきですか？

無断キャンセルが心配なら、使えます。ただし、実質の手数料が増えます（上の計算）。
