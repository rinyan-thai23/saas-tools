# 広告表示と運営方針

## 広告について
- 一部のリンクは広告（アフィリエイト）です。リンクを通じて申し込みがあると、運営者に報酬が入ることがあります。広告リンクがあるページには、冒頭に「PR」と書きます。
- 紹介報酬の有無や金額で、評価の内容は変えません。
- 現在、広告リンクは試験的に設定しているものがあり、遷移先は仮です。

## 情報の集め方
- 各製品の公式サイト、公式の資料、報道と、海外のレビューサイト（Capterra）の口コミを読んで、日本語にまとめています。
- 口コミは海外の事業者の声が中心で、日本の事業者の声ではありません。
- 公式で確認できなかったことは、「確認できなかった」と書きます。「記載が見つからなかった」ことと、「できない」ことは、区別します。
- 料金や仕様は変わります。申込前に公式で確認してください。法律や税務の助言ではありません。
