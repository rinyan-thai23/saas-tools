# Hostaway から Guesty へ乗り換える前に

> **結論**
> - Guesty の移行支援は、Pro（4室以上）では専任担当者が設定・データ移行・トレーニング・動作確認を行う "ProSwitch"（完了目安30日）と公式にあります。1〜3室の Lite は "1-on-1 onboarding" の記載のみで、詳細は未確認です。
> - 乗り換えると契約が長くなる可能性があります。Guesty の規約は初期期間13か月＋12か月ごとの自動更新、中途解約は最低月額×残り月数です（契約書の記載が優先。1〜3室の Lite に同じ形で当たるかは未確認）。
> - Hostaway 側の解約手続き・解約金は、規約本文に通常の解約の記載がなく、個別契約によります。まず手元の契約書を見てください。

## Hostaway の契約を確認する

- 規約には「契約期間は個別の契約（売買契約・サービス契約）に定める」とあります。通常の解約手続きと解約金は、規約本文には書かれていません（重大な違反時の即時解約の条項のみ）。
- 値上げは14日前までに通知され、同意しない場合は、発効の5日前までの通知で解約できる、と規約にあります。
- Hostaway からのデータの書き出し方法（エクスポート）は、今回は調べていません（未調査。ヘルプセンターは403で未取得）。

## Guesty 側で確認できたこと

| 項目 | 公式の記載 |
|---|---|
| Pro の移行 | ProSwitch：専任の担当者（Implementation Specialist）が設定・データ移行・役割別トレーニング・動作確認。"PMS onboarding is usually completed within 30 days" |
| 移行の進め方 | 既存データ（将来の予約を含む）は事前に新PMSへ移す。切替時のダウンタイムはほとんどのチャネルで約30分（FAQ） |
| 引き継げないもの | 他社PMS固有の連携は引き継げない。Open API など他社PMSに依存しない連携は引き継げる |
| インポート方法 | 大量データ向けに "templates and bulk tools" とあるが、形式・手順は記載なし |
| Lite の移行 | 他社から Lite へは "1-on-1 onboarding"（詳細は未確認）。Lite から Pro は同一プラットフォームで移行不要 |
| 契約 | 初期13か月（オンボーディング含む）、以後12か月ごとに自動更新。更新しない場合は終了の30日前までに書面。中途解約は最低月額×残り月数。Lite にも同じ形で当たるかは未確認 |
| 料金 | Lite は月$9/室＋予約の1%（Pay as you grow）から。Pro は見積りで非公開。オンボーディング費用の公式額は未確認 |
| 日本語 | サポート言語に日本語なし（公式）。管理画面は、2019年の公式ブログと検索抜粋の範囲で日本語なし（現行は第三者の情報のみ）。移行支援も日本語は一覧にない |

Hostaway の比較ページは Guesty のオンボーディングを "$1,500" と記載しますが、競合の主張で、Guesty 公式の数字ではありません。

## チャネルと機能の差

- **Lite（1〜3室）：** 接続先は Airbnb・Booking.com・Vrbo の3つです。Expedia は Pro 以上のため、Expedia を使っているなら Pro が前提になります。
- **Agoda：** Guesty は公式チャネル一覧に載っています。Hostaway は公式の一覧になく、接続は断定できません（未確認）。
- **楽天トラベル・じゃらん：** 両社とも公式ページに記載が見つかりませんでした。Guesty は全チャネル一覧の全文が取得できず、未確認です。
- **オーナーポータル：** Guesty は Pro 以上（Lite は対象外）。
- **有料アドオン：** Guesty は PriceOptimizer、LocksManager、GuestyPay、Trust Accounting など。金額は未確認です。

## 切り替えの注意（第三者の記載を含む）

Hospitable のヘルプ記事に「Hostaway から Airbnb の接続を切ったあと、解放に24〜48時間かかることがある」とあります。これは Hospitable への移行を説明した記事で、Guesty への切り替えでも同じかは確認できていません（未確認）。切替中の売り止めの要否は、Guesty の担当者に確認する項目です。

Capterra（海外レビュー、2026-11-03時点）は Hostaway が 1,623件／4.8、Guesty が 1,031件／4.6 です。Guesty には、サポートが一貫しない、会計・決済が分かりにくい、との投稿と、オンボーディング担当への称賛の両方があります（検索抜粋で、本文は未読）。英語圏の声で、日本の運営者の実感ではありません。

## 条件別の判断

| 条件 | 見るところ |
|---|---|
| 4室以上で移行を任せたい | ProSwitch の範囲（対象データ、期間、費用）を見積り時に書面で受け取る。[Guesty の見積り（PR）](/go/guesty/) |
| 1〜3室で価格を公開情報で見たい | Guesty Lite（14日無料、カード不要）。Expedia と、オーナーポータルは使えない |
| 契約期間を短くしたい | Guesty は13か月が基本（契約書の記載が優先。Lite にも同じ形で当たるかは未確認）。Hostaway に残る期間と比べる。[Hostaway の見積り（PR）](/go/hostaway/) |
| 日本語で相談したい | Guesty は公式のサポート言語に日本語なし。Hostaway は日本語の窓口の記載が確認できていない（未確認） |

## 乗り換え前に確認すること

- [ ] Hostaway の契約書で、期間・解約手続き・解約金を確認した
- [ ] Guesty の見積りで、月額・初期費用・オンボーディング費用・契約期間・解約金を書面で受け取った
- [ ] Hostaway のデータ（未来の予約、ゲスト情報、メッセージテンプレート）を控えた
- [ ] 現在使っているチャネル（Expedia、Agoda など）が、Guesty のプランで接続できるか確認した
- [ ] Airbnb の接続を切り替える手順と、売り止めの要否を担当者に確認した（[チェックリスト](/articles/switch-checklist-double-booking/)）
- [ ] 請求通貨が円か、USD請求の場合の為替の扱い（カード会社の手数料など）を確認した

## 未確認のこと

- Hostaway からのデータの書き出し方法（今回は調べていない）、通常の解約手続きと解約金
- Guesty の Pro の公式価格とオンボーディング費用、インポートの形式、Lite の移行の詳細
- Hostaway から Guesty へ切り替えるときの Airbnb の解放時間
- 両社の円（JPY）請求の可否、Hostaway の日本語サポート（Guesty は公式のサポート言語に日本語なし）
