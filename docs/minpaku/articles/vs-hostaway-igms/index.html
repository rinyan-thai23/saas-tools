Hostaway と iGMS を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

結論

  • この2製品のうち、公式ページに料金が載っているのは iGMS だけです（PRO は10室で月約$174【計算値】）。Hostaway は価格非公開の見積りです。
  • 管理画面の日本語は、iGMS は「英語とスペイン語」と公式に記載。Hostaway は日本語の記載を確認できませんでした（公式ヘルプが開けず、第三者の情報のみ）。
  • 楽天トラベル・じゃらんは、どちらの公式ページにも記載が見つかりませんでした（「接続できない」と確認したわけではありません）。

先に知っておくこと

営業形態によって、載せられる予約サイトが変わります。予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

予約サイト 公式に書かれている条件
楽天トラベル 旅館業の営業許可が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は Rakuten Oyado で登録、と案内
じゃらんnet 旅館業の宿泊営業許可が対象。民泊新法・特区民泊は「ご参画いただけません」
Airbnb ヘルプ：日本の民泊新法の宿は、ソフト連携で作成したリスティングを受け付けない。例外は Airbnb とライセンス契約した日本のAPIパートナー（名前は公式ページで見つからず）
  • Rakuten Oyado が「そのまま使える」とする既存ツールは、ねっぱん、AirHost、Beds24、suitebook です。Hostaway と iGMS の名前はありません。
  • 届出番号は、ツールを使っていても自分で Airbnb にログインして追加する必要がある、とヘルプにあります。
  • 制度側には、外国人宿泊者の国籍・旅券番号の記載と旅券の写しの保存、年180日の上限、2か月ごとの定期報告があります（観光庁・e-Gov）。両社とも対応する機能の記載は公式ページで見つかりませんでした。適格請求書も同様です。

条件別の選び方

  • 公式ページで価格を見て、カード登録なしで試したい人は iGMS。 無料プラン（予約5件まで）と14日トライアルがあります。
  • Expedia を API 接続で使いたい人： Hostaway は対応を確認できました（API 接続という説明は自社の主張）。iGMS は iCal（1時間更新）です。
  • 管理画面の日本語が必要な人： どちらも公式には確認できません。英語の画面で運用できるか、試してから決めてください。
  • 10室以上で年契約を考える人： iGMS は年間契約の途中解約で差額請求があります。Hostaway は見積り時に期間と解約条件を書面で確認します。
  • 楽天トラベル・じゃらんが必須の人： この2製品では確認できませんでした。民泊新法・特区民泊は両サイトとも対象外と明記しています。旅館業の許可施設をこの2製品につなげられるかは未確認です。

申し込む前に確認すること

  • [ ] 自分の営業形態（届出／許可／特区民泊）で、使いたい予約サイトに載せられるか。Airbnb には民泊新法の掲載をツールにつなげるかも確認した
  • [ ] Hostaway の見積りで、月額・初期費用・契約期間・解約条件・アドオンを書面で受け取った
  • [ ] iGMS の「課金される物件」の数え方（複数サイトの掲載のまとめ方）を確認した
  • [ ] 請求通貨が円か、USD請求ならカードの為替手数料はいくらか
  • [ ] 日本語が通じるサポートと日本時間の窓口があるか
  • [ ] 宿泊者名簿、年180日のカウント、定期報告を、ツール内で行うか別の方法かを決めた

未確認のこと

  • Hostaway の価格・無料トライアル・標準の契約期間・解約手続き（ヘルプは403で開けず）

  • 両社の円請求、楽天トラベル・じゃらん・Agoda への接続、Akerun・SESAME への対応
