# 校閲：switch-igms-to-hospitable

## 指摘

### 注意

1. **未確認のこと「iGMS から Hospitable へ移る場合のデータの書き出し方法（iGMS 側の公式ページに記載が見つかっていない）」**
   - カード：iGMS §7 は「他PMSから iGMS への移行」の行のみ。iGMS からの書き出しを調べた行はなく、「調べられなかったこと」にも載っていない。
   - 問題：「記載が見つかっていない」という調査結果がカードにない。
   - 修正案：「iGMS からの書き出し方法は未調査」とする。

### 軽微

2. **月額の目安の表の見出し「（USD、月払い、計算値）」**
   - カード：iGMS §2 は月払い・年払い別、Hospitable §2 の年払いは12%引き（計算値のカードなし）。
   - 問題：見出しは「月払い」だが、iGMS 列には年払いの数字も入っており、Hospitable 列は月払いのみ。年払い同士の比較ができない構成になっている（箇条書きで年払い12%引きは別に説明あり）。
   - 修正案：見出しを「月払い（iGMS は年払いも併記）」に直す。

3. **iGMS の14日無料トライアルが書かれていない**
   - カード：iGMS §2「無料トライアル」14日・カード不要。Hospitable の14日試用は記事に記載あり。
   - 問題：片方だけ記載があり、並びとして偏る。
   - 修正案：iGMS の試用（14日、カード不要）を一言足す。
