# 更新履歴

料金・仕様・契約条件は変わります。各ページの末尾に、**確認日**を書いています。誤りの訂正も、ここに記録します（連絡先は [広告表示と運営方針](/disclosure/) にあります）。

## 2026-11-07：ツール別ページの追加と、記事の全面的な書き直し

- **ツール別の紹介ページを11本追加**しました：[Hostaway](/articles/hostaway/)、[Guesty](/articles/guesty/)、[Lodgify](/articles/lodgify/)、[Hospitable](/articles/hospitable/)、[OwnerRez](/articles/ownerrez/)、[iGMS](/articles/igms/)、[Uplisting](/articles/uplisting/)、[Beds24](/articles/beds24/)、[PriceLabs](/articles/pricelabs/)、[Hostfully Guidebooks](/articles/hostfully-guidebooks/)、[Sirvoy](/articles/sirvoy/)。公式サイトの確認、海外レビュー（Capterra）の口コミの集計（関連順・新着順）、Web検索をもとにしています。
- **比較10本、代替6本、乗り換え8本、買う直前6本、日本対応8本、固定ページを、書き直しました。** 読者の状況（誰が、何に迷っているか）から入る書き方にし、ツール別ページの内容を材料に、毎回新しく調べて書いています。
  - 比較：[Guesty と Hostaway](/articles/vs-guesty-hostaway/) ほか10本
  - 代替：[Guesty の代替](/articles/alt-guesty/) ほか6本
  - 乗り換え：[Guesty から Hostaway へ](/articles/switch-guesty-to-hostaway/) ほか7本
  - 買う直前：[物件数別の料金早見表](/articles/buy-price-by-listings/)、[最低契約・解約条件](/articles/buy-contract-cancel/)、[申込前チェックリスト](/articles/buy-checklist/) ほか
  - 日本対応：[住宅宿泊事業法への対応](/articles/jp-minpaku-law/)、[楽天トラベル・じゃらん等の国内予約サイト連携](/articles/jp-ota-rakuten-jalan/) ほか
  - [総合比較表](/compare-table/)、[広告表示と運営方針](/disclosure/)
- 新しく加えた内容：
  - 口コミの**低評価（1〜2点）の割合**と、投稿者の規模・使用期間（口コミが少ない・偏っているものは注記）。
  - **民泊新法の人向けの先の確認**：Airbnb は、日本の民泊新法の宿で、ツール経由で作った掲載を受け付けません（例外は、Airbnb と契約した日本のAPIパートナー）。
  - 公式ページ同士の**食い違い**（Uplisting の契約条件、Lodgify の自動更新の通知など）。
  - 競合の比較ページの数字を「自社の主張」「競合の主張」として扱うこと。
- 出典のURLを本文に並べない形にしました。情報の集め方は [広告表示と運営方針](/disclosure/) にまとめています。
