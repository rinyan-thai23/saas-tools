# 校閲：switch-guesty-to-hostaway

照合したカード：Guesty、Hostaway、日本のOTA連携（記事の frontmatter の cards どおり）。記事は変更していない。

件数：要修正 0／注意 3／軽微 4

## 指摘

### 注意

1. **結論3「日本語の管理画面・日本語サポートは、どちらも公式で確認できていません。乗り換えても、この点は変わりません。」**
   - カード：Guesty §5「サポート言語」＝English, Spanish, French, Italian, German, Hebrew, Portuguese で日本語は無し（確認済）。「管理画面の日本語」＝現行は第三者のみ。Hostaway §5＝管理画面・サポート言語とも未確認。
   - 問題：Guesty は「日本語なし」が確認済なのに「確認できていない」と弱く書いている（記事2・記事4の表現とも食い違う）。「変わりません」は、Hostaway が未確認なのに言い切っている。
   - 修正案：「Guesty はサポート言語に日本語がなく（公式）、Hostaway は日本語対応の記載が確認できていません」とし、「変わりません」を削る。

2. **「Guesty からデータを書き出す方法は、開いた公式ページに記載が見つかりませんでした。」（Guesty の契約セクション）**
   - カード：Guesty カードに書き出し（エクスポート）を調べた行がなく、「調べられなかったこと」にも載っていない。
   - 問題：「記載が見つからなかった」という調査結果がカードにない。ヘルプセンター403は注記にあるが、書き出しを探した記録はない。
   - 修正案：「未調査（カードに記載なし）」と書くか、リサーチ役に追加調査を依頼して結果を待つ。

3. **チェックリスト「Guesty と Hostaway の同時接続ができるか、Hostaway に書面で確認した（開いた公式ページに記載なし）」**
   - カード：Hostaway §7・Guesty §7 のどちらにも、同時接続の可否を調べた行がない。
   - 問題：括弧内の「開いた公式ページに記載なし」の根拠がカードにない（Guesty 側 §7 は移行元の話のみ）。
   - 修正案：括弧を「未調査」に直す。

### 軽微

4. **「楽天トラベル・じゃらん：どちらの公式ページにも記載が見つかりませんでした」**
   - カード：Guesty §3＝「全チャネル一覧の全文は取得できず」（表示分には無し）。OTA カード 3-01。
   - 問題：Guesty は一覧の全文を取得できていない点が抜けている（記事2には書いてある）。
   - 修正案：「Guesty は全チャネル一覧の全文が未取得」を一言足す。

5. **「Hostaway には、値上げが頻繁、契約中の機能が後から追加料金になった…との投稿」を Capterra の段落に置いている**
   - カード：Hostaway §8「値上げの声」の出典は Software Advice／Capterra。同期漏れ約$400の出典は Capterra page=8。
   - 問題：値上げの声が Capterra のみと読める。
   - 修正案：「Capterra や Software Advice の投稿」とする。

6. **Capterra「Guesty 1,031件／4.6」**
   - カード：Guesty §8 の評価は「Capterra 4.4（477件）」（検索抜粋）。README は 1,031件／4.6（2026-11-03時点）。
   - 問題：記事は README に従っており誤りではないが、カードと README の数字が違う。
   - 修正案：リサーチ役にカードの数字の更新を依頼する。

7. **チェックリスト「Guesty から未来の予約・ゲスト情報・メッセージテンプレートを控えた」**
   - カード：Guesty §7＝「既存データ（将来の予約を含む）は事前に新PMSへ移す」のみ。ゲスト情報・テンプレートの記載は Guesty カードに無い。
   - 問題：一般的な助言で、カードにない対象を並べている。
   - 修正案：「未来の予約など、控えるデータの範囲を Hostaway に確認した」程度にする。
