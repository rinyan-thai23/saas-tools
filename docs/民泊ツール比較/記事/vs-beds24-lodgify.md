# 【民泊】Beds24 と Lodgify どっちがいい？料金・日本語・国内予約サイト・口コミを比較

この記事にはアフィリエイトリンク（PR）が含まれます。リンクは、Beds24 は海外公式（beds24.com）への紹介リンクです。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：日本語や国内の予約サイトが必要なら Beds24、自分の予約サイトを作りたいなら Lodgify

> - **日本語の画面・サポート、楽天トラベル・じゃらんが必要 → Beds24。** ただし**日本語版は、日本の販売会社（株式会社WeIns）経由**で、契約条件は海外公式と別です。
> - **自分の予約サイトを、プログラムなしで作りたい → Lodgify。** ただし管理画面・サポートの日本語は確認できません。
> - **とにかく安く → Beds24。** 海外公式は月€15.50から、日本の販売会社は月¥4,580から。Lodgify は1物件$14から（3室以上は$47〜）。
> - **画面の使いやすさを重視 → Lodgify。** Beds24 は画面が古く、「自分で調べて使う道具」と口コミで言われています。
> - **口コミの低評価の割合**は、Beds24 が約2%（55件中1件）、Lodgify が約7%（約190件中14件）。件数の差が大きく、目安です。

各ツールの詳しい情報は、[Beds24 の評判・口コミ](/articles/beds24/)、[Lodgify の評判・口コミ](/articles/lodgify/)にまとめています。

## 日本で使うなら：Beds24 は「窓口が2つ」ある

| | 海外公式（beds24.com） | 日本の販売会社（株式会社WeIns） |
|---|---|---|
| 通貨 | ユーロ | 円 |
| 管理画面 | 英語・ドイツ語 | 日本語版 |
| サポート | 英語またはドイツ語（チケットとフォーラム） | 日本語（基本操作は電話、設定の依頼はメール） |
| 契約 | 縛りなし。1か月前の通知で月末に解約 | 最低1か月・日割りなし。解約は毎月20日までにメール（電話不可）。再登録5万円 |

- **契約する窓口で条件が変わります。** 日本語で使いたいなら日本の販売会社ですが、解約が毎月20日締めのメールのみ、支払いはクレジットカードのみ、といった条件に注意してください。
- この記事の Beds24 の「PR」リンクは、海外公式への紹介リンクです。日本の販売会社へのリンクは付けていません。

Lodgify には日本の販売会社の情報が見つかりませんでした。公式サイトの言語は7つで、日本語はありません。

## 料金：どちらも公開。仕組みが違う

**Beds24 の目安（海外公式、月額・ユーロ。2チャネル）**

| 室数 | 月額 |
|---|---|
| 1室 | €16.60 |
| 3室 | €24.00 |
| 5室 | €31.40 |
| 10室 | €49.90 |

- 同じタイプの部屋が複数あるときは、さらに安くなります。日本の販売会社は、1棟貸しなどで月¥4,580から、10室・5予約サイトで月¥17,280（自社掲載の参考価格）。じゃらん・楽天トラベルは、月¥1,200／部屋タイプ＋初期費用¥3,000（3つ目の予約サイトは初期費用のみ）。

| プラン | 1物件の月額 | 物件数の制限 |

| Basic | $14 | 1物件まで |
| Starter | $26 | 2物件まで |

- 3室以上の正確な月額は、物件数で変わります。公式の料金ページで確認してください。
- 第三者の比較サイトには、「Lodgify は$16＋予約の1.9%」といった数字もありますが、**公式の記載（予約手数料0%、決済に別途1%）と合いません**。この記事は公式に合わせています。

## 直接予約サイト

- **Lodgify**：テンプレートで予約サイトを作れ、予約エンジンや埋め込みウィジェットもあります。年払いなら独自ドメインが無料。
- **Beds24**：予約エンジン、ウィジェット、WordPress プラグインが月額に含まれ、予約手数料はありません。口コミには、「無料だがデザインが簡素」という声があります。ゲストの予約ページは、**日本語を含む20以上の言語**に対応します。

デザインの作り込みなら Lodgify、費用を抑えて予約機能を持つなら Beds24、という使い分けです。

## 口コミ：不満の出方が違う

Capterra の海外レビュー（Beds24 55件、Lodgify 約190件）を読んだ結果です。英語圏の運営者の声が中心で、日本の運営者の声ではありません。Beds24 は件数が少なく、傾向は目安です。

| | Beds24 | Lodgify |
|---|---|---|
| 良い点で多い話題 | 連携・同期（約3割）、価格（約23%）、自動化 | 連携・同期（約4分の1）、サポート、使いやすさ |
| 改善点で多い話題 | サポート（メール中心）、画面の古さ、覚えること | 同期・接続の不具合、料金、サポートの遅れ |
| 特徴的な声 | 「自分で読み込む前提の道具」「技術者でない人にはおすすめしない」 | Vrbo の接続が何週間も有効にならず二重予約、年間契約の自動更新で返金なし |

日本語のレビューサイトでは、Beds24 の満足度が低い（1件・5点中2.0）という情報もあります。画面への不満、同期エラー、サポートの質のばらつき、という内容でしたが、件数が少なく、断定できません。

## 日本で使うときの注意（両社共通）

- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーで、**両社が該当するかは確認できていません。**
- **楽天トラベル・じゃらん**：両サイトは民泊新法・特区民泊の施設を対象外としています。Beds24 の日本の販売会社も、「じゃらんは民泊新法・特区民泊は掲載対象外」と案内しています。民泊を楽天トラベルに出す窓口の Rakuten Oyado は、Beds24 を「そのまま使える」ツールに挙げています。
- **決済**：Lodgify Payments は米国のホストだけです。Beds24 は Stripe などで、日本で使えるかは要確認です。
- 年180日の管理、届出番号、定期報告などの機能は、**両社とも公式ページに記載が見つかりませんでした**（「できない」と確認したわけではありません）。

## よくある質問

### Beds24 と Lodgify の一番大きな違いは何ですか？
日本での使いやすさと、画面です。Beds24 は日本の販売会社経由で日本語版と国内予約サイトの連携があり、安い一方、画面は古めで自分で調べて使う道具です。Lodgify は自分の予約サイトを作ることが中心で、画面は直感的ですが、日本語は確認できません。

### 日本語で使えるのはどちらですか？
Beds24 です。ただし日本の販売会社（株式会社WeIns）経由の日本語版です。Lodgify は、公式には日本語の管理画面もサポートも確認できませんでした。

### 安いのはどちらですか？
Beds24 の方が安い傾向です（海外公式は月€15.50から、日本の販売会社は月¥4,580から）。Lodgify は1物件の表示価格が$14〜$68で、3室以上は$47〜です。

### 解約しやすいのはどちらですか？
Beds24 の海外公式は縛りがなく、1か月前の通知で月末に解約できます。日本の販売会社は、毎月20日までにメールのみです。Lodgify は更新の通知なしに自動更新され、期間途中の返金がありません。

### 民泊新法の宿でも使えますか？
Airbnb のヘルプには、日本の民泊新法の宿について、ソフト連携で作った掲載を受け付けないという記載があります。例外は Airbnb と契約した日本のAPIパートナーです。両社が該当するかは確認できていないため、Airbnb と各社に確認してください。
