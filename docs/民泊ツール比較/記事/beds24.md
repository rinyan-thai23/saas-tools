# Beds24（ベッズ24）の評判・口コミまとめ｜日本の民泊で使える？

この記事にはアフィリエイトリンク（PR）が含まれます。リンクは海外公式（beds24.com）への紹介リンクです。紹介報酬の有無で、内容は変えていません。

## 先に結論：Beds24 はこんな人に向く

> - **向く人**：**とにかく安く、自分で設定を調べながら使える**人。月額€15.50からの従量制で、予約手数料はありません。**日本語版と楽天・じゃらん連携は、日本の販売会社が提供**しています。
> - **向かない人**：画面の使いやすさや、手厚いサポートを重視する人。口コミでは**「自分で調べる前提の道具（DIY）」**と言われています。
> - **口コミの特徴**：機能と価格は高評価。不満は、**画面が古い、覚えることが多い、サポートがメール中心**です。
> - **日本の民泊新法の人は要注意**：じゃらんは民泊新法の施設を対象外としています（[詳しくはこちら](#japan)）。

## Beds24とは？何ができるツールか

Beds24 は、ドイツ・ベルリンの会社（Beds24 GmbH）が運営する、民泊・ホテル・ゲストハウス向けの予約管理とチャネルマネージャーです。**機能が多く、細かく設定できる代わりに、画面は古めで、自分で調べて使う道具**です。公式は「セルフサービスのシステム」と書いています。

### 2つの窓口がある（日本では重要）
| | 海外公式（beds24.com） | 日本の販売会社（株式会社WeIns） |
|---|---|---|
| 通貨 | ユーロ | 円 |
| 管理画面 | 英語・ドイツ語 | 日本語版を提供 |
| サポート | 英語またはドイツ語（チケットとフォーラム） | 日本語（基本操作は電話、設定の依頼はメール） |
| 国内の予約サイト | 公式の連携は海外中心 | 楽天トラベル・じゃらん・Yahoo!トラベル等に対応 |
| トライアル | 14日間・カード不要 | 1か月無料 |

**契約する窓口で条件が変わります。** この記事の「海外公式」のリンクは、海外の公式サイトへの紹介リンクです。日本の販売会社にはリンクを付けていません。

### 主な機能
#### 予約サイトの一元管理
Airbnb・Booking.com・Expedia と連携します（いずれも公式のパートナー表示）。ほかにも多くのサイトに接続できます。

#### 予約エンジン・自動メッセージ
自社の予約サイトと予約エンジンが月額に含まれ、予約手数料はありません。自動メッセージ、自動の決済請求、レポート、チェックイン連携も含まれます。**ゲストの予約ページは20以上の言語に対応し、日本語もあります。**

#### スマートロック・価格ツール
海外公式では RemoteLock・Nuki・Jervis などと、日本の販売会社ではキーポ（美和ロック）・KEYVOX・RemoteLOCK と連携します。Akerun・SESAME は載っていません。価格ツールは PriceLabs・Beyond など。

#### 請求書
日本の販売会社のブログに、適用税率や事業者登録番号を載せた領収書を自動で作る設定方法があります（インボイス対応の設定）。

## Beds24の料金はいくら？

**料金は「基本料＋部屋数＋接続するチャネル数」の前払い従量制で、予約手数料はありません。** 契約や最低期間もなし、と公式は書いています。

### 海外公式（ユーロ・月額）
最低月額は€15.50。公式の計算式からの目安は次のとおりです（部屋のタイプ数と、チャネル数で変わります）。

| 室数 | 2チャネル（例：Airbnb＋Booking.com） |
|---|---|
| 1室 | €16.60 |
| 3室 | €24.00 |
| 5室 | €31.40 |
| 10室 | €49.90 |

- 同じタイプの部屋が複数あるときは、「部屋タイプ数」で数えるため、これより安くなることがあります。
- 独自の予約サイトの名前（Private label）は月€19。導入支援（有料）は€79から。
- **料金の改定**：6週間前の通知。異議があれば従前の料金で続けられます（規約）。

### 日本の販売会社（円・月額）
- 例：一棟貸しなど（Airbnb・Booking.com・Expedia）で**月¥4,580から**。10室（タイプ3・5OTA）で月¥17,280、20室で月¥24,210（いずれも自社掲載の参考価格）。
- 国内予約サイトの追加：じゃらん・楽天トラベル・Yahoo!トラベルは、月¥1,200／部屋タイプ＋初期費用¥3,000／部屋タイプ（3つ目の予約サイトは初期費用のみ）。
- **契約**：最低1か月・日割りなし。解約は**毎月20日までにメール**（電話不可）。解約した施設の再登録は5万円。支払いはクレジットカードのみ。

## Beds24の評判・口コミまとめ

海外のレビューサイト（Capterra）の口コミ55件を読んで、日本語にまとめました。**件数が少ない**ので、傾向は目安です。

> **読む前に**
> - 英語圏の運営者の声が中心で、日本の運営者の声ではありません。日本語の口コミは少なく、見つかったのは、レビューサイトの1件（満足度2.0）と、Trustpilot の日本語ページの要約（5点中2.8）だけです。後者はページを開けず、要約の確認のみです。
> - 投稿者の多くは、**2〜10人規模の事業者か自営業**。使用期間は、2年以上が約4分の1と、長く使う人も多めです。
> - 件数は、口コミ中の話題をキーワードで数えたおおよその数です。

### 良い口コミ：連携、価格、機能の多さ

- **予約サイトとの連携・同期**（良い点に挙げた人が約3割で最多）：接続できるサイトが多い、同期が安定している。
- **価格**（約23%）：安い、価格に対して機能が多い。
- **自動化**（約14%）：自動化の幅が広い。
- **API**：自分でデータを出し入れできる、という技術系の利用者の声。
- **サポート**（約16%）：担当者によっては丁寧、という声。

### 悪い口コミ：古い画面、覚えること、サポート

- **画面が古い、設定が見つけにくい**：画面が現代的でなく、設定項目が探しにくい。最近、更新が入ったという声もあります。
- **学習コストが高い**：「これは自分で読み込む前提の道具」「技術者でない人にはおすすめしない」という声。
- **サポートがメール中心**（改善点に挙げた人が約16%）：電話・チャットがなく、ドイツの営業時間内だけの対応、という声。**これは海外公式の話で、日本語のサポートは別の窓口**です。
- **料金設定が複雑、トレーニングやサポートが追加費用**という声。
- **自動メッセージやカレンダー同期の設定が複雑**、ログインの問題が出る、という声（2026年2月）。

### 低評価の傾向

55件のうち、1〜2点は1件（約2%）で、とても少ない水準です。その1件は2020年の投稿で、電話サポートがなく、Booking.com への切り替え時に価格と空室が消えた、という内容でした。ただし、日本語のレビューサイト（1件）では満足度が低く、**画面への不満、同期エラー、サポートの質が担当者でばらつく**、という内容でした。件数が少なく、断定はできません。

## <span id="japan"></span>Beds24は日本で使える？民泊の注意点

### 日本語は、日本の販売会社経由なら使える
海外公式の管理画面は英語・ドイツ語で、公式のWikiには「日本語版は、パートナーの Co-Reception（日本の販売会社）経由だけ」とあります。日本語のサポートも、その窓口です。**ほかの海外ツールより、日本語で使える可能性が高い**のが、Beds24 の特徴です。

### 国内の予約サイトにつなぐ方法
- **楽天トラベル**：公式のWikiには、接続は Vacation STAY（Rakuten Oyado）経由、とあります。日本の販売会社の案内は、別の手順（R-Connect の申請など）で、**現行の方式は確認できていません**。
- **じゃらん**：日本の販売会社が連動を提供しています。**ただし、じゃらんは民泊新法・特区民泊の施設を対象外**としています（旅館業の許可が必要）。
- 楽天トラベルも、民泊新法の施設は対象外です。民泊新法・特区民泊は、楽天グループの Rakuten Oyado が窓口で、**Rakuten Oyado が「そのまま使える」としているツールに Beds24 が入っています。**

### 住宅宿泊事業法（民泊新法）の場合は、先に確認が必要
- Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。Beds24 が該当するかは、確認できませんでした。
- 年180日の管理、届出番号の表示、定期報告など、日本の制度に当たる機能は、公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。

### 乗り換えの注意
日本の販売会社への申込フォームには、いま使っているサイトコントローラー名（ねっぱん／手間いらず／その他）を書く欄があります。国内予約サイトを他社のツールと連動している場合は、**先に解除して、解除後は売り止め**が必要です。既存の予約は自動で取り込まれず、手入力になります。

詳しくは [住宅宿泊事業法への対応](/articles/jp-minpaku-law/)、[楽天トラベル・じゃらん等の国内予約サイト連携](/articles/jp-ota-rakuten-jalan/)、[日本語UI・日本語サポート](/articles/jp-japanese-ui-support/) へ。

## よくある質問

### Beds24 は日本語に対応していますか？
海外公式の管理画面は英語・ドイツ語です。日本語版は、日本の販売会社（株式会社WeIns）経由で提供されていて、日本語のサポートもその窓口です。ゲストが見る予約ページは、日本語を含む20以上の言語に対応しています。

### Beds24 の料金はいくらですか？
海外公式は、最低月額€15.50からの従量制で、2チャネルの目安は1室€16.60、5室€31.40、10室€49.90です。日本の販売会社は、月¥4,580からです。予約手数料はありません。

### Beds24 に無料トライアルはありますか？
海外公式は14日間（カード不要。本番運用の前に支払いと本人確認が必要）、日本の販売会社は1か月無料です。

### 契約期間や解約条件は？
海外公式は、契約や最低期間はなく、1か月前の通知で月末に解約できます。日本の販売会社は、最低1か月・日割りなしで、解約は毎月20日までにメールのみ（電話不可）です。

### 日本の民泊新法の宿でも使えますか？
じゃらんと楽天トラベルは、民泊新法・特区民泊の施設を対象外としています。民泊を楽天トラベルに出す窓口の Rakuten Oyado は、Beds24 を「そのまま使える」ツールに挙げています。Airbnb は、日本の民泊新法の宿で、ソフト連携で作った掲載を受け付けません（例外は日本のAPIパートナー）。Beds24 が該当するかは確認できていないため、Airbnb と Beds24 の両方に確認してください。

### 楽天トラベルやじゃらんにつなげられますか？
日本の販売会社が、楽天トラベル・じゃらん・Yahoo!トラベルの連動を提供しています（旅館業の許可施設）。民泊新法・特区民泊は、じゃらんは対象外、楽天トラベルは Rakuten Oyado が窓口です。
