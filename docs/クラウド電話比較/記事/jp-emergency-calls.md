# 【クラウド電話】110・119にかけられる？緊急通報の扱いと備え

## 先に結論

> - **今回確認できた製品の公式の記載は、110・119について「発信できない」「利用できない」です。** Zoom Phone、RingEX、Dialpad（公式ヘルプの抜粋）がそうです。ほかの製品は、記載を確認できていません。
> - **クラウド電話から110・119にかけられることを、前提にしないでください。** 携帯電話か固定電話を、緊急用に残してください。
> - 消防庁の広報にも、「050」から始まる電話番号は119番通報できないものがあるので、事業者に確認を、と書かれています。
> - この記事は、**公式の記載の整理**です。法律の判断はしていません。

## 誰のための記事か

事務所の電話を、固定電話からクラウド電話に切り替えようとしている小さな事業者です。「普段の電話はクラウドで、いざというとき110・119は大丈夫か」を知りたい人向けです。

## 製品別：公式の記載

| 製品 | 110・119の記載 | 出どころ |
|---|---|---|
| [Zoom Phone](/articles/zoom-phone/) | **110・119・118は発信不可**（04、115、117、177、171、188、189、0570なども） | Zoom 日本の「電話番号の要件」ページの「サービスの制限」 |
| [RingEX（RingCentral）](/articles/ringex/) | 日本は「**緊急通報は利用できない**（Emergency calling unavailable）」 | RingCentral の緊急通報ポリシー（2023年12月20日改訂版） |
| [Dialpad](/articles/dialpad/) | **1で始まる3桁の番号（184・186を除く）は発信できない**。0570にも発信できない | Dialpad 公式ヘルプの抜粋（ページ本体は開けませんでした） |
| [Aircall](/articles/aircall/) | パソコンのアプリで国の緊急番号にかけられる国に、**日本は入っていない**。スマホのアプリは、緊急通報はスマホ本来の電話アプリに切り替えてつながる、との記載（日本の110・119が入るかは確認できず） | Aircall 公式ヘルプ「緊急通報と短い番号」 |
| [CloudTalk](/articles/cloudtalk/)、[CallHippo](/articles/callhippo/)、[JustCall](/articles/justcall/)、[GoTo Connect](/articles/goto-connect/)、[Nextiva](/articles/nextiva/)、[Telnyx](/articles/telnyx/) | **記載を確認できていません** | — |

**「記載がない」ことは、「かけられる」という意味ではありません。** 前提にしないで、申込前に書面で確認してください。

## 消防庁・警察の案内（公式）

- **消防庁の広報（「消防の動き」2025年11月号）**：「加入者番号が『050』から始まる電話番号は、119番通報できないものがありますので、自宅のIP電話が緊急通報に対応しているか、契約しているIP電話事業者に確認してください」とあります。**対応していない場合は、携帯電話から119番通報するか、管轄の消防本部の電話番号を控えておく**よう案内されています。
- **神奈川県警の案内（2023年7月更新）**：IP電話から110番通報した場合、**契約者情報（住所・氏名）が位置情報として通知される**、スマートフォン・携帯電話は、GPS衛星や基地局の位置から算出される位置情報が通知される、と説明されています。
- **総務省の情報通信白書（平成21年版）**：050型IP電話は緊急通報（110、119等）を利用できない点がある、0AB〜J型IP電話は緊急通報を利用できるなどの特徴がある、と説明しています。**2009年の記述**なので、今のクラウド電話の各製品の扱いは、各社の公式の記載を見てください。実際に、Zoom Phone や Dialpad は、0AB-J／0ABJの番号でも、110・119は発信できないと書いています。

## 事務所の備え

1. **携帯電話か固定電話を、緊急用に残す。**（クラウド電話に切り替えても、ひとつは残す）
2. **管轄の消防本部の電話番号を、控えておく。**（消防庁の案内）警察署の番号も控えておくと安心です。
3. **事務所の住所を、すぐ伝えられるようにしておく。** 貼り紙などにする。
4. 外出先のスマホは、**スマホ本来の電話アプリ**から通報する。クラウド電話のアプリは使わない。
5. 通報後は、**折り返しの電話**があることがあるので、携帯の電源を入れておく（消防庁）。
6. 契約するとき、**緊急通報の扱いを、書面で確認**する。

## 申し込む前に聞くこと

1. 110・119・118に、**発信できるか、できないか**。0AB-J／0ABJ の番号でも同じか。
2. できない場合、**画面や契約書に、その旨の記載があるか**。
3. スマホのアプリから通報する場合、**スマホ本来の電話に切り替わるか**。
4. 位置情報（住所）は、**通報先に通知されるか**。
5. 緊急通報に関して、**ほかに利用できない番号**（115、117、171、188、0570など）はあるか。

## よくある質問

### クラウド電話から、110番・119番に電話できますか？
製品で違います。Zoom Phone は発信不可、RingEX は利用できない、と公式に書いています。Dialpad は公式ヘルプの抜粋に発信できない、とあります。ほかは確認できていません。前提にしないでください。

### 050以外の番号（03・06）なら、かけられますか？
Zoom Phone と Dialpad は、03・06などの固定番号でも、110・119は発信できない、と書いています。番号の種類だけでは決まりません。

### 緊急時は、どうすればよいですか？
携帯電話などから通報してください。消防庁の案内では、クラウド電話が対応していない場合は、携帯電話から119番通報するか、管轄の消防本部の電話番号を控えておく、とあります。
