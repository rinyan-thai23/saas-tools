Lodgify（ロッジファイ）の評判・口コミまとめ｜日本の民泊で使える？

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

先に結論：Lodgify はこんな人に向く

  • 向く人：自分の予約サイト（直接予約）を持ちたい人。予約サイトを作る機能が中心で、予約ごとの手数料は取られません。小規模の自営業の運営者に使われています。
  • 向かない人：日本語の画面・サポートが必須の人。契約更新の連絡なしに自動更新されるのが困る人（規約にあります）。
  • 口コミの特徴：サポートと使いやすさは好評。不満は予約サイトとの同期のトラブルと、料金・自動更新に出ています。
  • 日本の民泊新法の人は要注意：Airbnb の日本向けルールで、ツール経由の掲載が受け付けられない場合があります（詳しくはこちら）。

Lodgifyとは？何ができるツールか

Lodgify は、民泊や短期賃貸のための管理ソフトで、自分の予約サイトを、プログラムなしで作れるのが最大の特徴です。Airbnb・Booking.com・Vrbo など複数の予約サイトとの同期（チャネルマネージャー）もできます。運営会社は英国法人（Codebay Solutions Limited）で、規約は英国法が基準です。

主な機能

直接予約サイトの作成

テンプレートで予約サイトを作れ、予約エンジンや、既存サイトに埋め込む予約ウィジェットもあります。年払いだと独自ドメインが無料になります。予約手数料はゼロですが、サイト経由のオンライン決済には別に1%がかかります。

予約サイトの一元管理

Airbnb・Booking.com・Vrbo と連携し、カレンダーを同期して二重予約を防ぎます。Google Vacation Rentals への掲載もあります。

メッセージ・自動化・タスク

AI対応の統合受信箱、ゲストへの自動メッセージ、清掃などのタスク管理があります。

スマートロック・決済

自社のスマートロック（月$7/台）と、Nuki・igloohome などとの連携があります。日本製のロックは、連携一覧に載っていません。自社の決済（Lodgify Payments）は米国のホストだけです。

ダイナミックプライシング

上位プランに含まれる料金の自動調整が、新しくなっています。

Lodgifyの評判・口コミまとめ

海外のレビューサイト（Capterra）の口コミ約190件を読んで、日本語にまとめました。

読む前に

  • 英語圏の運営者の声が中心で、日本の運営者の声ではありません。
  • 投稿者のほぼ全員が、自営業か2〜10人規模の事業者でした。使用期間は半年以内が約8割で、「導入直後の感想」が中心です。
  • 件数は、口コミ中の話題をキーワードで数えたおおよその数です。

良い口コミ：連携、サポート、使いやすさ

  • 予約サイトの連携・同期（良い点に挙げた人が約4分の1で最多）：複数のサイトを1つのカレンダーで管理できる。
  • サポートが親切（約2割）：導入時の個別サポートが丁寧、という声が多め。
  • 使いやすい（約2割）：画面が分かりやすい、予約サイトを簡単に作れる、という声。
  • コスパ：他の管理ツールより安い、という声。

悪い口コミ：同期のトラブルと料金

  • 予約サイトとの同期の不具合（改善点に挙げた人が約2割で最多）：Vrbo の連携が何週間も有効にならず二重予約になった、物件の紐づけを取り違えて、別の部屋に宿泊客を案内してしまった（2026年）、という投稿があります。個別の事例ですが、重い内容です。
  • 料金・追加費用（約16%）：思ったより高い、上位プランへの切り替えが高い、レポート機能が最上位プランだけ、という声。
  • 自動更新：低評価に、「年間契約が更新の警告なしに自動更新され、解約を頼んだらアカウントは閉じたが年額は返金されなかった」（2026年）という投稿があります。規約の内容（更新前の通知なし、期間途中の返金なし）と合っています。
  • サポートの返事が遅い：返信に5〜8日かかった、9日待った、という声。電話がなく、チケットだけ、という声。
  • 導入が大変：資料が分かりにくい、設定に時間がかかる、という声。

低評価（1〜2点）の傾向

約190件のうち、1〜2点は14件（約7%）です。Hostaway（約4%）より多く、Guesty（約13%）より少ない水準です。内容は「同期・接続の不具合」「サポートの遅れ」「営業の説明と実際のズレ」「自動更新と返金」に分かれていました。機能そのものより、つながり方と、困ったときの対応に不満が出る傾向です。

Lodgifyは日本で使える？民泊の注意点

日本語の画面・サポートは確認できない

公式サイトの言語は、英・西・仏・葡・伊・独・ギリシャ語の7つで、日本語はありません。管理画面そのものの言語は、確認できていません。サポートは「24時間」と公式に書かれていますが、電話番号は米・英・豪・伊・西・仏で、日本の番号はありません。サポートの言語一覧は、見つかりませんでした。

公式サイトは、通常の方法では開けなかった

Lodgify の公式サイト本体は、自動アクセスを断る仕組みで開けませんでした。この記事の公式情報は、Lodgify 自身が公開している同内容のコピー（マーケティングサイト）で確認したものです。内容が完全に同じかは、確認できていません。

住宅宿泊事業法（民泊新法）の場合は、先に確認が必要

  • Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。Lodgify が該当するかは、確認できませんでした。
  • 年180日の管理、届出番号の表示、定期報告、インボイスなど、日本の制度に当たる機能は、公式ページに記載が見つかりませんでした（「できない」と確認したわけではありません）。
  • 決済：Lodgify Payments は米国のホストだけです。日本のアカウントで Stripe や PayPal が使えるかは、確認できませんでした。

楽天トラベル・じゃらんには出せる？

楽天トラベルとじゃらんは、民泊新法・特区民泊の施設を対象外としています。Lodgify の連携一覧には、楽天トラベルも Agoda も載っていません。旅館業法の許可施設は、Lodgify に接続の可否を直接聞いてください。

詳しくは 住宅宿泊事業法への対応、楽天トラベル・じゃらん等の国内予約サイト連携、日本語UI・日本語サポート へ。

申し込む前に Lodgify へ聞くこと

  1. 3室以上の正確な月額と、プランごとの機能差（特にレポート、ダイナミックプライシング）。

  3. 日本から Stripe や PayPal を使えるか。決済の1%は誰の負担か。
  4. 日本語で問い合わせできるか。サポートの言語。
  5. 私の営業形態で、Airbnb・楽天トラベル・じゃらんに接続できるか。
  6. 今使っているツールがあるとき、導入時に設定やつながりに影響が出ないか。

よくある質問

Lodgify は日本語に対応していますか？

公式サイトの言語は英語・スペイン語・フランス語・ポルトガル語・イタリア語・ドイツ語・ギリシャ語で、日本語はありません。サポートの言語一覧も見つかりませんでした。管理画面の日本語は確認できていないため、無料トライアルで確かめてください。

Lodgify の料金はいくらですか？

1物件の月額の表示は、Basic $14、Starter $26、Professional $47、Ultimate $68です（年払いと推定）。物件が増えると上がります。3室以上は Professional 以上が前提です。

Lodgify に無料トライアルはありますか？

7日間の無料トライアルがあり、カード登録は不要です。

解約はしやすいですか？

公式には「長期契約はなく、いつでも解約できる」とあります。ただし規約では、前払いの期間が更新の通知なしに自動更新され、解約はアカウント画面から期間終了の1日前までです。期間の途中で解約しても、返金はありません。

日本の民泊新法の宿でも使えますか？

Airbnb のヘルプには、日本の民泊新法の宿について、ソフト連携で作った掲載を受け付けないという記載があります。例外は Airbnb と契約した日本のAPIパートナーです。Lodgify が該当するかは確認できていないため、Airbnb と Lodgify の両方に確認してください。

楽天トラベルやじゃらんにつなげられますか？

公式の連携一覧に、楽天トラベルもじゃらんも載っていません。両サイトは民泊新法・特区民泊の施設を対象外としています。旅館業法の許可施設は、Lodgify に接続の可否を問い合わせてください。
