## 指摘

### 1. 注意：Hostaway の Expedia「API 接続」は自社の主張である
- 記事（条件別）：「Expedia を API 接続で使いたい人：Hostaway は対応と確認でき、iGMS は iCal（1時間更新）です。」
- カード：Hostaway 3章 Expedia「対応」確認済。API 接続の記述（"Direct API connection, real-time sync"）は自社の比較ページの主張（接続方式の行）。
- 修正案：「Hostaway は対応を確認でき（API 接続は自社の主張）」と注記する。

### 2. 軽微：比較表「3・5・10室」の行に Hostaway の3室がない
- 記事：「公式の数字なし。第三者の推定は5〜9室で月$175〜$250、10室以上は1室$15〜$25」
- カード：Hostaway 2章「物件数別の目安：1・3室」は第三者推定で「1〜4室で月$125〜$175」。
- 修正案：3室の欄に「第三者の推定は1〜4室で月$125〜$175（食い違いあり）」を足すか、行の見出しを「5・10室」に変える。

### 3. 軽微：結論1「料金が公式ページに載っているのは iGMS だけです」
- 記事：「料金が公式ページに載っているのは iGMS だけです」
- 問題：この2製品の中での話だが、読者には市場全体の話に読める。本文の他製品（Hospitable など）は公開している。
- 修正案：「この2製品のうち、公式ページに料金が載っているのは iGMS だけです」とする。

### 4. 軽微：description の「公式情報で整理」
- 記事（frontmatter）：「料金の公開度、契約条件、日本語対応、楽天・じゃらんの扱いを公式情報で整理。」
- カード：Hostaway の日本語UI・口コミ・料金推定は「第三者のみ」または「未確認」が多い（ヘルプセンター403）。
- 修正案：「公式情報（確認できない点は未確認と明記）で整理」とする。
