# 【体験・ツアー】BókunとFareHarborを比較｜日本の事業者が申し込む前に見ること

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

## 先に結論

> - **日本の事業者は、まず Bókun（JTB BÓKUN）です。** JTB の資料に、円の料金表と日本語サポートの記載があります。FareHarbor は、公式の対応国に日本が見当たらず、契約できるかが先に問題になります。
> - **手数料の考え方が違います。** Bókun は月額＋1〜1.5%（日本版は月額＋1.25〜3.5%）。FareHarbor は月額の公開がなく、口コミではお客さんが払う約6%の予約手数料が目立ちます。
> - **FareHarbor に向く人**：アメリカなど対応国で事業をしていて、手厚い導入支援を受けたい人。日本の事業者には、現時点でおすすめしにくいです。

## 料金と手数料

- **Bókun**：月額に、予約ごとの手数料を足す形です。海外版は公式の料金ページに載っています。日本版の円の料金は、JTB の資料（2026年5月版）にあります。どちらも自社の発表です。
- **FareHarbor**：公式に価格はありません。口コミには「お客さんが払う6%の予約手数料が高い」「手数料を自分で負担できない」という声が複数あります。
- Bókun の公式ページは、FareHarbor の手数料を「6%」と書いて比べています。これは競合の主張で、公式の数字ではありません。口コミの声とは近い数字です。

**予約数が少ないうちは月額なしの方が軽い**ことがありますが、日本の事業者の場合は、そもそも契約できるかを先に確認してください。

## 予約サイト（OTA）との連携

- **Bókun**：公式は「2,600以上の販売会社、うち70以上の世界の予約サイトとつながる」と書いています（自社の主張）。Viator とは同じグループ（Tripadvisor）で、商品を取り込めると説明しています。JTB 版は「20社以上の海外予約サイトと連携」です。
- **FareHarbor**：公式は「250を超える予約サイトとAPIでつながる」と書いています（自社の主張）。

**どちらも、じゃらん・アソビュー・楽天などの日本のサイトとの連携は、確認できませんでした。**

## 契約・導入

- **導入の手助け**：第三者のレビューサイト（Dupple）は、Bókun は初期設定が複雑で時間がかかる、FareHarbor は設定の手助けが手厚い、と書いています。FareHarbor は公式も「私たちが画面を作り、今後の予約を移す」と説明しています。
- **契約の縛り**：Bókun は「いつでも解約できる」と公式にあります。FareHarbor は、口コミに「契約後に手数料や条件が変わった」という低評価があります。

## 口コミ（海外のレビュー）の違い

どちらも約180件を読んでいます。**どちらも海外の事業者の声で、日本の事業者の声ではありません。**

| | Bókun | FareHarbor |
|---|---|---|
| 良い点で多い話 | 使いやすさ（約3割）、サポート（約4分の1）、予約サイト連携 | 使いやすさ（約4割）、サポート（約4割） |
| 悪い点で多い話 | 画面が複雑、料金、連携の不具合 | お客さんへの上乗せ手数料（約1割）、覚えることが多い |
| 低評価（1〜2点） | 約7件（約4%） | 約11件（約6%） |
| 日本の投稿者 | 1人（旅行会社、3点） | 0人 |

**不満の中心が違います。** Bókun は「慣れるまで大変、連携が壊れることがある」。FareHarbor は「手数料が高い、サポートの返事がない」です。

## 日本の事業者として見るポイント

- **契約できるか**：FareHarbor は、公式ヘルプの対応国で日本が見当たらず、会社と銀行口座が同じ国という条件もあります（全文は未確認）。Bókun は日本版の窓口があります。
- **円と決済**：Bókun の日本版は円の料金表があります。FareHarbor は円の記載が確認できませんでした。
- **日本語**：Bókun の日本版は日本語サポートの記載があります。FareHarbor は英語です。管理画面の日本語は、どちらも確認できていません。

詳しくは、[Bókun の商品ページ](/articles/bokun/)、[FareHarbor の商品ページ](/articles/fareharbor/)へ。

## 申し込む前に聞くこと

1. **日本の事業者として契約できるか**（特に FareHarbor）。円で受け取れるか。
2. 手数料の総額（月額＋予約手数料＋決済手数料）を、書面で。誰が払うか。
3. 日本語で問い合わせできるか。日本時間の窓口は。
4. つなぎたい予約サイトの名前（日本のサイトを含む）で、接続できるか。
5. 今の予約を移すときの方法と日程。
6. 解約の条件と、データの書き出し。

## よくある質問

### 日本の事業者はどちらを選べばいいですか？
まず Bókun の日本版（JTB BÓKUN）です。円の料金表と日本語サポートの記載があるためです。FareHarbor は、公式の対応国に日本が見当たらないため、契約できるかの確認が先です。

### 手数料が安いのはどちらですか？
Bókun は月額＋1〜1.5%（日本版は1.25〜3.5%）と公式にあります。FareHarbor は公式に料金がなく、口コミでは約6%です。ただし、FareHarbor の公式の数字ではないので、見積りで確認してください。

### どちらも海外の予約サイトにつながりますか？
どちらも、Viator、GetYourGuide などの世界の予約サイトとつながると、公式に書いています。日本の予約サイトとの連携は、どちらも確認できませんでした。

### 無料で試せるのはどちらですか？
Bókun は14日間（日本版は30日間）の無料トライアルがあります。FareHarbor は無料トライアルの記載がなく、デモの申込です。
