【体験・ツアー】FareHarborの代替｜日本の事業者が選べる予約システム6つ

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

先に結論

  • 日本の事業者は、日本語の窓口がある製品から選ぶのが現実的です。 確認できたのは3つ：rezio（日本語サイトと円の料金表あり）、OMUSUBI（国産。国内OTAの予約メールを自動取込）、Bókun の日本版 JTB BÓKUN（円の料金表と日本語サポートの記載あり）。
  • FareHarbor をやめたい理由で多いのは3つ：①日本で契約できるか分からない ②お客さんが払う約6%の手数料（口コミ）③サポートの返事が遅い（口コミ）。
  • 海外の製品（Xola、Rezdy、Checkfront、Zaui）は、日本語サポートがなく、日本の事業者として契約できるかの確認が先です。

FareHarbor が合わない主なケース

FareHarbor の商品ページで書いたとおり、次のような人には向きません。

  • 日本の事業者：公式ヘルプの対応国に日本が見当たらず、会社と銀行口座が同じ国という条件がある（全文は未確認）。
  • 手数料を抑えたい人：口コミで、お客さんが払う約6%の予約手数料への不満が多い。
  • 日本語で相談したい人：公式サイトは英語。

1. rezio（日本語サイトあり）

台北が拠点の予約システムで、KKday 系列です。 公式の沿革には、2020年に日本と台湾の市場で始めたこと、2022年に KKday、Activity Japan（アクティビティジャパン）、Viator と API でつながったことが載っています。公式の日本語ページには「旅ナカ事業者用 基幹システム」とあり、円の料金表があります。

  • 確認できた料金：日本語ページのデータでは、月額（30日・税込）が ENTRY ¥0、STANDARD ¥990、ADVANCE ¥3,300、PREMIUM ¥11,000。英語ページには、USD $49.9／$99.9／$216.6 の3プランもあります（日本語ページとの対応関係は確認できていません）。
  • 手数料：自社サイト・予約エンジン経由は3.5%（ENTRY・STANDARD）〜2.5%（PREMIUM）、OTA 経由は rezio 側の手数料0%（OTA 各社の手数料は別）、手入力の予約は0%。オンライン決済の手数料との関係は確認できていません。
  • 機能：自社サイトの予約エンジン、言語・通貨の切り替え表示、在庫管理、スマホアプリ（QRコードでの受付）、サイトコントローラー（外部販路の管理）。
  • 連携：KKday、Viator、Google Things to do（公式）。じゃらん・アソビュー・楽天などは、記載が見つかりませんでした。

注意：Capterra では口コミを取得できず（0件）、第三者の口コミはほぼ読めていません。公式は日本の事業者の事例（観光農園、着物レンタル、観光施設など）を載せています。詳しくは rezio の商品ページへ。

2. Bókun（JTB BÓKUN）

日本には JTB が提供する日本版があります。円の料金表、30日の無料トライアル、日本語サポートの記載が JTB の資料にあります。詳しくは Bókun の商品ページ、Bókun と FareHarbor の比較へ。

3. Xola

月額なしで、手数料は2.39%＋0.30ドル（アメリカの場合）。日本語の窓口は確認できませんでした。楽天が2016年に出資しています。詳しくは Xola、Xola と FareHarbor の比較へ。

4. Rezdy

月額$49から、手数料3%、21日の無料トライアル。予約サイトとの接続が全プランで無制限です。2025〜2026年の口コミに厳しい声が集中しています。詳しくは Rezdy、Bókun と Rezdy の比較へ。

5. Checkfront

月額$99＋3%、店頭の予約は手数料なし。ツアー以外にレンタル・宿泊も扱えます。サポートは英語のみです。詳しくは Checkfront、Bókun と Checkfront の比較へ。

6. Zaui

月額$0で、お客さんのオンライン予約に6%。ツアーと送迎を1つで管理できるのが特徴です。FareHarbor と同じくらいの手数料なので、「手数料を下げたい」という目的には向きません。詳しくは Zauiへ。

国産の選択肢：OMUSUBI

SEEC（東京・沖縄）の国産の予約管理システムです。月額無料のフリープラン、じゃらん・アソビュー・アクティビティジャパンの予約メールの自動取込、日本語と電話のサポートが公式にあります。海外の予約サイトへの配信は、OMUSUBI 単体では記載がなく、JTB BÓKUN と連携して使います。詳しくは OMUSUBI の商品ページへ。

乗り換える前に聞くこと

  1. 日本の事業者として契約できるか。円で受け取れるか。
  2. 月額・予約手数料・決済手数料の総額を、書面で。
  3. 日本語で問い合わせできるか。日本時間の窓口は。
  4. 今の予約を、新しい製品へ移す方法と日程。
  5. 日本の予約サイト（じゃらん、アソビュー、楽天など）に接続できるか。
  6. 解約の条件と、データの書き出し。

よくある質問

FareHarbor の代替で、日本語に対応しているのは？

日本語の窓口が見つかったのは、rezio（日本語サイト）、OMUSUBI（国産）、Bókun の日本版（JTB BÓKUN）です。ほかの製品は、日本語サポートの記載が見つかりませんでした。

一番手数料が安いのは？

プランと前提で変わります。Bókun の海外版は月額＋1〜1.5%、rezio は日本語ページの PREMIUM で自社サイト経由2.5%・OTA 経由0%です。Xola の「2.39%＋0.30ドル」はアメリカの場合で、日本は書かれていません。総額は、見積りを書面でもらって比べてください。

rezio は信頼できますか？

親会社は KKday で、公式は多くの事業者が使っていると書いています（自社の主張）。ただし、このサイトでは第三者の口コミを読めていません。無料体験や相談で確かめてください。
