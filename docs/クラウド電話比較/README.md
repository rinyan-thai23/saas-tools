# クラウド電話比較サイト（設計図・フェーズ0）

**誰に**：日本で、個人事業主〜10人ほどの会社を経営していて、**日本の電話番号（03・06などの市外局番、050、0120/0800）を持ちながら、パソコンやスマホのアプリで電話を受けたい・かけたい**人。RingCentral、Dialpad、Zoom Phone などの海外のクラウド電話の名前は聞いたことがある。固定電話の工事や、スマホの私用番号を事業に使うことに困っている。

**悩み**：日本の番号が取れるのか（書類・審査・日数）／050と市外局番の違い／110・119など緊急通報はかけられるか／既存の番号をそのまま移せるか／通話料は円でいくらか／日本語の画面・サポート／請求書・領収書（インボイス）。

**何を**：買う直前・乗り換え・比較の記事だけ。「クラウド電話とは」などの一般論は作らない。
