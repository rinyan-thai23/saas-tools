# Guesty と Hostaway を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

> **結論**
> - 料金が公式ページに載り、14日間（カード不要）試せると確認できたのは Guesty Lite（1〜3室）だけ。4室以上の Guesty Pro と Hostaway は、どちらも価格非公開の見積りです。
> - 日本語の管理画面は、どちらも公式には確認できませんでした。サポート言語は、Guesty は公式の一覧に日本語がなく、Hostaway は言語の記載が見つかりませんでした。
> - 楽天トラベル・じゃらんは、どちらの公式ページにも記載が見つかりませんでした（「接続できない」と確認したわけではありません）。

## 先に知っておくこと（日本で使うときの前提）

### 1. 営業形態によって、使える予約サイトの条件が違う

予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

| 予約サイト | 公式に書かれている条件 |
|---|---|
| 楽天トラベル | 旅館業法の営業許可証を取得した施設が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は「Rakuten Oyado」で登録、と案内 |
| じゃらんnet | 旅館業法の宿泊営業許可を得た施設が対象。住宅宿泊事業法に基づく民泊と特区民泊は「ご参画いただけません」（ページに更新日の記載なし） |
| Rakuten Oyado | 「楽天トラベルに民泊施設（住宅宿泊事業法/特区民泊）を配信できるのはRakuten Oyadoだけです」と同社ページ。配信はインスタントブッキング対応施設のみ。販売手数料は一律3% |
| Airbnb | ヘルプ："In Japan, we don't accept listings created through software connections for places to stay (minpaku) used for Housing Accommodation Business under the Japanese Housing Accommodation Business Act" 。例外は、Airbnb とライセンス契約を結んだ日本のAPIパートナー |

- Rakuten Oyado のページで「そのまま使える」と書かれている既存ツールは、ねっぱん、AirHost、Beds24、suitebook。Guesty と Hostaway の名前は載っていません。
- Airbnb の例外にあたる「日本のAPIパートナー」の名前は、公式ページで見つかりませんでした。また、この文は「ソフト連携で作成されたリスティング」の扱いについての記載で、すでに Airbnb 上にある民泊新法の掲載を後からツールにつなぐ場合の扱いは、確認できていません（未確認）。申込前に Airbnb と各社へ確認する項目です。
- 同じ Airbnb ヘルプには、届出番号は「ツールを使っていても、自分でアカウントにログインして」追加する必要がある、という記載もあります。

## 条件別の選び方

- **1〜3室で、まず価格を公式ページで見て、カード登録なしで試したい人は Guesty Lite。** ただし Lite の接続先は Airbnb・Booking.com・Vrbo の3つで、オーナーポータルは使えません。4室になると Pro（見積り）に移ります。
- **4室以上で、見積りを取って比べる人は両方に同じ質問を出す。** 価格・初期費用・契約期間・解約金・値上げ条件を書面で出してもらうのが先です（チェックリスト参照）。
- **契約期間を短くしたい人：** Guesty は規約上13か月＋自動更新が基本（契約書の記載が優先）。Hostaway は規約が個別契約に委ねているため、見積り時に期間を確認してください。
- **Agoda も使う人：** Guesty は公式に掲載があります。Hostaway は接続を確認できていません。
- **予約サイトの日本語表示が必要な人：** Guesty は予約エンジンの日本語を第三者の抜粋が示しています（公式では未確認）。Hostaway の予約サイトは日本語なしとされています（言語は第三者のみ）。どちらも申込前に実画面で確認してください。
- **楽天トラベル・じゃらんが必須の人：** この2製品の公式ページでは確認できませんでした。民泊新法・特区民泊の施設は両サイトの対象外と各社が書いています（上の表）。旅館業法の許可施設については、Guesty・Hostaway それぞれの接続可否が未確認なので、申込前に各社へ問い合わせてください。

## 申し込む前に確認すること

- [ ] 自分の営業形態（住宅宿泊事業法の届出／旅館業法の許可／特区民泊の認定）で、使いたい予約サイトに載せられるか（楽天トラベル・じゃらん・Airbnb の公式条件を確認）
- [ ] Airbnb に、民泊新法の掲載をツールにつなげるか（既存の掲載を含む）を確認した
- [ ] 見積りで、月額・初期費用・オンボーディング費用・有料アドオンの内訳を書面で受け取った（Guesty Pro／Hostaway）
- [ ] 契約期間、自動更新の条件、中途解約の費用（Guesty は最低月額×残り月数と規約にある）を確認した
- [ ] 値上げの通知期間と、同意しない場合の解約条件を確認した（Hostaway は14日前通知、Guesty は日数の記載なし）
- [ ] 請求通貨が円で請求できるか、USDで請求される場合のカードの為替手数料を確認した
- [ ] サポートに日本語が通じるか、日本時間の窓口があるかを書面で確認した
- [ ] 日本語の管理画面が無い前提で、自分とスタッフが英語の画面で運用できるか、無料トライアル（Guesty Lite）やデモで試した
- [ ] 宿泊者名簿（国籍・旅券番号の記録、旅券の写し）に使う仕組みが、ツール内か外部サービス（Chekin 等）かを確認した
