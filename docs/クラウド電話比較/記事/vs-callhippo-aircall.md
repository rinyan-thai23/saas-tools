# 【クラウド電話】CallHippoとAircallを比較｜日本の事業者が申し込む前に見ること

## 先に結論

> - **日本の番号が目的なら、まず CallHippo です。** 公式に日本向けのページがあり、03・06・050・0120の番号、必要書類、日数が書かれています（自社の説明）。Aircall は、日本の番号を取れるという記載を、公式で確認できませんでした。
> - **人数の条件が違います。** Aircall は**最低3ライセンス**から。CallHippo は、公式の日本向けページに1ユーザーあたりの料金が載っています（最低人数は確認できていません）。
> - **どちらも、日本語の公式サイトと円の料金表は確認できませんでした。** 料金はドルです。**110・119は、前提にしないでください。**

## 日本の番号と通話

- **CallHippo**：日本向けページの表では、050は数日（海外の住所でもよい、と自社の説明）、03・06は15〜25営業日（東京・大阪周辺の住所の証明が必要）、0120・0800は1〜2週間です。携帯番号（090など）の説明は、公式で裏付けを確認できていません。**書類の条件は、Zoom Phone の公式ページと違って見えるため、書面で確認してください。**
- **Aircall**：日本の番号の記載はありません（「取れない」と確認したわけではありません）。日本宛の通話は、通話バンドルの「アジア・北米」に、固定電話宛だけが入っています。携帯宛は含まれず、バンドルの追加には担当者への連絡が必要です。
- **「無制限」に注意**：CallHippo の「無制限」は、米国・カナダ宛です。Aircall の「無制限」も、米国・カナダの範囲です。**日本宛の通話は、どちらも別の料金です。**

## 料金

- **CallHippo**：Starter $19、Professional $30、Ultimate $42（1ユーザー、月額）。10日間の無料トライアル。円は選べませんでした。
- **Aircall**：Essentials $30、Professional $50（1ライセンス）。最低3ライセンスなので、**3人だと月$90〜$150から**です（計算）。年払いで25%安い、と公式にあります。各プランに番号1つが含まれ、追加は1番号 月$6です。
- 日本の番号の月額と、日本宛の通話料は、どちらも確認できていません。

| | CallHippo | Aircall |

| 投稿者の国 | **インドが約47%**、米国約9% | 米国が約3割、フランス約14%、スペイン約11% |
| 日本の事業者 | なし | なし |
| 良い点で多い話 | サポートが親切（約4割）、使いやすさ | 使いやすさ（約4割）、CRM 連携 |
| 悪い点で多い話 | 料金、通話の安定性、請求・アカウントの停止 | 最低3ライセンス、契約・更新、サポート |

**注意したい点**：CallHippo は、「未払いの請求で、事前の通知なしに、アカウントと番号が止まった」という声が、2026年の複数の口コミにあります。Aircall は、「使わない契約を約1年払い続けた」「更新で隠れた費用があった」という声があります。**どちらも、請求と更新の条件が、不満の中心です。**

1. 日本の番号の種類ごとの**必要書類・日数・月額**。日本に住所がなくても取れるか。
