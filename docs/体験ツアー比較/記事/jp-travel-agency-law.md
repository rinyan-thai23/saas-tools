# 【体験・ツアー】予約システムを入れる前に｜旅行業法の登録が関わるか確認する窓口と、聞くこと

> **この記事は、法律や登録の要否を判断するものではありません。** 観光庁の公式ページで確認できたことと、予約システムの機能のうち「確認したほうがよいもの」を整理しただけです。実際の判断は、観光庁・都道府県・旅行業協会などの窓口に、事業の中身を伝えて確認してください。

## 先に結論

> - **予約システムを入れること自体で、旅行業の登録が必要になる、ということは、観光庁の公式ページには書かれていません。**
> - **ただし、事業の中身（何を、誰のために、報酬を得て売るか）によっては、旅行業法の登録が関わることがあります。** 自分の体験だけを売るのか、他社の運送・宿泊・ガイドなどを組み合わせたり、他社の商品を売ったりするのかで、状況は変わりえます。
> - **予約システムには、「他社の商品を売る」ための機能**（代理店・販売会社への卸し、セット商品、予約代理店機能など）が付いているものがあります。使う前に、窓口に確認してください。
> - 確認の窓口は、**観光庁（旅行振興）**、**都道府県の観光担当**、**旅行業協会**です（下に書きます）。

## 観光庁の公式ページで確認できたこと

観光庁「旅行業法概要」（最終更新2026年4月30日）の内容です。

- **旅行業・旅行業者代理業**：報酬を得て、旅行業法第2条第1項第1号〜第9号の行為を行う事業を営もうとする人は、観光庁長官または都道府県知事の登録が必要、とあります（第2条・第3条）。登録は、第1種、第2種、第3種、地域限定、旅行業者代理業に分かれ、第1種以外は都道府県が窓口です。
- **旅行サービス手配業（ランドオペレーター）**：報酬を得て、旅行業者のために、次の行為を事業として行う人は、都道府県知事の登録が必要、とあります（第2条・第23条）。
  - 運送（鉄道、バスなど）・宿泊（ホテル、旅館など）の手配
  - 全国通訳案内士・地域通訳案内士以外の者による、有償の通訳案内の手配
  - 免税店での物品販売の手配
- **旅行業務取扱管理者**：旅行業者等は、営業所ごとに1人以上の管理者を選ぶ義務があります。
- **営業保証金**：旅行業者は、一定額の保証金を供託する義務があります。
- **グレーゾーン解消制度**：新しい事業を始める前に、規制が当てはまるかを、あらかじめ照会できる制度です（経済産業省のページを案内）。

**このページからは、「自分の体験だけを、自分の予約ページで売る場合に、登録が必要か」は読み取れません。** 第2条第1項第1号〜第9号の具体的な内容は、法令（e-Gov 法令検索の旅行業法）で確認できます。

## 予約システムの機能で、確認したほうがよいもの

次のような機能は、**他社の商品を売る・他社に商品を売らせる**ためのものです。使う前に、窓口に「この使い方は、旅行業の登録に関わるか」を確認してください（関わるかどうかは、この記事では判断しません）。

| 機能 | 製品の例（公式の記載） |
|---|---|
| 代理店・販売会社に商品を卸す（マーケットプレイス） | [Bókun](/articles/bokun/)（2,600以上の販売会社）、[Rezdy](/articles/rezdy/)（1万2千以上の代理店の市場）、[FareHarbor](/articles/fareharbor/)（500以上の提携先） |
| 他社の商品を取り込んで売る | Bókun（Viator の商品の取り込み）。Rezdy には、販売会社向けの仕組みの案内もあります |
| 予約代理店機能 | JTB BÓKUN（月額10,000円（税別）の有料オプション。JTB の資料） |
| 事業者どうしの販売代理店連携、セット商品 | [OMUSUBI](/articles/omusubi/)（導入している事業者どうしで共通在庫を使う販売代理店連携、他社のプランを組み合わせたセット商品。公式のFAQ） |
| B2B専用の予約サイト | [rezio](/articles/rezio/)（旅行会社・ホテルとの取引用） |
| セット商品（複数の体験を組み合わせる） | Bókun（Combo Products） |

「他社の商品を売る」機能を使わず、**自分が提供する体験を、自分の予約ページと予約サイト（OTA）に出すだけ**なら、これらの機能は関係しません。ただし、それで登録が不要かどうかも、窓口に確認してください。

## 確認の窓口（観光庁の公式ページより）

- **観光庁 参事官（旅行振興）**：電話 03-5253-8111（国土交通省代表）。
- **都道府県の観光担当**：第1種以外の登録は、都道府県が窓口です。
- **旅行業協会**：
  - 日本旅行業協会（JATA）消費者相談室：03-3592-1266（10:00〜17:00、土日祝・年末年始を除く）
  - 全国旅行業協会（ANTA）：03-6277-8310（9:30〜17:15、土日祝・年末年始を除く）

  ※旅行業協会の窓口は、旅行業者の扱った業務に関する苦情・相談を扱う窓口として、観光庁のページに載っています。登録の要否の相談窓口は、観光庁・都道府県に確認してください。
- **グレーゾーン解消制度**：新しい事業の計画を、規制の適用の有無について、あらかじめ照会できます（経済産業省）。

## 予約システムの会社に聞くこと

1. **他社の商品を売る機能（代理店・販売会社への卸し、セット商品、予約代理店機能）は、どの契約・プランに含まれるか。**
2. その機能を使う事業者に、**旅行業の登録が必要かどうか**を、会社として案内しているか。案内している場合、その根拠は何か。
3. 自分の体験だけを売る場合に、**使わなくてよい機能**は何か。
4. 契約書や規約に、**旅行業法に関する事業者の責任**を定めた条文があるか。

## 自分で確認すること（窓口に伝える内容）

- **何を売るか**：自分で提供する体験か、他社が提供する体験か。運送・宿泊を含むか。
- **誰に売るか**：個人のお客さんか、旅行会社や代理店か。
- **報酬の形**：自分が受け取るお金の流れ（参加費、手数料、紹介料）。
- **どこで売るか**：自社の予約ページか、予約サイトか、販売会社か。

## よくある質問

### 予約システムを入れると、旅行業の登録が必要ですか？
観光庁の公式ページには、そのようには書かれていません。登録の要否は、事業の中身で決まります。窓口に、売るものと売り方を伝えて確認してください。

### 自分の体験だけを売るなら、登録は要りませんか？
この記事では、判断できません。観光庁のページからは読み取れませんでした。観光庁・都道府県の窓口で、事業の中身を伝えて確認してください。

### 予約システムの会社は、教えてくれますか？
会社によります。法的な判断を、予約システムの会社に任せるのは避けてください。窓口で確認した結果を、契約の前提にするのが安全です。
