Hostaway と OwnerRez を比較：日本の民泊で申し込む前に

この記事にはアフィリエイトリンク（PR）が含まれます。内容は公式ページ等の記載（取得日 2026-11-05）に基づき、リンクの有無では変えていません。

結論

  • 料金が最も具体的に出ているのは OwnerRez です。物件数別の基本料金表が公式にあり、最低月額は$40、契約縛り・予約手数料なし、14日間の無料トライアルがあります。Hostaway は価格非公開で、見積りを取る形でした。
  • OwnerRez は機能の一部（オーナー精算、SMS、ダイレクト予約サイト、QuickBooks 連携など）が別料金で、必要な機能を足すと基本料金の目安より高くなります。
  • 日本語の管理画面は、OwnerRez は公式の表示言語の一覧に日本語がなく、Hostaway は記述を確認できませんでした。楽天トラベル・じゃらんは、どちらの公式ページにも記載が見つかりませんでした。

先に知っておくこと（日本で使うときの前提）

予約サイト自身が公式ページに書いている条件です（法律の判断ではありません）。

  • 楽天トラベル：旅館業法の営業許可証を取得した施設が対象。「民泊新法（住宅宿泊事業法）の施設様はご参画いただけません」。民泊新法・特区民泊は「Rakuten Oyado」で登録、と案内。
  • じゃらんnet：旅館業法の宿泊営業許可を得た施設が対象。住宅宿泊事業法に基づく民泊と特区民泊は「ご参画いただけません」。
  • Rakuten Oyado で「そのまま使える」とされる既存ツールは、ねっぱん、AirHost、Beds24、suitebook。Hostaway・OwnerRez の名前は載っていません。
  • Airbnb：ヘルプに「In Japan, we don't accept listings created through software connections for places to stay (minpaku)…」とあり、例外は日本のAPIパートナー。その名前は公式で見つかりませんでした。既存の掲載を後からつなぐ場合の扱いは未確認です。届出番号は「ツールを使っていても、自分でログインして」追加する必要があります。
  • 取得できた公式ページに、届出番号・年180日の管理・定期報告・適格請求書（インボイス）に当たる機能の記載は、両社とも見つかりませんでした。宿泊者名簿は、日本の名簿要件に合う機能の記載は見つかりませんでした（Chekin 等の外部サービスとの提携・連携はありますが、日本の要件に合うかは未確認）。OwnerRez はサイトマップに japan・JPY・rakuten・jalan を含むURLがありませんでした。

条件別の選び方

  • 料金を公式ページで見て計算したい人： OwnerRez。物件数別の基本料金表が公式にあります。ただしオーナー精算やダイレクト予約サイトなどを足すと上がります。
  • 契約の縛りを避けたい人： OwnerRez は契約・解約金なしですが、未使用期間は返金されません。Hostaway は期間が個別契約なので、見積り時に確認します。
  • Expedia も使う人： Hostaway は対応。OwnerRez は連携一覧に記載がありません。
  • 設定の細かさより導入の手早さを重視する人： OwnerRez は設定が細かい分、学習に時間がかかるという声があります。Hostaway は見積りで導入支援の中身を確認してください。
  • 楽天トラベル・じゃらんが必須の人： 民泊新法・特区民泊の施設は両サイトの対象外と各社が書いています。旅館業法の許可施設については、Hostaway・OwnerRez とも接続可否が未確認なので、申込前に各社へ問い合わせてください。
