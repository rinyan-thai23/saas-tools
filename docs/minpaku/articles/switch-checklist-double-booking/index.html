【民泊】管理ツールの移行チェックリスト｜二重予約を防ぐ切り替えの手順

この記事に広告リンク（アフィリエイト）はありません。

先に結論：二重予約は、2つのツールが同じサイトに空室を送るときに起きる

  • 原因の中心：切り替えの間、旧ツールと新ツールの両方が同じ予約サイトに空室を送ってしまうことです（販売会社のガイドの説明）。
  • 対策の基本は3つ：①未来の予約を先に書き出す ②予約サイトを1つずつ切り替える ③旧ツールを止める前に、全予約を照合する。
  • 切り替え中は、即時予約（インスタントブッキング）を一時止めると、Hospitable のヘルプにあります。
  • 日本の民泊新法の人は、先に Airbnb の扱いを確認。 ツール経由の掲載が受け付けられない場合があります。
  • 以下のチェックリストは、各ツールの公式ヘルプと、販売会社・比較サイトの移行ガイドを整理したものです（販売会社の資料が中心で、第三者の検証はありません）。

切り替えの時系列チェックリスト

切り替えの1〜2週間前（準備）

  • [ ] 旧ツールの契約・更新日・解約の期限を確認した（年払いなら返金の可否も）
  • [ ] 新ツールの見積り・契約を書面で受け取った（期間、自動更新、解約条件）
  • [ ] 未来の予約をすべて書き出した（予約サイト別、直接予約・手動の予約も）。移行ガイドで最優先とされる項目です
  • [ ] 過去の予約、ゲスト情報、メッセージのテンプレート、清掃の指示、メモも書き出した
  • [ ] Airbnb で手動でブロックした日、ルール、カレンダーの設定を控えた（接続後に消えた、という口コミがあります）
  • [ ] 清掃やオーナー自身の利用など、手動で閉じるべき日を一覧にした（見落としが二重予約の原因になりえます）
  • [ ] 新ツールで、物件・料金・ルールを作った（まだ予約サイトには接続しない）
  • [ ] 民泊新法の人：Airbnb と新ツールに、既存の掲載をつなげられるかを確認した

切り替えの前日〜当日（停止期間を決める）

  • [ ] 宿泊の少ない日を選んだ
  • [ ] 近い日付の空室を手動で閉じた（または同期を一時停止した）
  • [ ] 即時予約を一時停止した（Hospitable のヘルプの案内）
  • [ ] 手書きの「親のカレンダー」を1つ用意した（切り替えの間、ここだけを正とする）
  • [ ] 旧ツールの自動メッセージを止める日を決めた（新ツールと重複して送らないため）

切り替え中（予約サイトを1つずつ）

  • [ ] 1つの予約サイトだけ、旧ツールの接続を外し、新ツールにつないだ
  • [ ] 接続後、そのサイトのカレンダー・料金・既存の予約が正しいか確認した
  • [ ] テスト予約（または問い合わせ）で、他のサイトの同じ日が閉じるか確認した
  • [ ] 次のサイトへ進む（同時に複数のサイトを触らない）
  • [ ] Vrbo など、サイト側に移行を依頼する手続きがあるものは、手続きの完了を確認した（Hospitable のヘルプ：Vrbo は移行を依頼し、その予約の支払いは旧ツールから受け取る形）
  • [ ] 切り替えで停止の時間が出るか確認した（Guesty の公式FAQでは、多くのチャネルで約30分）

切り替え後（数日〜数週間）

  • [ ] 全サイトのカレンダーを、自分の目で確認した（毎日）
  • [ ] 新ツールの予約と、旧ツールの予約を照合した（件数・日付・金額）
  • [ ] 自動メッセージが重複して送られていないか確認した
  • [ ] 清掃タスク、スマートロックの動作を確認した
  • [ ] 即時予約を再開した
  • [ ] 旧ツールを止める前に、予約・料金・同期の検証を終えた
  • [ ] 旧ツールを解約した（更新日の前）。データのアクセスが切れる日も確認した

起きやすい事故と、防ぎ方

事故 原因 防ぎ方
二重予約 切り替えの間、2つのツールが同じサイトに空室を送る 1サイトずつ切り替え、親のカレンダーを持つ
ブロックした日が消える 接続時に、手動のブロックや設定が上書きされる（iGMS・Guesty の口コミ） 事前に控え、接続後に確認
旧ツールの設定が外れる 無料トライアルで Airbnb をつなぐと、使っていた別ツールが外れる（Guesty の口コミ） 並行運用の前に、接続の挙動を確認
取り込んだ予約に連絡先がない 取り込みで、ゲストの連絡先が欠ける場合がある 取り込み後に確認し、手で補う
解約の遅れで、次の期間が前払いされる 自動更新（Lodgify は更新の通知なし） 更新日の前に解約
取り込んだ予約が予約サイトと紐づかない CSV の予約は、チャネルと結び付かない場合がある（Sirvoy など） 変更・キャンセルは各サイトで確認

日本で切り替えるときの注意

  • 民泊新法の人は先に確認：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。どのツールが該当するか確認できていません。 切り替えの前に、Airbnb と新ツールに確認してください。
  • 楽天トラベル・じゃらん：民泊新法・特区民泊の施設は対象外です。旅館業法の許可施設で国内サイトを他社のサイトコントローラーと連動している場合は、先に解除して、売り止めが必要です（Beds24 の日本の販売会社の案内）。
  • 日本語のサポート：切り替えの相談を日本語でできるツールは限られます。
  • 年180日の管理、届出番号、定期報告は、各ツールの公式ページに記載が見つかりませんでした。切り替えの間も、表計算などで別に管理してください。

よくある質問

切り替えの間に、二重予約を完全に防げますか？

完全には防げません。1サイトずつ切り替える、近い日付を手動で閉じる、即時予約を止める、親のカレンダーを持つ、で確率を下げます。

切り替えにどのくらいかかりますか？

小規模なら数日、物件が多いと数週間、という目安が販売会社の資料にあります。Guesty の移行ガイドは、全体で約30日としています。ツールと物件数によって変わります。

旧ツールは、いつ解約すればよいですか？

新ツールで、予約・料金・同期を数日確認したあと、旧ツールの更新日の前に解約してください。データのアクセスが切れる日も確認します。

日本の民泊新法の宿でも切り替えられますか？

Airbnb のヘルプには、日本の民泊新法の宿について、ソフト連携で作った掲載を受け付けないという記載があります。例外は Airbnb と契約した日本のAPIパートナーです。各ツールが該当するかは確認できていないため、Airbnb と新ツールに確認してください。
