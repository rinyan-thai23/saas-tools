【クラウド電話】無料トライアル比較

先に結論

  • 無料トライアルがあることは、多くの製品で確認できました。 ただし、日本の番号で試せるかを公式に書いているのは、Dialpad（ソフトバンク）だけです（050のみ、開通から30日）。
  • トライアルの制限に注意してください。RingEX は、最大5ユーザーまで、SMSは使えない、などの記載があります。JustCall は、トライアルが終わるとアクセスが制限されます。
  • トライアルの目的は、「日本で使うときの困りごと」を先に見つけることです。下の「14日間の試し方」を使ってください。

誰のための記事か

候補を2〜3つに絞って、無料トライアルで試してから契約したい、日本の小さな事業者向けです。

「日本の番号で試せる」が大事な理由

  • 多くの製品のトライアルは、米国・カナダの番号での記載です。日本の番号は、書類の審査があり、日数もかかります（日本の電話番号の取り方と審査）。
  • トライアル期間（10〜14日）より、日本の番号の開通のほうが長い場合があります（例：CallHippo の03・06は15〜25営業日、CloudTalk の03は15〜25営業日）。
  • 申し込む前に、聞いてください：「トライアルで、日本の番号を使えるか。使えない場合、日本の番号の通話品質は、どう試せるか」。

14日間の試し方（日本の事業者向け）

いつ 試すこと
1日目 管理画面の言語、アプリの入れ方（パソコン・スマホ）。日本語の表示か。
1〜3日目 サポートに質問を1つ送る（日本の番号の条件など）。返事の速さと中身を見る。
3〜7日目 自分のスマホ・固定電話から発着信して、音質、遅れ、途切れを見る。Wi-Fi と モバイル回線の両方で。
7日目 転送、留守電（日本語）、営業時間外の案内、グループで鳴らす設定。
10日目 110・119がかけられない場合の備え（携帯電話の併用）を決める。
12日目 通話料の請求の見え方。何が別料金か。
最終日 見積もりを、通話料込みで、書面でもらう。自動で有料に変わるかを確認する。

トライアルで見逃しやすい点

  • 自動で有料に切り替わるか（カード登録が必要な製品）。終了日をカレンダーに入れる。
  • トライアル中のデータが、本契約に引き継がれるか。
  • トライアルで使えない機能（RingEX は SMS）。
  • サポートの対応は、トライアル中と契約後で違うことがある。

申込前に確認すること

  1. トライアルで日本の番号を使えるか。
  2. カード登録の要否と、自動課金の有無。
  3. 期間と、延長の可否。
  4. 制限（人数、機能、通話料）。
  5. 終了後のデータの扱い。

→ 料金は、料金早見表へ。

よくある質問

無料トライアルで、日本の番号を使えますか？

Dialpad（ソフトバンク）は、050のトライアルを開通から30日と案内しています。ほかの製品は、日本の番号でのトライアルの記載を、確認できていません。

カードなしで試せるのは？

CallHippo、JustCall、CloudTalk は、カード不要と公式に書いています。

トライアル期間では足りないときは？

Dialpad は延長できません。ほかは、サポートに相談してください。期間内に、上の「14日間の試し方」を優先してください。
