# 【体験・ツアー】BókunとCheckfrontを比較｜ツアー専用か、レンタル・宿泊も扱うか

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

## 先に結論

> - **ツアー・体験だけで、海外の予約サイト（Viator など）に出したいなら Bókun。** 日本の事業者には、JTB BÓKUN（日本版）の窓口もあります。
> - **ツアーに加えて、レンタルや宿泊も1つで管理したいなら Checkfront** が候補です。ただし、**サポートは英語のみ**で、1つのアカウントで日本語と英語の予約画面を同時に出せない、と公式にあります。
> - **手数料は Bókun の方が低め**（計算）。Checkfront は月額$99＋オンライン予約3%の1種類です。

## 料金を計算してみる

**前提**：オンライン予約のみ。決済会社の手数料と為替は含まず、手数料をお客さんに上乗せしないで、事業者が払う場合の計算です。海外版の公式の価格を使っています。

| 月のオンライン売上 | Bókun Start（$49＋1.5%） | Bókun Plus（$149＋1.25%） | Checkfront（$99＋3%） |
|---|---|---|---|
| $2,000 | $79 | $174 | $159 |
| $5,000 | $124 | $211.5 | $249 |
| $10,000 | $199 | $274 | $399 |

（計算）

- Bókun Start は、売上が少なくても多くても、Checkfront より安いです。ただしプランごとに機能は違い、ユーザー数は Start が5人、Plus が10人です（公式）。
- Bókun Plus は、売上が月約$2,860を超えると、Checkfront より安くなります（計算）。
- **Checkfront の値上げ**：口コミに、年額が20%、前年は25%上がった、という声が1件あります（2025年）。

## 対応できる事業の幅

- **Bókun**：ツアー・アクティビティ向けです。販売先の幅（予約サイト・販売会社）が強みです。
- **Checkfront**：ツアーのほか、レンタル、宿泊も予約できます。「いろいろな予約の形」（1日、複数日、時間枠）を設定できる、と公式にあります。電子の同意書は標準で入っています。

**レンタルや貸切の宿を併せてやっている小さな事業者**には、Checkfront の幅が合います。

## 予約サイト（OTA）との連携

- **Bókun**：「2,600以上の販売会社、うち70以上の世界の予約サイト」（公式の自社の主張）。
- **Checkfront**：Google の Things to do、Viator、GetYourGuide など。「2万以上の販売会社」と書いています（自社の主張）。口コミには「予約サイトとの連携で、他のシステムより遅れている」という声があります。

**どちらも、日本の予約サイトとの連携は確認できませんでした。**

## 口コミ（海外のレビュー）の違い

| | Bókun | Checkfront |
|---|---|---|
| 良い点で多い話 | 使いやすさ（約3割）、サポート、予約サイト連携 | 使いやすさ（約4割）、サポート（約3割）、価格が手頃 |
| 悪い点で多い話 | 画面が複雑、料金、連携の不具合 | 値上げ、レポートが弱い、予約サイト連携の遅れ |
| 日本の投稿者 | 1人（旅行会社、3点） | 2人（宿のオーナー、自営業。どちらも4点） |

Checkfront の日本の投稿者（宿のオーナー）は、「家族経営の小さな事業にちょうどいい。サポートが一番良い」と書く一方、「日本なので、請求書などの翻訳をもっと柔軟にしてほしい」と要望しています。

## 日本の事業者として見るポイント

- **サポート**：Bókun は日本版の日本語サポートの記載があります。Checkfront は英語のみです。
- **決済**：Checkfront の公式の決済サービスは、対応国に日本が入っていません。ほかの決済会社（Stripe、Square、PayPal）と連携できると公式にあります。円で受け取れるかは、どちらも確認できていません（Bókun の日本版は円の料金表があります）。
- **言語**：日本のお客さんと外国人のお客さんの両方を受けたいときは、Checkfront の「言語を混ぜられない」仕様が影響します。最新の仕様を確認してください。

詳しくは、[Bókun](/articles/bokun/) と [Checkfront](/articles/checkfront/) の商品ページへ。

## よくある質問

### ツアーだけなら、どちらがいいですか？
Bókun が先です。日本向けの窓口があり、手数料も低めです（計算）。

### レンタルや宿泊も予約したいときは？
Checkfront が候補です。ツアーのほか、レンタル、宿泊も扱えると公式にあります。ただし、サポートは英語のみです。

### 手数料が安いのはどちらですか？
同じ売上なら、Bókun の方が安いです（計算）。Bókun はプランでユーザー数が違う（Start 5人、Plus 10人）ので、使う人数に合わせて選んでください。

### どちらも日本の予約サイトにつながりますか？
どちらも、日本の予約サイトとの連携は確認できませんでした。
