## 「日本の番号で試せる」が大事な理由

- 多くの製品のトライアルは、**米国・カナダの番号**での記載です。**日本の番号は、書類の審査があり、日数もかかります**（[日本の電話番号の取り方と審査](/articles/jp-number-acquisition/)）。
- トライアル期間（10〜14日）より、**日本の番号の開通のほうが長い**場合があります（例：CallHippo の03・06は15〜25営業日、CloudTalk の03は15〜25営業日）。
- **申し込む前に、聞いてください**：「トライアルで、日本の番号を使えるか。使えない場合、日本の番号の通話品質は、どう試せるか」。

## 14日間の試し方（日本の事業者向け）

| いつ | 試すこと |
|---|---|
| 1日目 | 管理画面の言語、アプリの入れ方（パソコン・スマホ）。日本語の表示か。 |
| 1〜3日目 | **サポートに質問を1つ送る**（日本の番号の条件など）。返事の速さと中身を見る。 |
| 3〜7日目 | **自分のスマホ・固定電話から発着信**して、音質、遅れ、途切れを見る。Wi-Fi と モバイル回線の両方で。 |
| 7日目 | 転送、留守電（日本語）、営業時間外の案内、グループで鳴らす設定。 |
| 10日目 | **110・119がかけられない**場合の備え（携帯電話の併用）を決める。 |
| 12日目 | 通話料の請求の見え方。何が別料金か。 |
| 最終日 | 見積もりを、通話料込みで、書面でもらう。**自動で有料に変わるか**を確認する。 |

## トライアルで見逃しやすい点

- **自動で有料に切り替わる**か（カード登録が必要な製品）。終了日をカレンダーに入れる。
- **トライアル中のデータが、本契約に引き継がれるか。**
- **トライアルで使えない機能**（RingEX は SMS）。
- **サポートの対応**は、トライアル中と契約後で違うことがある。

## よくある質問

### 無料トライアルで、日本の番号を使えますか？
Dialpad（ソフトバンク）は、050のトライアルを開通から30日と案内しています。ほかの製品は、日本の番号でのトライアルの記載を、確認できていません。

### カードなしで試せるのは？
CallHippo、JustCall、CloudTalk は、カード不要と公式に書いています。

### トライアル期間では足りないときは？
Dialpad は延長できません。ほかは、サポートに相談してください。期間内に、上の「14日間の試し方」を優先してください。
