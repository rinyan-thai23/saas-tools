## 指摘

### 1. 注意：Lodgify の契約が規約側の条件だけで書かれ、料金ページの「縛りなし」が落ちている
- 記事（比較表）：「規約：1・12・24か月の前払いで自動更新、更新前の通知なし。期間途中の解約は返金なし」
- 記事（条件別）：「契約を軽くしたい人：Beds24 公式は1か月前通知です。WeIns は毎月20日締め、Lodgify は自動更新で更新前の通知がありません。」
- カード：Lodgify 2章「契約縛り」料金ページ "There's no long-term contract. You can cancel your subscription at any time. If you're on an annual plan, you'll retain access until the end of your billing period." と、規約（自動更新・更新前の通知なし・期間途中の返金なし）が併存。
- 問題：Uplisting の記事では料金ページと規約の食い違いを両方書いているのに、ここでは Lodgify の規約側だけで、不利な印象になる。
- 修正案：「料金ページは『長期契約なし、いつでも解約可』。規約は前払い期間の自動更新で更新前の通知なし、期間途中は返金なし（食い違いではなく併存。どちらが実際の運用かは未確認）」と両方書く。

### 2. 注意：「見た目の良いダイレクト予約サイト」はカードにない評価
- 記事（条件別）：「見た目の良いダイレクト予約サイトを自分で作りたい人：Lodgify はノーコードの作成機能を持ちます。」
- カード：Lodgify 4章「ダイレクト予約サイト」Starter 以上でノーコードのサイト作成、予約エンジン、テンプレート。見た目の良さを示す記載なし。Beds24 の「デザインが簡素」は第三者の口コミ（8章）。
- 修正案：「ダイレクト予約サイトをノーコードで作りたい人」とし、見た目の評価は書かない。

### 3. 注意：Beds24 の PR リンク先を「海外の公式側の入口」と断定している
- 記事：「Beds24 の PR リンクは、海外の公式側の入口です。日本の販売会社（株式会社WeIns、co-reception.com）には PR リンクを付けておらず」
- カード：Beds24 6章 アフィリエイトは公式の紹介制度（association code、`beds24.com/join.html?referrercode=` 形式）。`/go/beds24/` の遷移先を確認した記載はない。日本の販売会社の紹介制度は未確認。記事末尾のコメントも「遷移先の確認」を依頼している。
- 問題：本文で断定し、コメントでは未確認と矛盾する。さらに alt-guesty・alt-hostaway は同じ `/go/beds24/` を「日本の販売会社経由」の推薦文脈で使っている。
- 修正案：断定を外すか、遷移先を確認してから書く。確認までは「PR リンクの遷移先は公式側を想定。WeIns 経由の契約には PR は付きません」とする。

### 4. 軽微：WeIns の料金例が税込かどうか書かれていない
- 記事：「¥4,580、10室（5サイト）¥17,280、20室 ¥24,210【確認済】」
- カード：Beds24 2-2「税込表記かどうかは3例では明記なし」（別ページは「税込4,580円/1棟から」）。
- 修正案：「税込かどうかは3例では明記なし」と添える（コメントの追加調査依頼にはあるが本文にない）。

### 5. 軽微：Beds24 公式の目安が「上限寄り」になりうる点が本文にない
- 記事：「各室が別タイプ・2チャネルで €24.00／€31.40／€49.90【計算値。実請求は未照合】」
- カード：2-1「目安の前提」同じ型の部屋は1リンクで数えるため、実際はこの目安より安くなり得る。
- 修正案：「同じ型の部屋が複数なら、これより安くなり得る」を足す。

### 6. 軽微：Beds24 の Airbnb・Booking.com・Vrbo を「API 連携」と書いている
- 記事：「『Preferred Partner』、双方向の API 連携【確認済】」
- カード：3章は「双方向XML連携」（Vrbo は XML＆iCal）。接続方式まとめでは「XML／API連携」。
- 修正案：「双方向の XML／API 連携」とする。

### 7. 軽微：公式Wikiの日本語版の記載が古い日付のまま
- 記事：「公式は英語・ドイツ語。日本語版は WeIns のみ（公式Wikiに記載）【確認済】」
- カード：5章 公式Wiki は 2020-11-17 編集。サポート言語の「英語・ドイツ語」も同ページ由来。
- 修正案：「公式Wikiの記載（2020年編集）」と日付を添える。
