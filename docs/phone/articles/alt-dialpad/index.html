【クラウド電話】Dialpadの代替｜日本の事業者が選べるクラウド電話6つ

先に結論

  • Dialpad は、日本の条件を公開しているクラウド電話の中で、条件が一番読みやすい製品です。 それでも合わない人はいます。理由で選び直しましょう。
  • 開通の速さで選ぶなら、Zoom Phone（新しい番号は最短3営業日）か CallHippo（050は数日、自社の説明）。通話が多いなら Zoom Phone のかけ放題を、見積もりで比べます。
  • 日本語の公式情報が読める代替は、Zoom Phone だけです。CallHippo と CloudTalk は、日本向けの番号ページがありますが、英語です。
  • 110・119は、どの製品も前提にしないでください。

Dialpad が合わない主なケース

Dialpad の商品ページで書いたとおり、次のような人には向きません。

  • すぐ使い始めたい人：本人確認の書類と簡易書留の郵送で、開通まで最短10〜15営業日かかります。
  • 通話料の総額を、事前に確定したい人：通話料は従量課金です。国内かけ放題の記載は、確認できていません。
  • 110・119、0570にかけたい人：公式ヘルプの抜粋に、発信できない、とあります。
  • 固定番号（03・06）を、あとから足したい人：検索で見えた公式ヘルプの抜粋（ページ本体は開けませんでした）に、0AB-J の番号は、0AB-J で契約したオフィスにだけ追加できる、050で契約済みのオフィスには追加できず、新しいオフィスを作る必要がある、とあります。最終的な可否は、ソフトバンクへ確認してください。

1. Zoom Phone

日本語の公式サイトと、番号の要件ページ（2026年10月18日更新）があります。050は番号の移行ができません（0ABJとフリーダイヤルは対応）。通話が少ない小さな事業者には割高になりうる、と公式ブログ自身が書いています。詳しくは Zoom Phone の商品ページ、Dialpad と Zoom Phone の比較へ。

2. CallHippo

日本向けの番号ページで、050、03、06、0120を案内しています。「通話無制限」は米国・カナダ宛だけです。未払いでアカウントと番号が止まった、という声が2026年の口コミにあります。詳しくは CallHippo の商品ページへ。

3. CloudTalk

日本向けの番号ページに、東京の03と0120・0800（着信のみ）が載っています。大阪などの市外局番と050は、載っていません。詳しくは CloudTalk の商品ページへ。

4〜6. RingEX、Aircall、JustCall

日本の条件は、公式で読み取れませんでした。RingEX は東京の市外局番のみ、という記載があります。詳しくは RingEX、Aircall、JustCall、Aircall と Dialpad の比較へ。

乗り換える前に聞くこと

  1. 日本の事業者として契約できるか。円で請求されるか。
  2. 日本の番号の種類ごとの必要書類・日数・月額。
  3. 通話料込みの月額を、見積もりで。
  4. 今の番号（050・0AB-J）を移せるか。費用と日数は。今の契約を解約するタイミングで、番号が使えない期間が出ないか。
  5. Dialpad（ソフトバンク）の解約の条件。日割りはなく、解約月は満額、と記載があります。
  6. 110・119にかけられない場合の備え。

よくある質問

Dialpad の代替で、日本語の公式情報が読めるのは？

Zoom Phone です。CallHippo と CloudTalk には、日本向けの番号ページ（英語）があります。

Dialpad から他社に、番号を移せますか？

他社への移行（ポートアウト）の条件は、今回は確認できていません。ソフトバンクに、条件・日数・費用を書面で確認してください。

乗り換えると、安くなりますか？

発信が少ないうちは、Dialpad の Standard（¥1,000）が安いです。国内の発信が多い場合は、Zoom Phone のかけ放題が有利になりえます。比較記事に計算があります。
