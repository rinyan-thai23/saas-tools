# 体験・ツアー予約システム比較（設計図・フェーズ0）

**誰に**：日本で体験・ツアー・アクティビティを、1〜5人で運営している人（カヤック・SUP・着物・料理教室・農業体験・ガイドツアー・貸切ツアーなど）。国内のOTA（じゃらん・アソビュー・ベルトラなど）だけに頼らず、**自分の予約ページ＋海外OTA（GetYourGuide・Viator・Tripadvisor）からの予約を、1つの在庫でまとめたい**人。海外の予約システム名（FareHarbor・Bókun・Xolaなど）は聞いたことがある。

**悩み**：日本語の情報がほぼない／円で請求・決済できるか／二重予約が怖い／日本のOTAにつながるか／インバウンド向けに英語の予約ページが欲しい。

**何を**：買う直前・乗り換え・比較の記事だけ。「体験事業の始め方」などの一般論は作らない。
