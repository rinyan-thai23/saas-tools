# 体験・ツアー比較 制作メモ（民泊と同じ作り方で品質が出るかの検証）

## 2026-11-07 #1 FareHarbor（商品ページ1本目）
- 準備：`ビルド/build.py` を設定ファイル化（`サイト設定.json`：名前・出力先・/go/禁止リスト）。民泊の出力は変わらず。`10_記事チェック.py` にジャンル名引数を追加。
- 材料：Capterra口コミ 関連順100＋新着順100 → 重複除き179件（`データ/06_体験ツアー口コミ/`）。Web検索3回、公式ページ約10枚。
- 学び
  - 公式の料金ページ・機能ページが、サイトの作りにより読めないことがある（アプリ画面が返る）。トップのナビからURLを拾うと読める（`/sell/payments/` など）。
  - 公式ヘルプ（help.fareharbor.com）は自動アクセスを403で断る。**検索結果の抜粋で見えた範囲は「確認済み」と書かず、全文未確認と明記した。**
  - **最大の発見**：公式の対応国ページに日本が見当たらない（カナダ・メキシコ・米国・英国）。民泊でいう「民泊新法」に当たる、この業種の最初の壁。他の製品でも、まず「日本の事業者が契約できるか」を調べる。
  - 手数料は料金ページがなく、口コミ（6%）と競合の比較ページ（競合の主張）しかない。必ず「競合の主張」と書き分ける。
  - 書いた後に口コミ原文と照合して、裏付けのない3か所（入金の速さ、手数料の肩代わり、電話予約）を直した。**書いた直後に、原文と照合する工程は必須。**
- 未調査：アフィリエイト（FareHarbor）。/go/ リンクなし、pr: false。

## 2026-11-07 #2 Bókun（商品ページ2本目）
- 材料：口コミ180件（関連順＋新着順）、公式の料金ページ、Web検索3回、**JTBの日本語概要資料（PDF）**、トラベルボイス記事、Bókun公式ブログ。
- 学び
  - **日本版（JTB BÓKUN）が見つかった**。円の料金表（月1,900/4,900/24,900円＋3.5/1.5/1.25%）、30日トライアル、日本語サポート、30言語機械翻訳。検索の抜粋で「JTB BÓKUN」を見つけ、JTBのPDFまで読んで裏を取った。**海外ツールは、日本の代理店・販売会社の日本語版がないかを必ず検索する**（民泊にはなかった型）。
  - 海外版と日本版でプラン名・数字が違う。表を分けて「どちらも自社の発表」と明記した。
  - 日本の投稿者の口コミが1件あった（日本の旅行会社CEO、3点）。「日本の事業者の声」は1人だけと明記。
  - 日本の予約サイト（じゃらん等）との連携は資料に記載なし → 「できない」とは書かず「記載が見つからなかった」。
  - アフィリは海外版(PartnerStack)のみ。日本版は未調査。/go/bokun/ は海外版へ（仮）。
  - 書いた後の原文照合で、裏付けのない「アイスランド生まれ」を削除。
