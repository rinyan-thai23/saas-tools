# 【民泊】Hostaway と Lodgify どっちがいい？直接予約・料金・口コミ・日本で使えるかを比較

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：目的が「自分の予約サイト」か「運営の自動化」かで決まります

> - **自分の予約サイト（直接予約）を持ちたい、料金を見て始めたい → Lodgify。** 料金が公開され、7日間カード不要で試せます。予約手数料はありません。
> - **複数の予約サイトで運営を自動化したい、導入の手助けがほしい → Hostaway。** ただし料金は見積り制です。
> - **3室以上なら、Lodgify は Professional（1物件あたり月$47〜）以上が前提。** 物件が増えると料金が上がるので、見積りと比べてください。
> - **契約で気をつけるのは Lodgify。** 更新の通知なしの自動更新、期間途中の返金なしが規約にあります。
> - **日本語の画面・サポートが必須 → どちらも不向き。**

## 直接予約サイト：どちらが向くか

民泊で「自分の予約サイトを持つ」目的なら、ここが一番の違いです。

- **Lodgify**：予約サイトを、プログラムなしで作れるのが最大の特徴です。テンプレート、予約エンジン、既存サイトに埋め込む予約ウィジェット、年払いなら独自ドメインが無料。予約手数料は0%ですが、サイト経由のオンライン決済には別に1%かかります。
- **Hostaway**：予約サイト（Booking Website）が契約に含まれます。上位版は月$49＋対象予約の0.5%で、ゲストに1.8%を上乗せする仕組みが公式にあります（米国のみ）。

第三者の比較でも、「Lodgify は予約サイトが中心、Hostaway は運営全体のプラットフォーム」という見方が多めでした。

ただし、**予約サイトの表示言語に日本語があるか**は、どちらも公式では確認できていません（Hostaway は英・仏・西・伊などで日本語なし、という第三者の情報。Lodgify は「32言語」とだけ書かれ、一覧は未確認）。日本語のゲストに直接予約を取りたい場合は、申込前に画面で確かめてください。

## 料金：Lodgify は公開、Hostaway は見積り

| | Hostaway | Lodgify |
|---|---|---|
| 1〜2室 | 公開なし | Basic $14（1物件まで）、Starter $26（2物件まで） |
| 3室以上 | 見積り | Professional $47〜、Ultimate $68〜（1物件あたり、物件数で変わる） |
| 初期費用 | 自社の比較ページに「$500」（自社の主張） | 1:1 の導入支援が Starter 以上に付く |

- Lodgify の金額は、1物件の表示価格です。**3室以上の正確な月額は、公式の料金ページ（物件数で計算）で確認**してください。
- Hostaway の月額は、第三者の推定がバラバラで、公式の裏付けがありません。
- **サポートの手段もプランで違います（Lodgify）**：メールは全プラン、電話は Professional 以上、ライブチャットは Ultimate だけです。

## 契約と解約：気をつける点が違う

- **Lodgify**：公式は「長期契約はなく、いつでも解約できる」と書きますが、規約では、1・12・24か月の前払いが**更新の通知なしに自動更新**されます。解約はアカウント画面から期間終了の1日前、メールなら5日前まで。期間途中の解約は返金なし。口コミにも、「年間契約が警告なしに自動更新され、返金されなかった」という低評価（2026年）があります。
- **Hostaway**：期間は個別契約。値上げは14日前に通知され、同意しない場合は、発効の5日前までの通知で解約できます。口コミには、「解約の連絡後も請求が続いた」「営業の説明と導入後が違った」という低評価があります。

## 口コミ：不満の出方が違う

Capterra の海外レビュー（Hostaway約170件、Lodgify約190件）を読んだ結果です。英語圏の運営者の声が中心で、日本の運営者の声ではありません。

| | Hostaway | Lodgify |
|---|---|---|
| 良い点で多い話題 | サポート（約3割）、導入支援、使いやすさ | 予約サイトとの連携（約4分の1）、サポート、使いやすさ |
| 改善点で多い話題 | 料金（約4分の1）、サポートの遅れ、学習の時間 | 同期・接続の不具合（約2割）、料金、サポートの遅れ |
| 投稿者 | 小規模の事業者や自営業が約9割 | ほぼ全員が自営業か2〜10人規模 |
| 特徴的な低評価 | 解約後も請求、同期漏れで約$400安く予約が入った | Vrbo の接続が何週間も有効にならず二重予約、物件の紐づけを取り違えて、別の部屋に宿泊客を案内 |

**Lodgify の低評価には、予約サイトとの同期・接続のトラブルが目立ち**、二重予約につながる重い内容もあります。個別の事例ですが、複数のサイトに出す運営では、トライアルで接続を確認しておきたい点です。

## 日本で使うときの注意（両社共通）

- **日本語**：どちらも公式サイトに日本語ページがありません。管理画面・サポートの日本語も確認できませんでした。
- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーで、**両社が該当するかは確認できていません。**
- **楽天トラベル・じゃらん**：民泊新法・特区民泊の施設は、どちらも対象外です。両社とも、公式の連携先に楽天トラベル・じゃらんの記載がありません。
- **決済**：Lodgify Payments は米国のホストだけです。Hostaway も、日本で使える決済は確認が必要です。
- 年180日の管理、届出番号、定期報告、インボイスなどの機能は、**両社とも公式ページに記載が見つかりませんでした**（「できない」と確認したわけではありません）。

## よくある質問

### Hostaway と Lodgify の一番大きな違いは何ですか？
Lodgify は自分の予約サイトを作ることが中心で、料金も公開されています。Hostaway は複数の予約サイトでの運営の自動化と導入支援が強みで、料金は見積りです。

### 3室ならどちらが安いですか？
Lodgify は Professional 以上が前提で、1物件あたりの表示価格は$47〜です。Hostaway は料金が非公開のため、比較には見積りが必要です。

### 無料トライアルがあるのはどちらですか？
Lodgify に7日間のトライアルがあり、カード登録は不要です。Hostaway は、公式ページでは確認できず、デモの申込のみです。

### 自動更新に気をつけるのはどちらですか？
規約上は Lodgify です。更新の通知なしに前払いの期間が自動更新され、期間の途中で解約しても返金されません。Hostaway は期間が個別契約なので、書面での確認が必要です。

### 日本語で使えるのはどちらですか？
どちらも、公式には日本語の管理画面もサポートも確認できませんでした。英語の画面で運用できるかを、トライアルやデモで確かめてください。
