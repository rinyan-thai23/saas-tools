# 経済事件コンテンツ

経済事件・詐欺・サイバー犯罪を題材にした、コンテンツ作りの作業場。
作成日: 2026-11-10

## ゴール

TSVの355件を、章ごとのテーマ（力学）に沿って、すべてコンテンツ化する。
本の仮題：『マーケティングは悪（ワル）から学べ！〜希代の詐欺師たちのスキームと、個人ビジネスへの応用思考〜』

## 考え方

- 「誰に読んでほしいか（Who）」を先に決める。事件（what）はそのあとで選ぶ。
- 読んだ人が「自分は騙されない」「身近な人に教えよう」「自分の商売に使える」と思えるものにする。

## フォルダ

```

├ 00_ナレッジ/                    書き上がっているサンプル
│  ├ 統合原稿.md                  序章＋第1〜7章＋終章（1本にまとめたもの）
│  ├ 構成案.md                    最初の構成案（章ごとの箇条書き）
│  └ 原文/                        アップロードされたままの2ファイル（触らない）
├ 01_型/
│  ├ 章の型.md                    1章の骨組みと守ること
│  └ 文体ガイド.md                サンプルの文体の癖
└ 02_進行/
   ├ 事件台帳.tsv                 355件の進行表（章テーマ・状態・裏取り・読者）
   ├ テーマ一覧.md                力学A〜G
   └ サンプル章の裏取りリスト.md   公開前に確認したい事実
```

## 進め方

1. 台帳の「章テーマ(力学)」を全件埋める（今ここ）
2. テーマごとに事件をまとめ、章の単位を決める
3. 章ごとに Who を決める → 型に沿って執筆 → 裏取り
4. 台帳の「状態」を更新

## 運用

- ブランチは切らず、`main` に直接プッシュする。
- TSVの金額・年・固有名詞は、書く前に一次情報で裏取りする。取れていないものは「未確認」と書く。
