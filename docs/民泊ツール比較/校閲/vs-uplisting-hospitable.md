# 校閲レポート：vs-uplisting-hospitable

- 照合先：事実カード Uplisting、Hospitable、日本のOTA連携、日本の制度
- 件数：要修正 0 ／ 注意 4 ／ 軽微 5
- 照合して一致を確認した主張：約55（3・5・10室の計算値すべて再計算、課金の数え方、トライアル、契約、値上げ、チャネル表、機能表、移行、Capterra、先に知っておくこと、法令4点）
- 内部リンク：`/go/uplisting/`、`/go/hospitable/` のみ。広告リンクはすべて `/go/`。PR 表記あり。

## 指摘

### 1. 注意：結論「料金はどちらも公開されています」が Hospitable の確度を超えている
- 記事（結論）：「料金はどちらも公開されています。」
- カード：Hospitable 2章「料金ページの表示状況」公式 pricing ページは月額が JS 描画（静的取得で「--」）。第三者は「2026年7月に Contact sales に置き換わった」と記録（未検証）。金額は公式ヘルプ記事の表から取得。Uplisting は料金ページのスクリプトから算出した値（画面表示そのものではない）。
- 問題：本文の注記では触れているが、結論が断定になっている。
- 修正案：「どちらも金額を確認できました（Hospitable は公式ヘルプの表、Uplisting は料金ページの計算ロジック）」とする。

### 2. 注意：結論「Hospitable は米ドルで」が本文・カードと合わない
- 記事（結論）：「Hospitable は米ドルで、円請求の記載は見つかりませんでした。」
- 記事（比較表）：「請求通貨は請求先住所で決まる。円の記載は見つからず」
- カード：Hospitable 5章「請求通貨」契約者の請求住所で決まる。記載に出る通貨は USD、EUR、GBP、AUD、CAD、THB（例）。JPY の記載は見つからず（未確認）。
- 修正案：「Hospitable の料金表は米ドル表示で、請求通貨は請求先住所で決まります。円請求の記載は見つかりませんでした」とする。

### 3. 注意：Uplisting「円の設定はありません」は請求通貨だけの確認
- 記事（結論）：「Uplisting は英ポンド等で、円の設定はありません。」
- カード：Uplisting 2章 JPY建ての価格「料金ページの通貨選択は GBP／EUR／USD／AUD／NZD／CAD のみ。JPYは見当たらない」（確認済、記載がないことの確認）。5章 通貨（JPY）「物件の売上通貨でJPYを扱えるかは記載を見つけられず」（未確認）。
- 問題：宿泊料の円設定ができないと読める。
- 修正案：「Uplisting の請求通貨に円はありません（宿泊料の円設定は未確認）」とする。

### 4. 注意：「別料金の例」のスマートロック £10 が Independent Host だけの条件になっていない
- 記事：「スマートロック（月£10、またはロック1台£4と表記が不一致）、本人確認（1回£1.25）、オーナー明細（月£40〜）」
- カード：Uplisting 2章 追加料金「スマートロック連携：Independent Hostは＋£10/月（Operator以上は込み）」。本人確認は「£15/月〜（Managerは込み）」と「1回£1.25」を併記。オーナー明細も「£40/月〜」と「Client Statements + Portal £8 p/l/m」が併記。
- 問題：この記事の主な読者（3〜15室）は Operator 以上になる場合が多く、スマートロックは込みになる。Uplisting だけ不利に読める。
- 修正案：「スマートロック（Independent Host は月£10、Operator 以上は込み。ヘルプには1台£4の記載もあり不一致）」とし、本人確認・オーナー明細も「ページ内で金額表記が複数ある」と添える。

### 5. 軽微：Uplisting の対象規模の引用が一部だけ
- 記事：「『10〜300+室の都市型の管理会社』。会員の多くは20室以上」
- カード：同じ出典に「20室未満の利用者も多いとも書いている」。
- 修正案：その一文を足す。

### 6. 軽微：Uplisting の金額は「計算値」だが由来が書かれていない
- 記事：凡例「【計算値】公式の単価からの計算（全物件が稼働する前提）」
- カード：Uplisting の金額は料金ページの HTML 内スクリプト（料金計算ロジック）から算出した値で、画面表示そのものではない。また Uplisting の課金は稼働を前提にせず「単価と下限の高い方」。
- 修正案：凡例に「Uplisting は料金ページのスクリプトから算出」を足し、「全物件が稼働する前提」は Hospitable のみの注記にする。

### 7. 軽微：Hospitable の値上げ「規約・ヘルプで該当条項は確認していない」はカードにない
- 記事：「規約・ヘルプで該当条項は確認していない【未確認】」
- カード：Hospitable に値上げ条項の行も「調べられなかったこと」の記載もない。
- 問題：未確認という結論は妥当だが、確認したという根拠がカードにない。
- 修正案：「カードに記載なし（未確認）」の意味で「値上げ条項は未確認」とし、追加調査依頼のコメントに残す。

### 8. 軽微：Uplisting の Vrbo「API 接続」
- 記事：「Airbnb・Booking.com・Vrbo ｜ API 接続【確認済】」
- カード：Airbnb は公式ソフトウェアパートナー、Booking.com は API連携、Vrbo は「公式連携あり」（API の明記なし）。
- 修正案：「公式連携（Airbnb・Booking.com は API）」とする。

### 9. 軽微：Hospitable の料金行に Essentials（$0）がない
- 記事：「3室の月額」「5室」「10室」は Professional と Mogul のみ。
- カード：Essentials は基本 $0、物件数無制限、ただしサポートは AI のみ・機能制限あり。
- 修正案：行の注記に「Essentials は $0（機能制限・サポートは AI のみ）」を足す。

## 問題なしと確認した主な点
- Uplisting：3室 £72、5室 £90、10室 £160／£208 は IH 72、Operator 床90、16×10、Manager 床208 と一致。Hospitable：$74／$99、$104／$159、$179／$309 は基本＋追加物件単価から再計算して一致。
- 契約縛りの食い違い（料金ページ「No contract」と規約「最低12か月」）は両方を書き、適用は未確認としている。
- Hospitable の管理画面「英語のみ」、定型メッセージ4言語、日本語要望「New」、Agoda 直接接続、Expedia iCal は一致。
- 「未確認」を「できない」と書いた箇所なし。法令の断定なし。
