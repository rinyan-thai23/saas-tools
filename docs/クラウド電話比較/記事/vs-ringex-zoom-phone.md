# 【クラウド電話】RingEX（RingCentral）とZoom Phoneを比較｜日本の事業者が申し込む前に見ること

## 先に結論

> - **日本で使う前提なら、今回確認できた範囲では Zoom Phone のほうが、条件が具体的に読めます。** 日本語の公式サイト、円の料金、050と03・06の番号、必要書類、日数が公開されています。
> - **RingEX（RingCentral）は、日本向けの条件が見つかりませんでした。** 公式の緊急通報ポリシー（2023年12月版）に「日本は東京の市外局番の番号のみ」とあるだけで、日本語の公式サイトと円の料金は確認できませんでした。「使えない」のではなく、**調べても読める情報が少ない**、ということです。
> - **どちらも、110・119は前提にしないでください。** RingEX は公式ポリシーに「利用できない」、Zoom Phone は日本向けページに「発信不可」とあります。

## 日本の番号

- **Zoom Phone**：公式の「電話番号の要件」ページ（2026年10月18日更新）に、050、0ABJ、0120・0800の機能と、移行の可否が表で載っています。
- **RingEX**：東京の市外局番の番号のみ、という記載が、確認できた唯一の公式の記載です。大阪・名古屋の番号、050、フリーダイヤルは、確認できていません。**古い版（2023年12月）なので、今の条件は直接確認してください。**

## 料金

- **Zoom Phone（円・税別）**：¥1,275（従量制、受電メイン）、¥2,400（050・国内かけ放題）、¥3,300（0ABJ＋050・国内かけ放題）。公式ブログ自身が、通話が少ない小さな事業者には割高になりうる、と書いています。
- **RingEX（ドル）**：Core $20、Advanced $25、Ultra $35（年払い、1ユーザー）。米国向けの料金ページです。**日本の番号の月額や日本宛の通話料は、確認できていません。** 「国内通話の定額」の「国内」に日本が入るかも、公式の料金ページから読み取れませんでした。

ドルと円は、そのまま並べて比べられません。**申込前に、通話料込みの月額を、円で見積もってもらってください。**

## 口コミ（海外のレビュー）の違い

RingEX は約8割、Zoom Phone は約5割が米国の投稿者です。**日本の事業者の口コミは、RingEX にはなく、Zoom Phone に自営業の方が1人**です。

| | RingEX | Zoom Phone |
|---|---|---|
| 良い点で多い話 | 使いやすさ（約4割）、工事なしで導入できる | 使いやすさ（約4割）、Zoom との一体感、通話の品質 |
| 悪い点で多い話 | 料金（約15%）、サポート（約13%）、通話の途切れ、契約・解約 | 料金（国際通話）、通話の安定性、機能の不足 |
| 低評価（1〜2点） | 約16件（約8%）。契約・解約、安定性、サポート | 2件（約2%） |
| 口コミの時期 | 2022〜2023年が多く、2024〜2026年は約25件 | 2025年が17件、2026年が7件 |

**Zoom Phone のほうが、低評価が少なく、口コミも新しめです。** ただし、約95件と件数は少なめです。RingEX には、「営業の説明と違った」「解約できない」という低評価が複数あります。

## 申し込む前に聞くこと

1. **日本で取れる番号の種類**と、自分の事業で必要な書類・日数。
2. **通話料を含めた月の総額**（円で）。
3. 今の電話番号を移せるか。費用と日数は。
4. 110・119にかけられない場合の備え。
5. 契約期間、自動更新、解約の条件。
6. 日本語の画面とサポート、日本時間の対応時間。
