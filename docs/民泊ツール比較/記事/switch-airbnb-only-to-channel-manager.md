# 【民泊】Airbnb だけの運営から、複数サイトへ｜チャネルマネージャーはいつ必要？

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：2つ目のサイトを増やす前に、同期の方法を決める

> - **Airbnb だけなら、同期の問題は起きません。** 2つ目のサイトを足すときが、切り替えのタイミングです。
> - **無料のカレンダー同期（iCal）は、更新が遅く、二重予約が起きえます。** 同期は1日に数回のことが多く、その間に別のサイトで同じ日が予約されると、二重になります（フォーラムや販売会社の説明）。
> - **API でつなぐチャネルマネージャーは、予約が入ると数秒でほかのサイトの同じ日を閉じる**と説明されています。月額が必要です。
> - **目安：2つ目のサイトを足すとき。** 部屋数の明確な基準は、見つかっていません。
> - **日本の民泊新法の人は、先に確認が必要。** Airbnb は、日本の民泊新法の宿で、ツール経由で作った掲載を受け付けません（例外あり）。

## 今の運営と、切り替えのタイミング

| 今の状況 | おすすめ |
|---|---|
| Airbnb だけ | そのままでよい。管理ツールは、自動メッセージや清掃の手配が目的なら検討 |
| 2つ目のサイトを足したい（少数の部屋） | 無料の iCal 同期は、二重予約のリスクを理解したうえで。リスクが気になるなら、無料プランのあるツールを |
| 3つ以上のサイト、または複数人で管理 | チャネルマネージャー（API 接続）を検討 |
| 日本の民泊新法で運営 | **先に Airbnb と各ツールに、つなげられるかを確認** |

## iCal と チャネルマネージャーの違い

| | iCal（カレンダー取り込み） | チャネルマネージャー（API 接続） |
|---|---|---|
| 費用 | 無料 | 月額（無料プランのあるツールもある） |
| 更新の速さ | 遅い（1日に数回のことが多い） | 速い（数秒〜数分と説明される） |
| 二重予約 | 起きえる | 起きにくい（ゼロとは限らない） |
| できること | 予約の日付の共有のみ | 料金・最低宿泊・予約・メッセージも |
| 向く規模 | 1〜2室・サイト2つまで | サイトが増える・部屋が増える |

「数秒」という速さは、販売会社の説明で、第三者の検証は確認できていません。Guesty の公式FAQには、切り替え時に多くのチャネルで約30分の停止が出る、とあります。

## 日本で複数サイトに出すときの注意

- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーです。**どのツールが該当するか確認できていません。** Airbnb にも、既存の掲載をツールにつなげられるかを聞いてください。
- **増やすサイトの条件**：楽天トラベルとじゃらんは、民泊新法・特区民泊の施設を対象外としています。Booking.com や Agoda などが民泊新法の施設を受け付けるかは、各サイトの案内で確認してください（今回は調べていません）。
- **日本語**：Beds24（日本の販売会社経由）以外は、公式に日本語の管理画面・サポートを確認できません。
- 年180日の管理、届出番号、定期報告などの機能は、各ツールの公式ページに記載が見つかりませんでした。複数のサイトに出すときも、**表計算など別の方法で管理する**前提にしてください。

## 切り替えの手順（簡単に）

1. **増やしたいサイトを決める**：そのサイトが、自分の営業形態を受け付けるか確認。
2. **同期の方法を決める**：iCal で試すか、チャネルマネージャーを入れるか。
3. **無料プラン・トライアルで試す**：実際に使う予約サイトを接続して、カレンダーが同期するか確認。
4. **二重予約を防ぐ**：新しいサイトを公開する前に、近い日付の空室を手動で閉じる。公開後、各サイトのカレンダーを確認。
5. **Airbnb の設定を控える**：手動でブロックした日、ルール、カレンダーの設定を書き出す（ツールに接続したとき消えた、という口コミがあります）。

## よくある質問

### チャネルマネージャーは、何室から必要ですか？
部屋数の基準は見つかりませんでした。2つ目の予約サイトを足すとき、または複数人で管理するときが、検討のタイミングです。

### iCal の同期だけで足りますか？
1〜2室で、サイトが2つまでなら、リスクを理解したうえで使えます。ただし、更新が遅く、同じ日に別のサイトで予約が入ると、二重予約になる可能性があります。

### 無料で始められるチャネルマネージャーはありますか？
iGMS（予約5件・メッセージ10件まで）、Hospitable（Essentials、機能に制限）、Sirvoy（1室まで。予約サイト連携は有料の Pro）に無料プランがあります。

### 日本の民泊新法の宿でも使えますか？
Airbnb のヘルプには、日本の民泊新法の宿について、ソフト連携で作った掲載を受け付けないという記載があります。例外は Airbnb と契約した日本のAPIパートナーです。各ツールが該当するかは確認できていないため、Airbnb とツールに確認してください。
