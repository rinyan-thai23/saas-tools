# 【クラウド電話】英語のクラウド電話を使うメリットと弱み

## 先に結論

> - **「英語だから使わない」は、もったいない場合があります。** 海外のクラウド電話には、**料金とトライアルの公開、CRM との連携の広さ、AI機能、日本の番号の条件を細かく公開している製品がある**という強みがあります。
> - **ただし、日本の事業者には、日本語のサポート、円での請求、インボイス、時差という弱みがあります。** これらは、翻訳では補えない部分です。
> - **日本語の公式サイトと円の料金表が確認できたのは、Dialpad（ソフトバンク経由）と Zoom Phone です。** 日本語の窓口が大事なら、この2つから見るのが現実的です。
> - **AI・翻訳の効果は、このサイトでは検証していません。** 誤訳や個人情報の扱いに注意が必要です。

## 誰のための記事か

「海外の製品は英語だけで不安」と感じている、日本の小さな事業者向けです。**英語でも使う価値があるか**、**どこまで自分で補えるか**を、判断するための記事です。

## 海外製の強み（公式の記載・口コミから）

### 1. 料金とトライアルが公開されている
- RingEX（RingCentral）、Nextiva、Aircall、JustCall、CallHippo、CloudTalk は、料金ページを公開しています（[料金早見表](/articles/buy-fee-table/)）。
- 無料トライアルは、CallHippo（10日）、JustCall（14日）、CloudTalk（14日）など（[無料トライアル比較](/articles/buy-trial-compare/)）。

### 2. CRM との連携の広さ
Aircall は250以上のサービスと連携（自社の主張）、CallHippo は95以上（料金ページでは50以上の表示もあります）、JustCall は100以上の CRM・データ連携（自社の主張）。営業・サポートのチームには、強みになります。

### 3. 日本の番号の条件を細かく公開している製品がある
- CloudTalk：東京の03とフリーダイヤルの、月額・必要書類・日数。
- CallHippo：050・03・06・0120の、必要書類と日数の表（自社の説明）。
- Telnyx：日本のローカル番号の月額と、必要書類のヘルプ。
- → [日本の電話番号の取り方と審査](/articles/jp-number-acquisition/)

### 4. AI機能
- Dialpad：日本市場で「AI要約」「AI文字起こし」を提供開始（Dialpad の日本語のプレスリリース、2025年7月16日）。
- Zoom Phone：日本語の公式ページに、通話の文字起こし・要約、ボイスメールからタスクを作る機能の説明があります。**日本語の通話で使えるかは、ページの記載から確認できていません。**
- ほかにも、RingEX、Aircall、CallHippo、JustCall などが、AI機能を案内しています（精度は、試して確かめてください）。

### 5. 口コミが多い
Capterra に、各製品で約100〜200件の口コミがあります（RingEX 約190件、Aircall 約170件、Nextiva 約185件など）。**ただし、海外の事業者の声で、日本の事業者の声ではありません。**

## 海外製は、料金が安い？

**必ずしも、安くはありません。** ドルやユーロの表示の月額のほかに、日本の番号の費用、日本宛の通話料、為替が加わります。

- 例：CallHippo と Aircall の「無制限」は、米国・カナダ宛だけです。日本宛は別料金です。
- 例：円で料金が確認できる Dialpad Standard は ¥1,000（税抜）から、Zoom Phone は ¥1,275（税別）からです。
- → [料金早見表](/articles/buy-fee-table/)、[通話料・円・インボイス](/articles/jp-billing-invoice/)

## 海外製の弱み（日本の事業者にとって）

| 弱み | 内容 |
|---|---|
| 日本語のサポート | 日本語の公式サイトが確認できたのは Dialpad と Zoom Phone。ほかは、確認できませんでした（[日本語で使える？](/articles/jp-language-support/)） |
| 円の請求・インボイス | 円の料金表は Dialpad と Zoom Phone のみ。インボイス対応は、どの製品も確認できていません（[通話料・円・インボイス](/articles/jp-billing-invoice/)） |
| 日本の番号 | Aircall、Nextiva、JustCall、GoTo Connect は、日本の番号の記載を確認できませんでした。RingEX は東京のみ |
| 緊急通報（110・119） | Zoom Phone、RingEX、Dialpad は発信不可と公式に（[110・119にかけられる？](/articles/jp-emergency-calls/)） |
| 時差 | サポートの対応時間が日本時間と合わないことがある。口コミに、保留が長い、折り返しがない、という声 |
| 契約・解約 | 口コミの低評価で多い不満。更新・解約・返金の条件に注意（[申込前チェックリスト](/articles/buy-checklist/)） |
| 個人情報 | 海外のサーバーに通話記録が保存されることがある（[通話録音と個人情報](/articles/jp-privacy-recording/)） |

## AI・翻訳で補える範囲

**この記事では、AI・翻訳の効果を自分で検証していません。** 一般的な使い方と、注意点です。

### 補えそうなこと
- **管理画面を読む**：ブラウザの翻訳機能などで、英語の画面を日本語にして読める。
- **サポートへの問い合わせの下書き**：英語の質問を、翻訳ツールで作る。

### 補えないこと・注意
- **契約・料金・返金・解約の条項**は、誤訳が損害につながるため、翻訳だけで済ませず、人が確認する。
- **お客さんの個人情報が出ている画面**を、翻訳サービスに送る場合は、利用条件と社内ルールを確認する。
- **時差と返事の速さ**は、翻訳では解決しない。
- **日本の番号の本人確認や、郵送物の受け取り**など、手続きの現実の作業は残る。

## 英語の壁を、トライアルで確かめる方法

1. **英語の管理画面を開いて**、ブラウザの翻訳で、番号の取得まで進めてみる。
2. **サポートに、1つ質問**を出す（日本の番号の条件など）。返事の速さと、内容を見る。
3. **契約・解約・返金の条項**を、翻訳＋原文で読む。
4. この負担が、**毎月の運用として続けられるか**を判断する。

## 向いている人・向いていない人

| | 向いている人 | 向いていない人 |
|---|---|---|
| 英語 | 英語の画面・メールで、問い合わせに困らない | 日本語の窓口が必須 |
| 番号 | 日本の番号の条件を、自分で読み込める | 手続きを、日本語で代行してほしい |
| 請求 | ドル・ユーロの請求と為替を、経理で扱える | 円・インボイス形式が必須 |
| リスク | 緊急通報の備え（携帯）と、契約の確認をできる | 契約トラブルを避けたい |
