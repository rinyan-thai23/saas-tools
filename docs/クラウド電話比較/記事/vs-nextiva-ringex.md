# 【クラウド電話】NextivaとRingEX（RingCentral）を比較｜日本の事業者が申し込む前に見ること

## 先に結論

> - **この2つは、どちらも米国発で、日本の事業者向けの情報が少ない製品です。** 日本の番号が目的なら、[Dialpad](/articles/dialpad/) や [Zoom Phone](/articles/zoom-phone/) のほうが、公式の条件を読みやすいです。
> - **日本の番号は、RingEX にだけ記載があります。** RingCentral の公式の緊急通報ポリシー（2023年12月版）に「日本は東京の市外局番の番号のみ」とあります。Nextiva は、日本の番号を取れるという記載を、公式で確認できませんでした。
> - **日本から米国向けに使うなら**、どちらも選択肢になります。**契約・解約の不満**は、両方の口コミにあります。

## 日本の番号と通話

- **RingEX**：確認できた唯一の公式の記載は、東京の市外局番の番号のみ、というものです。住所はその範囲内が必要です。大阪・名古屋の番号、050、フリーダイヤルは、確認できていません。**2023年12月の版なので、今の条件は直接確認してください。**
- **Nextiva**：公式のサポート記事で確認できたのは、国際電話を**かける**機能です。初期状態では国際ダイヤルが止められていて、サポートに依頼して有効にします。日本の番号を取れる、という記載はありません（「取れない」と確認したわけではありません）。

## 料金

- **Nextiva**：NEXT Core $15、Engage $25、Scale $75（年払い、1ユーザー）。月払いは Core $23、Engage $50。
- **RingEX**：Core $20、Advanced $25、Ultra $35（年払い）。月払いは $30／$35／$45。
- **年払いの安さの幅が違います。** Nextiva は最大50%、RingEX は最大33%安い、と公式にあります。
- どちらも、**日本の番号の月額、日本宛の通話料、円の請求は、確認できていません。**

## 口コミ（海外のレビュー）の違い

どちらも**日本の事業者の口コミはありません**。

| | Nextiva | RingEX |
|---|---|---|
| 良い点で多い話 | サポートが親切（約3割）、使いやすさ、番号の移行がスムーズ | 使いやすさ（約4割）、工事なしで導入できる |
| 悪い点で多い話 | サポートへの不満（約2割）、契約・解約、管理画面の複雑さ | 料金（約15%）、サポート（約13%）、通話の途切れ、契約・解約 |
| 口コミの時期 | **2023〜2024年に約160件**。2025〜2026年は計12件 | 2022〜2023年が多く、2024〜2026年は約25件 |
| 低評価の内容 | 「解約がほぼ不可能」「高くて割に合わない」。2025〜2026年に4件 | 「営業の説明と違った」「解約できない」「安定性」 |

**共通する注意点**：どちらも、「解約できない」「説明と違った」という声が低評価にあります。**契約期間、自動更新、解約の条件**は、書面で確認してください。Nextiva は、新しい口コミにサポートへの厳しい声が目立つ、という傾向があります（件数が少ないので、参考程度です）。

## 申し込む前に聞くこと

1. 日本の番号を取れるか。種類、必要書類、日数、月額。
2. 日本宛の通話料の単価と、国際ダイヤルの有効化の方法。円で請求されるか。
3. **契約期間、自動更新、解約の条件、値上げの通知。**
4. 今の電話番号を移せるか。
5. 110・119にかけられない場合の備え。
6. 日本時間のサポートの有無。
