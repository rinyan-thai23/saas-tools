## 取得日の方針

- 記事・表の料金、仕様、契約条件、日本対応の情報は、公式ページ等を開いて確認した日（取得日）を付けています。最初に作成した時点の取得日は、すべて 2026-11-05 です。
- 取得日は、実際に確かめた日だけを書きます。確かめ直していない記事の取得日を、更新日に合わせて書き換えることはしません。
- 料金・仕様を再確認して変わっていた場合は、取得日と本文を更新し、このページに「何を」「どの記事で」変えたかを記録します。変わっていなかった場合は、取得日だけを更新します。
- 誤りを訂正した場合は、訂正した記事・表と内容を、このページに記録します。
- 記事の `updated`（更新日）は、記事を最後に直した日です。取得日と同じとは限りません。
- Capterra の評価・口コミ数は、取得日とは別に「2026-11-03 時点」の数字を使っています。海外レビューの数字は件数が日々変わるため、そのつど時点を書きます。
- 料金や仕様は、取得日のあとに変わることがあります。申込前に、必ず公式ページで再確認してください。

## 2026-11-05 取得分の取得方法に関する注記

公式ページを開けなかった、または一部しか確認できなかったものは、次のように扱っています。各記事・表では、この扱いを確度（確認済／第三者のみ／未確認）で示しています。

| ツール | 取得方法の注記 |
|---|---|
| Guesty | ヘルプセンターを開けなかった。ヘルプ記事の内容は検索結果の抜粋でしか見ておらず、「第三者のみ」としている |
| Hostaway | ヘルプセンターを開けなかった（同上）。料金ページは価格表ではなく、物件数を答えるフォームだった |
| Lodgify | 本体サイトとヘルプセンターを開けなかった。公式のマーケティングサイトの公開コピーを代わりに確認した。本体サイトの同名ページと内容が同一かは照合していない。物件数別の料金はスライダー計算で取得できなかった |
| OwnerRez | アフィリエイトの正式な規約はアプリ内（ログイン後）にあり、本文を確認できなかった。5室以外の合計額は、公式の料金表から計算した値 |
| Hospitable | 料金ページの月額がJavaScript描画で取れなかったため、公式ヘルプ記事の表で確認した。合計額は計算した値 |
| iGMS | 料金は公式の料金ページと、ページが読み込む公開データで確認した。合計額は、1物件あたりの月額に物件数を掛けた計算値 |
| Uplisting | 料金ページがJavaScript描画のため、ページ内の料金計算ロジックから価格を読み取った。物件数別の目安は算出した値 |
| Beds24 | 海外公式（Beds24 GmbH）と日本の販売会社（株式会社WeIns / Co-Reception）で条件が別。日本語UI・円建て・名簿オプションなどは日本の販売会社版の情報。海外公式の料金は、計算機のスクリプトから読み取った。日本の販売会社の計算機は動的描画で式を読めず、自社掲載の3例のみ確認した |
| PriceLabs | 料金ページがJavaScript描画のため、ページ内の公式データとヘルプ記事で確認した。件数別の目安は、単価表からの計算値 |
| Hostfully Guidebooks | 公式の料金ページ本文に Pro の金額が出ないため、申込時のチェックアウト画面で確認した |
| Sirvoy | 料金はページ内のデータと計算スクリプトで確認した。年払いの金額の一部は計算値 |
