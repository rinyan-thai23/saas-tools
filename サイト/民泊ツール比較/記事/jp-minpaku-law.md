# 住宅宿泊事業法（届出番号・年180日・定期報告）に対応できる民泊管理ツールは？海外ツールの記載を確認

> **結論**
> - 調べた海外ツールの公式ページ（Hospitable は検索要約のみ）で、日本の届出番号の表示・年180日の管理・定期報告に当たる本体機能を「ある」と書いているものは見つからなかった。「ない」と確認したのではなく、記載が見つからなかったという意味。
> - 手がかりがあったのは Beds24 の日本の販売会社（株式会社WeIns）だけ。定期報告用の集計シートを無料配布している（外部シートで、システム本体の機能ではない）。
> - **法的な判断は、行政書士・自治体・保健所などに確認してください。** この記事は公的文書の記載の紹介までで、解釈はしません。

## 公的文書に書かれていること（引用のみ）

| 論点 | 記載 | 出典 |
|---|---|---|
| 届出番号・標識 | 規則第4条第7項「都道府県知事は、第一項の届出があったときは、届出者に、届出番号を通知しなければならない。」／法第13条「届出住宅ごとに、公衆の見やすい場所に…標識を掲げなければならない」 | e-Gov（法・規則） |
| 予約サイトでの届出番号 | ガイドライン「仲介サイトにおいて、届出番号等、物件の適法性に関する情報を表示することとする。」（表示する主体は仲介サイトと書かれている）。事業者自身の広告に届出番号を表示せよと直接定める条文は、法・規則・国規則・施行令の本文では見つからなかった（告示・通知・条例は未検索） | 観光庁ガイドライン |
| 年180日 | 法第2条第3項「一年間で百八十日を超えないもの」／規則第3条「毎年四月一日正午から翌年四月一日正午まで」、「正午から翌日の正午までの期間を一日」／ポータル「届出住宅ごとに算定します。」 | e-Gov、民泊制度ポータル |
| 超えたとき | ガイドライン4-8「営業日数が180日を超過し、…旅館業法違反とする場合には、住宅宿泊事業者自らが仲介サイト上の予約のキャンセルや新規予約の停止を手続きするよう都道府県知事等から指導を行う」「新規予約募集を停止する措置を講ずること。」（引用の範囲で、解釈は加えていません）。別に、仲介サイトは届出番号と営業日を観光庁へ日ごとに報告している（観光庁の記載） | 観光庁 |
| 定期報告 | 規則第12条：毎年2・4・6・8・10・12月の15日までに、前2か月の「宿泊させた日数」「宿泊者数」「延べ宿泊者数」「国籍別の宿泊者数の内訳」。ポータル「民泊制度運営システムを利用して行うことが原則」（自治体独自の様式がある場合あり） | e-Gov、民泊制度ポータル |
| 条例 | 法第18条：自治体が区域を定めて実施期間を制限できる。各自治体の中身は今回未調査 | e-Gov |

## ツール側で確認したい点

上の記載から、ツールに聞いておきたい点を挙げます（義務かどうかの判断ではありません）。

1. 物件ごとに届出番号を登録・表示できるか。なお Airbnb のヘルプは、番号の追加は管理ツールを使っていても本人がログインして行う旨を書いています（OTA側の規則）。
2. 4月1日正午始まりの年度で、物件ごとの宿泊日数を数えたり出力したりできるか。
3. 上限が近づいたとき、新規予約を止められるか（カレンダーの手動ブロックで足りるか）。
4. 2か月ごとの報告項目（日数・宿泊者数・延べ・国籍別）を出力できるか。国籍は宿泊者名簿とつながります（[宿泊者名簿の記事](/articles/jp-guest-register/)）。

## 条件別の見方

| あなたの条件 | 調べた記載から言えること |
|---|---|
| 定期報告の集計を楽にしたい | 手がかりがあったのは Beds24（WeIns）の配布シート。ほかは記載が見つからず、申込前に質問が必要 |
| 届出番号・180日はツールではなく自分で管理する | ツール側に機能の記載がない場合の管理方法は、自治体や専門家に確認 |
| 無料トライアルで確かめたい | 上の4点を、試用中に画面で確かめる |

## 申込前にサポートへ送る英文の例

```
Hello, I operate a registered minpaku (Japanese Housing Accommodation Business) property. Before subscribing, could you confirm in writing:
1) Can I store and display a notification (registration) number per property? 2) Can you count nights per property for a year starting April 1 and block new bookings after a set number of nights? 3) Can I export nights, guest counts and guest nationality for each two-month period?
```
