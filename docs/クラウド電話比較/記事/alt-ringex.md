# 【クラウド電話】RingEX（RingCentral）の代替｜日本の事業者が選べるクラウド電話7つ

## 先に結論

> - **日本の事業者は、日本の条件が公式で読める製品から選ぶのが現実的です。** 確認できたのは4つ：**Zoom Phone**（円の料金表、日本の番号の要件ページ）、**Dialpad**（ソフトバンクが円の料金と本人確認を公開）、**CallHippo**（日本向けの番号ページ）、**CloudTalk**（日本向けの番号ページ。東京の03とフリーダイヤル）。
> - **RingEX をやめたい理由で多いのは3つ**：①日本向けの条件が読めない ②料金・契約への不満（口コミ）③サポートの返事が遅い（口コミ）。
> - **110・119の発信は、どの製品も前提にできません。** 公式に「発信不可」とあるもの（RingEX、Zoom Phone、Dialpad）もあります。

## RingEX が合わない主なケース

[RingEX の商品ページ](/articles/ringex/)で書いたとおり、次のような人には向きません。

- **日本語の公式情報で確認したい人**：日本語の公式サイトと円の料金を確認できませんでした。
- **東京以外の番号が欲しい人**：公式ポリシー（2023年12月版）に、日本は東京の市外局番の番号のみ、とあります。
- **契約・解約のトラブルを避けたい人**：口コミの低評価に、「説明と違った」「解約できない」という声が複数あります。

## 1. Zoom Phone（円の料金表あり）

日本語の公式サイトがあり、番号の種類ごとの機能・移行の可否・必要書類・日数が、公式の日本向けページに載っています（2026年10月18日更新）。**個人事業主は開業届で足りる**、と書かれています。ただし、**050は番号の移行ができません**。通話が少ない小さな事業者には、割高になりうる、と公式ブログ自身が書いています。詳しくは [Zoom Phone の商品ページ](/articles/zoom-phone/)、[RingEX と Zoom Phone の比較](/articles/vs-ringex-zoom-phone/)へ。

## 2. Dialpad（ソフトバンク経由）

ソフトバンクが、円の料金表・本人確認の書類・日数を公開しています。Standard は1ライセンスから契約でき、**050が1つ含まれます**。03・06は、1番号 月¥500（税抜）で追加できます。開通は最短10〜15営業日で、書類と郵送があります。詳しくは [Dialpad の商品ページ](/articles/dialpad/)、[RingEX と Dialpad の比較](/articles/vs-ringex-dialpad/)、[Dialpad と Zoom Phone の比較](/articles/vs-dialpad-zoom-phone/)へ。

## 3. CallHippo

日本の番号の専用ページがあり、050は海外の住所でも取れる、と自社が説明しています。「通話無制限」は米国・カナダ宛のみで、日本宛は従量です。未払いでアカウントと番号が止まった、という声が2026年の口コミにあります。詳しくは [CallHippo の商品ページ](/articles/callhippo/)へ。

## 4. CloudTalk

日本向けの番号ページに、東京の03（月$6＋有効化$6）と、0120・0800（月$35＋$35。**着信のみ**）が載っています。大阪などの市外局番と050は、載っていません。詳しくは [CloudTalk の商品ページ](/articles/cloudtalk/)へ。

## 5〜7. Aircall、Nextiva、JustCall（日本の番号は確認できず）

3人以上のチームで CRM との連携が目的の [Aircall](/articles/aircall/)、米国向けの [Nextiva](/articles/nextiva/)、自動発信（パワーダイヤラー）のある [JustCall](/articles/justcall/) は、日本の番号を取れるという記載を、公式で確認できませんでした（「取れない」と確認したわけではありません）。日本の番号が目的なら、上の4つを先に比べてください。

## 乗り換える前に聞くこと

1. 日本の事業者として契約できるか。円で請求されるか。
2. 日本の番号の種類ごとの**必要書類・日数・月額**。
3. **通話料込みの月額**を、見積もりで。
4. 今の番号を移せるか。費用と日数は。
5. RingEX の**解約の条件、最低利用期間、番号を他社へ移すときの条件**。
6. 110・119にかけられない場合の備え。

## よくある質問

### RingEX の代替で、日本の公式情報が読めるのは？
Zoom Phone、Dialpad（ソフトバンク）、CallHippo、CloudTalk の4つです。ほかは、日本の番号の記載を確認できませんでした。

### 一番安いのは？
プランと通話量で変わります。月額だけなら、Dialpad の Standard が ¥1,000（税抜）から、CallHippo の Starter が $18〜$19 からです（最低2ユーザー）。通話料や番号の費用が別なので、見積もりで比べてください。

### 今の RingEX の電話番号は、移せますか？
他社への移行（ポートアウト）の条件は、今回は確認できていません。RingCentral に、条件・日数・費用を書面で確認してください。
