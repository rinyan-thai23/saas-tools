# 【民泊】Hostaway と OwnerRez どっちがいい？料金・サポート・口コミ・日本で使えるかを比較

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容や順番は変えていません。

## 先に結論：料金を見て自分で進めるなら OwnerRez、導入の手助けがほしいなら Hostaway

> - **料金表を見て、自分で設定しながら使う → OwnerRez。** 物件数別の料金が公開され、14日間無料。契約縛りも予約手数料もありません。
> - **導入の手助けがほしい、複数の予約サイトで運営を自動化したい → Hostaway。** ただし料金は見積り制で、契約期間も個別契約です。
> - **3〜10室の月額の目安：OwnerRez は月$70〜$127（公式の単価から計算）。** Hostaway は公式の数字がありません。
> - **日本語の画面・サポートが必須 → どちらも不向き。**
> - **日本の民泊新法の人は、どちらも先に確認が必要**（Airbnb の扱い）。

## 2つのツールの違い（早見表）

| | Hostaway | OwnerRez |
|---|---|---|
| 向く運営者 | 複数サイトの運営を自動化したい人。導入支援がほしい人 | 料金を見て、自分で設定しながら使う人 |
| 料金の公開 | 非公開（見積り） | 公開（物件数別の料金表） |
| 無料トライアル | 公式では確認できず（デモのみ） | 14日間（プレミアム機能も期間中は無料） |
| 契約 | 個別契約による | 契約縛りも解約金もなし。ただし未使用期間の返金なし |
| 予約手数料 | 予約サイトは契約に含む。上位版は月$49＋0.5% | なし（決済会社の手数料は別） |
| 導入支援 | オンボーディングが手厚いと口コミで評判。初期費用は自社の比較ページに「$500」 | 無料の通話（Jumpstart、1時間）。データ移行の代行はなし |
| 口コミの低評価率 | 約4%（約170件中7件） | 0%（102件中0件。5点が約9割で偏りあり） |
| 日本語 | 画面・サポートとも確認できず | 画面の言語に日本語なし（11言語）。サポートの日本語も確認できず |

各ツールの詳しい情報は、[Hostaway の評判・口コミ](/articles/hostaway/)、[OwnerRez の評判・口コミ](/articles/ownerrez/)にまとめています。

## 料金：OwnerRez は見える、Hostaway は見えない

**OwnerRez（公式の料金表、月額・米ドル）**

| 物件の順番 | 1物件あたり |
|---|---|
| 1つ目 | $40（最低月額） |
| 2〜3つ目 | $15 |
| 4つ目 | $10 |
| 5〜9つ目 | $8 |
| 10〜19つ目 | $7 |

- 公式の単価からの計算で、3室は月$70、5室は月$88、10室は月$127です。
- 独自ドメインの予約サイト、SMS、AI、会計連携などは別料金です。足すと、上の目安より高くなります。

**Hostaway**：料金ページは、物件数を答えると見積りが来る入力フォームです。第三者の推定は数字がバラバラで、公式の裏付けがありません。比較サイトには、ホテル向けの掲載価格を引いたとみられる高い数字もあり、そのまま使えません。

## 契約と解約：OwnerRez は縛りなし、Hostaway は確認が必要

- **OwnerRez**：契約も最低期間もなく、いつでもアカウントを閉鎖できます。ただし**未使用期間の返金はありません**。閉鎖すると、決済・予約サイト連携・サイトなどが止まり、データは残ります。
- **Hostaway**：期間は個別契約。値上げは14日前に通知され、同意しない場合は、発効の5日前までの通知で解約できます。口コミには、「営業の説明と導入後が違った」「12か月契約で、試用なしだった」「解約の連絡後も請求が続いた」という低評価があります。

**Hostaway は、期間・解約金・値上げの条件を書面でもらってから**申し込むのが安全です。

## サポート：評価の出方が違う

Capterra の海外レビュー（Hostaway約170件、OwnerRez102件）を読んだ結果です。英語圏の運営者の声が中心で、日本の運営者の声ではありません。

| | Hostaway | OwnerRez |
|---|---|---|
| サポートが良い点に挙がる割合 | 約3割 | 約44%（最多） |
| 改善点で多い話題 | 料金（約4分の1）、サポートの遅れ、学習の時間 | 覚えることの多さ（約16%）、サポートの遅れ（約15%） |
| 特徴的な声 | 導入支援が手厚い。ただし解約・契約の不満も | 問い合わせに必ず返信がある。ただしメール中心で、24時間ではない |

OwnerRez は、サポートの電話窓口が案内されておらず、公式も「すぐに返信できないことがあります」と書いています。

**注意**：OwnerRez の口コミ集は、低評価が1件もなく、5点が約9割です。満足した人が書きやすい仕組みの可能性があり、実際より良く見えている可能性があります。

## 日本で使うときの注意（両社共通）

- **日本語**：Hostaway は公式サイトに日本語ページがなく、管理画面・サポートの日本語も確認できません。OwnerRez は画面の言語が11あり、日本語は入っていません（公式のフォーラムに多言語化の要望が「計画中」。2022年）。
- **民泊新法の人は先に確認**：Airbnb のヘルプには、日本の民泊新法の宿について「ソフト連携で作った掲載は受け付けない」とあります。例外は、Airbnb と契約した日本のAPIパートナーで、**両社が該当するかは確認できていません。**
- **楽天トラベル・じゃらん**：民泊新法・特区民泊の施設は、どちらも対象外です。両社とも、公式の連携先に楽天トラベル・じゃらんの記載がありません。
- **請求通貨**：どちらも円は確認できません（OwnerRez は米ドル表示）。
- 年180日の管理、届出番号、定期報告、インボイスなどの機能は、**両社とも公式ページに記載が見つかりませんでした**（「できない」と確認したわけではありません）。

## 申し込む前に、両社へ聞く質問

1. 自分の物件数・使いたい機能での、正確な月額（アドオン込み）。
2. 契約期間、解約時の返金、途中解約の費用。
3. 請求通貨は円にできるか。ドル請求なら、実質の手数料はいくらか。
4. 日本語で問い合わせできるか。日本時間の窓口、電話の有無。
5. 私の営業形態で、Airbnb・楽天トラベル・じゃらんに接続できるか。
6. 今使っているツールがある場合、データはどう引き継ぐか（OwnerRez は代行なし）。
7. 使いたい日本のスマートロック（Akerun、SESAME など）は連携できるか。

## よくある質問

### Hostaway と OwnerRez の一番大きな違いは何ですか？
料金の公開と、導入の進め方です。OwnerRez は物件数別の料金表が公開され、契約縛りがなく、自分で設定して進めます。Hostaway は料金が見積りで、導入の手助けが口コミで評判です。

### 3室ならどちらが安いですか？
OwnerRez は、公式の単価からの計算で月$70です（追加の有料機能を除く）。Hostaway は公式の料金がなく、見積りが必要です。

### 無料トライアルがあるのはどちらですか？
OwnerRez に14日間のトライアルがあります。Hostaway は、公式ページでは確認できず、デモの申込のみです。

### 解約しやすいのはどちらですか？
OwnerRez は契約縛りがなく、いつでも閉鎖できますが、未使用期間の返金はありません。Hostaway は期間が個別契約なので、書面での確認が必要です。

### 日本語で使えるのはどちらですか？
どちらも、公式には日本語の管理画面もサポートも確認できませんでした。英語の画面で運用できるかを、トライアルやデモで確かめてください。
