Xola（ゾラ）の評判・口コミまとめ｜日本の体験・ツアーで使える？

先に結論：Xola はこんな人に向く

  • 向く人：月額の固定費をかけずに始めたい人。サポートの手厚さを重視する人。予約が少ない時期の負担を軽くしたい人。
  • 向かない人：お客さんに手数料を上乗せしたくない人。日本語の画面・サポートが必須の人。
  • 最初に確認すること：日本の事業者が契約できるか、円で決済できるか。 公式に日本の記載が見つかりませんでした。口コミも、ほぼアメリカの事業者です（詳しくはこちら）。

Xolaとは？何ができるツールか

Xola は、ツアー・アクティビティの予約と、お客さんへの案内（マーケティング）をまとめたシステムです。公式によると、2011年にアメリカで創業しました。日本の楽天が、2016年に約250万ドル（約2億7千万円）を出資したと、旅行業界の報道にあります。ただし当時は「主にアメリカで提供している」とされ、日本向けの展開は報じられていません。

主な機能

予約の受付とチェックアウト

自分のサイトで予約を受け付けます。カートに入れて離れたお客さんへの再案内（放棄カートの再販売）や、クーポン、ギフト、セット商品が公式に載っています。

予約サイトとの連携

Expedia、Viator、Tripadvisor、GetYourGuide、Google の「Things to do」とつながり、二重予約を防ぐと説明しています（自社の主張）。Airbnb 体験（Airbnb Experiences）とつなぐ機能も公式で案内しています。

現場の道具

スタッフのシフトと割り当て、道具の管理（貸し出しの重なり防止）、電子の同意書（ウェーバー）、スマホアプリ、QRの受付、店頭のレジ（POS）。公式は、80以上のアプリ・連携があると書いています。

分析

お客さんの数字、売上の分析、お客さんの満足度調査（NPS）があります。

Xolaの料金はいくら？

月額の固定費がありません。 公式の料金ページは、次のように説明しています。

  • お客さんの支払いごとに「パートナー手数料」2.39%＋0.30ドル（アメリカの場合）。
  • 月額契約なし。予約サイト経由の追加手数料なし。隠れた費用なし。
  • 手数料はお客さんに上乗せする仕組みとして、公式が説明しています。
  • 「アメリカ以外は料金が変わる」と注記があります。日本の料金は載っていません。

口コミの手数料の声は、次のようにバラバラです。

  • 「6%の予約手数料をお客さんに上乗せしている。それでも予約は増えた」（2020年、アメリカの事業者）。
  • 「3%の新しい料金は好きではない。お客さんに転嫁したくないので、費用が増えた」（2020年）。
  • 「競合より手数料は高めだが、お客さんに回せるので問題ない」（2020年）。

料金のしくみが2020年ごろに変わった、という声が複数あります。今の正確な割合は、見積り（デモ）で書面で確認してください。

Xolaの評判・口コミまとめ

海外のレビューサイト（Capterra）の口コミ約180件を読んで、日本語にまとめました。

読む前に

  • 投稿者の国が分かるもののうち、約9割がアメリカです。日本の事業者の口コミはありませんでした。
  • 投稿者は、2〜50人規模の事業者が中心。使用期間が「1年以上」の人は約5割で、長く使っている人が多めです。
  • 件数は、口コミ中の話題をキーワードで数えたおおよその数です。

良い口コミ：使いやすさとサポート

  • 使いやすい（良い点に挙げた人が約5割で最多）。予約を自分で入れやすい、画面が分かりやすい、という声。
  • サポートが速く、親切（約4割）。いつでも連絡がつく、設定を手伝ってくれる、という声が目立ちます。
  • 画面が見やすい：デザインがきれい、という声（約1割）。
  • お客さんが自分で予約できて、電話が減る、という声。

悪い口コミ：料金、レポート、不具合

  • 料金（改善点で約16%で最多）：手数料の上乗せがお客さんに不評、料金体系の変更、という声。
  • レポート・会計が見づらい（約1割）：税込みと税抜きの合計が分かりにくい、売上を見るのに手間がかかる、という声。
  • 機能の細かい足りない点：ガイドの割り当てが硬い、店頭のレジとの連携が弱い、同じ人が複数枠を予約したときに、メールが枠の数だけ届く、という声。
  • 動作が遅い・不具合（約6%）：画面が遅い、アプリが使いにくい、という声。

低評価（1〜2点）の傾向

口コミ約180件のうち、1〜2点は3件だけです。ほとんどが4〜5点です。 低評価の中身は、「以前は良かったが、体制が変わって対応が悪くなった」「払い戻しの手続きと、予約の直後に引かれる3%」「脱出ゲーム向けには画面が使いにくい」です。古い口コミ（2018〜2020年）が中心です。

Xolaは日本で使える？体験・ツアーの注意点

日本語の画面・サポート

Capterra の表記では、対応言語に日本語が入っています。ただし、公式サイトは英語だけで、日本語ページは確認できませんでした。管理画面とサポートが日本語かは、確認できていません。サポートは「24時間365日。メール、チャット、電話」と公式にあります。

日本の事業者が契約できるか、円で決済できるか

公式の支払い規約によると、決済は Stripe が処理します。Stripe が使えない国では、別の決済会社（Authorize.net）を使う、とあります。日本の事業者が契約できるか、円で受け取れるかは、公式に書かれていませんでした。 料金ページの「アメリカ以外は料金が変わる」という注記も、日本の金額ではありません。デモの前に、必ず聞いてください。

日本の予約サイトにつながる？

連携先として公式に載っているのは、Expedia、Viator、Tripadvisor、GetYourGuide、Google です。じゃらん、アソビュー、楽天トラベルなどの日本のサイトは、公式に記載が見つかりませんでした（「できない」と確認したわけではありません）。

Airbnb 体験との連携

Airbnb 体験とつなぐ機能を公式で案内しています。日本の事業者が使えるかは、確認できていません。

Xolaが向いている人・向いていない人

向いている人 向いていない人
料金 月額なしで始めたい。手数料をお客さんに回せる お客さんに手数料を上乗せしたくない
言語 英語の画面・サポートで困らない 日本語の画面・サポートが必須
お客さん 海外のお客さん、海外の予約サイト中心 日本の予約サイトが主力
国 アメリカなど、対応国で事業をしている 日本の事業者（契約できるか未確認）

申し込む前に Xola へ聞くこと

  1. 日本の法人・個人事業で契約できるか。 日本の銀行口座に、円で入金されるか。
  2. 日本の場合の手数料の割合。お客さんが払うか、事業者が払うか。変更の条件。
  3. 払い戻し（返金）のときの手数料の扱い。
  4. 日本語で問い合わせできるか。日本時間の窓口はあるか。
  5. 日本の予約サイトに接続できるか（使いたいサイト名で）。
  6. Airbnb 体験との連携は、日本の事業者も使えるか。
  7. 解約の条件と、データの書き出し。

よくある質問

Xola は日本語に対応していますか？

Capterra の表記では、対応言語に日本語が入っています。ただし公式サイトは英語だけで、管理画面とサポートの日本語対応は、公式には確認できませんでした。申込前に確認してください。

Xola の料金はいくらですか？

公式の料金ページでは、月額契約なしで、お客さんの支払いごとに2.39%＋0.30ドル（アメリカの場合）の手数料です。アメリカ以外は料金が変わると書かれていて、日本の金額は載っていません。

Xola は無料で試せますか？

公式には「無料デモ」の案内があります。無料トライアルの記載は確認できませんでした。

日本の事業者でも契約できますか？

公式に、日本の事業者向けの記載は見つかりませんでした。決済は Stripe が処理します。契約の可否と、円での入金ができるかは、デモの前に問い合わせで確認してください。

日本の予約サイトにつなげられますか？

公式で案内されている連携先は、Expedia、Viator、Tripadvisor、GetYourGuide、Google です。日本の予約サイトの記載は見つかりませんでした。

手数料は誰が払いますか？

公式は、お客さんが払う仕組みとして説明しています。口コミには、お客さんに上乗せしても予約が増えた事業者と、転嫁したくなくて費用が増えた事業者の、両方がいます。
