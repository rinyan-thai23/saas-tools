# 広告表示と運営方針

## 広告について
- 一部のリンクは広告（アフィリエイト）になる予定です。リンクを通じて申し込みがあると、運営者に報酬が入ることがあります。広告リンクがあるページには、冒頭に「PR」と書きます。
- 紹介報酬の有無や金額で、評価の内容は変えません。
- 現在、このサイトには広告リンクを設定していません。

## 情報の集め方
- 各製品の公式サイトとヘルプ、公式の資料、ソフトバンクなど日本の販売元のページと、海外のレビューサイト（Capterra）の口コミを読んで、日本語にまとめています。
- 法令・制度に関する記述は、総務省、個人情報保護委員会、国税庁、消防庁、国民生活センター、警察のページなど、公的機関の資料を直接読んで引用しています。
- 口コミは海外の事業者の声が中心で、日本の事業者の声ではありません。投稿者の国と、時期（古い口コミが多い製品もあります）を、各ページに書いています。
- 公式で確認できなかったことは、「確認できなかった」と書きます。「記載が見つからなかった」ことと、「できない」ことは、区別します。
- 公式サイトに接続できなかった製品（GoTo Connect）は、その旨を冒頭に書いています。
- 料金や仕様は変わります。同じ会社でも、ページによって記載が違うことがあります（例：CallHippo）。申込前に公式で確認してください。

## 法律・税・個人情報について
- このサイトは、法律・税務・個人情報保護の助言ではありません。特定の製品が法令に当たるか、適法か、経費にできるか、などの判断は書きません。
- 判断が必要なときは、弁護士・税理士などの専門家、または各公的機関の窓口に確認してください。

## 調べていないこと
- 日本の会社が提供するクラウド電話（国産のクラウドPBXなど）は、口コミの材料がなく、同じ基準で比べられないため、今回は商品ページに入れていません。
- 各製品の日本語の管理画面・アプリの表示、データの保存場所は、公式で確認できていません。
