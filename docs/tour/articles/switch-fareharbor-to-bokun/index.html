【体験・ツアー】FareHarborからBókunへ乗り換える手順｜予約・商品・Viatorの移し方と注意点

この記事にはアフィリエイトリンク（PR）が含まれます。紹介報酬の有無で、内容は変えていません。

先に結論

  • 乗り換えは「Bókun を準備 → 切り替え日を決める → 古い方を止める」の順です。Bókun の公式は「Bókun が整うまでは、今のシステムで今の予約を続けるのがよい」と案内しています。
  • 過去の予約は、表計算（スプレッドシート）で Bókun に取り込めます（公式の説明）。FareHarbor から予約レポートをCSVで出せる、と他社の移行案内にあります。
  • Viator に出している商品は、1クリックで Bókun に取り込めます（公式の説明）。
  • 日本の事業者は、日本版（JTB BÓKUN）の窓口で、移行の手助けがあるかを先に聞いてください。 日本版の移行支援は、確認できていません。

この記事の前提

  • FareHarbor は、公式ヘルプの対応国に日本が見当たらない製品です（全文は未確認）。この記事は、すでに FareHarbor を使っている人（国外の事業所など）と、乗り換えを検討している人向けです。
  • 手順の多くは、Bókun の公式の説明（自社の主張）です。FareHarbor 側の手順は、他社の移行案内に基づきます。

乗り換えの前に確認すること

  1. FareHarbor の契約条件：契約期間、解約の方法、データの保持期間、書き出せる項目。FareHarbor の解約条件は、公式で確認できませんでした。担当者に書面で聞いてください。
  2. Bókun の料金：海外版は月額$49／$149／$499＋手数料1.5%／1.25%／1%。日本版は1,900円／4,900円／24,900円（税別）＋3.5%／1.5%／1.25%（JTB の資料）。詳しくは Bókun、比較記事へ。
  3. 日本の事業者として契約できるか、円で受け取れるか。

乗り換えの手順

1. Bókun の無料トライアルで試す

  • 海外版は14日間（カード不要）、日本版は30日間です。
  • 公式の「初心者向けコース」（動画）で、アカウントの設定を学べます。

2. 商品を移す

  • Viator に出している商品：Viator から1クリックで取り込めます。公式は「2分」と説明しています。取り込みは Viator → Bókun の一方向で、Viator 側の商品は変わりません。取り込むには、Viator 上の商品が有効である必要があります（Bókun のヘルプ）。
  • それ以外の商品：自分で作ります。複数の商品は、テンプレートで早くできる、と公式にあります。自社サイトの商品を自動で取り込む機能（AI Product Importer）も公式に載っています。

3. 予約の受け方を決める

  • Bókun の公式は、今のシステムで直販の予約を続けたまま、Bókun を予約サイトや販売会社の予約に使うやり方も案内しています。
  • 一気に切り替えるのが不安なら、まず予約サイト側だけを Bókun にして、慣れてから自社サイトを移します。

4. 過去・今後の予約を移す

  • 過去の予約：表計算で取り込めます（Bókun の公式）。「カスタム価格」と「通貨」の列に値を入れる必要があります。Bókun の保存済みの価格を使う場合は、予約日が価格を保存した日より前だと使えません。確認のための手助けもあります、と公式にあります。
  • FareHarbor からの書き出し：他社（TRYTN）の移行案内によると、FareHarbor の管理画面で、期間を指定して予約レポート（Booking Details）をCSVで出せます。画面が止まる場合は、期間を短く分けます。未使用のギフトカードも、CSVで書き出せるとあります。FareHarbor 公式の手順ではなく、画面の項目名は変わっている可能性があります。
  • 今後の予約（先の日付）：自動で移す方法は、FareHarbor・Bókun のどちらの公式でも確認できませんでした。Bókun の公式は、予約を表計算で取り込む方法を案内しています。件数が多い場合は、先に件数を数えて、Bókun のサポートに移し方を聞いてください。
  • Viator の予約：Viator をつなぐと、前の月の予約が自動で入る、と公式にあります。古い予約は、取り込み機能を使います。
  • なお、Bókun の公式ページには、地域ごとに説明が少し違うものがあります。FareHarbor の予約をどこまで移せるかは、Bókun のサポートに直接確認してください。

5. 切り替えの日を決める

  • いつから、新しい予約を Bókun だけに入れるかを、日付で決めます。
  • 切り替えの日から、FareHarbor には新しい予約を入れません。電話・窓口の予約も、Bókun に入れます。
  • 数日は、FareHarbor と Bókun の予約を見比べて、ずれがないか確認します。

6. FareHarbor を止める

  • すべての予約サイト（OTA）の接続を、Bókun 側に切り替えてから、FareHarbor を解約します。
  • 予約サイトの接続を切り替えている間に、両方のシステムに在庫が残らないよう、順番を決めます。

二重予約を防ぐ注意点（Viator と同期するとき）

Bókun のヘルプによると、次の点に注意が必要です。

  • Viator の商品の内容を Viator 側で変えると、Bókun 側の内容が上書きされることがあります。
  • Viator 側で予約を変更しても、その変更が Bókun に届かない場合があります。その場合は、両方で更新します。
  • 受付の締め切り時間（カットオフ）は、両方で合わせます。

乗り換えで失敗しやすいこと

  • 先の予約を取り込み忘れる：二重予約の原因になります。件数を数えて、チェックしながら進めます。
  • 予約サイトの接続を切り替える順番を間違える：在庫が両方に残ります。1つずつ切り替えます。
  • FareHarbor を先に解約する：予約の書き出しができなくなる可能性があります。解約は最後にします。

申し込む前に聞くこと

  1. 日本の事業者として契約できるか。円で受け取れるか。日本版（JTB BÓKUN）の移行支援はあるか。
  2. 今後の予約を、まとめて移す方法はあるか。件数の上限は。
  3. FareHarbor の予約を、どこまで取り込めるか。
  4. 予約サイトの接続を切り替えるときの、在庫の扱い。
  5. 無料トライアルの期間中に、本番の商品で試せるか。
  6. FareHarbor の解約条件と、データ保持の期間。

よくある質問

過去の予約は、すべて移せますか？

Bókun の公式は、表計算で取り込めると説明しています。ただし、列の指定や価格の扱いに条件があります。FareHarbor からどこまで書き出せるかは、確認できていません。

Viator の商品はそのまま使えますか？

Viator から1クリックで取り込めます。取り込みは一方向で、Viator 側の商品は変わりません。

乗り換えにどれくらいかかりますか？

Viator の商品の取り込みは、公式で「2分」です。ほかの商品を作る場合は、数が多いほど時間がかかります。予約の移行を含めた全体の期間は、確認できていません。

日本版（JTB BÓKUN）でも同じ手順ですか？

確認できていません。日本版の窓口に、移行の手順と手助けの有無を聞いてください。
