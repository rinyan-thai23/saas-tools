Guesty から Hostaway へ乗り換える前に

結論

  • 先に見るのは Guesty の契約書です。規約には「13か月＋12か月ごとの自動更新」「中途解約は最低月額×残り月数」「全リスティングの停止手順が終わるまで契約が続く」とあります。ただし冒頭に「契約書の記載が優先」ともあり、あなたの契約でどうなるかは契約書で確認するしかありません。
  • Hostaway の移行支援は、公式ブログに「24/7 のサポートとライブのオンボーディング」とあるだけで、手順・期間・費用は開いた公式ページに見つかりませんでした。取り込み方法（CSV など）も未確認です。
  • 日本語まわりは、Guesty は公式のサポート言語に日本語がなく（確認済）、Hostaway は日本語の管理画面・サポートの記載が確認できていません。

先に Guesty の契約を確認する

項目 公式の記載（Guesty 規約・料金ページ）
期間 初期期間13か月（オンボーディング含む）。以後12か月ごとに自動更新
更新しない場合 期間終了の30日前までに書面で通知
中途解約 Early Termination Fee：最低月額×残り月数（Pro は最低月額の金額が非公開）
解約の完了 全リスティングの停止手順が終わるまで、契約は終了扱いにならない
例外 規約冒頭に "Unless otherwise stated in the Guesty Contract"。契約書の記載が優先
  • Lite（1〜3室）と Pro で、この規約が同じように当たるかは未確認です。
  • 利用者側の声として、BBB には「申込時に12か月の契約義務と早期解約金の説明がなかった」との苦情があります（2024年7月の申込。検索抜粋で、全件ではありません）。
  • Guesty からデータを書き出す方法（エクスポート）は、今回は調べていません（未調査）。ヘルプセンターは403で開けていません。

Hostaway 側で確認できたこと

項目 記載
料金 非公開（物件数を答えるフォーム→見積り）。第三者の推定はサイトごとに大きく異なり、公式の裏付けなし

機能とチャネルの差（公式の記載の範囲）

  • Airbnb・Booking.com・Vrbo・Expedia： どちらも公式の連携として載っています（Guesty の Expedia は Pro 以上）。
  • Agoda： Guesty は公式チャネル一覧に載っています。Hostaway は公式の一覧になく、接続は断定できません（未確認）。Agoda も使っているなら、先に Hostaway に確認する項目です。
  • 楽天トラベル・じゃらん： どちらの公式ページにも記載が見つかりませんでした（Guesty は全チャネル一覧の全文が未取得。「接続できない」と確認したわけではありません）。
  • スマートロック： Guesty は LocksManager（有料アドオン）、Hostaway は Nuki・igloohome・TTLock など。Akerun・SESAME は両社とも公式の一覧で確認できていません。
  • 決済： GuestyPay は米国・カナダ・EU/UK のみ。Hostaway は Stripe などの連携を挙げていますが、日本での利用可否は未確認です。
  • ダイレクト予約サイト： Hostaway の Booking Website は契約に含まれ、上位の Pro は月$49＋対象予約の0.5%。対応言語は第三者の抜粋で English、Spanish、French、Italian です（日本語なし）。

利用者の声（第三者のみ。検索抜粋で、本文は未読）

Capterra（海外レビュー、2026-11-03時点）は Hostaway が 1,623件／4.8、Guesty が 1,031件／4.6 です。Hostaway には、Capterra や Software Advice の投稿に、値上げが頻繁、契約中の機能が後から追加料金になった、価格の同期漏れで設定より約$400安く予約が入った（Capterra）、との声があります。サポートは遅いとの声と迅速との声の両方があります。これは英語圏の運営者の声で、日本の運営者の実感ではありません。

条件別の判断

条件 見るところ
Guesty の契約更新日が近い 更新拒否の期限（終了の30日前までの書面通知）に間に合うか。乗り換え先の稼働日と重ねるかを決める
契約期間の途中 最低月額×残り月数を計算し、乗り換え後の費用と並べる
Agoda を使っている Hostaway の Agoda 接続を書面で確認
見積りを取って比べたい Guesty の見積り（PR） と Hostaway の見積り（PR） に同じ質問（月額・初期費用・期間・解約金・値上げ条件）を出す

乗り換え前に確認すること

  • [ ] Guesty の契約書で、期間・更新日・解約金・停止手順を確認した
  • [ ] Guesty と Hostaway の同時接続ができるか、Hostaway に書面で確認した（今回は調べていない・未調査）
  • [ ] Hostaway の移行支援の内容（対象データ、期間、費用）を書面で受け取った
  • [ ] Guesty から未来の予約など、控えるデータの範囲を Hostaway に確認した

  • [ ] 請求通貨（円か）、サポートの日本語・日本時間の窓口を確認した

  • Hostaway の公式の料金、無料トライアルの有無、標準の契約期間、解約手続き
